# Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition

Yosuke Higuchi, Tetsuji Ogawa and Tetsunori Kobayashi Department of Communications and Computer Engineering, Waseda University, Tokyo, Japan

###### Abstract

We propose to utilize an instruction-tuned large language model (LLM) for guiding the text generation process in automatic speech recognition (ASR). Modern LLMs are adept at performing various text generation tasks through zero-shot learning, prompted with instructions designed for specific objectives. This paper explores the potential of LLMs to derive linguistic information that can facilitate text generation in end-to-end ASR models. Specifically, we instruct an LLM to correct grammatical errors in an ASR hypothesis and use the LLM-derived representations to refine the output further. The proposed model is built on the joint CTC and attention architecture, with the LLM serving as a front-end feature extractor for the decoder. The ASR hypothesis, subject to correction, is obtained from the encoder via CTC decoding and fed into the LLM along with a specific instruction. The decoder subsequently takes as input the LLM output to perform token predictions, combining acoustic information from the encoder and the powerful linguistic information provided by the LLM. Experimental results show that the proposed LLM-guided model achieves a relative gain of approximately 13% in word error rates across major benchmarks.

###### Index Terms:

End-to-end ASR, instruction-tuned large language model, language model integration, grammatical error correction.

## I Introduction

Driven by rapid advancements in self-supervised pre-training methods \[[1](https://arxiv.org/html/2309.10524v3#bib.bib1), [2](https://arxiv.org/html/2309.10524v3#bib.bib2)\], large language models (LLMs) have shown remarkable versatility in acquiring various capabilities with minimal or even no task-specific training data \[[3](https://arxiv.org/html/2309.10524v3#bib.bib3), [4](https://arxiv.org/html/2309.10524v3#bib.bib4), [5](https://arxiv.org/html/2309.10524v3#bib.bib5), [6](https://arxiv.org/html/2309.10524v3#bib.bib6), [7](https://arxiv.org/html/2309.10524v3#bib.bib7)\]. This has highlighted the potential of LLMs to address different downstream natural language processing (NLP) tasks in a few-shot or even zero-shot manner, enabling highly flexible functions that have been beneficial to end users \[[8](https://arxiv.org/html/2309.10524v3#bib.bib8)\].

Such few-/zero-shot learning capabilities of LLMs can be improved by strategically using the prompting mechanism to guide their behavior. In-context learning \[[4](https://arxiv.org/html/2309.10524v3#bib.bib4)\] allows LLMs to learn tasks without requiring parameter updates, which is achieved by adding a few input-output examples prior to a target input. To further enhance the controllability of LLMs, instruction fine-tuning \[[9](https://arxiv.org/html/2309.10524v3#bib.bib9), [10](https://arxiv.org/html/2309.10524v3#bib.bib10), [11](https://arxiv.org/html/2309.10524v3#bib.bib11)\] is employed to make the model adhere more closely to instructions. This has allowed for generating responses that align with desired outcomes, substantially boosting zero-shot performance on unseen tasks.

In this work, we explore the application of the LLM’s zero-shot learning capability for solving speech-processing tasks, focusing on end-to-end automatic speech recognition (ASR). We aim to align a specific speech-processing task with a related task in NLP and use the linguistic information embedded within the LLM to facilitate solving the target speech task. Specifically, we relate the end-to-end ASR task to zero-shot grammatical error correction \[[12](https://arxiv.org/html/2309.10524v3#bib.bib12), [13](https://arxiv.org/html/2309.10524v3#bib.bib13), [14](https://arxiv.org/html/2309.10524v3#bib.bib14)\]. Recent efforts have revealed the effectiveness of using LLMs for ASR error correction as post-processing \[[15](https://arxiv.org/html/2309.10524v3#bib.bib15), [16](https://arxiv.org/html/2309.10524v3#bib.bib16), [17](https://arxiv.org/html/2309.10524v3#bib.bib17), [18](https://arxiv.org/html/2309.10524v3#bib.bib18)\], wherein the model is instructed to select the most probable output from an $`N`$-best hypothesis list. Our approach, in contrast, attempts to directly integrate the LLM’s inherent ability to correct grammatical errors into an ASR formulation that is optimized in an end-to-end manner.

The proposed model is based on the joint connectionist temporal classification (CTC) and attention architecture \[[19](https://arxiv.org/html/2309.10524v3#bib.bib19)\]. The core component of our model is the LLM-guided decoder, which augments the original decoder by employing a fixed-parameter LLM to serve as a front-end feature extractor. This integration allows for enhancing the language modeling capabilities in the decoder, inheriting the LLM’s proficiency in correcting grammatical errors. Additionally, the cross-attention mechanism facilitates aligning the LLM-derived representations with the speech information embedded by the encoder. To optimize the extraction of linguistic features beneficial for the decoder, we also design an effective prompting strategy for the LLM, using a hypothesized text sequence generated through CTC decoding.

## II Background

### II-A Instruction-Tuned LLM

The recent LLMs possess the capability to be “prompted” to execute specific tasks. We focus on Llama2-Chat, an instruction-tuned version of Llama2 \[[20](https://arxiv.org/html/2309.10524v3#bib.bib20)\], as a pre-trained LLM used in this work. We hereafter refer to this chat model as “Llama2” for brevity. Llama2, consisting of deep Transformer decoder-based layers \[[21](https://arxiv.org/html/2309.10524v3#bib.bib21), [2](https://arxiv.org/html/2309.10524v3#bib.bib2)\], outputs a $`D^{\mathsf{l}\mathsf{l}\mathsf{m}}`$-dimensional hidden vector $`\mathbf{e}_{n}`$ at a token position $`n`$ as

```math
{\mathbf{e}_{n} = {\text{Llama2}{(\underset{\text{Instruction}}{\underbrace{W^{\mathsf{i}\mathsf{n}\mathsf{s}}}},\underset{\text{User Input}}{\underbrace{W^{\mathsf{u}\mathsf{s}\mathsf{r}}}},\underset{\text{Response}}{\underbrace{W_{<n}}})}} \in {\mathbb{R}}^{D^{\mathsf{l}\mathsf{l}\mathsf{m}}}},
```

where $`W^{\mathsf{i}\mathsf{n}\mathsf{s}} \in \mathcal{V}^{N^{\mathsf{i}\mathsf{n}\mathsf{s}}}`$ is an $`N^{\mathsf{i}\mathsf{n}\mathsf{s}}`$-length sequence that specifies the instruction of an intended task; $`W^{\mathsf{u}\mathsf{s}\mathsf{r}} \in \mathcal{V}^{N^{\mathsf{u}\mathsf{s}\mathsf{r}}}`$ is an $`N^{\mathsf{u}\mathsf{s}\mathsf{r}}`$-length sequence that serves as the given input for the task; $`W = {(w_{n} \in \mathcal{V}|n = 1,\cdots,N)}`$ is an $`N`$-length sequence generated by the LLM; and $`\mathcal{V}`$ is the vocabulary of Llama2. The previous tokens are represented as $`W_{< n} = {(w_{0},\cdots,w_{n - 1})}`$, where $`w_{0} = \text{<s>}`$ is a start-of-sentence symbol. Typically, the combined $`W^{\mathsf{i}\mathsf{n}\mathsf{s}}`$ and $`W^{\mathsf{u}\mathsf{s}\mathsf{r}}`$ is referred to as a prompt, which guides the model to generate a response $`W`$ in a specific manner (see Fig. [1](https://arxiv.org/html/2309.10524v3#S3.F1 "Figure 1 ‣ Overview ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition") for example).

Llama2 computes the likelihood of a target sequence $`W`$ as

```math
{{p{(\left. W \middle| {W^{\mathsf{i}\mathsf{n}\mathsf{s}},W^{\mathsf{u}\mathsf{s}\mathsf{r}}} \right.)}} = {\prod\limits_{n = 1}^{N + 1}{p{(\left. w_{n} \middle| {W_{< n},W^{\mathsf{i}\mathsf{n}\mathsf{s}},W^{\mathsf{u}\mathsf{s}\mathsf{r}}} \right.)}}}},
```

where $`w_{N + 1} = \text{</s>}`$ is an end-of-sentence symbol. The probability of generating $`w_{n}`$ in Eq. ([2](https://arxiv.org/html/2309.10524v3#S2.E2 "In II-A Instruction-Tuned LLM ‣ II Background ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")) is computed using $`\mathbf{e}_{n}`$ from Eq. ([1](https://arxiv.org/html/2309.10524v3#S2.E1 "In II-A Instruction-Tuned LLM ‣ II Background ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")) as

```math
{{p{(\left. w_{n} \middle| {W_{< n},W^{\mathsf{i}\mathsf{n}\mathsf{s}},W^{\mathsf{u}\mathsf{s}\mathsf{r}}} \right.)}} = {\sigma{({\text{Lin}_{D^{\mathsf{l}\mathsf{l}\mathsf{m}}\rightarrow{{|\mathcal{V}|} + 1}}{(\mathbf{e}_{n})}})}} \in {\lbrack 0,1\rbrack}^{{|\mathcal{V}|} + 1}},
```

where $`\text{Lin}_{D^{\mathsf{l}\mathsf{l}\mathsf{m}}\rightarrow{{|\mathcal{V}|} + 1}}{( \cdot )}`$ projects a $`D^{\mathsf{l}\mathsf{l}\mathsf{m}}`$-dimensional feature vector to a logit, and $`\sigma{( \cdot )}`$ represents the softmax function.

### II-B Joint CTC/Attention-based End-to-End ASR

Let $`O \in {\mathbb{R}}^{T \times F}`$ denote a $`T`$-length input speech sequence with $`F`$-dimensional acoustic features and $`W \in \mathcal{V}^{N}`$ represent the corresponding target token sequence. End-to-end ASR aims to directly map $`O`$ to $`W`$ by modeling the posterior distribution of $`p{(\left. W \middle| O \right.)}`$ using a single deep neural network.

Attention-based encoder-decoder (AED) \[[22](https://arxiv.org/html/2309.10524v3#bib.bib22), [23](https://arxiv.org/html/2309.10524v3#bib.bib23), [21](https://arxiv.org/html/2309.10524v3#bib.bib21)\] formulates end-to-end ASR using a probabilistic chain rule as

```math
{{p^{\mathsf{a}\mathsf{e}\mathsf{d}}{(\left. W \middle| O \right.)}} \triangleq {\prod\limits_{n = 1}^{N + 1}{p{(\left. w_{n} \middle| {W_{< n},O} \right.)}}}}.
```

The token emission probability in Eq. ([4](https://arxiv.org/html/2309.10524v3#S2.E4 "In II-B Joint CTC/Attention-based End-to-End ASR ‣ II Background ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")) is computed as

$`H = {(\mathbf{h}_{1},\cdots,\mathbf{h}_{T'})}`$$`{= {\text{Encoder}{(O)}} \in {\mathbb{R}}^{T' \times D^{\mathsf{a}\mathsf{s}\mathsf{r}}}},`$$`p{(\left. w_{n} \middle| {W_{< n},O} \right.)}`$$`{= {\text{Decoder}{(W_{< n},H)}} \in {\lbrack 0,1\rbrack}^{{|\mathcal{V}|} + 1}},`$

where $`\text{Encoder}{( \cdot )}`$ first down-samples $`O`$ (i.e., $`T' = {T/4}`$) and then converts it into a sequence of $`D^{\mathsf{a}\mathsf{s}\mathsf{r}}`$-dimensional hidden vectors $`H`$. $`\text{Decoder}{( \cdot )}`$ represents autoregressive decoder layers, followed by a linear layer and the softmax function, which map to the output vocabulary, $`\mathcal{V} \cup {\{\text{</s>}\}}`$. Here, the decoder is equipped with the cross-attention mechanism for aligning each token in $`W_{< n}`$ to the encoder output $`H`$. The AED model is optimized by minimizing the negative log-likelihood of Eq. ([4](https://arxiv.org/html/2309.10524v3#S2.E4 "In II-B Joint CTC/Attention-based End-to-End ASR ‣ II Background ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")), $`\mathcal{L}^{\mathsf{a}\mathsf{e}\mathsf{d}} \triangleq {- {{\log p^{\mathsf{a}\mathsf{e}\mathsf{d}}}{(\left. W \middle| O \right.)}}}`$.

CTC \[[24](https://arxiv.org/html/2309.10524v3#bib.bib24)\] formulates end-to-end ASR by evaluating all possible alignments between $`O`$ and $`W`$. To align the sequences at the frame level, $`W`$ is augmented by allowing repeated occurrences of the same token and inserting a blank symbol \<b\>. Let $`A = {(a_{t} \in \mathcal{V} \cup {\{\text{<b>}\}}|t = 1,\cdots,T')}`$ be an alignment sequence, and CTC models the posterior distribution of $`p{(\left. W \middle| O \right.)}`$ as

```math
{{p^{\mathsf{c}\mathsf{t}\mathsf{c}}{(\left. W \middle| O \right.)}} \triangleq {\sum\limits_{A \in {\mathcal{B}^{- 1}{(W)}}}{\prod\limits_{t = 1}^{T'}{p{(\left. a_{t} \middle| O \right.)}}}}},
```

where $`\mathcal{B}:{A\mapsto W}`$ is a collapsing function that removes repeated tokens and blank symbols in $`A`$, and $`\mathcal{B}^{- 1}{(W)}`$ is a set of all possible alignments compatible with $`W`$. Using the encoder output $`H`$ from Eq. ([5](https://arxiv.org/html/2309.10524v3#S2.E5 "In II-B Joint CTC/Attention-based End-to-End ASR ‣ II Background ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")), the token emission probability in Eq. ([7](https://arxiv.org/html/2309.10524v3#S2.E7 "In II-B Joint CTC/Attention-based End-to-End ASR ‣ II Background ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")) is computed as

```math
{{p{(\left. a_{t} \middle| O \right.)}} = {\text{CTC}{(\mathbf{h}_{t})}} \in {\lbrack 0,1\rbrack}^{{|\mathcal{V}|} + 1}},
```

where $`\text{CTC}{( \cdot )}`$ represents a linear layer and the softmax function that maps to the output vocabulary of CTC, $`\mathcal{V} \cup {\{\text{<b>}\}}`$. The CTC model is optimized by minimizing the negative log-likelihood of Eq. ([7](https://arxiv.org/html/2309.10524v3#S2.E7 "In II-B Joint CTC/Attention-based End-to-End ASR ‣ II Background ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")), $`\mathcal{L}^{\mathsf{c}\mathsf{t}\mathsf{c}} \triangleq {- {{\log p^{\mathsf{c}\mathsf{t}\mathsf{c}}}{(\left. W \middle| O \right.)}}}`$.

AED and CTC can be effectively combined to enhance robustness during training and inference processes of end-to-end ASR \[[25](https://arxiv.org/html/2309.10524v3#bib.bib25), [19](https://arxiv.org/html/2309.10524v3#bib.bib19)\]. The objective function of the joint model is defined as a linear interpolation of $`\mathcal{L}^{\mathsf{c}\mathsf{t}\mathsf{c}}`$ and $`\mathcal{L}^{\mathsf{a}\mathsf{e}\mathsf{d}}`$ as $`\mathcal{L}^{{\mathsf{c}\mathsf{t}\mathsf{c}}\text{-}{\mathsf{a}\mathsf{e}\mathsf{d}}} = {{\lambda\mathcal{L}^{\mathsf{c}\mathsf{t}\mathsf{c}}} + {{({1 - \lambda})}\mathcal{L}^{\mathsf{a}\mathsf{e}\mathsf{d}}}}`$, where $`\lambda`$ ($`0 < \lambda < 1`$) is a tunable weight. Joint decoding is performed using a one-pass beam search, with the score of a hypothesis $`\hat{W}`$ calculated using Eqs. ([4](https://arxiv.org/html/2309.10524v3#S2.E4 "In II-B Joint CTC/Attention-based End-to-End ASR ‣ II Background ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")) and ([7](https://arxiv.org/html/2309.10524v3#S2.E7 "In II-B Joint CTC/Attention-based End-to-End ASR ‣ II Background ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")) as $`{\xi{\log p^{\mathsf{c}\mathsf{t}\mathsf{c}}}{(\left. \hat{W} \middle| O \right.)}} + {{({1 - \xi})}{\log p^{\mathsf{a}\mathsf{e}\mathsf{d}}}{(\left. \hat{W} \middle| O \right.)}}`$, where $`\xi`$ ($`0 \leq \xi \leq 1`$) is a tunable weight to define the importance of the CTC score. See \[[26](https://arxiv.org/html/2309.10524v3#bib.bib26)\] for a detailed decoding algorithm.

## III End-to-End ASR Guided by Instruction-Tuned LLM

#### Overview

Figure [1](https://arxiv.org/html/2309.10524v3#S3.F1 "Figure 1 ‣ Overview ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition") illustrates the proposed LLM-guided end-to-end ASR model. Our model is built on the joint CTC and attention framework (as formulated in Sec. [II-B](https://arxiv.org/html/2309.10524v3#S2.SS2 "II-B Joint CTC/Attention-based End-to-End ASR ‣ II Background ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")), modifying the decoder by introducing an instruction-tuned LLM as its frontend, which we refer to as LLM-guided decoder. Here, the LLM is specifically employed to enhance the language modeling capabilities of the decoder, aiming to improve ASR performance. To optimally derive linguistic features that facilitate the text generation process in the decoder, we capitalize on the LLM’s potential as a zero-shot grammatical error correction model \[[13](https://arxiv.org/html/2309.10524v3#bib.bib13), [14](https://arxiv.org/html/2309.10524v3#bib.bib14), [17](https://arxiv.org/html/2309.10524v3#bib.bib17)\], designing an effective prompting strategy. Specifically, a hypothesized output sequence from CTC is fed into the LLM along with explicit instruction to correct word errors. The decoder then uses the LLM-derived features to refine the output further, while the cross-attention mechanism incorporates speech information from the encoder to mitigate hallucinations and overcorrections.

The following section delves into a precise formulation that substantiates the effectiveness of our model design, which is followed by detailed descriptions of training and inference strategies.

### III-A Formulation

The proposed model formulates end-to-end ASR by factorizing the posterior distribution $`p{(\left. W \middle| O \right.)}`$ as

```math
{{p{(\left. W \middle| O \right.)}} = {\sum\limits_{\overset{\sim}{W} \in {\mathcal{H}{(W)}}}{p{(\left. W \middle| {\overset{\sim}{W},O} \right.)}p{(\left. \overset{\sim}{W} \middle| O \right.)}}}},
```

where $`\overset{\sim}{W} \in \mathcal{V}^{M}`$ is an $`M`$-length hypothesized output sequence, and $`\mathcal{H}{(W)}`$ represents a set of all possible output sequences compatible with $`W`$. In other words, $`\mathcal{H}{(W)}`$ comprises sequences that are prone to be misrecognized from input speech $`O`$, with $`\overset{\sim}{W}`$ derived from $`p{(\left. \overset{\sim}{W} \middle| O \right.)}`$. In Eq. ([9](https://arxiv.org/html/2309.10524v3#S3.E9 "In III-A Formulation ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")), we further factorize $`p{(\left. W \middle| {\overset{\sim}{W},O} \right.)}`$ by applying a probabilistic chain rule as

```math
{{p{(\left. W \middle| {\overset{\sim}{W},O} \right.)}} = {\prod\limits_{n = 1}^{N + 1}{p{(\left. w_{n} \middle| {\overset{\sim}{W},W_{< n},O} \right.)}}}}.
```

Eq. ([10](https://arxiv.org/html/2309.10524v3#S3.E10 "In III-A Formulation ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")) follows the same formulation as AED in Eq. ([4](https://arxiv.org/html/2309.10524v3#S2.E4 "In II-B Joint CTC/Attention-based End-to-End ASR ‣ II Background ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")), but it additionally conditions the hypothesized output $`\overset{\sim}{W}`$. More intuitively, Eq. ([10](https://arxiv.org/html/2309.10524v3#S3.E10 "In III-A Formulation ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")) can be interpreted as a model that estimates each current token based on previously predicted tokens $`W_{< n}`$, while also recovering errors present in the hypothesized output sequence $`\overset{\sim}{W}`$.

The token emission probability in Eq. ([10](https://arxiv.org/html/2309.10524v3#S3.E10 "In III-A Formulation ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")) is modeled similarly to the AED model, with a modification to the decoder (i.e., Eq. ([6](https://arxiv.org/html/2309.10524v3#S2.E6 "In II-B Joint CTC/Attention-based End-to-End ASR ‣ II Background ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition"))) as

$`{\mathbf{e}_{n} = {\text{Llama2}{(W^{\mathsf{i}\mathsf{n}\mathsf{s}},\overset{\sim}{W},W_{< n})}} \in {\mathbb{R}}^{D^{\mathsf{l}\mathsf{l}\mathsf{m}}}},`$$`p{(\left. w_{n} \middle| {\overset{\sim}{W},W_{< n},O} \right.)}`$$`{= {\text{LLMGuidedDecoder}{(\mathbf{e}_{1},\cdots,\mathbf{e}_{n},H)}} \in {\lbrack 0,1\rbrack}^{{|\mathcal{V}|} + 1}},`$

where $`H`$ is the encoder output, as derived from Eq. ([5](https://arxiv.org/html/2309.10524v3#S2.E5 "In II-B Joint CTC/Attention-based End-to-End ASR ‣ II Background ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")). In Eq. ([11](https://arxiv.org/html/2309.10524v3#S3.E11 "In III-A Formulation ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")), the Llama2 output $`\mathbf{e}_{n}`$ is obtained as in Eq. ([1](https://arxiv.org/html/2309.10524v3#S2.E1 "In II-A Instruction-Tuned LLM ‣ II Background ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")), where a hypothesized output sequence is used as the user input, i.e., $`W^{\mathsf{u}\mathsf{s}\mathsf{r}} = \overset{\sim}{W}`$, accompanied by an instruction $`W^{\mathsf{i}\mathsf{n}\mathsf{s}}`$ that directs the LLM toward the grammatical error correction task (see Sec. [V-A](https://arxiv.org/html/2309.10524v3#S5.SS1 "V-A Expeirmental Setup ‣ V Experiments ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition") for the actual prompt). Such a prompting strategy is expected to facilitate the modeling of Eq. ([10](https://arxiv.org/html/2309.10524v3#S3.E10 "In III-A Formulation ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")). Eq. ([12](https://arxiv.org/html/2309.10524v3#S3.E12 "In III-A Formulation ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")) represents the LLM-guided decoder, the key component of the proposed model, which is identical to the standard decoder in Eq. ([6](https://arxiv.org/html/2309.10524v3#S2.E6 "In II-B Joint CTC/Attention-based End-to-End ASR ‣ II Background ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")) but takes the Llama2 outputs $`(\mathbf{e}_{1},\cdots,\mathbf{e}_{n})`$ as input.

### III-B Inference

The most probable sequence is estimated by solving Eq. ([9](https://arxiv.org/html/2309.10524v3#S3.E9 "In III-A Formulation ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")) as

$`\hat{W}`$$`{= {\underset{W}{\text{argmax}}{\sum\limits_{\overset{\sim}{W} \in {\mathcal{H}{(W)}}}{p{(\left. W \middle| {\overset{\sim}{W},O} \right.)}p{(\left. \overset{\sim}{W} \middle| O \right.)}}}}},`$$`{{\approx {{\underset{W}{\text{argmax}}p}{(\left. W \middle| {{\overset{\sim}{W}}',O} \right.)}}},{{\text{where}{\overset{\sim}{W}}'} = {{\underset{\overset{\sim}{W}}{\text{argmax}}p}{(\left. \overset{\sim}{W} \middle| O \right.)}}}}.`$

To handle the intractable summation over $`\overset{\sim}{W}`$ in Eq. ([13](https://arxiv.org/html/2309.10524v3#S3.E13 "In III-B Inference ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")), we apply the Viterbi approximation with respect to $`p{(\left. \overset{\sim}{W} \middle| O \right.)}`$, which results in Eq ([14](https://arxiv.org/html/2309.10524v3#S3.E14 "In III-B Inference ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")). In Eq. ([14](https://arxiv.org/html/2309.10524v3#S3.E14 "In III-B Inference ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")), $`{\overset{\sim}{W}}'`$ is first obtained through the best path decoding of CTC \[[27](https://arxiv.org/html/2309.10524v3#bib.bib27)\] using probabilities calculated by Eq. ([8](https://arxiv.org/html/2309.10524v3#S2.E8 "In II-B Joint CTC/Attention-based End-to-End ASR ‣ II Background ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")), which involves finding the most probable alignment $`\hat{A}`$ by concatenating the most active tokens at each time frame, $`{\hat{a}}_{t} = {{\text{argmax}_{a_{t}}p}{(\left. a_{t} \middle| O \right.)}}`$, and applying the collapsing function as $`{\overset{\sim}{W}}' = {\mathcal{B}{(\hat{A})}}`$. We then use this CTC output $`{\overset{\sim}{W}}'`$ to compute $`p{(\left. W \middle| {{\overset{\sim}{W}}',O} \right.)}`$ as in Eq. ([10](https://arxiv.org/html/2309.10524v3#S3.E10 "In III-A Formulation ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")), which is combined with the CTC score derived from Eq. ([7](https://arxiv.org/html/2309.10524v3#S2.E7 "In II-B Joint CTC/Attention-based End-to-End ASR ‣ II Background ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")) to perform the joint CTC and attention decoding \[[26](https://arxiv.org/html/2309.10524v3#bib.bib26)\].

### III-C Training

The training process for the proposed model unfolds in two steps:

1.  1.  Train a joint CTC and attention model using $`\mathcal{L}^{{\mathsf{c}\mathsf{t}\mathsf{c}}\text{-}{\mathsf{a}\mathsf{e}\mathsf{d}}}`$.
2.  2.  Using $`\text{Encoder}{( \cdot )}`$ and $`\text{CTC}{( \cdot )}`$ trained in Step 1 and pre-trained $`\text{Llama2}{( \cdot )}`$, train only $`\text{LLMGuidedDecoder}{( \cdot )}`$ (in Eq. ([12](https://arxiv.org/html/2309.10524v3#S3.E12 "In III-A Formulation ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition"))).

We freeze all the pre-trained networks in Step 2 not only to enhance training efficiency but also to enable the LLM-guided decoder to focus exclusively on text generation, ensuring to align the LLM-derived features with the speech information from the encoder.

In Step 2, the objective function of the proposed model is defined by the negative log-likelihood of Eq. ([9](https://arxiv.org/html/2309.10524v3#S3.E9 "In III-A Formulation ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")) expanded with Eq. ([10](https://arxiv.org/html/2309.10524v3#S3.E10 "In III-A Formulation ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")),

$`-`$$`\log{\sum\limits_{\overset{\sim}{W} \in {\mathcal{H}{(W)}}}{\prod\limits_{n = 1}^{N + 1}{p{(\left. w_{n} \middle| {\overset{\sim}{W},W_{< n},O} \right.)}p{(\left. \overset{\sim}{W} \middle| O \right.)}}}}`$$`{\leq \underset{\triangleq \mathcal{L}^{{\mathsf{l}\mathsf{l}\mathsf{m}}\text{-}{\mathsf{d}\mathsf{e}\mathsf{c}}}}{\underbrace{-{{\mathbb{E}}_{\overset{\sim}{W}\sim{p⁢{({\overset{\sim}{W}|O})}}}⁢\left\lbrack {\log ⁢{\underset{n=1}{\overset{N+1}{\prod}}{p⁢{(\left. w_{n} \middle| {\overset{\sim}{W},W_{<n},O} \right.)}}}} \right\rbrack}}}}.`$

The intractable marginalization over $`\overset{\sim}{W}`$ in Eq. ([15](https://arxiv.org/html/2309.10524v3#S3.E15 "In III-C Training ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")) is approximated by computing the expectation with respect to the sampling distribution based on the probability distribution of $`p{(\left. \overset{\sim}{W} \middle| O \right.)}`$, which results in Eq. ([16](https://arxiv.org/html/2309.10524v3#S3.E16 "In III-C Training ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")). Practically, $`\mathcal{L}^{{\mathsf{l}\mathsf{l}\mathsf{m}}\text{-}{\mathsf{d}\mathsf{e}\mathsf{c}}}`$ is computed in a manner similar to the AED loss $`\mathcal{L}^{\mathsf{a}\mathsf{e}\mathsf{d}}`$, calculating the cross-entropy losses at each token prediction. The sampling process of $`\overset{\sim}{W}`$ in Eq. ([16](https://arxiv.org/html/2309.10524v3#S3.E16 "In III-C Training ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")) is implemented by running the encoder in “training mode” (with dropout enabled) and performing the best path decoding of CTC, which is a similar strategy commonly utilized in uncertainty estimation \[[28](https://arxiv.org/html/2309.10524v3#bib.bib28), [29](https://arxiv.org/html/2309.10524v3#bib.bib29)\].

## IV Related Work

#### LLMs with Speech Input

Prior studies have explored the incorporation of speech information in LLMs \[[30](https://arxiv.org/html/2309.10524v3#bib.bib30), [31](https://arxiv.org/html/2309.10524v3#bib.bib31)\], primarily focusing on enabling LLMs to accept speech input. To convert speech into the input space of LLMs, discrete representations are typically derived from pre-trained acoustic models \[[32](https://arxiv.org/html/2309.10524v3#bib.bib32), [33](https://arxiv.org/html/2309.10524v3#bib.bib33)\]. Alternatively, pre-trained ASR models can be used to compress speech into a more manageable length \[[34](https://arxiv.org/html/2309.10524v3#bib.bib34), [35](https://arxiv.org/html/2309.10524v3#bib.bib35), [36](https://arxiv.org/html/2309.10524v3#bib.bib36), [37](https://arxiv.org/html/2309.10524v3#bib.bib37), [38](https://arxiv.org/html/2309.10524v3#bib.bib38), [39](https://arxiv.org/html/2309.10524v3#bib.bib39)\]. Our approach to utilizing LLMs for speech tasks is related to these studies, but differs conceptually in that we do not seek to directly adapt LLMs to speech. Instead, the proposed model aims to extract linguistic features from LLMs for improving ASR models, without requiring fine-tuning or modifications to off-the-shelf LLMs.

#### LM Integration in End-to-End ASR

It has been a widely adopted practice to use separate LMs to improve the performance of end-to-end ASR systems. The traditional approach includes rescoring \[[40](https://arxiv.org/html/2309.10524v3#bib.bib40), [23](https://arxiv.org/html/2309.10524v3#bib.bib23)\]. Advanced methods include incorporating LMs into beam search or directly into the model architectures, through techniques like shallow fusion \[[41](https://arxiv.org/html/2309.10524v3#bib.bib41), [42](https://arxiv.org/html/2309.10524v3#bib.bib42)\] and deep fusion \[[42](https://arxiv.org/html/2309.10524v3#bib.bib42), [43](https://arxiv.org/html/2309.10524v3#bib.bib43), [44](https://arxiv.org/html/2309.10524v3#bib.bib44)\]. More recently, these LM integration approaches have been promisingly extended for use with LLMs \[[45](https://arxiv.org/html/2309.10524v3#bib.bib45), [46](https://arxiv.org/html/2309.10524v3#bib.bib46), [47](https://arxiv.org/html/2309.10524v3#bib.bib47)\]. While the above methods primarily focus on enhancing ASR models with LM information at the output level, our approach utilizes an LLM as a feature extractor for the decoder to guide its text generation. Nonetheless, we show that the proposed model remains compatible with conventional LM fusion techniques.

#### Two-Pass End-to-End ASR

In ASR, it is a common practice to employ a second-pass model to refine outputs produced by a first-pass model \[[48](https://arxiv.org/html/2309.10524v3#bib.bib48), [23](https://arxiv.org/html/2309.10524v3#bib.bib23), [49](https://arxiv.org/html/2309.10524v3#bib.bib49), [50](https://arxiv.org/html/2309.10524v3#bib.bib50)\]. End-to-end modeling of ASR has allowed to jointly train the first-pass and second-pass models \[[51](https://arxiv.org/html/2309.10524v3#bib.bib51), [52](https://arxiv.org/html/2309.10524v3#bib.bib52), [53](https://arxiv.org/html/2309.10524v3#bib.bib53), [54](https://arxiv.org/html/2309.10524v3#bib.bib54), [55](https://arxiv.org/html/2309.10524v3#bib.bib55), [56](https://arxiv.org/html/2309.10524v3#bib.bib56)\]. The proposed formulation in Eq. ([9](https://arxiv.org/html/2309.10524v3#S3.E9 "In III-A Formulation ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")) shares similarities with these two-pass approaches. However, it differs in that the LLM-guided decoder does not specifically deliberate on hypotheses to generate a text sequence. Instead, it leverages a hypothesized output to derive linguistic features from the LLM.

## V Experiments

### V-A Expeirmental Setup

We used ESPnet \[[57](https://arxiv.org/html/2309.10524v3#bib.bib57)\] for conducting our experiments, and all the codes are made publicly available at [https://github.com/YosukeHiguchi/espnet/tree/llm-guided-asr](https://github.com/YosukeHiguchi/espnet/tree/llm-guided-asr).

#### Data

We focused on English ASR tasks, using various corpora spanning different amounts of data and domains, including LibriSpeech (LS) \[[58](https://arxiv.org/html/2309.10524v3#bib.bib58)\], TED-LIUM2 (TED2) \[[59](https://arxiv.org/html/2309.10524v3#bib.bib59)\], and CoVoST2 (CV2) \[[60](https://arxiv.org/html/2309.10524v3#bib.bib60)\]. In addition to the full 960-hour training set in LS (LS-960), we used the train-clean-100 set (LS-100) to explore a lower-resource scenario and conduct further investigations. We used CV2 for training models with punctuation and casing preserved, which can be crucial for the LLM to accurately process text sequences. During the evaluation, we removed punctuations to exclusively assess ASR performance.

#### Modeling

We developed our baseline models within the joint CTC/attention framework (see Sec. [II-B](https://arxiv.org/html/2309.10524v3#S2.SS2 "II-B Joint CTC/Attention-based End-to-End ASR ‣ II Background ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")), which used the Conformer-based architecture \[[61](https://arxiv.org/html/2309.10524v3#bib.bib61), [62](https://arxiv.org/html/2309.10524v3#bib.bib62)\]. This baseline model also corresponds to the initial joint CTC/attention model trained in Step 1 in Sec. [III-C](https://arxiv.org/html/2309.10524v3#S3.SS3 "III-C Training ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition"). The proposed model was constructed by substituting the decoder of the baseline model with the LLM-guided decoder (as detailed in Step 2 in Sec. [III-C](https://arxiv.org/html/2309.10524v3#S3.SS3 "III-C Training ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")). The encoder consisted of two convolutional neural network layers followed by a stack of $`12`$ Conformer blocks. The number of head $`D^{\mathsf{h}\mathsf{e}\mathsf{a}\mathsf{d}}`$, the dimension of a self-attention layer $`D^{\mathsf{a}\mathsf{s}\mathsf{r}}`$, the dimension of a feed-forward network $`D^{\mathsf{f}\mathsf{f}}`$, and the kernel size were set to ($`4`$, $`256`$, $`1024`$, $`31`$). The decoder was a stack of $`6`$ Transformer decoder blocks, with ($`D^{\mathsf{h}\mathsf{e}\mathsf{a}\mathsf{d}}`$, $`D^{\mathsf{a}\mathsf{s}\mathsf{r}}`$, $`D^{\mathsf{f}\mathsf{f}}`$) set to ($`4`$, $`256`$, $`2048`$). For the LLM, we used Llama2-Chat (7B) provided by HuggingFace \[[63](https://arxiv.org/html/2309.10524v3#bib.bib63)\]. To connect Llama2 with the LLM-guided decoder, we applied a linear layer to map the dimensions from $`D^{\mathsf{l}\mathsf{l}\mathsf{m}} = 4096`$ to $`D^{\mathsf{a}\mathsf{s}\mathsf{r}} = 256`$.

#### Training and Decoding

We primarily followed optimization configurations specified in the ESPnet recipes for each dataset. The baseline model was trained for up to 50 epochs, and subsequently, the proposed model featuring the LLM-guided decoder was trained for up to 50 epochs for LS-100 and up to 25 epochs for the other datasets. For both the baseline and proposed models, we set the score weight $`\xi`$ to $`0.3`$ during the joint CTC/attention decoding, unless specified otherwise. The beam size $`B`$ was set to either $`1`$ or $`20`$.

#### Prompting

We heuristically designed a prompt to guide Llama2 in performing grammatical error correction, setting $`W^{\mathsf{i}\mathsf{n}\mathsf{s}}`$ (in Eq. ([11](https://arxiv.org/html/2309.10524v3#S3.E11 "In III-A Formulation ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition"))) to “You will be provided with a statement in quotes. Correct the wrong words and provide your revised version.”. As specified in this instruction, we enclosed a user input (i.e., a hypothesis) within double quotation marks, which has been found crucial for the model to accurately identify the target sequence. Through qualitative observation, we selected a prompt that adhered accurately to the specified task and minimized hallucinations. Additionally, we aimed to keep the prompt concise to reduce memory usage during training.

### V-B Main Results

Table [I](https://arxiv.org/html/2309.10524v3#S4.T1 "TABLE I ‣ Two-Pass End-to-End ASR ‣ IV Related Work ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition") presents a comparison of the baseline and proposed models across all the tasks, evaluated by the word error rate (WER). The A0 results represent the CTC decoding performance, with $`\xi`$ set to $`1.0`$. Setting $`\xi`$ to $`0.3`$ for the joint decoding resulted in improvements across the tasks (A0 vs. A1). The proposed model, featuring the LLM-guided decoder, achieved the best overall performance among the results with a beam size of $`B = 1`$ (A0, A1 vs. A2). This indicates the successful incorporation of the LLM into the text generation process, while only requiring the retraining of minimal parameters (i.e., $`18.8`$M). In the proposed inference algorithm (detailed in Sec. [III-B](https://arxiv.org/html/2309.10524v3#S3.SS2 "III-B Inference ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")), the CTC decoding results (A0) served as an input to the LLM (i.e., $`\overset{\sim}{W}`$ in Eq. ([11](https://arxiv.org/html/2309.10524v3#S3.E11 "In III-A Formulation ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition"))). Thus, the gains from A0 suggest that the proposed model effectively used the LLM to improve the hypothesized outputs, as expected in Eq. ([10](https://arxiv.org/html/2309.10524v3#S3.E10 "In III-A Formulation ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")). In CV2, the proposed model demonstrated a notably higher level of improvements, particularly considering the gains from the CTC decoding results in A0. We attribute this to the use of unnormalized text, which enabled the LLM to extract precise linguistic information. When we set $`B`$ to $`20`$, the proposed model consistently outperformed the baseline across all tasks (A3 vs. A4). However, it appeared that our model benefited less from beam search decoding than the baseline model, likely because the LLM’s confidence in its predictions restricted the search space. Nonetheless, even with $`B = 1`$, our model still surpassed the baseline with $`B = 20`$ (A2 vs. A3). This shows the potential to reduce the computational burden required for running the LLM during inference, as observed by the real-time factor (RTF) measured using a single A100 GPU.

### V-C Ablation Study

We conducted several ablation studies for the proposed model to assess the effectiveness of both the use of the LLM and the prompt. Table [V-B](https://arxiv.org/html/2309.10524v3#S5.SS2 "V-B Main Results ‣ V Experiments ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition") presents the results of these ablation studies on LS-100.

#### Importance of LLM

We ablated the LLM from the proposed model (B1) by training the decoder from scratch without Llama2 during Step 2 of the training process in Sec. [III-C](https://arxiv.org/html/2309.10524v3#S3.SS3 "III-C Training ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition"). Compared to the baseline results, this ablated training yielded only marginal improvement (A1, A3 vs. B1). The proposed model, in contrast, achieved significantly better results thanks to the utilization of the LLM (A2, A4 vs. B1).

#### Influence of Prompt

First, we trained the LLM-guided decoder by removing the prompt from the LLM input (B2), setting $`W^{\mathsf{i}\mathsf{n}\mathsf{s}} = \varnothing`$ and $`\overset{\sim}{W} = \varnothing`$ in Eq. ([11](https://arxiv.org/html/2309.10524v3#S3.E11 "In III-A Formulation ‣ III End-to-End ASR Guided by Instruction-Tuned LLM ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")). While this modification resulted in modest gains compared to the baseline model (A1, A3 vs. B2), it adversely affected the performance of the proposed model (A2, A4 vs. B2). Next, we trained the LLM-guided decoder with a task instruction that diverged from grammatical error correction (B3), specifying $`W^{\mathsf{i}\mathsf{n}\mathsf{s}}`$ to “You will be provided with a statement in quotes, and your task is to translate it into Japanese.”. While the modified prompt yielded improvements over the baseline (A1, A3 vs. B3), the proposed model with the proper prompt demonstrated superior performance (A2, A4 vs. B2). The findings from B2 and B3 suggest that designing an appropriate prompt is crucial in our model to effectively harness the capabilities of LLMs for assisting the target speech task.

### V-D Comparison with Conventional LM Integration Methods

Table [V-C](https://arxiv.org/html/2309.10524v3#S5.SS3.SSS0.Px2 "Influence of Prompt ‣ V-C Ablation Study ‣ V-B Main Results ‣ V Experiments ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition") lists WERs for LS-100, reporting the performance of the baseline model (A3) when decoded using the LLM (i.e., Llama2). Here, the proposed approach (A4) is compared with shallow fusion, rescoring, and zero-shot grammatical error correction (GEC) methods. Zero-shot GEC was performed by directly evaluating the response generated by the LLM, given the instruction (detailed in Sec. [V-A](https://arxiv.org/html/2309.10524v3#S5.SS1 "V-A Expeirmental Setup ‣ V Experiments ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition")) to improve the CTC decoding results (i.e., A0). Both shallow fusion and rescoring resulted in notable performance improvements over the baseline. Zero-shot GEC, in contrast, appeared to be challenging, as the LLM tended to produce hallucinations or overcorrections. These issues led to generating words not present in the speech input, indicating a need for a dedicated mechanism to align the LLM outputs with the speech information. While rescoring delivered promising results, the proposed model demonstrated compatibility with rescoring to achieve the best overall performance.

## VI Conclusion

We proposed to use an instruction-tuned LLM for guiding the text generation process in end-to-end ASR. By integrating the LLM as a frontend feature extractor for the decoder and utilizing a precise prompting strategy in conjunction with CTC decoding, our model effectively utilized linguistic features from the LLM to improve ASR performance. One inherent limitation of the proposed model is its high computational cost, as evidenced by RTFs reported in Table [I](https://arxiv.org/html/2309.10524v3#S4.T1 "TABLE I ‣ Two-Pass End-to-End ASR ‣ IV Related Work ‣ Harnessing the Zero-Shot Power of Instruction-Tuned Large Language Model for Guiding End-to-End Speech Recognition"). Future research should explore the use of lightweight, efficient LLMs, which are actively studied in NLP field \[[64](https://arxiv.org/html/2309.10524v3#bib.bib64)\].
