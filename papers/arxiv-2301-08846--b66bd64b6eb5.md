###### Abstract

Machine learning methods for conditional data generation usually build a
mapping from source conditional data $`X`$ to target data $`Y`$. The
target $`Y`$ (e.g., text, speech, music, image, video) is usually
high-dimensional and complex, and contains information that does not
exist in source data, which hinders effective and efficient learning on
the source-target mapping. In this paper, we present a learning paradigm
called regeneration learning for data generation, which first generates
$`Y^{\prime}`$ (an abstraction/representation of $`Y`$) from $`X`$ and
then generates $`Y`$ from $`Y^{\prime}`$. During training,
$`Y^{\prime}`$ is obtained from $`Y`$ through either handcrafted rules
or self-supervised learning and is used to learn
$`X\rightarrow Y^{\prime}`$ and $`Y^{\prime}\rightarrow Y`$.
Regeneration learning extends the concept of representation learning to
data generation tasks, and can be regarded as a counterpart of
traditional representation learning, since 1) regeneration learning
handles the abstraction ($`Y^{\prime}`$) of the target data $`Y`$ for
data generation while traditional representation learning handles the
abstraction ($`X^{\prime}`$) of source data $`X`$ for data
understanding; 2) both the processes of $`Y^{\prime}\rightarrow Y`$ in
regeneration learning and $`X\rightarrow X^{\prime}`$ in representation
learning can be learned in a self-supervised way (e.g., pre-training); 3) both the mappings from $`X`$ to $`Y^{\prime}`$ in regeneration
learning and from $`X^{\prime}`$ to $`Y`$ in representation learning are
simpler than the direct mapping from $`X`$ to $`Y`$. We show that
regeneration learning can be a widely-used paradigm for data generation
(e.g., text generation, speech recognition, speech synthesis, music
composition, image generation, and video generation) and can provide
valuable insights into developing data generation methods.

## 1 Introduction

### 1.1 Data Understanding and Generation

Typical machine learning tasks, in the field of natural language
processing \[49, 13, 77, 18, 8\], speech \[2, 34, 51, 79, 71\], computer
vision \[25, 69, 45, 33, 28\], and etc, usually handle a mapping from
source data $`X`$ to target data $`Y`$. For example, $`X`$ is image and
$`Y`$ is class label in image classification \[17\]; $`X`$ is style tag
and $`Y`$ is sentence in style-controlled text generation \[50\]; $`X`$
is text and $`Y`$ is speech in text-to-speech synthesis \[70, 71\].

Depending on the relative amount of information that $`X`$ and $`Y`$
contain, these mappings can be divided into data understanding \[45,
18\], data generation \[28, 8\], and the combination of data
understanding and generation \[1, 31, 29, 10, 71\]. Figure 1 shows the
three types of tasks and the relative information between $`X`$ and
$`Y`$:

- •
  Data understanding tasks, in which $`X`$ contains much more
  information than $`Y`$ (e.g., image classification \[17, 45\],
  objective detection \[27, 60\], sentence classification \[90\],
  machine reading comprehension \[55\]).
- •
  Data generation tasks, in which $`Y`$ contains much more information
  than $`X`$ (e.g., text generation \[8\] or image synthesis \[28, 42\]
  from class label).
- •
  Data understanding/generation tasks, in which $`X`$ contains no
  significantly more or less information than $`Y`$ (e.g., image
  transfer \[91\], text-to-image synthesis \[57, 58, 86, 64, 11\],
  neural machine translation \[1, 31\], text-to-speech synthesis \[71,
  70\], automatic speech recognition \[34\]). In this case, we need both
  data understanding capability on the source $`X`$ and data generation
  capability on the target $`Y`$.

The information mismatch between $`X`$ and $`Y`$ leads to different
strategies for solving different tasks. For data understanding tasks,
$`X`$ is usually high-dimensional, complex, and redundant compared to
$`Y`$, and the key is to learn highly abstractive or discriminative
representations (sometimes need to remove unnecessary information) for
$`X`$ in order to better predict $`Y`$. Thus, representation
learning \[3\]¹¹ 1 One of the most impactful conferences in deep
learning is ICLR, which is short for “The International Conference on
Learning Representations”. and especially self-supervised
pre-training \[18, 8\] have become some of the hottest topics in deep
learning research in the past years. For data generation tasks, $`Y`$ is
usually high-dimensional, complex, and redundant compared to $`X`$, and
the key is how to better represent the distribution of $`Y`$ and better
generate $`Y`$ from $`X`$. For data understanding/generation tasks, they
need the capability in both understanding and generation, i.e., extract
good representations from $`X`$ and fully generate the information in
$`Y`$.

### 1.2 Challenges of Data Generation

For the data generation tasks and the generation part of the data
understanding/generation tasks (we call both the two types as data
generation tasks in the remaining of this paper), they face distinctive
challenges that cannot be addressed by the traditional formulation of
representation learning.

- •
  First, for the generation tasks where $`Y`$ contains much more complex
  information than $`X`$, the generation models face severe one-to-many
  mapping problems (ill-posed or ill-condition problem) \[5\], which
  increases the learning difficulty. For example, in class-conditioned
  image generation, a class label “dog” can correspond to different
  images that contain dogs. Incorrect modeling on the ill-posed problem
  could result in overfitting on the training set and poor
  generalization on the test set.
- •
  Second, for the generation tasks (e.g., speech recognition \[34\],
  speech synthesis \[70\], talking-head video synthesis \[74\]) where
  $`X`$ contains no significant more or less information than $`Y`$,
  there are two situations: 1) the mapping between $`X`$ and $`Y`$ is
  not one-to-one (e.g., multiple words with the same pronunciation can
  correspond to one speech segment in automatic speech recognition, and
  multiple speech with different speaking rates can correspond to one
  text sequence in text-to-speech synthesis), which faces the same
  problem mentioned above; 2) there are some spurious correlations
  between $`X`$ and $`Y`$, e.g., the speaking timber in source speech
  has no correlation with the head pose in target video \[12\] for
  talking-head video synthesis, and some information in target melody
  has no correlation with source lyric in lyric-to-melody
  generation \[39\]. Fitting these spurious correlations can be harmful
  for generation in inference.

### 1.3 Why Regeneration Learning

Some generative models (e.g., GANs \[28\], VAEs \[42\], autoregressive
models \[51, 8\], normalizing flows \[62, 41\], diffusion models \[36\])
have achieved rapid progress in a variety of data generation tasks.
Ideally, as long as generative models are powerful enough, they can fit
any complex data distribution. However, in practice, they cannot model
the complex distribution and one-to-many mapping well due to many
reasons, such as too complicated data mapping, too heavy computation
cost, and data sparsity, etc. In analogy to data understanding tasks,
although learning a powerful model (e.g., CNN or Transformer) to
directly classify source data into target labels would ideally achieve
very good accuracy, it still suffers from low accuracy, and some
advanced representation learning methods such as large-scale
self-supervised pre-training \[18\] can greatly boost the accuracy.

In this paper, we present a learning paradigm called regeneration
learning for data generation tasks. Instead of directly generating
target data $`Y`$ from source data $`X`$, regeneration learning first
generates $`Y^{\prime}`$ (a representation of $`Y`$) from $`X`$ and then
generates $`Y`$ from $`Y^{\prime}`$. Regeneration learning extends the
concept of representation learning to data generation tasks and learns a
good representation ($`Y^{\prime}`$) of the target data $`Y`$ to ease
the generation: 1) $`X\rightarrow Y^{\prime}`$ mapping will be less
one-to-many than $`X\rightarrow Y`$ since $`Y^{\prime}`$ is a
compact/representative version of $`Y`$; 2) $`Y^{\prime}\rightarrow Y`$
mapping can be learned in a self-supervised way ($`Y^{\prime}`$ is
obtained from $`Y`$) and can be empowered by large-scale pre-training
that is similar to that in traditional representation learning for data
understanding tasks (e.g., BERT \[18\]).

In the rest of this paper, we first introduce the basic formulation of
regeneration learning and its connection to other learning methods and
paradigms in Section 2, then summarize the applications of regeneration
learning in Section 3, and finally list some research opportunities on
regeneration learning in Section 4.

## 2 Formulations of Regeneration Learning

In this section, we introduce regeneration learning, which leverages
intermediate representations of target data $`Y`$ to bridge the
information mismatch between $`X`$ and $`Y`$. There are three steps in
regeneration learning:

- •
  Step 1: Convert target data $`Y`$ into an abstractive/representative
  version $`Y^{\prime}`$.
- •
  Step 2: Learn a model to generate $`Y^{\prime}`$ from source data
  $`X`$.
- •
  Step 3: Learn another model to generate $`Y`$ from $`Y^{\prime}`$.

This learning paradigm is called regeneration learning due to the
following reasons: 1) Literally, it has two generation steps that first
generate $`Y^{\prime}`$ and then generate $`Y`$ (i.e., regenerate),
which is in analogy to what ‘‘represent’’ is to ‘‘present’’ in
representation learning²² 2 Strictly speaking, “represent” in
representation learning means “using one thing to signify another
thing”, which is different from “re-present” that means “to present
again”. However, the meaning of “represent” has a close relation to
“re-represent”: suppose you use $`X^{\prime}`$ to signify $`X`$ (i.e.,
represent $`X`$ with $`X^{\prime}`$ and thus $`X^{\prime}`$ is the
representation of $`X`$), and then in this case, you actually re-present
$`X`$ using $`X^{\prime}`$.. 2) Metaphorically, in analogy to what
“represent” in representation learning means, i.e., “using one thing to
signify another thing”, the word “regenerate” in regeneration learning
means to generate one thing to signify another thing (i.e., generate
$`Y^{\prime}`$ to signify $`Y`$). Regeneration learning has several
advantages: 1) the mapping from $`Y^{\prime}`$ to $`Y`$ can be learned
in a self-supervised way, which is much more data-efficient; 2) the
mapping from $`X`$ to $`Y^{\prime}`$ is simpler than the direct mapping
from $`X`$ to $`Y`$.

We first introduce the three steps in regeneration learning in
section 2.1 and discuss the connections of regeneration learning to
existing methods in Section 2.2 and the relationships between
regeneration learning and representation learning in Section 2.3.

### 2.1 Basic Formulation

#### Generate $`Y^{\prime}`$ from Target $`Y`$.

There are three principles when converting $`Y`$ to $`Y^{\prime}`$: 1)
$`Y^{\prime}`$ should be more abstractive and representative than $`Y`$; 2) the removed information from $`Y`$ to $`Y^{\prime}`$ has no or little
correlation with source data $`X`$, i.e., $`Y^{\prime}`$ is a compact
version of $`Y`$ but still maintains its correlation with $`X`$; 3) the
conversion from $`Y`$ to $`Y^{\prime}`$ should be easy, e.g., processed
by simple transformation or extraction tools, or at least not relying on
labeled data if model learning is needed. According to the above
principles, there are different ways to convert $`Y`$ into
$`Y^{\prime}`$, as shown in the “Basic Formulation” in Table 1:

|             |                  |                        |                                                                        |
| ----------- | ---------------- | ---------------------- | ---------------------------------------------------------------------- |

|             |                  | Grapheme-to-Phoneme    | Text (e.g., learning$`\rightarrow^{\prime}`$l\textipa3:rni\textipaN)   |

|             |                  | 3D Image Analysis      | Image (Face to 3D Co-efficient)                                        |

- •
  Explicit transformation. We can convert $`Y`$ into $`Y^{\prime}`$ with
  some explicit transformation methods: 1) Mathematical transformation
  such as Fourier or Wavelet transformation. For example, we can convert
  a speech waveform into a sequence of linear-scale or mel-scale
  spectrograms using short-time Fourier transformation (STFT) \[79,
  65\]. 2) Modality transformation such as grapheme-to-phoneme
  conversion. For example, we can convert a text/character/grapheme
  sequence into a phoneme sequence using the grapheme-to-phoneme
  conversion model \[68\]. 3) Data analysis. For example, we can extract
  music templates (chord, rhythm, etc) from a melody sequence using some
  music analysis tools to get the abstraction of the music \[39\] or
  extract the 3D face parameters from a face image \[47\] using a 3D
  face model \[6\]. 4) Downsampling. For example, we can simply
  down-sample an image from $`256*256`$ resolution to $`64*64`$ or a
  speech sequence from 48kHz sampling rate to 24kHz. These
  transformation methods are usually built on well-established methods
  or tools, and the $`Y^{\prime}`$ transformed from $`Y`$ is usually in
  an explicit data format.
- •
  Implicit transformation. Different from the explicit transformation
  that converts $`Y`$ into $`Y^{\prime}`$ with explicit data format
  using some well-built rules, algorithms, or models, end-to-end
  learning achieves this conversion by learning an intermediate and
  implicit representation through analysis-by-synthesis pipeline or
  reconstruction. Some commonly-used models include auto-encoder (AE),
  denoising auto-encoder (DAE), variational auto-encoder (VAE) \[42\],
  vector-quantized auto-encoder (VQ-VAE) \[76, 59\], diffusion
  autoencoder (DiffsuionAE) \[52\], etc. Beyond the learned encoder that
  converts $`Y`$ into $`Y^{\prime}`$, they can additionally learn a
  decoder that converts $`Y^{\prime}`$ back to $`Y`$, which can be used
  in the third step of regeneration learning.

#### Generate $`Y^{\prime}`$ from Source $`X`$.

The generation from $`X`$ to $`Y^{\prime}`$ can be approached by any
machine learning method, similar to those used to model
$`X\rightarrow Y`$ (e.g., Autoregressive Model, GAN, VAE, Flow,
Diffusion). Since $`Y^{\prime}`$ is extracted from $`Y`$ satisfying the
above three principles, the task of $`X\rightarrow Y^{\prime}`$ is
easier than that of $`X\rightarrow Y`$. For example, generating
mel-spectrograms from text is much simpler than generating waveform in
text-to-speech synthesis, generating 3D face parameters from the speech
is much simpler than generating face image in talking-head video
synthesis, and generating representation sequence (latent code sequence)
from source condition is much simpler than generating pixel-level images
in the conditional image or video generation.

#### Generate Target $`Y`$ from $`Y^{\prime}`$.

Since we can easily extract $`Y^{\prime}`$ from $`Y`$ by tools or models
without relying on any paired training data (i.e., $`X`$ and $`Y`$), we
can train a model to predict $`Y`$ from $`Y^{\prime}`$ in a
self-supervised way, where the paired training data $`(Y^{\prime},Y)`$
can be collected in large scale without much cost. We can also conduct
pre-training to enhance the capability of $`Y^{\prime}\rightarrow Y`$ by
only using a large amount of unpaired data $`Y`$. Note that when using
auto-encoding methods to convert $`Y`$ into $`Y^{\prime}`$, we can
already get a decoder that converts $`Y^{\prime}`$ to $`Y`$, without the
need to train another model.

#### Infer $`Y`$ from $`X`$ via $`Y^{\prime}`$.

We discuss how to combine the two generation steps
$`X\rightarrow Y^{\prime}`$ and $`Y^{\prime}\rightarrow Y`$ together to
generate $`Y`$ from $`X`$. Note that since $`X\rightarrow Y`$ mapping is
one-to-many, the prediction of $`Y`$ from $`X`$ is distribution-wise,
i.e., $`Y\sim P(Y|X)`$, instead of point-wise. Similarly, since
$`Y^{\prime}`$ is a compact version of $`Y`$ that incurs information
loss, $`Y^{\prime}\rightarrow Y`$ is also a one-to-many mapping and
should also be modeled in a distribution-wise way, i.e.,
$`Y\sim P(Y|Y^{\prime})`$. Furthermore, although the ill-posed mapping
problem in $`X\rightarrow Y^{\prime}`$ is largely alleviated compared to
that in $`X\rightarrow Y`$, the $`X\rightarrow Y^{\prime}`$ mapping is
still one-to-many in general, and thus should be modeled in a
distribution-wise way too, i.e., $`Y^{\prime}\sim P(Y^{\prime}|X)`$. On
the other hand, $`Y\rightarrow Y^{\prime}`$ is usually point-wise since
it is converted by a deterministic function. But it can also be
distribution-wise, such as using a VAE encoder to get the mean and
variance of $`Y^{\prime}`$ from $`Y`$. However, no matter whether
$`Y\rightarrow Y^{\prime}`$ is point-wise or distribution-wise,
$`X\rightarrow Y^{\prime}`$ and $`Y^{\prime}\rightarrow Y`$ should be
distribution-wise. We usually leverage deep generative models (e.g.,
autoregressive models, GANs, VAEs, normalizing flows, and denoising
diffusion probabilistic models) to learn the conditional distributions
$`P(Y^{\prime}|X)`$ and $`P(Y|Y^{\prime})`$. After that, given a data
sample $`X`$, we can first sample $`Y^{\prime}`$ from the conditional
distribution $`P(Y^{\prime}|X)`$, and then given the sampled data
$`Y^{\prime}`$, we can further sample $`Y`$ from the conditional
distribution $`P(Y|Y^{\prime})`$, i.e.,
$`Y^{\prime}\sim P(Y^{\prime}|X)`$, $`Y\sim P(Y|Y^{\prime})`$.

### 2.2 Connections to Other Methods

In this subsection, we discuss some methods that have connections to
regeneration learning, including the methods that are basic and extended
versions of regeneration learning, and that do not belong but are
related to regeneration learning.

#### Basic Versions of Regeneration Learning

According to the formulation in Section 2.1, some methods can be
regarded as the basic versions of regeneration learning, such as:

- •
  Template-based methods that extract a concrete template from target
  data and then regenerate target data from the template generated from
  source data \[39\].
- •
  Vocoding methods that convert speech waveform to spectrograms using
  Fourier transformation and regenerate waveform from the spectrograms
  that are generated from the source text or speech \[79, 61, 43\].
- •
  Grapheme/phoneme conversions that convert text/character sequence into
  phoneme sequence, and regenerate text/character sequence from the
  phoneme sequence that is generated from source speech \[87\].
- •
  Auto-encoding methods that convert target data into representations
  and regenerate target data from representations that are generated
  from source data \[76, 59, 57, 71\].

#### Extended Versions of Regeneration Learning

Some methods do not strictly follow the three-step definition of
regeneration learning, but can be regarded as an extended version of
regeneration learning. We show these $`Y\rightarrow Y^{\prime}`$
conversion methods in “Extended Formulation” in Table 1 and introduce
them as follows.

- •
  In autoregressive generation, we use structure factorization to
  factorize the target data $`Y`$ into each step $`Y_{1:t}`$ in an
  autoregressive manner. We can regard a partial sequence $`Y_{<t}`$ as
  a simple/compact version of $`Y_{<t+1}`$, and all the intermediate
  partial sequences $`Y_{<1},Y_{<2},...Y_{<T}`$ as the simple/compact
  versions of $`Y_{1:T}`$, where $`T`$ is the length of the target
  sequence $`Y`$. In this case, the regeneration contains multiple
  generation steps, and in each step, $`Y_{<t+1}`$ is generated from
  $`Y_{<t}`$.
- •
  In denoising diffusion probabilistic models \[36\], we can gradually
  add noise on original data $`Y`$ ($`Y_{0}`$) to get a diffused version
  of data $`Y_{t}`$ \[36\]. Similar to autoregressive generation, the
  diffusion model is also an extended version of regeneration learning,
  where $`Y_{t+1}`$ can be regarded as a compact version of $`Y_{t}`$.
  Iterative-based non-autoregressive sequence generation \[26\] can also
  be regarded as regeneration learning following the same spirit.
- •
  There are some methods that combine auto-encoders with diffusion
  models \[75, 63\], which first convert target data $`Y`$ into latent
  vector $`Z`$ (denoted as $`Z_{0}`$) using VAE or VQ-VAE, and then
  gradually add noise on $`Z_{0}`$ to get $`Z_{t}`$. They first generate
  $`Z_{0}`$ through the diffusion model and then regenerate target $`Y`$
  using the decoder of VAE or VQ-VAE.

#### Related to Regeneration Learning

We describe some methods that are related but do not belong to
regeneration learning.

- •
  After $`Y`$ is generated, post-refine methods can be used to further
  improve the quality of generated $`Y`$. However, we do not regard them
  as regeneration learning, since they do not take the abstraction
  version of $`Y`$ but directly take $`Y`$ as the generation target.
- •
  In the glancing mechanism \[53, 37\], some tokens from $`Y`$ are
  glanced at and taken as the input to predict $`Y`$. We also do not
  regard this mechanism as regeneration learning since there is no
  $`Y^{\prime}`$ used in the learning process.
- •
  In knowledge distillation \[9, 35, 40\], the student takes the output
  of the teacher ($`Y^{\prime}`$) as the learning target, which seems to
  be regeneration learning. However, knowledge distillation does not
  belong to regeneration learning due to several reasons. First, the
  student model in knowledge distillation does not regenerate $`Y`$ from
  $`Y^{\prime}`$. Second, knowledge distillation can be
  distribution-wise \[35\] or point-wise (e.g., sequence-level
  distillation \[40\]), and in distribution-wise distillation,
  $`Y^{\prime}`$ is richer than $`Y`$, instead of an abstractive version
  of $`Y`$ as in regeneration learning.

We will study the relation between regeneration learning and other
iterative-based learning methods such as GFlowNet \[4\] for future work.

### 2.3 Regeneration Learning vs. Representation Learning

Regeneration learning extends the concept of representation learning to
data generation, and thus it can be regarded as a special type of
representation learning for data generation. Furthermore, we can regard
regeneration learning as a counterpart of traditional representation
learning, since 1) regeneration learning handles the abstraction
($`Y^{\prime}`$) of the target data $`Y`$ for data generation, while
traditional representation learning handles the abstraction
($`X^{\prime}`$) of source data $`X`$ for data understanding; 2) both
the processes of $`Y^{\prime}\rightarrow Y`$ in regeneration learning
and $`X\rightarrow X^{\prime}`$ in traditional representation learning
can be learned in a self-supervised way (e.g., pre-training); 3) both
the mappings from $`X`$ to $`Y^{\prime}`$ in regeneration learning and
from $`X^{\prime}`$ to $`Y`$ in traditional representation learning are
simpler than the direct mapping from $`X`$ to $`Y`$. Figure 2 shows the
comparison between regeneration learning and traditional representation
learning.

## 3 Applications of Regeneration Learning

A variety of tasks in conditional data generation (e.g., text
generation, speech recognition, speech synthesis, music composition,
image generation, and video generation) can benefit from this
regeneration learning paradigm. We list some typical generation tasks in
Table 2, and introduce each task that leverages regeneration learning as
follows.

| Task                         | $`X`$          | $`Y`$             | $`Y^{\prime}`$     | $`Y\rightarrow Y^{\prime}`$ & $`Y^{\prime}\rightarrow Y`$ |
| ---------------------------- | -------------- | ----------------- | ------------------ | --------------------------------------------------------- |
| Speech Synthesis             | Text           | Waveform          | Spectrogram / Code | STFT & Vocoder / Codec                                    |
| Speech Recognition           | Speech         | Character         | Phoneme            | G2P & P2G                                                 |
| Text Generation              | Text/Knowledge | Text              | Template           | Text2Template & Template2Text                             |
| Lyric/Video to Melody        | Lyric/Video    | Melody            | Music Template     | Music Analysis & Generation                               |
| Talking-Head Synthesis       | Speech         | Video             | 3D Face Parameters | 3D Face Analysis & Rendering                              |
| Image/Video/Sound Generation | Class/Text     | Image/Video/Sound | Latent Code        | Codec Extraction & Generation                             |

Table 2: Typical data (text, speech, music, sound, image, and video)
generation tasks that leverage regeneration learning.

- •
  Text-to-Speech Synthesis. In text-to-speech synthesis (e.g., Tacotron
  2 \[65\], FastSpeech \[61\]), the target waveform is converted into
  mel-spectrogram sequence using short-time Fourier transformation
  (STFT), and an acoustic model is used to predict mel-specotrgram
  sequence from the source text, and a vocoder is used to generate
  waveform from predicted mel-spectrogram sequence. There are also some
  works \[32, 48\] using VQ-VAE to convert speech waveforms into
  continuous vectors or discrete tokens to bridge the mapping between
  text and speech.
- •
  Automatic Speech Recognition. Some works \[78, 87, 89\] in automatic
  speech recognition first transform target character sequence into
  phoneme sequence using grapheme-to-phoneme (G2P) conversion, and use
  an acoustic model to predict phoneme sequence from source speech
  sequence, and then use another model to generate character sequence
  from predicted phoneme sequence.
- •
  Text Generation. Some works \[80, 84\] in text generation first
  convert a target sentence into a template or syntax sequence using
  template extraction or syntax parsing, and then predict template or
  syntax sequence from the source text or from scratch, and generate
  target text from the predicted template or syntax sequence.
- •
  Melody Generation. Some works \[39, 81, 15, 92, 19\] in melody
  generation first extract music template from target melody sequence,
  and then predict the template from source conditions (e.g., lyrics,
  background videos, dancing videos) and generate a melody from the
  predicted template, such as TeleMelody \[39\].
- •
  Talking-Head Video Synthesis. In talking-head video synthesis, some
  pipelines \[74, 38, 85, 46, 67, 47, 72\] for high-quality face
  synthesis usually extracts the 3D face parameters from the target face
  images through 3D face models \[6, 73, 24\], and generates the 3D face
  parameters from source speech or text, and then generates the face
  images from the generated 3D face parameters.
- •
  Image/Video/Sound Generation. In image/video/sound generation, since
  the images or audios are too complex that incur too much computation,
  many works \[57, 20, 82, 56, 7, 83, 44\] first covert images/waveforms
  into discrete visual/audio tokens using VQ-VAE/VQ-GAN \[76, 23, 88\]
  or into continuous hidden representations using CLIP \[54, 58\], and
  then generate these visual/audio tokens or hidden either conditioning
  on text (e.g., DALL-E 1/2 \[57, 58\], StableDiffusion \[63\],
  AudioGen \[44\] ) or from prefix/scratch (e.g., AudioLM \[7\],
  VideoGPT \[82\], LVT \[56\]), and finally regenerate
  images/videos/audios from the generated tokens using the decoder in
  previous VQ-VAE/VQ-GAN or separate decoders such as GANs, VAEs,
  normalizing flows, or diffusion models.

Basically speaking, a conditional data generation task can leverage
regeneration learning as long as they fit into some situations:

- •
  The target data is too high-dimensional and complex to generate, or
  incurs too much computation cost, such as waveform generation in
  text-to-speech synthesis \[65, 61, 70\], and image/video/sound
  generation \[57, 20, 82, 56, 63, 44\]. In this case, converting target
  data $`Y`$ into more compact $`Y^{\prime}`$ will greatly reduce the
  computation cost and free the model to focus more on how to generate
  high-level abstractive or semantic information of target data, but not
  on the minor details.
- •
  The source data $`X`$ and target data $`Y`$ have too much uncorrelated
  information (i.e., $`X\cap Y\ll X\cup Y`$), such as lyric/video and
  melody in conditional melody generation \[39, 81, 15, 92, 19\], speech
  and face images in talking-head video synthesis \[74, 38, 85, 46, 67,
  47\]. Directly learning the mapping between $`X`$ and $`Y`$ would lead
  to overfitting. Thus, converting $`Y`$ into more compact
  $`Y^{\prime}`$ will make the mapping between $`X`$ and $`Y^{\prime}`$
  less ill-posed and ease the model learning.
- •
  There lack of paired $`X`$ and $`Y`$, and thus regeneration learning
  can be leveraged to train $`Y^{\prime}\rightarrow Y`$ with large-scale
  self-supervised learning based on only target data $`Y`$.

## 4 Research Opportunities on Regeneration Learning

We discuss some research opportunities to make regeneration learning
more powerful to solve a variety of data generation tasks, and list some
corresponding research questions (RQ) both in each subsection and in
Table 3, mainly from three perspectives: 1) how to get $`Y^{\prime}`$; 2) how to learn the mapping $`X\rightarrow Y^{\prime}`$ and
$`Y^{\prime}\rightarrow Y`$; 3) how to reduce the training-inference
mismatch in regeneration learning pipeline.

### 4.1 How to Get $`Y^{\prime}`$

How to find an appropriate $`Y^{\prime}`$ is important for
$`X\rightarrow Y^{\prime}`$ and $`Y^{\prime}\rightarrow Y`$ mapping. For
example, in text-to-speech synthesis, mel-spectrograms and mel-frequency
cepstral coefficients (MFCCs) are both possible $`Y^{\prime}`$ for
target waveform $`Y`$. However, mel-spectrograms are demonstrated to be
much better than MFCCs, since MFCCs are too abstractive that lose a lot
of fine-grained information, thus making it difficult to reconstruct
$`Y`$ from $`Y^{\prime}`$. In the following, we list several possible
research points to get a better $`Y^{\prime}`$.

#### Better Implicit Learning.

Beyond using some handcrafted rules or well-developed tools to find
$`Y^{\prime}`$, we can automatically learn $`Y^{\prime}`$ from $`Y`$.
The typical methods are based on an analysis-by-synthesis pipeline,
e.g., variational auto-encoder (VAE) \[42\] and vector-quantized
variational auto-encoder (VQ-VAE) \[76\]. For example, in text-to-speech
synthesis \[14, 71, 48\], NaturalSpeech \[71\] leverages VAE and
DelightfulTTS 2 \[48\] leverages VQ-VAE to learn intermediate
representations $`Y^{\prime}`$ from speech waveform $`Y`$ and
reconstruct $`Y`$ from $`Y^{\prime}`$. The motivation is that the
commonly-used intermediate representations (e.g., mel-spectrograms) are
extracted by SFTF algorithms that may not be optimal, while those
learned by VAE could be better representations of waveform and ease the
generation process. In the image and video domain, VQ-VAE \[76\] is
widely used to learn discrete visual tokens to represent images and
videos. However, some other works try to further improve the discrete
token extraction of VQ-VAE by introducing hierarchical learning (e.g.,
VQ-VAE-2 \[59\]), adding adversarial loss (e.g., VQ-GAN \[23\]) and
perceptual loss (e.g., PECO \[22\]), residual quantizers \[30, 88, 16\],
or leverage diffusion models to learn the hidden representation \[52\].

- •
  RQ1: How to design better analysis-by-synthesis methods (beyond VAE,
  VQ-VAE, DiffusionAE, etc) to learn $`Y^{\prime}`$?
- •
  RQ2: How to design better learning paradigms other than
  analysis-by-synthesis to learn $`Y^{\prime}`$?

| Perspective                                             | ID  | Research Questions                                                                                                                                |
| ------------------------------------------------------- | --- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| $`Y\rightarrow Y^{\prime}`$                             | 1   | How to design better analysis-by-synthesis methods (beyond VAE, VQ-VAE, DiffusionAE, etc) to learn $`Y^{\prime}`$?                                |
|                                                         | 2   | How to design better learning paradigms other than analysis-by-synthesis to learn $`Y^{\prime}`$?                                                 |
|                                                         | 3   | How to leverage unpaired data $`Y`$ and/or paired data $`(X,Y)`$ to learn $`Y^{\prime}`$?                                                         |
|                                                         | 4   | How to better trade off the difficulty between $`X\rightarrow Y^{\prime}`$ and $`Y^{\prime}\rightarrow Y`$ mappings when learning $`Y^{\prime}`$? |
|                                                         | 5   | How to disentangle semantic meaning and perceptual details to learn a more semantic instead of detailed $`Y^{\prime}`$?                           |

Table 3: Research questions on regeneration learning.

#### Learning $`Y^{\prime}`$ by Considering $`X`$.

An intuition is that the abstractive representation $`Y^{\prime}`$
should not only depends on $`Y`$, but also be correlated to $`X`$ in
order to facilitate the prediction of $`Y^{\prime}`$ from $`X`$. To this
end, we formulate a learning strategy as follows. We take the target
data $`Y`$ as the input of the target encoder to get
$`Y^{\prime}=f_{Y}(Y)`$ and use the target decoder to reconstruct
$`Y\sim P(Y|Y^{\prime})`$. We further take source data $`X`$ as the
input of the source encoder to get $`X^{\prime}=f_{X}(X)`$ and encourage
$`X^{\prime}`$ and $`Y^{\prime}`$ to contain information with each other
by using some losses such as contrastive loss or L1/L2 loss:
$`||X^{\prime}-f_{Y^{\prime}}(Y^{\prime})||^{2}_{2}`$ and
$`||Y^{\prime}-f_{X^{\prime}}(X^{\prime})||^{2}_{2}`$. Additionally, we
use a loss $`-\log P(Y|f_{X^{\prime}}(X^{\prime}))`$ to encourage the
target decoder to get used to the $`Y^{\prime}`$ predicted from
$`X^{\prime}`$, which can also address the problems mentioned in
Section 4.3. The total loss is as follows:

```math
L=-\log P(Y|Y^{\prime})+||X^{\prime}-f_{Y^{\prime}}(Y^{\prime})||^{2}_{2}+||Y^{\prime}-f_{X^{\prime}}(X^{\prime})||^{2}_{2}-\log P(Y|f_{X^{\prime}}(X^{\prime})), \tag{1}
```

where $`Y^{\prime}=f_{Y}(Y)`$ and $`X^{\prime}=f_{X}(X)`$. We can
leverage both unpaired data $`Y`$ and paired data $`(X,Y)`$ to learn
$`Y^{\prime}`$ according to Equation 1. When using unpaired data $`Y`$
for learning, we only use the first loss term. We leave the theoretical
and empirical investigation of Equation 1 as future work, but at the
same time also welcome researchers to study this topic if you are
interested.

Except for leveraging paired data $`(X,Y)`$ to learn a good
$`Y^{\prime}`$, we can also leverage some prior knowledge about $`X`$
when choosing how to convert $`Y`$ into $`Y^{\prime}`$. For example, in
automatic speech recognition, we know that the source $`X`$ is speech
and thus we convert text sequence $`Y`$ into phoneme sequence
$`Y^{\prime}`$ to ease the conversion from $`X`$ to $`Y^{\prime}`$. In
text-to-image synthesis (e.g., DALL-E 2 \[58\]), the image is converted
into CLIP \[54\] features that are close to text representations to ease
text-to-image conversion.

However, there is a trade-off on the difficulties between
$`X\rightarrow Y^{\prime}`$ and $`Y^{\prime}\rightarrow Y`$, since
considering more $`X`$ when learning $`Y^{\prime}`$ will ease the
learning of $`X\rightarrow Y^{\prime}`$ while making the learning of
$`Y^{\prime}\rightarrow Y`$ harder. We should make a good trade-off to
get better overall performance.

- •
  RQ3: How to leverage unpaired data $`Y`$ and/or paired data $`(X,Y)`$
  to learn $`Y^{\prime}`$?
- •
  RQ4: How to better trade off the difficulty between
  $`X\rightarrow Y^{\prime}`$ and $`Y^{\prime}\rightarrow Y`$ mappings
  when learning $`Y^{\prime}`$?

#### Disentangling Semantic Meaning from Perceptual Details.

Generally speaking, $`X\rightarrow Y^{\prime}`$ cares more about
semantic mapping/conversion from source to target, while
$`Y^{\prime}\rightarrow Y`$ cares more about rendering perceptual
details to obtain the target $`Y`$. For example, in text-to-image
synthesis, $`X\rightarrow Y^{\prime}`$ converts source text into
discrete visual tokens that describe the semantic meanings of the target
image, and $`Y^{\prime}\rightarrow Y`$ renders the image details from
visual tokens. How to design a learning mechanism to better disentangle
the semantic meaning and perceptual details and let $`Y^{\prime}`$ focus
on semantic meaning will be a good research opportunity.

- •
  RQ5: How to disentangle semantic meaning and perceptual details to
  learn a more semantic instead of detailed $`Y^{\prime}`$?

#### Discrete vs. Continuous $`Y^{\prime}`$.

Both discrete and continuous $`Y^{\prime}`$ can be leveraged to bridge
the mapping between $`X`$ and $`Y`$. For example, using similar VQ-VAE
to quantize speech waveforms, DelightfulTTS 2 \[48\] leverages
continuous vectors as $`Y^{\prime}`$ while DiscreTalk \[32\] leverages
discrete tokens as $`Y^{\prime}`$. Which kinds of representations
(discrete vs continuous) are better choices for $`Y^{\prime}`$ is also
an interesting point to investigate.

- •
  RQ6: How to determine the discrete or continuous format of
  $`Y^{\prime}`$ for each data generation task?

### 4.2 How to Learn $`X\rightarrow Y^{\prime}`$ and $`Y^{\prime}\rightarrow Y`$

Regeneration learning decomposes a conditional data generation task
$`X\rightarrow Y`$ into data conversion and data rendering processes.
The data conversion process converts source data $`X`$ into the target
domain, which maintains the concrete semantics but does not necessarily
contain fine-grained details. The data rendering process further renders
the fine-grained details of the target data to achieve high-quality data
generation. Roughly speaking, $`X\rightarrow Y^{\prime}`$ undertakes
more on the role of data conversion, while $`Y^{\prime}\rightarrow Y`$
undertakes more on the role of data rendering.

How to design better training methods on $`X\rightarrow Y^{\prime}`$ and
$`Y^{\prime}\rightarrow Y`$ would be important for the final performance
of $`X\rightarrow Y`$ mapping in regeneration learning. Advanced
generative models such as autoregressive models \[51, 8\], VAEs \[42\],
GANs \[28\], normalizing flows \[21, 62\], and diffusion models \[66,
36\] can play an important role. Furthermore, considering
$`Y^{\prime}\rightarrow Y`$ mapping can usually be learned through
large-scale self-supervised methods, we should leverage more unpaired
data when learning $`Y^{\prime}\rightarrow Y`$.

- •
  RQ7: How to design better generative models to learn
  $`X\rightarrow Y^{\prime}`$ and $`Y^{\prime}\rightarrow Y`$ mapping?
- •
  RQ8: How to leverage the assumption of semantic conversion in
  $`X\rightarrow Y^{\prime}`$ and detail rendering in
  $`Y^{\prime}\rightarrow Y`$ to design better methods?
- •
  RQ9: How to leverage large-scale self-supervised learning for
  $`Y^{\prime}\rightarrow Y`$ mapping?

### 4.3 How to Reduce Training-Inference Mismatch in $`X\rightarrow Y^{\prime}\rightarrow Y`$

The model of $`Y^{\prime}\rightarrow Y`$ is trained in a self-supervised
way, where $`Y^{\prime}`$ is extracted from $`Y`$ in training. However,
$`Y^{\prime}`$ is predicted from $`X`$ in inference, which causes the
training-inference mismatch. How to reduce the mismatch is important to
ensure the performance of this cascaded system
($`X\rightarrow Y^{\prime}`$ and $`Y^{\prime}\rightarrow Y`$). A
straightforward way is to design an end-to-end optimization method
between $`X\rightarrow Y^{\prime}`$ and $`Y^{\prime}\rightarrow Y`$, but
still maintain $`Y^{\prime}`$ as an intermediate representation. For
example, NaturalSpeech \[71\] leverages VAEs and normalizing flows with
bidirectional prior/posterior optimization to achieve end-to-end
learning. Can we design other methods to reduce the training-inference
mismatch in regeneration learning?

- •
  RQ10: How to reduce the training-inference mismatch in regeneration
  learning?

## 5 Conclusion

In this paper, we present a learning paradigm called regeneration
learning for data generation tasks. Literally, it means generating the
data two times: first generates an intermediate representation
$`Y^{\prime}`$ from source data $`X`$, and then generates a target data
$`Y`$ from $`Y^{\prime}`$. Metaphorically, it means generating
$`Y^{\prime}`$ as intermediate representations to signify $`Y`$, in
analogy to representation learning. Regeneration learning can be
regarded as a counterpart of traditional representation learning:
regeneration learning handles the abstraction ($`Y^{\prime}`$) of the
target data $`Y`$ for data generation while representation learning
handles the abstraction ($`X^{\prime}`$) of source data $`X`$ for data
understanding, and both the processes of $`Y^{\prime}\rightarrow Y`$ in
regeneration learning and $`X\rightarrow X^{\prime}`$ in representation
learning can be learned in a self-supervised way (it is also a
counterpart in literally: presentation$`\rightarrow`$representation vs.
generation$`\rightarrow`$regeneration). We discuss the connections of
regeneration learning to other methods, demonstrate a variety of data
generation tasks that can benefit from regeneration learning, and
further point out some research opportunities on regeneration learning.
Regeneration learning can be a widely-used paradigm for high-quality
data generation and can provide valuable insights into developing data
generation methods.
