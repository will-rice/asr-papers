FrugalML: How to Use ML Prediction APIs\
More Accurately and Cheaply
========================================

Lingjiao Chen, Matei Zaharia, James Zou\
Stanford University

###### Abstract

Prediction APIs offered for a fee are a fast-growing industry and an important part of machine learning as a service. While many such services are available, the heterogeneity in their price and performance makes it challenging for users to decide which API or combination of APIs to use for their own data and budget. We take a first step towards addressing this challenge by proposing FrugalML, a principled framework that jointly learns the strength and weakness of each API on different data, and performs an efficient optimization to automatically identify the best sequential strategy to adaptively use the available APIs within a budget constraint. Our theoretical analysis shows that natural sparsity in the formulation can be leveraged to make FrugalML efficient. We conduct systematic experiments using ML APIs from Google, Microsoft, Amazon, IBM, Baidu and other providers for tasks including facial emotion recognition, sentiment analysis and speech recognition. Across various tasks, FrugalML can achieve up to 90% cost reduction while matching the accuracy of the best single API, or up to 5% better accuracy while matching the best API’s cost.

## 1 Introduction

Machine learning as a service (MLaaS) is a rapidly growing industry. For example, one could use Google prediction API \[9\] to classify an image for \$0.0015 or to classify the sentiment of a text passage for \$0.00025. MLaaS services are appealing because using such APIs reduces the need to develop one’s own ML models. The MLaaS market size was estimated at \$1 billion in 2019, and it is expected to grow to \$8.4 billion by 2025 \[1\].

Third-party ML APIs come with their own challenges, however. A major challenge is that different companies charge quite different amounts for similar tasks. For example, for image classification, Face++ charges \$0.0005 per image \[6\], which is 67% cheaper than Google \[9\], while Microsoft charges \$0.0010 \[11\]. Moreover, the prediction APIs of different providers perform better or worse on different types of inputs. For example, accuracy disparities in gender classification were observed for different skin colors \[22, 33\]. As we will show later in the paper, these APIs’ performance also varies by class—for example, we found that on the FER+ dataset, the Face++ API had the best accuracy on *surprise* images while the Microsoft API had the best performance on *neutral* images. The more expensive APIs are not uniformly better; and APIs tend to have specific classes of inputs where they perform better than alternatives. This heterogeneity in price and in performance makes it challenging for users to decide which API or combination of APIs to use for their own data and budget.

In this paper, we propose FrugalML, a principled framework to address this challenge. FrugalML jointly learns the strength and weakness of each API on different data, then performs an efficient optimization to automatically identify the best adaptive strategy to use all the available APIs given the user’s budget constraint. FrugalML leverages the modular nature of APIs by designing adaptive strategies that can call APIs sequentially. For example, we might first send an input to API A. If A returns the label “dog” with high confidence—and we know A tends to be accurate for dogs—then we stop and report “dog”. But if A returns “hare” with lower confidence, and we have learned that A is less accurate for “hare,” then we might adaptively select a second API B to make additional assessment.

FrugalML optimizes such adaptive strategies to substantially improve prediction performance over simpler approaches such as model cascades with a fixed quality threshold (Figure 1). Through experiments with real commercial ML APIs on diverse tasks, we observe that FrugalML typically reduces costs more than 50% and sometimes up to 90%. Adaptive strategies are challenging to learn and optimize, because the choice of the 2^(nd) predictor, if one is chosen, could depend on the prediction and confidence of the first API, and because FrugalML may need to allocate different fractions of its budget to predictions for different classes. We prove that under quite general conditions, there is natural sparsity in this problem that we can leverage to make FrugalML efficient.

#### Related Work.

MLaaS: With the growing importance of MLaaS APIs \[2, 3, 6, 9, 10, 11\], existing research has largely focused on evaluating individual API for their performance \[51\], robustness \[27\], and applications \[22, 28, 40\]. On the other hand, FrugalML aims at finding strategies to select from or use multiple APIs to reduce costs and increase accuracy.

Mixtures of Experts: A natural approach to exploiting multiple predictors is mixture of experts \[31, 30, 52\], which uses a gate function to decide which expert to use. Substantial research has focused on developing gate function models, such as SVMs \[24, 50\], Gaussian Process \[25, 49\], and neutral networks \[42, 41\]. However, applying mixture of experts for MLaaS would result in fixed cost and thus would not allow users to specify a budget constraint as in FrugalML. As we will show later, sometimes FrugalML with a budget constraint can even outperform mixture of experts algorithms while using less budget.

Model Cascades: Cascades consisting of a sequence of models are useful to balance the quality and runtime of inference \[44, 45, 23, 32, 43, 46, 48, 34\]. While model cascades use predicted quality score alone to avoid calling computationally expensive models, FrugalML’ strategies can utilize both quality score and predicted class to select a downstream expensive add-on service. Designing such strategies requires solving a significantly harder optimization problem, e.g., choosing how to divide the available budget between classes (§3), but also improves performance substantially over using the quality score alone (§4).

## 2 Preliminaries

#### Notation.

In our exposition, we denote matrices and vectors in bold, and scalars, sets, and functions in standard script. We let $`\mathbf{1}_{m}`$ denote the $`m \times 1`$ all ones vector, while $`\mathbf{1}_{n \times m}`$ denotes the all ones $`n \times m`$ matrix. We define $`\mathbf{0}_{m},\mathbf{0}_{n \times m}`$ analogously. The subscripts are omitted when clear from context. Given a matrix $`\mathbf{A} \in {\mathbb{R}}^{n \times m}`$, we let $`\mathbf{A}_{i,j}`$ denote its entry at location $`(i,j)`$, $`\mathbf{A}_{i, \cdot} \in {\mathbb{R}}^{1 \times m}`$ denote its $`i`$th row, and $`\mathbf{A}_{\cdot ,j} \in {\mathbb{R}}^{n \times 1}`$ denote its $`j`$th column. Let $`\lbrack n\rbrack`$ denote $`\{ 1,2,\cdots,n\}`$. Let $`\mathbb{1}`$ represent the indicator function.

#### ML Tasks.

Throughout this paper, we focus on (multiclass) classification tasks, where the goal is to classify a data point $`x`$ from a distribution $`D`$ into $`L`$ label classes. Many real world ML APIs aim at such tasks, including facial emotion recognition, where $`x`$ is a face image and label classes are emotions (happy, sad, etc), and text sentiment analysis, where $`x`$ is a text passage and the label classes are attitude sentiment (either positive or negative).

#### MLaaS Market.

Consider a MLaaS market consisting of $`K`$ different ML services which aim at the same classification task. Taken a data point $`x`$ as input, the $`k`$th service returns to the user a predicted label $`{y_{k}\hspace{0pt}{(x)}} \in {\lbrack L\rbrack}`$ and its quality score $`{q_{k}\hspace{0pt}{(x)}} \in {\lbrack 0,1\rbrack}`$, where larger score indicates higher confidence of its prediction. This is typical for many popular APIs. There is also a unit cost associated with each service. Let the vector $`\mathbf{c} \in {\mathbb{R}}^{K}`$ denote the unit cost of all services. Then $`\mathbf{c}_{k} = 0.005`$ simply means that users need to pay $`0.005`$ every time they call the $`k`$th service. We use $`y\hspace{0pt}{(x)}`$ to denote $`x`$’s true label, and let $`{r^{k}\hspace{0pt}{(x)}} \triangleq \mathbb{1}_{{y_{k}\hspace{0pt}{(x)}} = {y\hspace{0pt}{(x)}}}`$ be the reward of using the $`k`$ service on $`x`$.

## 3 FrugalML: a Frugal Approach to Adaptively Leverage ML Services

![Refer to caption](https://ar5iv.labs.arxiv.org/html/2006.07512/assets/x2.png)

Figure 2: In FrugalML, a base service is first selected and called. If its quality score is smaller than the threshold for its predicted label, FrugalML chooses an add-on service to invoke and returns its prediction. Otherwise, the base service’s prediction is returned.

In this section, we present FrugalML, a formal framework for API calling strategies to obtain accurate and cheap predictions from a MLaaS market. All proofs are left to the appendix. We generalize the scheme in Figure 1 (c) to $`K`$ ML services and $`L`$ label classes. Let a tuple $`s \triangleq {(\mathbf{p}^{\lbrack 1\rbrack},\mathbf{Q},\mathbf{P}^{\lbrack 2\rbrack})}`$ represent a calling strategy produced by FrugalML. Given an input data $`x`$, FrugalML first calls a base service, denoted by $`A_{s}^{\lbrack 1\rbrack}`$, which with probability $`\mathbf{p}_{i}^{\lbrack 1\rbrack}`$ is the $`i`$th service and returns quality score $`q_{i}\hspace{0pt}{(x)}`$ and label $`y_{i}\hspace{0pt}{(x)}`$. Let $`D_{s}`$ be the indicator of whether the quality score is smaller than the threshold value $`\mathbf{Q}_{i,{y_{i}\hspace{0pt}{(x)}}}`$. If $`D_{s} = 1`$, then FrugalML invokes an add-on service, denoted by $`A_{s}^{\lbrack 2\rbrack}`$, with probability $`\mathbf{P}_{i,{y_{i}\hspace{0pt}{(x)}},j}^{\lbrack 2\rbrack}`$ being the $`j`$th service and producing $`y_{j}\hspace{0pt}{(x)}`$ as the predicted label $`{\hat{y}}^{s}\hspace{0pt}{(x)}`$. Otherwise, FrugalML simply returns label $`{{\hat{y}}^{s}\hspace{0pt}{(x)}} = {y_{i}\hspace{0pt}{(x)}}`$ from the base service. This process is summarized in Figure 2. Note that the strategy is adaptive: the choice of the add-on API can depend on the predicted label and quality score of the base model.

The set of possible strategies can be parametrized as $`S \triangleq \left. \{{(\mathbf{p}^{\lbrack 1\rbrack},\mathbf{Q},\mathbf{P}^{\lbrack 2\rbrack})} \middle| {{\mathbf{p}^{\lbrack 1\rbrack} \succcurlyeq \mathbf{0} \in {\mathbb{R}}^{K}},{{{\mathbf{1}^{T}\hspace{0pt}\mathbf{p}^{\lbrack 1\rbrack}} = 1},{{\mathbf{Q} \in {\mathbb{R}}^{K \times L}},{\mathbf{0} \preccurlyeq \mathbf{Q} \preccurlyeq \mathbf{1}}}},{{\mathbf{P}^{\lbrack 2\rbrack} \in {\mathbb{R}}^{K \times L \times K}},{{\mathbf{P}^{\lbrack 2\rbrack} \succcurlyeq \mathbf{0}},{{\mathbf{1}^{T}\hspace{0pt}\mathbf{P}_{k,\ell, \cdot}^{\lbrack 2\rbrack}} = 1}}}}\} \right.`$. Our goal is to choose the optimal strategy $`s^{\ast}`$ that maximizes the expected accuracy while satisfies the user’s budget constraint $`b`$. This is formally stated as below.

###### Definition 1.

Given a user budget $`b`$, the optimal FrugalML strategy $`s^{\ast} = {(\mathbf{p}^{{\lbrack 1\rbrack} \ast},\mathbf{Q}^{\ast},\mathbf{P}^{{\lbrack 2\rbrack} \ast})}`$ is

``` math
{s^{\ast} \triangleq {{\arg{\max\limits_{s \in S}{\mathbb{E}}}}\hspace{0pt}{\lbrack{r^{s}\hspace{0pt}{(x)}}\rbrack}\hspace{0pt}\text{~s.t.~}\hspace{0pt}{\mathbb{E}}\hspace{0pt}{\lbrack{\eta^{\lbrack s\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}} \leq b},
```

where $`{r^{s}\hspace{0pt}{(x)}} \triangleq \mathbb{1}_{{{\hat{y}}^{s}\hspace{0pt}{(x)}} = {y\hspace{0pt}{(x)}}}`$ is the reward and $`\eta^{\lbrack s\rbrack}\hspace{0pt}{(x,\mathbf{c})}`$ the total cost of strategy $`s`$ on $`x`$.

###### Remark 1.

The above definition can be generalized to wider settings. For example, instead of 0-1 loss, the reward can be negative square loss to handle regression tasks. We pick the concrete form for demonstration purposes. The cost of strategy $`s`$, $`\eta^{\lbrack s\rbrack}\hspace{0pt}{(x,\mathbf{c})}`$, is the sum of all services called on $`x`$. For example, if service $`1`$ and $`2`$ are called for predicting $`x`$, then $`\eta^{\lbrack s\rbrack}\hspace{0pt}{(x,\mathbf{c})}`$ becomes $`\mathbf{c}_{1} + \mathbf{c}_{2}`$.

Given the above formulation, a natural question is how to solve it efficiently. In the following, We first highlight an interesting property of the optimal strategy, sparsity, which inspires the design of the efficient solver, and then present the algorithm for the solver.

### 3.1 Sparsity Structure in the Optimal Strategy

We show that if problem 3.1 is feasible and has unique optimal solution, then we must have $`{\|\mathbf{p}^{{\lbrack 1\rbrack} \ast}\|} \leq 2`$. In other words, the optimal strategy should only choose the base service from at most two services (instead of $`K`$) in the MLaaS market. This is formally stated in Lemma 1.

###### Lemma 1.

If problem 3.1 is feasible, then there exists one optimal solution $`s^{\ast} = {(\mathbf{p}^{{\lbrack 1\rbrack} \ast},\mathbf{Q}^{\ast},\mathbf{P}^{{\lbrack 2\rbrack} \ast})}`$ such that $`{\|\mathbf{p}^{{\lbrack 1\rbrack} \ast}\|} \leq 2`$.

To see this, let us first expand $`{\mathbb{E}}\hspace{0pt}{\lbrack{r^{s}\hspace{0pt}{(x)}}\rbrack}`$ and $`{\mathbb{E}}\hspace{0pt}{\lbrack{\eta^{s}\hspace{0pt}{(x)}}\rbrack}`$ by the law of total expectation.

###### Lemma 2.

The expected accuracy is $`{\mathbb{E}}{\lbrack r^{s}{(x)}\rbrack} = \sum_{i = 1}^{K}\Pr{\lbrack A_{s}^{\lbrack 1\rbrack} = i\rbrack}\Pr{\lbrack D_{s} = 0|A_{s}^{\lbrack 1\rbrack} = i\rbrack}{\mathbb{E}}{\lbrack r^{i}{(x)}|D_{s} = 0,A_{s}^{\lbrack 1\rbrack} = i\rbrack} + \sum_{{i,j} = 1}^{K}\Pr{\lbrack A_{s}^{\lbrack 1\rbrack} = i\rbrack}\Pr{\lbrack D_{s} = 1|A_{s}^{\lbrack 1\rbrack} = i\rbrack}\Pr{\lbrack A_{s}^{\lbrack 2\rbrack} = j|D_{s} = 1,A_{s}^{\lbrack 1\rbrack} = i\rbrack}{\mathbb{E}}{\lbrack r^{j}{(x)}|D_{s} = 1,A_{s}^{\lbrack 1\rbrack} = i)}\rbrack`$. The expected cost is $`{{\mathbb{E}}\hspace{0pt}{\lbrack{\eta^{s}\hspace{0pt}{(x)}}\rbrack}} = {{\sum_{i = 1}^{K}{{\Pr{\lbrack{A_{s}^{\lbrack 1\rbrack} = i}\rbrack}}\hspace{0pt}{\Pr{\lbrack{D_{s} = \left. 0 \middle| A_{s}^{\lbrack 1\rbrack} \right. = i}\rbrack}}\hspace{0pt}\mathbf{c}_{i}}} + {\sum_{{i,j} = 1}^{K}{{\Pr{\lbrack{A_{s}^{\lbrack 1\rbrack} = i}\rbrack}}\hspace{0pt}{\Pr{\lbrack{D_{s} = \left. 1 \middle| A_{s}^{\lbrack 1\rbrack} \right. = i}\rbrack}}\hspace{0pt}{\Pr{\lbrack{A_{s}^{\lbrack 2\rbrack} = \left. j \middle| D_{s} \right. = 1},{A_{s}^{\lbrack 1\rbrack} = i}\rbrack}}\hspace{0pt}\left( {\mathbf{c}_{i} + \mathbf{c}_{j}} \right)}}}`$.

Note that both $`{\mathbb{E}}\hspace{0pt}{\lbrack{r^{s}\hspace{0pt}{(x)}}\rbrack}`$ and $`{\mathbb{E}}\hspace{0pt}{\lbrack{\eta^{s}\hspace{0pt}{(x)}}\rbrack}`$ are linear in $`\Pr{\lbrack{A_{s}^{\lbrack 1\rbrack} = i}\rbrack}`$, which by definition equals $`\mathbf{p}_{i}^{\lbrack 1\rbrack}`$. Thus, fixing $`\mathbf{Q}`$ and $`\mathbf{P}^{\lbrack 2\rbrack}`$, problem 3.1 becomes a linear programming in $`\mathbf{p}^{\lbrack 1\rbrack}`$. Intuitively, the corner points of its feasible region must be 2-sparse, since except $`{{\mathbb{E}}\hspace{0pt}{\lbrack{\eta^{s}\hspace{0pt}{(x)}}\rbrack}} \leq b`$ and $`{\mathbf{1}^{T}\hspace{0pt}\mathbf{p}^{\lbrack 1\rbrack}} \leq 1`$ , all other constraints ($`\mathbf{p}^{\lbrack 1\rbrack} \succcurlyeq \mathbf{0}`$) force sparsity. As the optimal solution of a linear programming should be a corner point, $`\mathbf{p}^{\lbrack 2\rbrack}`$ must also be 2-sparse.

This sparsity structure helps reduce the computational complexity for solving problem 3.1. In fact, the sparsity structure implies problem 3.1 becomes equivalent to a master problem

``` math
{{{\max\limits_{{(i_{1},i_{2},p_{1},p_{2},b_{1},b_{2})} \in C}{\ \hspace{0pt}p_{1}\hspace{0pt}g_{i_{1}}}}\hspace{0pt}{({b_{1}/p_{1}})}} + {p_{2}\hspace{0pt}g_{i_{2}}\hspace{0pt}{({b_{2}/p_{2}})}\hspace{0pt}\ \hspace{0pt}s}}.t.{{b_{1} + b_{2}} \leq b}
```

where $`c = \left. \{{(i_{1},i_{2},p_{1},p_{2},b_{1},b_{2})} \middle| {{{i_{1},i_{2}} \in {\lbrack K\rbrack}},{{p_{1},p_{2}} \geq 0},{{{p_{1} + p_{2}} = {1,b_{1}}},{b_{2} \geq 0}}}\} \right.`$, and $`g_{i}\hspace{0pt}{(b')}`$ is the optimal value of the subproblem

``` math
\begin{array}{cl}
 & {\max\limits_{{\mathbf{Q},\mathbf{P}^{\lbrack 2\rbrack}}:{s = {(\mathbf{e}_{i},\mathbf{Q},\mathbf{P}^{\lbrack 2\rbrack})} \in S}}{\mathbb{E}}{\lbrack r^{s}{(x)}\ s.t.\ {\mathbb{E}}{\lbrack\eta^{s}{(x)}\rbrack} \leq b'}}
\end{array}
```

Here, the master problem decides which two services ($`i_{1},i_{2}`$) can be the base service, how often ($`p_{1},p_{2}`$) they should be invoked, and how large budgets ($`b_{1},b_{2}`$) are assigned, while for a fixed base service $`i`$ and budget $`b'`$, the subproblem maximizes the expected reward.

### 3.2 A Practical Algorithm

Now we are ready to give the sparsity-inspired algorithm for generating an approximately optimal strategy $`\hat{s}`$, summarized in Algorithm 1.

Input : $`K,M,\mathbf{c},b`$, $`{\{{y\hspace{0pt}{(x_{i})}},{\{{q_{k}\hspace{0pt}{(x_{i})}},{y_{k}\hspace{0pt}{(x_{i})}}\}}_{k = 1}^{K}\}}_{i = 1}^{N}`$

Output : FrugalML strategy tuple $`\hat{s} = \left( {\hat{\mathbf{p}}}^{\lbrack 1\rbrack},\hat{\mathbf{Q}},{\hat{\mathbf{P}}}^{\lbrack 2\rbrack} \right)`$

1:  Estimate $`{\mathbb{E}}\hspace{0pt}{\lbrack\left. {r_{i}\hspace{0pt}{(x)}} \middle| {D_{s},A_{s}^{\lbrack 1\rbrack}} \right.\rbrack}`$ from the training data $`{\{{y\hspace{0pt}{(x_{i})}},{\{{q_{k}\hspace{0pt}{(x_{i})}},{y_{k}\hspace{0pt}{(x_{i})}}\}}_{k = 1}^{K}\}}_{i = 1}^{N}`$

2:  For $`i \in {\lbrack K\rbrack}`$, $`b_{m}' \in {\lbrack 0,\frac{{\|{\mathbf{2}\hspace{0pt}\mathbf{c}}\|}_{\infty}}{M},\cdots,{\|{2\hspace{0pt}\mathbf{c}}\|}_{\infty}\rbrack}`$, solve problem 3.3 to find optimal value $`g_{i}\hspace{0pt}{(b_{m}')}`$

3:  For $`i \in {\lbrack K\rbrack}`$, construct function $`g_{i}\hspace{0pt}{( \cdot )}`$ by linear interpolation on $`b_{0}',b_{1}',\cdots,b_{M}'`$.

4:  Solve problem 3.2 to find optimal solution $`i_{1}^{\ast},i_{2}^{\ast},p_{1}^{\ast},p_{2}^{\ast},b_{1}^{\ast},b_{2}^{\ast}`$

5:  For $`t \in {\lbrack 2\rbrack}`$, let $`{i = i_{t}^{\ast}},{b' = {b_{t}^{\ast}/p_{t}^{\ast}}}`$, solve problem 3.3 to find the optimal solution $`\mathbf{Q}_{\lbrack i_{t}^{\ast}\rbrack},\mathbf{P}_{\lbrack i_{t}^{\ast}\rbrack}^{\lbrack 2\rbrack}`$

6:  $`{{\hat{\mathbf{p}}}^{\lbrack 1\rbrack} = {{p_{1}^{\ast}\hspace{0pt}\mathbf{e}_{i_{1}^{\ast}}} + {p_{2}^{\ast}\hspace{0pt}\mathbf{e}_{i_{2}^{\ast}}}}},{{\hat{\mathbf{Q}} = {\mathbf{Q}_{\lbrack i_{1}^{\ast}\rbrack} + \mathbf{Q}_{\lbrack i_{2}^{\ast}\rbrack}}},{{\hat{\mathbf{P}}}^{\lbrack 2\rbrack} = {\mathbf{P}_{\lbrack i_{1}^{\ast}\rbrack}^{\lbrack 2\rbrack} + \mathbf{P}_{\lbrack i_{2}^{\ast}\rbrack}^{\lbrack 2\rbrack}}}}`$

7:  Return $`\hat{s} = \left( {\hat{\mathbf{p}}}^{\lbrack 1\rbrack},\hat{\mathbf{Q}},{\hat{\mathbf{P}}}^{\lbrack 2\rbrack} \right)`$

Algorithm 1 FrugalML Strategy Training.

Algorithm 1 consists of three main steps. First, the conditional accuracy $`{\mathbb{E}}\hspace{0pt}{\lbrack\left. {r_{i}\hspace{0pt}{(x)}} \middle| {D_{s},A_{s}^{\lbrack i\rbrack}} \right.\rbrack}`$ is estimated from the training data (line 1). Next (line 2 to line 4), we find the optimal solution $`i_{1}^{\ast},i_{2}^{\ast},p_{1}^{\ast},p_{2}^{\ast},b_{1}^{\ast},b_{2}^{\ast}`$ to problem 3.2. To do so, we first evaluate $`g_{i}\hspace{0pt}{(b')}`$ for $`M + 1`$ different budget values (line 2), and then construct the functions $`g_{i}\hspace{0pt}{( \cdot )}`$ via linear interpolation (line 3) while enforce $`{{g_{i}\hspace{0pt}{(b')}} = 0},{{\forall b'} \leq \mathbf{c}_{i}}`$. Given (piece-wise linear) $`g_{i}\hspace{0pt}{( \cdot )}`$, problem 3.2 can be solved by enumerating a few linear programming (line 4). Finally, the algorithm seeks to find the optimal solution in the original domain of the strategy, by solving subproblem 3.3 for base service being $`i_{1}^{\ast}`$ and $`i_{2}^{\ast}`$ separately (line 5), and then align those solutions appropriately (line 6). We leave the details of solving subproblem 3.3 to the supplement material due to space constraint. Theorem 3 provides the performance analysis of Algorithm 1.

###### Theorem 3.

Suppose $`{\mathbb{E}}\hspace{0pt}{\lbrack\left. {r_{i}\hspace{0pt}{(x)}} \middle| {D_{s},A_{s}^{\lbrack 1\rbrack}} \right.\rbrack}`$ is Lipschitz continuous with constant $`\gamma`$ w.r.t. each element in $`\mathbf{Q}`$. Given $`N`$ i.i.d. samples $`{\{{y\hspace{0pt}{(x_{i})}},{\{{({y_{k}\hspace{0pt}{(x_{i})}},{q_{k}\hspace{0pt}{(x_{i})}})}\}}_{k = 1}^{K}\}}_{i = 1}^{N}`$, the computational cost of Algorithm 1 is $`O\hspace{0pt}\left( {{N\hspace{0pt}M\hspace{0pt}K^{2}} + {K^{3}\hspace{0pt}M^{3}\hspace{0pt}L} + {M^{L}\hspace{0pt}K^{2}}} \right)`$. With probability $`1 - \epsilon`$, the produced strategy $`\hat{s}`$ satisfies $`{{{\mathbb{E}}\hspace{0pt}{\lbrack{r^{\hat{s}}\hspace{0pt}{(x)}}\rbrack}} - {{\mathbb{E}}\hspace{0pt}{\lbrack{r^{s^{\ast}}\hspace{0pt}{(x)}}\rbrack}}} \geq {- {O\hspace{0pt}\left( {\sqrt{\frac{{\log\epsilon} + {\log M} + {\log K} + {\log L}}{N}} + \frac{\gamma}{M}} \right)}}`$, and $`{{\mathbb{E}}\hspace{0pt}{\lbrack{\eta^{\lbrack\hat{s}\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}} \leq b`$.

As Theorem 3 suggests, the parameter $`M`$ is used to balance between computational cost and accuracy drop of $`\hat{s}`$.

For practical cases where $`K`$ and $`L`$ (the number of classes) are around ten and $`N`$ is more than a few thousands, we have found $`M = 10`$ is a good value for good accuracy and small computational cost. Note that the coefficient of the $`K^{L}`$ terms is small: in experiments, we observe it takes only a few seconds for $`{L = 31},{M = 40}`$. For datasets with very large number of possible labels, we can always cluster those labels into a few ”supclasses”, or adopt approximation algorithms to reduce $`O\hspace{0pt}{(M^{L})}`$ to $`O\hspace{0pt}{(M^{2})}`$ (see details in the supplemental materials). In addition, slight modification of $`\hat{s}`$ can satisfy strict budget constraint: if budgets allows, use $`\hat{s}`$ to pick APIs; otherwise, switch to the cheapest API.

## 4 Experiments

We compare the accuracy and incurred costs of FrugalML to that of real world ML services for various tasks. Our goal is four-fold: (i) understanding when and why FrugalML can reduce cost without hurting accuracy, (ii) evaluating the cost savings by FrugalML, (iii) investigating the trade-offs between accuracy and cost achieved by FrugalML, and (iv) measuring the effect of training data size on FrugalML’s performance.

#### Facial Emotion Recognition: A Case Study.

Let us start with facial emotion recognition on the FER+ dataset. We set budget $`b = 5`$, the price of FACE++, the cheapest API (except the open source CNN model from GitHub) and obtain a FrugalML strategy by training on half of FER+. Figure 3 demonstrates the learned FrugalML strategy. Interestingly, as shown in Figure 3(b), FrugalML’s accuracy is higher than that of the best ML service (Microsoft Face), while its cost is much lower. This is because base service’s quality score, utilized by FrugalML, is a better signal than raw image to identify if its prediction is trustworthy. Furthermore, the quality score threshold, produced by FrugalML also depends on label predicted by the base service. This flexibility helps to increase accuracy as well as to reduce costs. For example, using a universal threshold $`0.86`$ leads to misclassfication on Figure 3(f), while $`0.93`$ causes unnecessary add-on service call on Figure 3 (c).

For comparison, we also train a mixture of experts strategy with a softmax gating network and the majority voting ensemble method. The learned mixture of experts always uses Microsoft API, leading to the same accuracy (81%) and same cost (\$10). The accuracy of majority voting on the test data is slightly better at 82%, but substantially worse than the performance of FrugalML using a small budget of $`\$ 5`$. Majority vote, and other standard ensemble methods, needs to collect the prediction of all services, resulting in a cost (\$30) which is 6 times the cost of FrugalML. Moreover, both mixture of experts and ensemble method require fixed cost, while FrugalML gives the users flexibility to choose a budget.

#### Analysis of Cost Savings.

Next, we evaluate how much cost can be saved by FrugalML to reach the highest accuracy produced by a single API on different tasks, to obtain some qualitative sense of FrugalML. As shown in Table 3, FrugalML can typically save more than half of the cost. In fact, the cost savings can be as high as 90% on the AUDIOMNIST dataset. This is likely because the base service’s quality score is highly correlated to its prediction accuracy, and thus FrugalML only needs to call expensive services for a few difficult data points. A relatively small saving is reached for SA tasks (e.g., on IMDB). This might be that the quality score of the rule based SA tool is not highly reliable. Another possible reason is that SA task has only two labels (positive and negative), limiting the power of FrugalML.

#### Accuracy and Cost Trade-offs.

Now we dive deeply into the accuracy and cost trade-offs achieved by FrugalML, shown in Figure 4. Here we also compare with two oblations to FrugalML, “Base=GH”, where the base service is forced to be the GitHub model, and “QS only”, which further forces a universal quality score threshold across all labels.

While using any single ML service incurs a fixed cost, FrugalML allows users to pick any point in its trade-off curve, offering substantial flexibility. In addition to cost saving, FrugalML sometimes can achieve higher accuracy than any ML services it calls. For example, on FER+ and AFFECTNET, more than 2% accuracy improvement can be reached with small cost, and on RAFDB, when a large cost is allowed, more than 5% accuracy improvement is gained. It is also worthy noting that each component in FrugalML helps improve the accuracy. On WAIMAI, for instance, “Base=GH” and ”QS only” lead to significant accuracy drops. For speech datasets such as COMMAND, the drop is negligible, as there is no significant accuracy difference between different labels (utterance). Another interesting observation is that there is no universally “best” service for a fixed task. For SA task, Baidu NLP achieves the highest accuracy for WAIMAI and SHOP datasets, but Google NLP has best performance on YELP and IMDB. Fortunately, FrugalML adaptively learns the optimal strategy.

## 5 Conclusion and Open Problems

In this work we proposed FrugalML, a formal framework for identifying the best strategy to call ML APIs given a user’s budget. Both theoretical analysis and empirical results demonstrate that FrugalML leads to significant cost reduction and accuracy improvement. FrugalML is also efficient to learn: it typically takes a few minutes on a modern machine. Our research characterized the substantial heterogeneity in cost and performance across available ML APIs, which is useful in its own right and also leveraged by FrugalML. Extending FrugalML to produce calling strategies for ML tasks beyond classification (e.g., object detection and language translation) is an interesting future direction. As a resource to stimulate further research in MLaaS, we will also release a dataset used to develop FrugalML, consisting of 612,139 samples annotated by the APIs, and our code.

## Appendix B Algorithm Subroutines

In this section we provide the details of the subroutines used in the training algorithm for FrugalML. There are in total four components: (i) estimating parameters, (ii) solving subproblem 3.3 to obtain its optimal value and solution, (iii) constructing the function $`g_{i}\hspace{0pt}{( \cdot )}`$, and (iv) solving the master problem 3.2.

#### Estimating Parameters.

Instead of directly estimating $`{\mathbb{E}}\hspace{0pt}{\lbrack\left. {r_{i}\hspace{0pt}{(x)}} \middle| {D_{s},A_{s}^{\lbrack i\rbrack}} \right.\rbrack}`$, we estimate $`\mathbf{A},{\mathbf{r}^{b}\hspace{0pt}{(\mathbf{1}_{K \times L})}}`$, and $`\mathbf{r}^{\lbrack - \rbrack}\hspace{0pt}{( \cdot )}`$ as defined in Section A, which are sufficient for the subroutines to solve the subproblem 3.3. Let $`\hat{\mathbf{A}},{{\hat{\mathbf{r}}}^{b}\hspace{0pt}{(\mathbf{1}_{K \times L})}}`$, and $`{\hat{\mathbf{r}}}^{\lbrack - \rbrack}\hspace{0pt}{( \cdot )}`$ be the corresponding estimation from the training datasets. Now we describe how to obtain them from a dataset $`{\{{y\hspace{0pt}{(x_{i})}},{\{{q_{k}\hspace{0pt}{(x_{i})}},{y_{k}\hspace{0pt}{(x_{i})}}\}}_{k = 1}^{K}\}}_{i = 1}^{N}`$.

To estimate $`\mathbf{A}`$, we simply apply the empirical mean estimator and obtain $`{\hat{\mathbf{A}}}_{k,\ell} \triangleq {\frac{1}{N}\hspace{0pt}{\sum_{i = 1}^{N}\mathbb{1}_{\{{{y_{k}\hspace{0pt}{(x_{i})}} = \ell}\}}}}`$. To estimate $`\mathbf{r}^{b}\hspace{0pt}{(\mathbf{1}_{K \times L})}`$, and $`\mathbf{r}^{\lbrack - \rbrack}\hspace{0pt}{( \cdot )}`$, we first compute $`{{\hat{\psi}}_{k_{1},k_{2},\ell}\hspace{0pt}{(\alpha_{m})}} \triangleq \frac{\sum_{i = 1}^{N}\mathbb{1}_{\{{{{y_{k_{1}}\hspace{0pt}{(x_{i})}} = \ell},{{{\hat{q}}_{m,k_{1},\ell} \geq {q_{k_{1}}\hspace{0pt}{(x_{i})}}},{{y_{k_{2}}\hspace{0pt}{(x_{i})}} = {y\hspace{0pt}{(x_{i})}}}}}\}}}{\sum_{i = 1}^{N}\mathbb{1}_{\{{{{y_{k_{1}}\hspace{0pt}{(x_{i})}} = \ell},{{\hat{q}}_{m,k_{1},\ell} \geq {q_{k_{1}}\hspace{0pt}{(x_{i})}}}}\}}}`$, for $`{\alpha_{m} = \frac{m}{M}},{m \in {{\{ 0\}} \cup {\lbrack M\rbrack}}}`$, where $`{\hat{q}}_{m,k,\ell} \triangleq {Q\hspace{0pt}u\hspace{0pt}a\hspace{0pt}n\hspace{0pt}t\hspace{0pt}i\hspace{0pt}l\hspace{0pt}e\hspace{0pt}{(\left. \{{q_{k}\hspace{0pt}{(x_{i})}} \middle| {{{y_{k}\hspace{0pt}{(x_{i})}} = \ell},{i \in {\lbrack N\rbrack}}}\} \right.,\alpha_{m})}}`$ is the empirical $`\alpha_{m}`$-quantile of the quality score of the $`k`$th service conditional on its predicted label being $`\ell`$. ### C.1 Helpful Lemmas

We first provide some useful lemmas throughout this section.

###### Lemma 4.

Suppose the linear optimization problem

``` math
\begin{aligned}
{\max\limits_{\mathbf{z} \in {\mathbb{R}}^{K}}\ } & {\mathbf{u}^{T}\hspace{0pt}\mathbf{z}} \\
{s.t.\ } & {{{\mathbf{v}^{T}\hspace{0pt}\mathbf{z}} \leq w},{{{\mathbf{1}^{T}\hspace{0pt}\mathbf{z}} \leq 1},{\mathbf{z} \geq 0}}}
\end{aligned}
```

is feasible. Then there exists one optimal solution $`\mathbf{z}^{\ast}`$ such that $`{\|\mathbf{z}^{\ast}\|}_{0} \leq 2`$.

###### Proof.

Let $`\mathbf{z}^{\ast}`$ be one solution. If $`{\|\mathbf{z}^{\ast}\|}_{0} \leq 2`$, then the statement holds. Suppose $`{\|\mathbf{z}^{\ast}\|}_{0} = \text{nnz} > 2`$ (and thus $`K \geq 3`$). W.l.o.g., let the first nnz elements in $`\mathbf{z}^{\ast}`$ be the nonzero elements. Let $`i_{\min} = {\arg{\min_{i:{i \leq \text{nnz}}}\mathbf{v}_{i}}}`$ and $`i_{\max} = {\arg{\max_{i:{i \leq \text{nnz}}}\mathbf{v}_{i}}}`$. If $`\mathbf{v}_{i_{\max}} > \mathbf{v}_{i_{\min}}`$, construct $`\mathbf{z}'`$ by

``` math
\begin{array}{r}
{\mathbf{z}_{i}' = \begin{cases}
{{\mathbf{z}_{i}^{\ast}\mspace{7mu}{({= 0})}},} & {\text{if~}{i > \text{nnz}}} \\
{\frac{{\mathbf{v}_{1:\text{nnz}}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}^{\ast}} - {\mathbf{v}_{i_{\min}}\hspace{0pt}\mathbf{1}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}}}{\mathbf{v}_{i_{\max}} - \mathbf{v}_{i_{\min}}},} & {\text{if~}{i = i_{\max}}} \\
{\frac{{- {\mathbf{v}_{1:\text{nnz}}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}^{\ast}}} + {\mathbf{v}_{i_{\max}}\hspace{0pt}\mathbf{1}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}}}{\mathbf{v}_{i_{\max}} - \mathbf{v}_{i_{\min}}},} & {\text{if~}{i = i_{\min}}} \\
{0,} & \text{otherwise}
\end{cases}}
\end{array}
```

Otherwise, construct $`\mathbf{z}'`$ by

``` math
\begin{array}{r}
{\mathbf{z}_{i}' = \begin{cases}
{{\mathbf{z}_{i}^{\ast}\mspace{7mu}{({= 0})}},} & {\text{if~}{i > \text{nnz}}} \\
{{\mathbf{1}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}^{\ast}},} & {\text{if~}{i = i_{\max}}} \\
{0,} & \text{otherwise}
\end{cases}}
\end{array}
```

Now our goal is to prove that $`\mathbf{z}'`$ is one optimal solution and $`{\|\mathbf{z}'\|}_{0} \leq 2`$.

\(i\) We first show that $`\mathbf{z}'`$ is a feasible solution.

\(1\) $`\mathbf{v}_{i_{\max}} > \mathbf{v}_{i_{\min}}`$: If $`i \notin {\{ i_{\max},i_{\min}\}}`$, clearly $`\mathbf{z}_{i}' = 0 \geq 0`$. Since $`\mathbf{z}^{\ast}`$ is feasible, $`\mathbf{z}_{1:\text{nnz}}^{\ast} \geq 0`$. By definition, $`\mathbf{z}_{i_{\max}}' = \frac{{\mathbf{v}_{1:\text{nnz}}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}^{\ast}} - {\mathbf{v}_{i_{\min}}\hspace{0pt}\mathbf{1}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}}}{\mathbf{v}_{i_{\max}} - \mathbf{v}_{i_{\min}}} = {\frac{1}{\mathbf{v}_{i_{\max}} - \mathbf{v}_{i_{\min}}}\hspace{0pt}{\sum_{j = 1}^{\text{nnz}}{{({\mathbf{v}_{j} - \mathbf{v}_{i_{\min}}})}\hspace{0pt}\mathbf{z}_{j}^{\ast}}}} \geq 0`$, and similarly $`\mathbf{z}_{i_{\min}}' \geq 0`$. Thus, we have $`\mathbf{z}' \geq 0`$.

In addition,

``` math
\begin{array}{cl}
{\mathbf{v}^{T}\hspace{0pt}\mathbf{z}'} & {= {{\frac{{\mathbf{v}_{1:\text{nnz}}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}^{\ast}} - {\mathbf{v}_{i_{\min}}\hspace{0pt}\mathbf{1}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}}}{\mathbf{v}_{i_{\max}} - \mathbf{v}_{i_{\min}}}\hspace{0pt}\mathbf{v}_{i_{\max}}} + {\frac{{- {\mathbf{v}_{1:\text{nnz}}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}^{\ast}}} + {\mathbf{v}_{i_{\max}}\hspace{0pt}\mathbf{1}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}}}{\mathbf{v}_{i_{\max}} - \mathbf{v}_{i_{\min}}}\hspace{0pt}\mathbf{v}_{i_{m\hspace{0pt}i\hspace{0pt}n}}}}} \\
 & {= {\mathbf{v}_{1:\text{nnz}}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}^{\ast}} = {\mathbf{v}^{T}\hspace{0pt}\mathbf{z}^{\ast}} \leq w}
\end{array}
```

where the last equality is due to the fact that $`{\mathbf{z}_{i} = 0},{{\forall i} > \text{nnz}}`$. Similiarly, we have

``` math
\begin{array}{cl}
{\mathbf{1}^{T}\hspace{0pt}\mathbf{z}'} & {= {\frac{{\mathbf{v}_{1:\text{nnz}}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}^{\ast}} - {\mathbf{v}_{i_{\min}}\hspace{0pt}\mathbf{1}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}}}{\mathbf{v}_{i_{\max}} - \mathbf{v}_{i_{\min}}} + \frac{{- {\mathbf{v}_{1:\text{nnz}}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}^{\ast}}} + {\mathbf{v}_{i_{\max}}\hspace{0pt}\mathbf{1}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}}}{\mathbf{v}_{i_{\max}} - \mathbf{v}_{i_{\min}}}}} \\
 & {{= {\mathbf{1}_{1:\text{nnz}}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}^{\ast}} = {\mathbf{1}^{T}\hspace{0pt}\mathbf{z}^{\ast}} \leq 1}.}
\end{array}
```

\(2\) $`\mathbf{v}_{i_{\max}} = \mathbf{v}_{i_{\min}}`$: It is clear that $`\mathbf{z}' \geq 0`$ and $`{\mathbf{1}^{T}\hspace{0pt}\mathbf{z}} \leq 1`$ by definition. Note that by definition $`{\mathbf{v}^{T}\hspace{0pt}\mathbf{z}'} = {\mathbf{v}_{i_{\max}}\hspace{0pt}\mathbf{1}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}^{\ast}}`$. $`\mathbf{v}_{i_{\max}} = \mathbf{v}_{i_{\min}}`$ implies that for $`{i = {1,2,\cdots,\text{nnz}}},{\mathbf{v}_{i} = \mathbf{v}_{i_{\max}}}`$, and thus $`{\mathbf{v}_{i_{\max}}\hspace{0pt}\mathbf{1}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}^{\ast}} = {\mathbf{v}_{1:\text{nnz}}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}^{\ast}}`$. Note that only the first nnz elements in $`\mathbf{z}^{\ast}`$ are nonzeros, we have $`{\mathbf{v}_{1:\text{nnz}}^{T}\hspace{0pt}\mathbf{z}_{1:\text{nnz}}^{\ast}} = {\mathbf{v}^{T}\hspace{0pt}\mathbf{z}^{\ast}}`$. That is to say,

``` math
{\mathbf{v}^{T}\hspace{0pt}\mathbf{z}'} = {\mathbf{v}^{T}\hspace{0pt}\mathbf{z}^{\ast}} \leq w
```

Hence, we have shown that $`{{\mathbf{v}^{T}\hspace{0pt}\mathbf{z}'} \leq w},{{{\mathbf{1}^{T}\hspace{0pt}\mathbf{z}'} \leq 1},{\mathbf{z}' \geq 0}}`$ always hold, i.e., $`\mathbf{z}'`$ is a feasible solution to the linear optimization problem.

\(ii\) Now we show that $`\mathbf{z}'`$ is one optimal solution, i.e., $`{\mathbf{u}^{T}\hspace{0pt}\mathbf{z}'} = {\mathbf{u}^{T}\hspace{0pt}\mathbf{z}^{\ast}}`$.

``` math
\begin{array}{r}

\end{array}
```

Since $`\mathbf{z}^{\ast}`$ is one optimal solution and clearly LCQ (linearity constraint qualification) is satisfied, KKT conditions must hold. That is, there exists $`\mathbf{μ}`$ such that

``` math
\begin{array}{cl}
 & {{\frac{\partial{\mathcal{L}\hspace{0pt}{(\mathbf{z}^{\ast},{\mathbf{μ}})}}}{\partial\mathbf{z}_{i}} = {{\mathbf{u}_{i} + {{\mathbf{μ}}_{1}\hspace{0pt}\mathbf{v}_{i}} + {\mathbf{μ}}_{2}} - {\mathbf{μ}}_{i + 2}} = 0},{\forall i}} \\

 & {{{\mathbf{v}^{T}\hspace{0pt}\mathbf{z}^{\ast}} \leq w},{{{\mathbf{1}^{T}\hspace{0pt}\mathbf{z}^{\ast}} \leq 1},{\mathbf{z} \geq 0}}}
\end{array}
```

For ease of exposition, denote $`\hat{\mathbf{μ}} = {\lbrack{\mathbf{μ}}_{3},{\mathbf{μ}}_{4},\cdots,{\mathbf{μ}}_{K + 2}\rbrack}^{T}`$. ``` math
\begin{array}{r}
{{\mathbf{u}^{T}\hspace{0pt}\mathbf{z}'} = {{{- {{\mathbf{μ}}_{1}\hspace{0pt}\mathbf{v}^{T}\hspace{0pt}\mathbf{z}'}} - {{\mathbf{μ}}_{2}\hspace{0pt}\mathbf{1}^{T}\hspace{0pt}\mathbf{z}'}} + {{\hat{\mathbf{μ}}}^{T}\hspace{0pt}\mathbf{z}'}}}

``` math
\begin{array}{r}
{{\mathbf{u}^{T}\hspace{0pt}\mathbf{z}^{\ast}} = {{{- {{\mathbf{μ}}_{1}\hspace{0pt}\mathbf{v}^{T}\hspace{0pt}\mathbf{z}^{\ast}}} - {{\mathbf{μ}}_{2}\hspace{0pt}\mathbf{1}^{T}\hspace{0pt}\mathbf{z}^{\ast}}} + {{\hat{\mathbf{μ}}}^{T}\hspace{0pt}\mathbf{z}^{\ast}}}}
\end{array}
```

The condition $`{{\mathbf{μ}}_{i + 2}\hspace{0pt}\mathbf{z}_{i}^{\ast}} = 0`$ implies that at least one of the terms must be 0. Since it holds for every $`i`$, the summation over $`i`$ is also 0, i.e., $`{{\hat{\mathbf{μ}}}^{T}\hspace{0pt}\mathbf{z}^{\ast}} = {\sum_{i = 1}^{K}{{\mathbf{μ}}_{i + 2}\hspace{0pt}\mathbf{z}_{i}^{\ast}}} = 0`$. Noting that the first nnz elements in $`\mathbf{z}^{\ast}`$ are nonzeros, we must have $`{{\mathbf{μ}}_{i + 2} = 0},{i \leq \text{nnz}}`$, and in particular, $`{\mathbf{μ}}_{i_{\max} + 2} = {\mathbf{μ}}_{i_{\min} + 2} = 0`$. Hence, $`{{\hat{\mathbf{μ}}}^{T}\hspace{0pt}\mathbf{z}'} = {\sum_{i = 1}^{K}{{\mathbf{μ}}_{i + 2}\hspace{0pt}\mathbf{z}_{i}'}} = {{{\mathbf{μ}}_{i_{\max} + 2}\hspace{0pt}\mathbf{z}_{i_{\max}}'} + {{\mathbf{μ}}_{i_{\min} + 2}\hspace{0pt}\mathbf{z}_{i_{\min}}'}} = 0`$. Thus, we have

``` math
\begin{array}{r}
{{\mathbf{u}^{T}\hspace{0pt}\mathbf{z}'} = {{- {{\mathbf{μ}}_{1}\hspace{0pt}\mathbf{v}^{T}\hspace{0pt}\mathbf{z}'}} - {{\mathbf{μ}}_{2}\hspace{0pt}\mathbf{1}^{T}\hspace{0pt}\mathbf{z}'}}}
\end{array}
```
``` math
\begin{array}{r}
{{\mathbf{u}^{T}\hspace{0pt}\mathbf{z}^{\ast}} = {{- {{\mathbf{μ}}_{1}\hspace{0pt}\mathbf{v}^{T}\hspace{0pt}\mathbf{z}^{\ast}}} - {{\mathbf{μ}}_{2}\hspace{0pt}\mathbf{1}^{T}\hspace{0pt}\mathbf{z}^{\ast}}}}
\end{array}
```

In part (i), it is shown that $`{\mathbf{v}^{T}\hspace{0pt}\mathbf{z}^{\ast}} = {\mathbf{v}^{T}\hspace{0pt}\mathbf{z}'}`$ and $`{\mathbf{1}^{T}\hspace{0pt}\mathbf{z}^{\ast}} = {\mathbf{1}^{T}\hspace{0pt}\mathbf{z}'}`$. Hence, we must have

``` math
\begin{array}{r}
{{\mathbf{u}^{T}\hspace{0pt}\mathbf{z}^{\ast}} = {\mathbf{u}^{T}\hspace{0pt}\mathbf{z}'}}
\end{array}
```

In other words, $`\mathbf{z}'`$ has the same objective function value as $`\mathbf{z}^{\ast}`$. Since $`\mathbf{z}^{\ast}`$ is one optimal solution, $`\mathbf{z}'`$ must also be one optimal solution (since it is also feasible as shown in part (i)). By definition, $`{\|\mathbf{z}'\|}_{0} \leq 2`$, which finishes the proof. ∎

###### Lemma 5.

Let $`F\hspace{0pt}{(w)}`$ be the optimal value of the linear optimization problem

``` math
\begin{aligned}
{\max\limits_{\mathbf{z} \in {\mathbb{R}}^{K}}\ } & {\mathbf{u}^{T}\hspace{0pt}\mathbf{z}} \\
{s.t.\ } & {{{\mathbf{v}^{T}\hspace{0pt}\mathbf{z}} \leq w},{{\mathbf{z} \geq 0},{{\mathbf{C}\mathbf{z}} \leq \mathbf{d}}}}
\end{aligned}
```

where $`{\mathbf{u},\mathbf{C},\mathbf{v}} \geq \mathbf{0}`$, $`\mathbf{d} > 0`$. Then $`F\hspace{0pt}{(w)}`$ is Lipschitz continuous.

###### Proof.

Note that since $`\mathbf{d} > \mathbf{0}`$, there exists some $`w^{\ast}`$, such that its corresponding optimal $`\mathbf{z}^{\ast}`$ satisfies $`{\mathbf{C}\mathbf{z}}^{\ast} < d`$. Thus, $`\mathbf{z}^{\ast}`$ must also be the optimal solution to

``` math
\begin{aligned}
{\max\limits_{\mathbf{z} \in {\mathbb{R}}^{K}}\ } & {\mathbf{u}^{T}\hspace{0pt}\mathbf{z}} \\
{s.t.\ } & {{{\mathbf{v}^{T}\hspace{0pt}\mathbf{z}} \leq w^{\ast}},{\mathbf{z} \geq 0}}
\end{aligned}
```

If $`{\mathbf{v}^{T}\hspace{0pt}\mathbf{z}^{\ast}} < w^{\ast}`$, then $`\hat{\mathbf{z}} = {\frac{w^{\ast}}{\mathbf{v}^{T}\hspace{0pt}\mathbf{z}}\hspace{0pt}\mathbf{z}^{\ast}}`$ is also a feasible solution, but $`{\mathbf{u}^{T}\hspace{0pt}\hat{\mathbf{z}}} = {\frac{w^{\ast}}{\mathbf{v}^{T}\hspace{0pt}\mathbf{z}}\hspace{0pt}\mathbf{u}^{T}\hspace{0pt}\mathbf{z}^{\ast}} > {\mathbf{u}^{T}\hspace{0pt}\mathbf{z}^{\ast}}`$, a contradiction. Thus, we must have $`{\mathbf{v}^{T}\hspace{0pt}\mathbf{z}^{\ast}} = w^{\ast}`$. Now we claim that $`\mathbf{z}' = {\frac{w'}{w^{\ast}}\hspace{0pt}\mathbf{z}^{\ast}}`$ is one optimal solution to

``` math
\begin{aligned}
{\max\limits_{\mathbf{z} \in {\mathbb{R}}^{K}}\ } & {\mathbf{u}^{T}\hspace{0pt}\mathbf{z}} \\
{s.t.\ } & {{{\mathbf{v}^{T}\hspace{0pt}\mathbf{z}} \leq w'},{\mathbf{z} \geq 0}}
\end{aligned}
```

Suppose not. Then there exists another optimal solution $`\mathbf{z}^{\operatorname{\prime\prime}}`$. Since $`\mathbf{z}'`$ is not optimal, we must have $`{\mathbf{u}^{T}\hspace{0pt}\mathbf{z}^{\operatorname{\prime\prime}}} > {\mathbf{u}^{T}\hspace{0pt}\mathbf{z}'} = {\frac{w'}{w^{\ast}}\hspace{0pt}\mathbf{u}^{T}\hspace{0pt}\mathbf{z}^{\ast}}`$. Now let $`\mathbf{z}^{\operatorname{\prime\prime\prime}} = {\frac{w^{\ast}}{w'}\hspace{0pt}\mathbf{z}^{\operatorname{\prime\prime}}}`$. Then by definition, we must have $`\mathbf{z}^{\operatorname{\prime\prime\prime}}`$ is a solution to problem C.1, since $`\mathbf{z}^{\operatorname{\prime\prime\prime}} \geq 0`$ and $`{\mathbf{v}^{T}\hspace{0pt}\mathbf{z}^{\operatorname{\prime\prime\prime}}} = {\mathbf{v}^{T}\hspace{0pt}\frac{w^{\ast}}{w'}\hspace{0pt}\mathbf{z}^{\operatorname{\prime\prime}}} \leq {\frac{w^{\ast}}{w'}\hspace{0pt}\mathbf{v}^{T}\hspace{0pt}\mathbf{z}^{\operatorname{\prime\prime}}} \leq {\frac{w^{\ast}}{w'}\hspace{0pt}w'} = w^{\ast}`$. However, $`{\mathbf{u}^{T}\hspace{0pt}\mathbf{z}^{\operatorname{\prime\prime\prime}}} = {\mathbf{u}^{T}\hspace{0pt}\frac{w^{\ast}}{w'}\hspace{0pt}\mathbf{z}^{\operatorname{\prime\prime}}} = {\frac{w^{\ast}}{w'}\hspace{0pt}\mathbf{u}^{T}\hspace{0pt}\mathbf{z}^{\operatorname{\prime\prime}}} > {\frac{w^{\ast}}{w'}\hspace{0pt}\mathbf{u}^{T}\hspace{0pt}\mathbf{z}'} = {\frac{w^{\ast}}{w'}\hspace{0pt}\frac{w'}{w^{\ast}}\hspace{0pt}\mathbf{u}^{T}\hspace{0pt}\mathbf{z}^{\ast}} = {\mathbf{u}^{T}\hspace{0pt}\mathbf{z}^{\ast}}`$. That is to say, $`\mathbf{z}^{\operatorname{\prime\prime\prime}}`$ is a feasible solution to problem C.1 but also have a objective value that is strictly higher than that of the optimal solution. A contradiction.

Thus we must have that $`\mathbf{z}'`$ is one optimal solution to problem C.2.

Now we consider $`0 \leq w' \leq w^{\ast}`$ and $`w' \geq w^{\ast}`$ separately.

case (i): Suppose $`0 \leq w' \leq w^{\ast}`$. Note that $`{\mathbf{v}^{T}\hspace{0pt}\mathbf{z}^{\ast}} \leq w^{\ast}`$ since $`\mathbf{z}^{\ast}`$ is a feasible solution to problem C.1 and by assumption $`{\mathbf{C}\mathbf{z}}^{\ast} < \mathbf{d}`$. Hence, we must have $`{\mathbf{C}\mathbf{z}}' = {\frac{w'}{w^{\ast}}\hspace{0pt}{\mathbf{C}\mathbf{z}}'} < \mathbf{d}`$. That is to say, adding a constraint $`{\mathbf{C}\mathbf{z}} \leq \mathbf{d}`$ to problem C.2 does not change the optimal solution. Thus, $`\mathbf{z}'`$ is also an optimal solution to

``` math
\begin{aligned}
{\max\limits_{\mathbf{z} \in {\mathbb{R}}^{K}}\ } & {\mathbf{u}^{T}\hspace{0pt}\mathbf{z}} \\
{s.t.\ } & {{{\mathbf{v}^{T}\hspace{0pt}\mathbf{z}} \leq w^{\ast}},{{\mathbf{z} \geq 0},{{\mathbf{C}\mathbf{z}} \leq \mathbf{d}}}}
\end{aligned}
```

Hence, we have $`{F\hspace{0pt}{(w')}} = {\mathbf{u}^{T}\hspace{0pt}\mathbf{z}'} = {\mathbf{u}^{T}\hspace{0pt}\frac{w'}{w^{\ast}}\hspace{0pt}\mathbf{z}^{\ast}} = {\frac{w'}{w^{\ast}}\hspace{0pt}F\hspace{0pt}{(w^{\ast})}}`$. That is to say, if $`w' \leq w`$, then $`F\hspace{0pt}{(w')}`$ is a linear function of $`w'`$ and thus must be Lipschitz continuous.

case (ii): Suppose $`w' \geq w^{\ast}`$. Note that we have just shown that $`\mathbf{z}'`$ is one optimal solution to problem C.2. Adding a constraint to problem problem C.2 only leads to smaller objective value. That is to say, $`{\mathbf{u}^{T}\hspace{0pt}\mathbf{z}'} \geq {F\hspace{0pt}{(w')}}`$, which is the optimal value to

``` math
\begin{aligned}
{\max\limits_{\mathbf{z} \in {\mathbb{R}}^{K}}\ } & {\mathbf{u}^{T}\hspace{0pt}\mathbf{z}} \\
{s.t.\ } & {{{\mathbf{v}^{T}\hspace{0pt}\mathbf{z}} \leq w^{\ast}},{{\mathbf{z} \geq 0},{{\mathbf{C}\mathbf{z}} \leq \mathbf{d}}}}
\end{aligned}
```

On the other hand, by definition, we have $`{\mathbf{u}^{T}\hspace{0pt}\mathbf{z}'} = {\mathbf{u}^{T}\hspace{0pt}\frac{w'}{w^{\ast}}\hspace{0pt}\mathbf{z}^{\ast}} = {\frac{w'}{w^{\ast}}\hspace{0pt}F\hspace{0pt}{(w^{\ast})}}`$, and thus we have

``` math
\begin{array}{r}
{{\frac{w'}{w^{\ast}}\hspace{0pt}F\hspace{0pt}{(w^{\ast})}} \geq {F\hspace{0pt}{(w')}}}
\end{array}
```

Now let us consider $`w^{1} \geq w^{1} \geq w^{\ast}`$. Let $`\mathbf{z}^{1},\mathbf{z}^{2}`$ be their corresponding solutions. Since $`w^{2} \geq w^{1}`$, we have $`{F\hspace{0pt}{(w^{2})}} \geq {F\hspace{0pt}{(w^{1})}}`$. Let $`\mathbf{z}^{3} = {\frac{w^{1}}{w^{2}}\hspace{0pt}\mathbf{z}^{2}}`$. Then $`{\mathbf{v}^{T}\hspace{0pt}\mathbf{z}^{3}} = {\mathbf{v}^{T}\hspace{0pt}\frac{w^{1}}{w^{2}}\hspace{0pt}\mathbf{z}^{2}} \leq {\frac{w^{1}}{w^{2}}\hspace{0pt}w^{2}} = w^{1}`$ and $`{\mathbf{C}\mathbf{z}}^{3} = {\mathbf{C}\hspace{0pt}\frac{w^{1}}{w^{2}}\hspace{0pt}\mathbf{z}^{2}} \leq {\frac{w^{1}}{w^{2}}\hspace{0pt}\mathbf{d}} \leq \mathbf{d}`$. That is to say, $`\mathbf{z}^{3}`$ is also a solution to

``` math
\begin{aligned}
{\max\limits_{\mathbf{z} \in {\mathbb{R}}^{K}}\ } & {\mathbf{u}^{T}\hspace{0pt}\mathbf{z}} \\
{s.t.\ } & {{{\mathbf{v}^{T}\hspace{0pt}\mathbf{z}} \leq w^{1}},{{\mathbf{z} \geq 0},{{\mathbf{C}\mathbf{z}} \leq \mathbf{d}}}}
\end{aligned}
```

Thus, the objective value must be smaller than the optimal one, i.e., $`{\mathbf{u}^{T}\hspace{0pt}\mathbf{z}^{3}} \leq {F\hspace{0pt}{(w^{1})}}`$. Noting that $`{\mathbf{u}^{T}\hspace{0pt}\mathbf{z}^{3}} = {\mathbf{u}^{T}\hspace{0pt}\frac{w^{1}}{w^{2}}\hspace{0pt}\mathbf{z}^{2}} = {\frac{w^{1}}{w_{2}}\hspace{0pt}F\hspace{0pt}{(w^{2})}}`$, we have $`{\frac{w^{1}}{w_{2}}\hspace{0pt}F\hspace{0pt}{(w^{2})}} \leq {F\hspace{0pt}{(w^{1})}}`$. which is $`{{F\hspace{0pt}{(w^{2})}} - {F\hspace{0pt}{(w^{1})}}} \leq {\frac{w_{2} - w_{1}}{w_{1}}\hspace{0pt}F\hspace{0pt}{(w^{1})}}`$. Note that we have proved $`{\frac{w'}{w^{\ast}}\hspace{0pt}F\hspace{0pt}{(w^{\ast})}} \geq {F\hspace{0pt}{(w')}}`$ in C.3, i.e., $`\frac{F\hspace{0pt}{(w')}}{w'} \leq \frac{F\hspace{0pt}{(w^{\ast})}}{w^{\ast}}`$, for any $`w' \geq w^{\ast}`$. Thus, we have $`{{F\hspace{0pt}{(w^{1})}}/w^{1}} \leq \frac{F\hspace{0pt}{(w^{\ast})}}{w^{\ast}}`$. That implies $`{{F\hspace{0pt}{(w^{2})}} - {F\hspace{0pt}{(w^{1})}}} \leq {\frac{w_{2} - w_{1}}{w_{1}}\hspace{0pt}F\hspace{0pt}{(w^{1})}} \leq {{({w^{2} - w^{1}})}\hspace{0pt}\frac{F\hspace{0pt}{(w^{\ast})}}{w^{\ast}}}`$. We also have $`{F\hspace{0pt}{(w^{1})}} \leq {F\hspace{0pt}{(w^{2})}}`$. That is to say, for any $`w^{2} \geq w^{1} \geq w^{\ast}`$, we have $`{- {{({w^{2} - w^{1}})}\hspace{0pt}\frac{F\hspace{0pt}{(w^{\ast})}}{w^{\ast}}}} \leq 0 \leq {{F\hspace{0pt}{(w^{2})}} - {F\hspace{0pt}{(w^{1})}}} \leq {{({w^{2} - w^{1}})}\hspace{0pt}\frac{F\hspace{0pt}{(w^{\ast})}}{w^{\ast}}}`$ and thus we have just proved that $`f\hspace{0pt}{(w')}`$ is Lipschitz continuous for $`w' \geq w^{\ast}`$.

Now let us consider all $`w`$. We have shown that $`F\hspace{0pt}{(w)}`$ is Lipschitz continuous when $`w \leq w^{\ast}`$ and when $`w \geq w^{\ast}`$. Let $`\gamma_{1}`$ and $`\gamma_{2}`$ denote the Lipschitz constant for both case. Now we can prove that $`F\hspace{0pt}{(w)}`$ is Lipschitz continuous with constant $`\gamma_{1} + \gamma_{2}`$ for any $`w \geq 0`$.

Let us consider any two $`w_{1},w_{2}`$. If they are both smaller than $`w^{\ast}`$ or larger than $`w^{\ast}`$, then clearly we must have $`{|{{F\hspace{0pt}{(w_{1})}} - {F\hspace{0pt}{(w_{2})}}}|} \leq {{({\gamma_{1} + \gamma_{2}})}\hspace{0pt}{|{w_{1} - w_{2}}|}}`$. We only need to consider when $`w_{1} \leq w^{\ast}`$ and $`w_{2} \geq w^{\ast}`$. As $`F\hspace{0pt}{(w)}`$ is Lipschitz continuous on each side, we have

``` math
\begin{array}{cl}
{|{{F\hspace{0pt}{(w_{1})}} - {F\hspace{0pt}{(w_{2})}}}|} & {= {|{{{{F\hspace{0pt}{(w_{1})}} - {F\hspace{0pt}{(w^{\ast})}}} + {F\hspace{0pt}{(w^{\ast})}}} - {F\hspace{0pt}{(w_{2})}}}|}} \\
 & {\leq {{|{{F\hspace{0pt}{(w_{1})}} - {F\hspace{0pt}{(w^{\ast})}}}|} + {|{{F\hspace{0pt}{(w^{\ast})}} - {F\hspace{0pt}{(w_{2})}}}|}}} \\
 & {\leq {{\gamma_{1}\hspace{0pt}{|{w_{1} - w^{\ast}}|}} + {\gamma_{2}\hspace{0pt}{|{w_{2} - w^{\ast}}|}}}} \\
 & {\leq {{\gamma_{1}\hspace{0pt}{|{w_{1} - w_{2}}|}} + {\gamma\hspace{0pt}{|{w_{2} - w_{1}}|}}} = {{({\gamma_{1} + \gamma_{2}})}\hspace{0pt}{|{w_{1} - w_{2}}|}}}
\end{array}
```

where the first inequality is by triangle inequality, the second ineuqaltiy is by the Lipschitz continuity of $`F\hspace{0pt}{(w)}`$ on each side, and the last inequality is due to the assumption that $`w_{1} \leq w^{\ast}`$ and $`w_{2} \geq w^{\ast}`$. Thus, we can conclude that $`F\hspace{0pt}{(w)}`$ must be Lipschitz continuous on for any $`w \geq 0`$.

∎

###### Lemma 6.

Suppose function $`f\hspace{0pt}{(x)}`$ is a Lipschitz continuous with constant $`\Delta^{1}`$ on the interval $`\lbrack a,b\rbrack`$. Let $`{x_{i} = {\frac{i}{M}\hspace{0pt}{({b - a})}}},{i = {0,1,\cdots,M}}`$. Assume for all $`i`$, $`{|{{\hat{f}\hspace{0pt}{(x_{i})}} - {f\hspace{0pt}{(x_{i})}}}|} \leq \Delta^{2}`$. Let $`{\hat{f}}^{L\hspace{0pt}I}\hspace{0pt}{(x)}`$ be the linear interpolation using $`\hat{f}\hspace{0pt}{(x_{i})}`$, i.e., $`{{{{\hat{f}}^{L\hspace{0pt}I}\hspace{0pt}{(x)}} \triangleq {{\frac{{\hat{f}\hspace{0pt}{(x_{i})}} - {\hat{f}\hspace{0pt}{(x_{i - 1})}}}{x_{i} - x_{i - 1}}\hspace{0pt}{({x - x_{i}})}} + {\hat{f}\hspace{0pt}{(x_{i})}}}},{x_{i - 1} \leq x \leq x_{i}}},{{\forall i} \in {\lbrack M\rbrack}}`$. Then we have $`{|{{f\hspace{0pt}{(x)}} - {{\hat{f}}^{L\hspace{0pt}I}\hspace{0pt}{(x)}}}|} \leq {{3\hspace{0pt}\Delta^{2}} + \frac{2\hspace{0pt}\Delta_{1}\hspace{0pt}{({b - a})}}{M}}`$

###### Proof.

For simplicity, let $`\mu = \frac{b - a}{M}`$. Suppose $`x_{i - 1} \leq x \leq x_{i}`$. By construction of $`{\hat{f}}^{L\hspace{0pt}I}\hspace{0pt}{(x)}`$, we must have

``` math
\begin{aligned}
{{|{{{\hat{f}}^{L\hspace{0pt}I}\hspace{0pt}{(x_{i})}} - {{\hat{f}}^{L\hspace{0pt}I}\hspace{0pt}{(x)}}}|} \leq} & {{|{{{\hat{f}}^{L\hspace{0pt}I}\hspace{0pt}{(x_{i})}} - {{\hat{f}}^{L\hspace{0pt}I}\hspace{0pt}{(x_{i - 1})}}}|} = {|{{\hat{f}\hspace{0pt}{(x_{i})}} - {\hat{f}\hspace{0pt}{(x_{i - 1})}}}|}} \\
 = & {|{{{{{{\hat{f}\hspace{0pt}{(x_{i})}} - {f\hspace{0pt}{(x_{i})}}} + {f\hspace{0pt}{(x_{i})}}} - {f\hspace{0pt}{(x_{i - 1})}}} + {f\hspace{0pt}{(x_{i - 1})}}} - {\hat{f}\hspace{0pt}{(x_{i - 1})}}}|} \\
 \leq & {{|{{\hat{f}\hspace{0pt}{(x_{i})}} - {f\hspace{0pt}{(x_{i})}}}|} + {|{{f\hspace{0pt}{(x_{i})}} - {f\hspace{0pt}{(x_{i - 1})}}}|} + {|{{f\hspace{0pt}{(x_{i - 1})}} - {\hat{f}\hspace{0pt}{(x_{i - 1})}}}|}} \\
 \leq & {{\Delta^{2} + {\Delta^{1}\hspace{0pt}{|{x_{i} - x_{i - 1}}|}} + \Delta^{2}} = {{2\hspace{0pt}\Delta^{2}} + {\Delta^{1}\hspace{0pt}\mu}}}
\end{aligned}
```

where the last inequality is due to the Lipschitz continuity and assumption $`{|{{\hat{f}\hspace{0pt}{(x_{i})}} - {f\hspace{0pt}{(x_{i})}}}|} \leq \Delta^{2}`$. Since function $`f\hspace{0pt}{(x)}`$ is Lipschitz continuous with constant $`\Delta^{1}`$, we have

``` math
\begin{array}{r}
{{|{{f\hspace{0pt}{(x)}} - {f\hspace{0pt}{(x_{i})}}}|} \leq {\Delta^{1}\hspace{0pt}{|{x - x_{i}}|}} \leq {\Delta^{1}\hspace{0pt}{|{x_{i} - x_{i - 1}}|}} = {\Delta^{1}\hspace{0pt}\mu}}
\end{array}
```

By assumption, we have $`{|{{\hat{f}\hspace{0pt}{(x_{i})}} - {f\hspace{0pt}{(x_{i})}}}|} \leq \Delta^{2}`$.

Combining the above, we have

``` math
\begin{array}{cl}
{|{{f\hspace{0pt}{(x)}} - {{\hat{f}}^{L\hspace{0pt}I}\hspace{0pt}{(x)}}}|} & {= {|{{{{{{f\hspace{0pt}{(x)}} - {f\hspace{0pt}{(x_{i})}}} + {f\hspace{0pt}{(x_{i})}}} - {{\hat{f}}^{L\hspace{0pt}I}\hspace{0pt}{(x_{i})}}} + {{\hat{f}}^{L\hspace{0pt}I}\hspace{0pt}{(x_{i})}}} - {{\hat{f}}^{L\hspace{0pt}I}\hspace{0pt}{(x)}}}|}} \\
 & {\leq {{|{{f\hspace{0pt}{(x)}} - {f\hspace{0pt}{(x_{i})}}}|} + {|{{f\hspace{0pt}{(x_{i})}} - {{\hat{f}}^{L\hspace{0pt}I}\hspace{0pt}{(x_{i})}}}|} + {|{{{\hat{f}}^{L\hspace{0pt}I}\hspace{0pt}{(x_{i})}} - {{\hat{f}}^{L\hspace{0pt}I}\hspace{0pt}{(x)}}}|}}} \\
 & {= {{|{{f\hspace{0pt}{(x)}} - {f\hspace{0pt}{(x_{i})}}}|} + {|{{f\hspace{0pt}{(x_{i})}} - {\hat{f}\hspace{0pt}{(x_{i})}}}|} + {|{{{\hat{f}}^{L\hspace{0pt}I}\hspace{0pt}{(x_{i})}} - {{\hat{f}}^{L\hspace{0pt}I}\hspace{0pt}{(x)}}}|}}} \\
 & {\leq {{\Delta^{1}\hspace{0pt}\mu} + \Delta^{2} + {2\hspace{0pt}\Delta^{2}} + {\Delta^{1}\hspace{0pt}\mu}} = {{3\hspace{0pt}\Delta^{2}} + {2\hspace{0pt}\Delta^{1}\hspace{0pt}\mu}} = {{3\hspace{0pt}\Delta^{2}} + \frac{2\hspace{0pt}\Delta_{1}\hspace{0pt}{({b - a})}}{M}}}
\end{array}
```

where the first inequality is due to triangle inequality, and the second inequality is simply applying what we have just shown. Note that this holds regardless of the value of $`i`$. Thus, this holds for any $`x`$, which completes the proof. ∎

###### Lemma 7.

Let $`f,f',g,g'`$ be functions defined on $`\Omega_{\mathbf{z}}`$, such that $`{\max_{\mathbf{z} \in \Omega_{\mathbf{z}}}{|{{({f\hspace{0pt}\mathbf{z}})} - {f'\hspace{0pt}{(\mathbf{z})}}}|}} \leq \Delta_{1}`$ and $`{\max_{\mathbf{z} \in \Omega_{\mathbf{z}}}{|{{g\hspace{0pt}{(\mathbf{z})}} - {g'\hspace{0pt}{(\mathbf{z})}}}|}} \leq \Delta_{2}`$. If

``` math
\begin{aligned}
{\mathbf{z}^{\ast} = {\arg\max\limits_{\mathbf{z} \in \Omega_{\mathbf{z}}}}} & {f\hspace{0pt}{(\mathbf{z})}} \\
{{s.t}.} & {{g\hspace{0pt}{(\mathbf{z})}} \leq 0}
\end{aligned}
```

and

``` math
\begin{aligned}
{\mathbf{z}' = {\arg\max\limits_{\mathbf{z} \in \Omega_{\mathbf{z}}}}} & {f'\hspace{0pt}{(\mathbf{z})}} \\
{{s.t}.} & {{{g'\hspace{0pt}{(\mathbf{z})}} \leq \Delta_{2}},}
\end{aligned}
```

then we must have

``` math
\begin{aligned}
{f\hspace{0pt}{(\mathbf{z}')}} & {\geq {{f\hspace{0pt}{(\mathbf{z}^{\ast})}} - {2\hspace{0pt}\Delta_{1}}}} \\
{g\hspace{0pt}{(\mathbf{z}')}} & {{\leq {2\hspace{0pt}\Delta_{2}}}.}
\end{aligned}
```

###### Proof.

Note that $`{\max_{\mathbf{z} \in \Omega_{\mathbf{z}}}{|{{({f\hspace{0pt}\mathbf{z}})} - {f'\hspace{0pt}{(\mathbf{z})}}}|}} \leq \Delta_{1}`$ implies $`{f\hspace{0pt}{(\mathbf{z})}} \geq {{f'\hspace{0pt}{(\mathbf{z})}} - \Delta_{1}}`$ for any $`\mathbf{z} \in \Omega_{\mathbf{z}}`$. Specifically,

``` math
{f\hspace{0pt}{(\mathbf{z}')}} \geq {{f'\hspace{0pt}{(\mathbf{z}')}} - \Delta_{1}}
```

Noting $`{\max_{\mathbf{z} \in \Omega_{\mathbf{z}}}{|{{g\hspace{0pt}{(\mathbf{z})}} - {g'\hspace{0pt}{(\mathbf{z})}}}|}} \leq \Delta_{2}`$, we have $`{g'\hspace{0pt}{(\mathbf{z}^{\ast})}} \leq {{g\hspace{0pt}{(\mathbf{z}^{\ast})}} + \Delta_{2}} \leq \Delta_{2}`$, where the last inequality is due to $`{g\hspace{0pt}{(\mathbf{z}^{\ast})}} \leq 0`$ by definition. Since, $`\mathbf{z}^{\ast}`$ is a feasible solution to the second optimization problem, and the optimal value must be no smaller than the value at $`\mathbf{z}^{\ast}`$. That is to say,

``` math
\begin{array}{r}
{{f'\hspace{0pt}{(\mathbf{z}')}} \geq {f'\hspace{0pt}{(\mathbf{z}^{\ast})}}}
\end{array}
```

Hence we have

``` math
{f\hspace{0pt}{(\mathbf{z}')}} \geq {{f'\hspace{0pt}{(\mathbf{z}')}} - \Delta_{1}} \geq {{f'\hspace{0pt}{(\mathbf{z}^{\ast})}} - \Delta_{1}}
```

In addition, $`{\max_{\mathbf{z} \in \Omega_{\mathbf{z}}}{|{{({f\hspace{0pt}\mathbf{z}})} - {f'\hspace{0pt}{(\mathbf{z})}}}|}} \leq \Delta_{1}`$ implies $`{f'\hspace{0pt}{(\mathbf{z})}} \geq {{f\hspace{0pt}{(\mathbf{z})}} - \Delta_{1}}`$ for any $`\mathbf{z} \in \Omega_{\mathbf{z}}`$. Thus, we have $`{f'\hspace{0pt}{(\mathbf{z}^{\ast})}} \geq {{f\hspace{0pt}{(\mathbf{z})}^{\ast}} - \Delta_{1}}`$ and thus

``` math
{f\hspace{0pt}{(\mathbf{z}')}} \geq {{f'\hspace{0pt}{(\mathbf{z}^{\ast})}} - \Delta_{1}} \geq {{f\hspace{0pt}{(\mathbf{z}^{\ast})}} - {2\hspace{0pt}\Delta_{1}}}
```

By $`{\max_{\mathbf{z} \in \Omega_{\mathbf{z}}}{|{{g\hspace{0pt}{(\mathbf{z})}} - {g'\hspace{0pt}{(\mathbf{z})}}}|}} \leq \Delta_{2}`$, we have $`{g\hspace{0pt}{(\mathbf{z}')}} \leq {{g'\hspace{0pt}{(\mathbf{z}')}} + \Delta_{2}} \leq {2\hspace{0pt}\Delta_{2}}`$, where the last inequality is by definition of $`\mathbf{z}'`$. ∎

### C.3 Proof of Lemma 2

###### Proof.

Let us first consider the expected accuracy. By law of total expectation, we have

``` math
{{\mathbb{E}}\hspace{0pt}{\lbrack{r^{s}\hspace{0pt}{(x)}}\rbrack}} = {\sum\limits_{i = 1}^{K}{{\Pr{\lbrack{A_{s}^{\lbrack 1\rbrack} = i}\rbrack}}\hspace{0pt}{\mathbb{E}}\hspace{0pt}{\lbrack{\left. {r^{s}\hspace{0pt}{(x)}} \middle| A_{s}^{\lbrack 1\rbrack} \right. = i}\rbrack}}}
```

And we can further expand the conditional expectation by

``` math
\begin{array}{cl}
 & {{\mathbb{E}}\hspace{0pt}{\lbrack{\left. {r^{s}\hspace{0pt}{(x)}} \middle| A_{s}^{\lbrack 1\rbrack} \right. = i}\rbrack}} \\
 = & {\Pr{\lbrack D_{s} = 0|A_{s}^{\lbrack 1\rbrack} = i,\rbrack}{\mathbb{E}}{\lbrack r^{s}{(x)}|A_{s}^{\lbrack 1\rbrack} = i,D_{s} = 0\rbrack} + \Pr{\lbrack D_{s} = 1|A_{s}^{\lbrack 1\rbrack} = i,\rbrack}{\mathbb{E}}{\lbrack r^{s}{(x)}|A_{s}^{\lbrack 1\rbrack} = i,D_{s} = 1\rbrack}} \\
 = & {\Pr{\lbrack D_{s} = 0|A_{s}^{\lbrack 1\rbrack} = i,\rbrack}{\mathbb{E}}{\lbrack r^{i}{(x)}|A_{s}^{\lbrack 1\rbrack} = i,D_{s} = 0\rbrack} + \Pr{\lbrack D_{s} = 1|A_{s}^{\lbrack 1\rbrack} = i,\rbrack}{\mathbb{E}}{\lbrack r^{s}{(x)}|A_{s}^{\lbrack 1\rbrack} = i,D_{s} = 1\rbrack}}
\end{array}
```

where the last equality is because when $`D_{s} = 0`$, i.e., no add-on service is called, the strategy always uses the base service’s prediction and thus $`{r^{s}\hspace{0pt}{(x)}} = {r^{i}\hspace{0pt}{(x)}}`$. For the second term, we can bring in $`A_{s}^{\lbrack 2\rbrack}`$ and apply law of total expectation, to obtain

``` math
\begin{array}{cl}
{{\mathbb{E}}\hspace{0pt}{\lbrack{{\left. {r^{s}\hspace{0pt}{(x)}} \middle| A_{s}^{\lbrack 1\rbrack} \right. = i},{D_{s} = 1}}\rbrack}} & {= {\sum\limits_{j = 1}^{K}{{\Pr{\lbrack{A_{s}^{\lbrack 2\rbrack} = \left. j \middle| A_{s}^{\lbrack 1\rbrack} \right. = i},{D_{s} = 1}\rbrack}}\hspace{0pt}{\mathbb{E}}\hspace{0pt}{\lbrack{{\left. {r^{s}\hspace{0pt}{(x)}} \middle| A_{s}^{\lbrack 1\rbrack} \right. = i},{{D_{s} = 1},{A_{s}^{\lbrack 2\rbrack} = j}}}\rbrack}}}} \\
 & {= {\sum\limits_{j = 1}^{K}{{\Pr{\lbrack{A_{s}^{\lbrack 2\rbrack} = \left. j \middle| A_{s}^{\lbrack 1\rbrack} \right. = i},{D_{s} = 1}\rbrack}}\hspace{0pt}{\mathbb{E}}\hspace{0pt}{\lbrack{{\left. {r^{j}\hspace{0pt}{(x)}} \middle| A_{s}^{\lbrack 1\rbrack} \right. = i},{{D_{s} = 1},{A_{s}^{\lbrack 2\rbrack} = j}}}\rbrack}}}}
\end{array}
```

where the last equality is by observing that given the second add-on service is $`j`$, the reward simply becomes $`r^{j}\hspace{0pt}{(x)}`$. Combining the above, we have $`{\mathbb{E}}{\lbrack r^{s}{(x)}\rbrack} = \sum_{i = 1}^{K}\Pr{\lbrack A_{s}^{\lbrack 1\rbrack} = i\rbrack}\Pr{\lbrack D_{s} = 0|A_{s}^{\lbrack 1\rbrack} = i\rbrack}{\mathbb{E}}{\lbrack r^{i}{(x)}|D_{s} = 0,A_{s}^{\lbrack 1\rbrack} = i\rbrack} + \sum_{{i,j} = 1}^{K}\Pr{\lbrack A_{s}^{\lbrack 1\rbrack} = i\rbrack}\Pr{\lbrack D_{s} = 1|A_{s}^{\lbrack 1\rbrack} = i\rbrack}\Pr{\lbrack A_{s}^{\lbrack 2\rbrack} = j|D_{s} = 1,A_{s}^{\lbrack 1\rbrack} = i\rbrack}{\mathbb{E}}{\lbrack r^{j}{(x)}|D_{s} = 1,A_{s}^{\lbrack 1\rbrack} = i)}\rbrack`$, which is the desired property.

Similarly, we can expand the expected cost by law of total expectation

``` math
{{\mathbb{E}}\hspace{0pt}{\lbrack{\eta^{s}\hspace{0pt}{(x)}}\rbrack}} = {\sum\limits_{i = 1}^{K}{{\Pr{\lbrack{A_{s}^{\lbrack 1\rbrack} = i}\rbrack}}\hspace{0pt}{\mathbb{E}}\hspace{0pt}{\lbrack{\left. {\eta^{s}\hspace{0pt}{(x)}} \middle| A_{s}^{\lbrack 1\rbrack} \right. = i}\rbrack}}}
```

And we can further expand the conditional expectation by

``` math
\begin{array}{cl}
 & {{\mathbb{E}}\hspace{0pt}{\lbrack{\left. {\eta^{s}\hspace{0pt}{(x)}} \middle| A_{s}^{\lbrack 1\rbrack} \right. = i}\rbrack}} \\
 = & {\Pr{\lbrack D_{s} = 0|A_{s}^{\lbrack 1\rbrack} = i,\rbrack}{\mathbb{E}}{\lbrack\eta^{i}{(x)}|A_{s}^{\lbrack 1\rbrack} = i,D_{s} = 0\rbrack} + \Pr{\lbrack D_{s} = 1|A_{s}^{\lbrack 1\rbrack} = i,\rbrack}{\mathbb{E}}{\lbrack\eta^{s}{(x)}|A_{s}^{\lbrack 1\rbrack} = i,D_{s} = 1\rbrack}} \\
 = & {\Pr{\lbrack D_{s} = 0|A_{s}^{\lbrack 1\rbrack} = i,\rbrack}\mathbf{c}_{i} + \Pr{\lbrack D_{s} = 1|A_{s}^{\lbrack 1\rbrack} = i,\rbrack}{\mathbb{E}}{\lbrack\eta^{s}{(x)}|A_{s}^{\lbrack 1\rbrack} = i,D_{s} = 1\rbrack}}
\end{array}
```

where the last equality is because when $`D_{s} = 0`$, i.e., no add-on service is called, the strategy always uses the base service’s prediction and incurs the base service’s cost $`{\eta^{s}\hspace{0pt}{(x)}} = \mathbf{c}_{i}`$. For the second term, we can bring in $`A_{s}^{\lbrack 2\rbrack}`$ and apply law of total expectation, to obtain

``` math
\begin{array}{cl}
{{\mathbb{E}}\hspace{0pt}{\lbrack{{\left. {\eta^{s}\hspace{0pt}{(x)}} \middle| A_{s}^{\lbrack 1\rbrack} \right. = i},{D_{s} = 1}}\rbrack}} & {= {\sum\limits_{j = 1}^{K}{{\Pr{\lbrack{A_{s}^{\lbrack 2\rbrack} = \left. j \middle| A_{s}^{\lbrack 1\rbrack} \right. = i},{D_{s} = 1}\rbrack}}\hspace{0pt}{\mathbb{E}}\hspace{0pt}{\lbrack{{\left. {\eta^{s}\hspace{0pt}{(x)}} \middle| A_{s}^{\lbrack 1\rbrack} \right. = i},{{D_{s} = 1},{A_{s}^{\lbrack 2\rbrack} = j}}}\rbrack}}}} \\
 & {= {\sum\limits_{j = 1}^{K}{{\Pr{\lbrack{A_{s}^{\lbrack 2\rbrack} = \left. j \middle| A_{s}^{\lbrack 1\rbrack} \right. = i},{D_{s} = 1}\rbrack}}\hspace{0pt}{({\mathbf{c}_{i} + \mathbf{c}_{j}})}}}}

where the last equality is because given the base service is $`i`$ and add-on service is $`j`$, the cost is simply the sum of their cost $`\mathbf{c}_{i} + \mathbf{c}_{j}`$. Combining all the above equations, we have the expected cost $`{{\mathbb{E}}\hspace{0pt}{\lbrack{\eta^{s}\hspace{0pt}{(x)}}\rbrack}} = {{\sum_{i = 1}^{K}{{\Pr{\lbrack{A_{s}^{\lbrack 1\rbrack} = i}\rbrack}}\hspace{0pt}{\Pr{\lbrack{D_{s} = \left. 0 \middle| A_{s}^{\lbrack 1\rbrack} \right. = i}\rbrack}}\hspace{0pt}\mathbf{c}_{i}}} + {\sum_{{i,j} = 1}^{K}{{\Pr{\lbrack{A_{s}^{\lbrack 1\rbrack} = i}\rbrack}}\hspace{0pt}{\Pr{\lbrack{D_{s} = \left. 1 \middle| A_{s}^{\lbrack 1\rbrack} \right. = i}\rbrack}}\hspace{0pt}{\Pr{\lbrack{A_{s}^{\lbrack 2\rbrack} = \left. j \middle| D_{s} \right. = 1},{A_{s}^{\lbrack 1\rbrack} = i}\rbrack}}\hspace{0pt}\left( {\mathbf{c}_{i} + \mathbf{c}_{j}} \right)}}}`$, which is the desired term. Thus, we have shown a form of expected accuracy and cost which is exactly the same as in Lemma 2, which completes the proof. ∎

\end{aligned}
```

But noting that $`\mathbf{\Pi}'`$ by definition is also a feasible solution to the problem C.7, this inequality implies that the objective function achieved by $`\mathbf{\Pi}'`$ is strictly larger than that achieved by one optimal solution to C.7. A contradiction. Hence, $`(p^{\ast},\mathbf{\Pi}^{\ast})`$ is one optimal solution.

Next we show that $`\mathbf{\Pi}^{\ast}`$ must follow the presented form. Since $`{\|\mathbf{\Pi}^{\ast}\|}_{0} \leq 2`$, we can consider the cases separately.

\(i\) $`{\|\mathbf{\Pi}^{\ast}\|}_{0} = 1`$: Assume $`\mathbf{\Pi}_{i}^{\ast} \neq 0`$. Then problem C.7 becomes

``` math
\begin{aligned}
{\max\limits_{\mathbf{\Pi}_{i} \in {\mathbb{R}}^{+}}\ } & {\mathbf{\Pi}_{i}\hspace{0pt}{\overline{r}}_{i,p^{\ast}}} \\
{s.t.\ } & {{{\mathbf{c}_{i}\hspace{0pt}\mathbf{\Pi}_{i}} \leq \frac{B}{p^{\ast}}},{\mathbf{\Pi}_{i} \leq 1}}
\end{aligned}
```

Since the objective function is monotonely increasing w.r.t. $`\mathbf{\Pi}_{i}`$, we must have $`\mathbf{\Pi}_{i}^{\ast} = {\min{\{\frac{B}{p^{\ast}\hspace{0pt}\mathbf{c}},1\}}}`$

\(ii\) $`{\|\mathbf{\Pi}^{\ast}\|}_{0} = 2`$: Assume $`{\mathbf{\Pi}_{i}^{\ast} \neq 0},{\mathbf{\Pi}_{j}^{\ast} \neq 0}`$. Then problem C.7 becomes

``` math
\begin{aligned}
{\max\limits_{{\mathbf{\Pi}_{i} \in {\mathbb{R}}^{+}},{\mathbf{\Pi}_{j} \in {\mathbb{R}}^{+}}}\ } & {{\mathbf{\Pi}_{i}\hspace{0pt}{\overline{r}}_{i,p^{\ast}}} + {\mathbf{\Pi}_{j}\hspace{0pt}{\overline{r}}_{j,p^{\ast}}}} \\
{s.t.\ } & {{{{\mathbf{c}_{i}\hspace{0pt}\mathbf{\Pi}_{i}} + {\mathbf{c}_{j}\hspace{0pt}\mathbf{\Pi}_{j}}} \leq \frac{B}{p^{\ast}}},{{\mathbf{\Pi}_{i} + \mathbf{\Pi}_{j}} \leq 1}}
\end{aligned}
```

As a linear programming, if it has a solution, then there must exist one solution on the corner point. Since $`{\mathbf{\Pi}_{i}^{\ast} \neq 0},{\mathbf{\Pi}_{j}^{\ast} \neq 0}`$, the two constraints must be satisfied to achieve a corner point. The two constraints form a system of linear equations, and solving it gives $`{\mathbf{\Pi}_{i}^{\ast} = \frac{{B/p} - \mathbf{c}_{j}}{\mathbf{c}_{i} - \mathbf{c}_{j}}},{\mathbf{\Pi}_{j}^{\ast} = \frac{\mathbf{c}_{i} - {B/p}}{\mathbf{c}_{i} - \mathbf{c}_{j}}}`$, which completes the proof. ∎

Now we are ready to prove Lemma 12. Recall that in Algorithm 2, we compute $`{(\mu_{1},i_{1})} = {{\arg{\max_{{\mu \in {\lbrack 0,1\rbrack}},{i \in {\lbrack K\rbrack}}}\phi_{i}}}\hspace{0pt}{(\mu)}}`$ and $`{(\mu_{2},i_{2},j_{2})} = {{\arg{\max_{{\mu \in {{\lbrack\frac{\beta}{\mathbf{c}_{i}},{\min{\{\frac{\beta}{\mathbf{c}_{j}},1\}}}\rbrack},i}},{{j \in {\lbrack K\rbrack}},{\mathbf{c}_{i} > \mathbf{c}_{j}}}}\phi_{i,j}}}\hspace{0pt}{(\mu)}}`$. If $`{\phi_{i_{1}}\hspace{0pt}{(\mu_{1})}} \geq {\phi_{i_{2},j_{2}}\hspace{0pt}{(\mu_{2})}}`$, let $`\rho = \mu_{1}`$ and $`\mathbf{\Pi} = {\left\lbrack {\mathbb{1}_{\mu_{1} < \frac{\beta}{\mathbf{c}_{i_{1}}}} + {\frac{\beta}{\mathbf{c}_{i}}\hspace{0pt}\mathbb{1}_{\mu_{1} \geq \frac{\beta}{\mathbf{c}_{i_{1}}}}}} \right\rbrack\hspace{0pt}\mathbf{e}_{i_{1}}}`$. Otherwise, let $`\rho = \mu_{2}`$ and $`\mathbf{\Pi} = {{\frac{{\beta/\mu_{2}} - \mathbf{c}_{j_{2}}}{\mathbf{c}_{j_{2}} - \mathbf{c}_{j_{2}}}\hspace{0pt}\mathbf{e}_{i_{2}}} + {\frac{\mathbf{c}_{i_{2}} - {\beta/\mu_{2}}}{\mathbf{c}_{i_{2}} - \mathbf{c}_{i_{2}}}\hspace{0pt}\mathbf{e}_{j_{2}}}}`$. Recall that $`{\phi_{i}\hspace{0pt}{(\mu)}} \triangleq {{{\overline{\mathbf{r}}}_{k,\ell}\hspace{0pt}{(\mathbf{1}_{K \times L})}} + {{\min{\{\frac{\beta}{\mathbf{c}_{i}},\mu\}}}\hspace{0pt}{\overset{\sim}{\mathbf{r}}}_{i}^{k,\ell}\hspace{0pt}{(\mu)}}}`$ and $`{\phi_{i,j}\hspace{0pt}{(\mu)}} \triangleq {{{\overline{\mathbf{r}}}_{k,\ell}\hspace{0pt}{(\mathbf{1}_{K \times L})}} + {\frac{\beta - {\mu\hspace{0pt}\mathbf{c}_{j}}}{\mathbf{c}_{i} - \mathbf{c}_{j}}\hspace{0pt}{\overset{\sim}{\mathbf{r}}}_{i}^{k,\ell}\hspace{0pt}{(\mu)}} + {\frac{{\mu\hspace{0pt}\mathbf{c}_{i}} - \beta}{\mathbf{c}_{i} - \mathbf{c}_{j}}\hspace{0pt}{\overset{\sim}{\mathbf{r}}}_{j}^{k,\ell}\hspace{0pt}{(\mu)}}}`$.

Let us consider the two cases separately.

(i): $`{\phi_{i_{1}}\hspace{0pt}{(\mu_{1})}} \geq {\phi_{i_{2},j_{2}}\hspace{0pt}{(\mu_{2})}}`$, and thus $`\rho = \mu_{1}`$ and $`\mathbf{\Pi} = {\left\lbrack {\mathbb{1}_{\mu_{1} < \frac{\beta}{\mathbf{c}_{i_{1}}}} + {\frac{\beta}{\mathbf{c}_{i}}\hspace{0pt}\mathbb{1}_{\mu_{1} \geq \frac{\beta}{\mathbf{c}_{i_{1}}}}}} \right\rbrack\hspace{0pt}\mathbf{e}_{i_{1}}}`$.

According to Lemma 13, there exists a solution $`{\check{\rho}}^{\ast},{\check{\mathbf{\Pi}}}^{\ast}`$ to the above problem, such that

- •
  $`{\check{\mathbf{\Pi}}}_{i}^{\ast} = 1`$ for some $`i`$, and $`{\check{\mathbf{\Pi}}}_{k}^{\ast} = 0`$, for all $`k \neq i`$
- •
  $`{\check{\mathbf{\Pi}}}_{i}^{\ast} = \frac{\beta}{\rho\hspace{0pt}\mathbf{c}_{i}}`$ for some $`i`$, and $`{\check{\mathbf{\Pi}}}_{k}^{\ast} = 0`$, for all $`k \neq i`$
- •
  $`{{\check{\mathbf{\Pi}}}_{i}^{\ast} = \frac{{\beta/\rho} - \mathbf{c}_{j}}{\mathbf{c}_{i} - \mathbf{c}_{j}}},{{\check{\mathbf{\Pi}}}_{j}^{\ast} = \frac{\mathbf{c}_{i} - {\beta/\rho}}{\mathbf{c}_{i} - \mathbf{c}_{j}}}`$, for some distinct $`i,j`$, and $`{\check{\mathbf{\Pi}}}_{k}^{\ast} = 0`$, for all $`k \neq {i,j}`$

If the first or second condition happens, the objective then becomes $`\phi_{i}\hspace{0pt}{({\check{\rho}}^{\ast})}`$. If the third condition happens, then the objective becomes $`\phi_{{i,j},}\hspace{0pt}{({\check{\rho}}^{\ast})}`$. Since $`{\phi_{i_{1}}\hspace{0pt}{(\mu_{1})}} \geq {\phi_{i_{2},j_{2}}\hspace{0pt}{(\mu_{2})}}`$, we must have $`{\phi_{i}\hspace{0pt}{({\check{\rho}}^{\ast})}} \geq {\phi_{{i,j},}\hspace{0pt}{({\check{\rho}}^{\ast})}}`$ and thus it must be either first or second condition. By construction of $`\mu_{1}`$, we must have $`\mu_{1} = {\hat{\rho}}^{\ast}`$. If $`{\check{\rho}}^{\ast} = \mu_{1} < \frac{\beta}{\mathbf{c}_{i_{1}}}`$, i.e., $`\frac{\beta}{\mathbf{c}_{i_{1}}\hspace{0pt}{\check{\rho}}^{\ast}} > 1`$, and thus second case cannot happen, and it has to be the first case and thus $`{\check{\mathbf{\Pi}}}_{i_{1}}^{\ast} = 1`$. By definition, we also have $`\mathbf{\Pi} = \mathbf{e}_{i_{1}}`$. And thus, we have $`{\check{\mathbf{\Pi}}}^{\ast} = \mathbf{\Pi}`$. If $`{\check{\rho}}^{\ast} = \mu_{1} \geq \frac{\beta}{\mathbf{c}_{i_{1}}}`$, i.e., $`\frac{\beta}{\mathbf{c}_{i_{1}}\hspace{0pt}{\check{\rho}}^{\ast}} \leq 1`$, then the second case must happen. Thus, we must have $`{\check{\mathbf{\Pi}}}_{i_{1}}^{\ast} = \frac{\beta}{\rho\hspace{0pt}\mathbf{c}}`$. Meanwhile, by definition, we have $`\mathbf{\Pi} = {\frac{\beta}{\mathbf{c}_{i}\hspace{0pt}\rho}\hspace{0pt}\mathbf{e}_{i_{1}}} = {\check{\mathbf{\Pi}}}^{\ast}`$.

(ii): $`{\phi_{i_{1}}\hspace{0pt}{(\mu_{1})}} \geq {\phi_{i_{2},j_{2}}\hspace{0pt}{(\mu_{2})}}`$, and thus $`\rho = \mu_{2}`$ and $`\mathbf{\Pi} = {{\frac{{\beta/\mu_{2}} - \mathbf{c}_{j_{2}}}{\mathbf{c}_{j_{2}} - \mathbf{c}_{j_{2}}}\hspace{0pt}\mathbf{e}_{i_{2}}} + {\frac{\mathbf{c}_{i_{2}} - {\beta/\mu_{2}}}{\mathbf{c}_{i_{2}} - \mathbf{c}_{i_{2}}}\hspace{0pt}\mathbf{e}_{j_{2}}}}`$. We can use a similar argument to show that $`\mathbf{\Pi} = {\check{\mathbf{\Pi}}}^{\ast}`$.

That is to say, no matter which case we are in, the optimal solution is always returned. ∎

###### Lemma 14.

The function $`{\hat{h}}_{k,\ell}\hspace{0pt}{(\beta)}`$ is Lipschitz continuous with constant $`O\hspace{0pt}{(\gamma)}`$ for $`\beta \geq 0`$.

###### Proof.

Let us use $`\phi_{k,\ell}\hspace{0pt}{()}`$ to denote $`{\hat{h}}_{k,\ell}\hspace{0pt}{()}`$ for notation simplification. Consider $`\beta`$ and $`\beta + \Delta`$, and our goal is to bound $`{\phi_{k,\ell}\hspace{0pt}{({\beta + \Delta})}} - {\phi_{k,\ell}\hspace{0pt}{(\beta)}}`$. Let $`\rho^{\beta + \Delta},\mathbf{\Pi}^{\beta + \Delta}`$ be the corresponding solution to $`\beta + \Delta`$, i.e., the solution to

``` math
\begin{aligned}
{\max\limits_{{\rho,\mathbf{\Pi}} \in \Omega_{2}}\ } & {{{\overline{\mathbf{r}}}_{k,\ell}\hspace{0pt}{(\mathbf{1}_{K \times L})}} + {{{\rho\hspace{0pt}\mathbf{\Pi}^{T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho)}}} \\
\text{s.t.~} & {{{\rho\hspace{0pt}{({\mathbf{\Pi} - {\mathbf{\Pi} \odot \mathbf{e}_{k}}})}^{T}\hspace{0pt}\mathbf{c}} \leq {\beta + \Delta}}.}
\end{aligned}
```

Let $`\rho' = {\frac{\beta}{\beta + \Delta}\hspace{0pt}\rho^{\beta + \Delta}}`$. It is clear that $`\rho',\mathbf{\Pi}^{\beta + \Delta}`$ is one solution to

``` math
\begin{aligned}
{\max\limits_{{\rho,\mathbf{\Pi}} \in \Omega_{2}}\ } & {{{\overline{\mathbf{r}}}_{k,\ell}\hspace{0pt}{(\mathbf{1}_{K \times L})}} + {{{\rho\hspace{0pt}\mathbf{\Pi}^{T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho)}}} \\
\text{s.t.~} & {{{\rho\hspace{0pt}{({\mathbf{\Pi} - {\mathbf{\Pi} \odot \mathbf{e}_{k}}})}^{T}\hspace{0pt}\mathbf{c}} \leq \beta}.}
\end{aligned}
```

Thus, $`{{\overline{\mathbf{r}}}_{k,\ell}\hspace{0pt}{(\mathbf{1}_{K \times L})}} + {{{\rho'\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho')}}`$ must be smaller or equal to $`\phi_{k,\ell}\hspace{0pt}{(\beta)}`$, which is the optimal solution. Thus we must have

``` math
\begin{aligned}
{{\phi_{k,\ell}\hspace{0pt}{({\beta + \Delta})}} - {\phi_{k,\ell}\hspace{0pt}{(\beta)}}} & {\leq {{\phi_{k,\ell}\hspace{0pt}{({\beta + \Delta})}} - {{\overline{\mathbf{r}}}_{k,\ell}\hspace{0pt}{(\mathbf{1}_{K \times L})}} - {{{\rho'\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho')}}}}
\end{aligned}
```

Note that by definition,

``` math
\begin{array}{r}
{{\phi_{k,\ell}\hspace{0pt}{({\beta + \Delta})}} = {{{\overline{\mathbf{r}}}_{k,\ell}\hspace{0pt}{(\mathbf{1}_{K \times L})}} + {{{\rho^{\beta + \Delta}\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}}}}
\end{array}
```

The above inequality becomes

``` math
\begin{array}{cl}
{{\phi_{k,\ell}\hspace{0pt}{({\beta + \Delta})}} - {\phi_{k,\ell}\hspace{0pt}{(\beta)}}} & {\leq {{{{\rho^{\beta + \Delta}\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}} - {{{\rho'\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho')}}}} \\
 & {= {{{{\rho^{\beta + \Delta}\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}} - {{{\rho'\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}}}} \\
 & {{+ {{{\rho'\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}}} - {{{\rho'\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho')}}} \\
 & {= {{{{\rho^{\beta + \Delta}\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}} - {{{\frac{\beta}{\beta + \Delta}\hspace{0pt}\rho^{\beta + \Delta}\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}}}} \\
 & {{+ {{{\rho'\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}}} - {{{\rho'\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho')}}} \\
 & {= {{{\frac{\Delta}{\beta + \Delta}\hspace{0pt}\rho^{\beta + \Delta}\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}}} \\
 & {{+ {{{\rho'\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}}} - {{{\rho'\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho')}}}
\end{array}
```

where the first equality is by adding and subtracting $`{{\rho'\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}`$, and the second equality is simply plugging in the value of $`\rho'`$. According to Lemma 13, $`\mathbf{\Pi}^{\beta + \Delta}`$ must be sparse.

\(i\) If $`\mathbf{\Pi}_{k}^{\beta + \Delta} = 1`$, then only the base service ($`k`$th service) is used when budget is $`\beta + \Delta`$ When the budget becomes smaller, i.e., becomes $`\beta`$, it is always possible to always use the base service. Hence, we must have $`{{\phi_{k,\ell}\hspace{0pt}{({\beta + \Delta})}} - {\phi_{k,\ell}\hspace{0pt}{(\beta)}}} = 0`$.

\(ii\) Otherwise, since $`{\|\mathbf{\Pi}^{\beta + \Delta}\|} \leq 2`$, there are at most two elements in $`\mathbf{\Pi}^{\beta + \Delta}`$ that are not zeros. Let $`{k_{1},k_{2}} \neq k`$ denote the indexes. Then the constraint gives

``` math
{{\rho^{\beta + \Delta}\hspace{0pt}\mathbf{\Pi}_{k_{1}}^{\beta + \Delta}\hspace{0pt}\mathbf{c}_{k_{1}}} + {\rho^{\beta + \Delta}\hspace{0pt}\mathbf{\Pi}_{k_{2}}^{\beta + \Delta}\hspace{0pt}\mathbf{c}_{k_{2}}}} \leq {\beta + \Delta}
```
``` math
{{({{\rho^{\beta + \Delta}\hspace{0pt}\mathbf{\Pi}_{k_{1}}^{\beta + \Delta}} + {\rho^{\beta + \Delta}\hspace{0pt}\mathbf{\Pi}_{k_{2}}^{\beta + \Delta}}})}\hspace{0pt}{\min\limits_{j \neq k}\mathbf{c}_{j}}} \leq {{\rho^{\beta + \Delta}\hspace{0pt}\mathbf{\Pi}_{k_{1}}^{\beta + \Delta}\hspace{0pt}\mathbf{c}_{k_{1}}} + {\rho^{\beta + \Delta}\hspace{0pt}\mathbf{\Pi}_{k_{2}}^{\beta + \Delta}\hspace{0pt}\mathbf{c}_{k_{2}}}} \leq {\beta + \Delta}
```

That is to say,

``` math
{\rho^{\beta + \Delta}\hspace{0pt}{({\mathbf{\Pi}_{k_{1}}^{\beta + \Delta} + \mathbf{\Pi}_{k_{2}}^{\beta + \Delta}})}} \leq {{({\beta + \Delta})}/{({\min\limits_{j \neq k}\mathbf{c}_{j}})}}
```

Thus we have

``` math
\begin{array}{cl}
{{{\frac{\Delta}{\beta + \Delta}\hspace{0pt}\rho^{\beta + \Delta}\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}} & {= {\frac{\Delta}{\beta + \Delta}\hspace{0pt}\rho^{\beta + \Delta}\hspace{0pt}{({{{\mathbf{\Pi}_{k_{1}}^{{({\beta + \Delta})}\hspace{0pt}T} \cdot {\overset{\sim}{\mathbf{r}}}_{k_{1}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}} + {{\mathbf{\Pi}_{k_{1}}^{{({\beta + \Delta})}\hspace{0pt}T} \cdot {\overset{\sim}{\mathbf{r}}}_{k_{1}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}}})}}} \\
 & {\leq {\frac{\Delta}{\beta + \Delta}\hspace{0pt}\rho^{\beta + \Delta}\hspace{0pt}{({\mathbf{\Pi}_{k_{1}}^{{({\beta + \Delta})}\hspace{0pt}T} + \mathbf{\Pi}_{k_{1}}^{{({\beta + \Delta})}\hspace{0pt}T}})}}} \\
 & {\leq {{\frac{\Delta}{\beta + \Delta}\hspace{0pt}{({\beta + \Delta})}}/{({\min\limits_{j \neq k}\mathbf{c}_{j}})}}} \\
 & {= \frac{\Delta}{\min_{j \neq k}\mathbf{c}_{j}}}
\end{array}
```

In addition, note that by assumption, $`{\overset{\sim}{\mathbf{r}}}^{k,\ell}\hspace{0pt}{(\rho)}`$ is Lipschitz continuous with constant $`\gamma`$. Hence, we must have

``` math
\begin{array}{r}
{{\overset{\sim}{\mathbf{r}}}_{j}^{k,\ell}{(\rho')} \geq {\overset{\sim}{\mathbf{r}}}_{j}^{k,\ell}{(\rho^{\beta + \Delta})} - \gamma|{(\rho' - \rho^{\beta + \Delta}|)} = {\overset{\sim}{\mathbf{r}}}_{j}^{k,\ell}{(\rho^{\beta + \Delta})} - \gamma\frac{\Delta}{\beta + \Delta}\rho^{\beta + \Delta}}
\end{array}
```

And thus

``` math
\begin{array}{cl}
 & {{{{\rho'\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}} - {{{\rho'\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho')}}} \\
 \leq & {{{{{\rho'\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}} - {{{\rho'\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}}} + {{{\rho'\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot \mathbf{1}}\hspace{0pt}\gamma\hspace{0pt}\frac{\Delta}{\beta + \Delta}\hspace{0pt}\rho^{\beta + \Delta}}} \\
 = & {\rho'\hspace{0pt}{({\mathbf{\Pi}_{k_{1}}^{{({\beta + \Delta})}\hspace{0pt}T} + \mathbf{\Pi}_{k_{2}}^{{({\beta + \Delta})}\hspace{0pt}T}})}\hspace{0pt}\gamma\hspace{0pt}\frac{\Delta}{\beta + \Delta}\hspace{0pt}\rho^{\beta + \Delta}} \\
 = & {\rho^{\beta + \Delta}\hspace{0pt}\frac{\beta}{\beta + \Delta}\hspace{0pt}{({\mathbf{\Pi}_{k_{1}}^{{({\beta + \Delta})}\hspace{0pt}T} + \mathbf{\Pi}_{k_{2}}^{{({\beta + \Delta})}\hspace{0pt}T}})}\hspace{0pt}\gamma\hspace{0pt}\frac{\Delta}{\beta + \Delta}\hspace{0pt}\rho^{\beta + \Delta}}
\end{array}
```

Now plugging in

``` math
{\rho^{\beta + \Delta}\hspace{0pt}{({\mathbf{\Pi}_{k_{1}}^{\beta + \Delta} + \mathbf{\Pi}_{k_{2}}^{\beta + \Delta}})}} \leq {{({\beta + \Delta})}/{({\min\limits_{j \neq k}\mathbf{c}_{j}})}}
```

We can further have

``` math
\begin{array}{cl}
 & {{{{\rho'\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}} - {{{\rho'\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho')}}} \\
 \leq & {\rho^{\beta + \Delta}\hspace{0pt}\frac{\beta}{\beta + \Delta}\hspace{0pt}{({\mathbf{\Pi}_{k_{1}}^{{({\beta + \Delta})}\hspace{0pt}T} + \mathbf{\Pi}_{k_{2}}^{{({\beta + \Delta})}\hspace{0pt}T}})}\hspace{0pt}\gamma\hspace{0pt}\frac{\Delta}{\beta + \Delta}\hspace{0pt}\rho^{\beta + \Delta}} \\
 \leq & {{{\frac{\beta}{\beta + \Delta}\hspace{0pt}{({\beta + \Delta})}}/{({\min\limits_{j \neq k}\mathbf{c}_{j}})}}\hspace{0pt}\gamma\hspace{0pt}\frac{\Delta}{\beta + \Delta}\hspace{0pt}\rho^{\beta + \Delta}} \\
 \leq & {{\Delta\hspace{0pt}\gamma}/{({\min\limits_{j \neq k}\mathbf{c}_{j}})}}
\end{array}
```

Combining it with

``` math
\begin{aligned}
{{{\frac{\Delta}{\beta + \Delta}\hspace{0pt}\rho^{\beta + \Delta}\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}} & {\leq \frac{\Delta}{\min_{j \neq k}\mathbf{c}_{j}}}
\end{aligned}
```

we have

``` math
\begin{array}{cl}
{{\phi_{k,\ell}\hspace{0pt}{({\beta + \Delta})}} - {\phi_{k,\ell}\hspace{0pt}{(\beta)}}} & {\leq {{{\frac{\Delta}{\beta + \Delta}\hspace{0pt}\rho^{\beta + \Delta}\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}}} \\
 & {{+ {{{\rho'\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho^{\beta + \Delta})}}} - {{{\rho'\hspace{0pt}\mathbf{\Pi}^{{({\beta + \Delta})}\hspace{0pt}T}} \cdot {\overset{\sim}{\mathbf{r}}}^{k,\ell}}\hspace{0pt}{(\rho')}}} \\
 & {\leq {{\Delta/{({\min\limits_{j \neq k}\mathbf{c}_{j}})}} + {{\Delta\hspace{0pt}\gamma}/{({\min\limits_{j \neq k}\mathbf{c}_{j}})}}}} \\
 & {= \frac{\Delta\hspace{0pt}{({1 + \gamma})}}{\min_{j \neq k}\mathbf{c}_{j}}}
\end{array}
```

Thus, no matter which case, we always have

``` math
\begin{aligned}
{{\phi_{k,\ell}\hspace{0pt}{({\beta + \Delta})}} - {\phi_{k,\ell}\hspace{0pt}{(\beta)}}} & {\leq {\frac{1 + \gamma}{\min_{j \neq k}\mathbf{c}_{j}} \cdot \Delta}}
\end{aligned}
```

In addition, since $`\phi_{k,\ell}\hspace{0pt}{(\beta)}`$ must be monotone, we have

``` math
\begin{aligned}
{{\phi_{k,\ell}\hspace{0pt}{({\beta + \Delta})}} - {\phi_{k,\ell}\hspace{0pt}{(\beta)}}} & {\geq 0 \geq {- {\frac{1 + \gamma}{\min_{j \neq k}\mathbf{c}_{j}} \cdot \Delta}}}
\end{aligned}
```

That is to say, $`\phi_{k,\ell}\hspace{0pt}{(\beta)}`$ is Lipschitz continuous with constant $`\frac{1 + \gamma}{\min_{j \neq k}\mathbf{c}_{j}}`$, which finishes the proof. ∎

Now we are ready to prove Lemma 11. By definition, there must exist a $`{\mathbf{λ}}'`$, such that $`{g_{i}'\hspace{0pt}{(b')}} = {\sum_{\ell = 1}^{L}{{\hat{\mathbf{A}}}_{i,\ell}\hspace{0pt}{\hat{h}}_{k,\ell}\hspace{0pt}{({{\mathbf{λ}}_{\ell}'\hspace{0pt}{({b' - \mathbf{c}_{i}})}})}}}`$. Let $`\Lambda_{M} = \left. \{{{\mathbf{λ}} \in {\mathbb{R}}^{L}} \middle| {{{\mathbf{λ}} \geq 0},{{{\mathbf{1}^{T}\hspace{0pt}{\mathbf{λ}}} = 1},{{{\mathbf{λ}}_{\ell}\hspace{0pt}M} \in {{\lbrack M\rbrack} \cup {\{ 0\}}}}}}\} \right.`$. Then there must exists a $`\hat{\mathbf{λ}} \in \Lambda_{M}`$ such that $`{|{{\mathbf{λ}}_{\ell}' - {\hat{\mathbf{λ}}}_{\ell}}|} \leq \frac{1}{M}`$. By Lemma 14, we have $`|{\hat{h}}_{k,\ell}{({\mathbf{λ}}_{\ell}'{(b' - \mathbf{c}_{i})})}) - \hat{h}_{k,\ell}({\hat{\mathbf{λ}}}_{\ell}{(b' - \mathbf{c}_{i})})| \leq O(\frac{\gamma}{M})`$. Note that $`\hat{\mathbf{A}}`$ is empirical probability matrix, by construction, $`{\sum_{\ell}^{L}\hat{\mathbf{A}_{i,\ell}}} = 1`$ and each $`\mathbf{A}_{i,\ell}`$ is non-negative. Thus, we must have $`{|{{\sum_{\ell = 1}^{L}{{\hat{\mathbf{A}}}_{i,\ell}\hspace{0pt}{\hat{h}}_{k,\ell}\hspace{0pt}{({{\hat{\mathbf{λ}}}_{\ell}\hspace{0pt}{({b' - \mathbf{c}_{i}})}})}}} - {g_{i}'\hspace{0pt}{(b')}}}|} = {|{{\sum_{\ell = 1}^{L}{{\hat{\mathbf{A}}}_{i,\ell}\hspace{0pt}{\hat{h}}_{k,\ell}\hspace{0pt}{({{\hat{\mathbf{λ}}}_{\ell}\hspace{0pt}{({b' - \mathbf{c}_{i}})}})}}} - {\sum_{\ell = 1}^{L}{{\hat{\mathbf{A}}}_{i,\ell}\hspace{0pt}{\hat{h}}_{k,\ell}\hspace{0pt}{({{\mathbf{λ}}_{\ell}'\hspace{0pt}{({b' - \mathbf{c}_{i}})}})}}}}|} \leq {O\hspace{0pt}{(\frac{\gamma}{M})}}`$. On the other hand, by construction, $`{\hat{g}}_{i}\hspace{0pt}{(b')}`$ produced by the subroutine to solve problem 3.3 is $`{\sum_{\ell = 1}^{L}{{\hat{\mathbf{A}}}_{i,\ell}\hspace{0pt}{\hat{h}}_{k,\ell}\hspace{0pt}{(\beta_{t_{\ell}^{\ast}})}}} = {\max_{t_{1},t_{2},\cdots,t_{L}}\hspace{0pt}{\sum_{\ell = 1}^{L}{{\hat{\mathbf{A}}}_{i,\ell}\hspace{0pt}{\hat{h}}_{k,\ell}\hspace{0pt}{(\beta_{t_{\ell}})}}}} = {\max_{t_{1},t_{2},\cdots,t_{L}}\hspace{0pt}{\sum_{\ell = 1}^{L}{\mathbf{A}_{i,\ell}\hspace{0pt}{\hat{h}}_{k,\ell}\hspace{0pt}{({\frac{t_{\ell}^{\ast}}{M}\hspace{0pt}{({b' - \mathbf{c}_{i}})}})}}}} \geq {\sum_{\ell = 1}^{L}{\mathbf{A}_{i,\ell}\hspace{0pt}{\hat{h}}_{k,\ell}\hspace{0pt}{({{\hat{\mathbf{λ}}}_{\ell}\hspace{0pt}{({b' - \mathbf{c}_{i}})}})}}}`$. Combing this with $`{{\sum_{\ell = 1}^{L}{{\hat{\mathbf{A}}}_{i,\ell}\hspace{0pt}{\hat{h}}_{k,\ell}\hspace{0pt}{({{\hat{\mathbf{λ}}}_{\ell}\hspace{0pt}{({b' - \mathbf{c}_{i}})}})}}} - {g_{i}'\hspace{0pt}{(b')}}} \geq {- {O\hspace{0pt}{(\frac{\gamma}{M})}}}`$, we immediately obtain $`{{{\hat{g}}_{i}\hspace{0pt}{(b')}} - {g_{i}'\hspace{0pt}{(b')}}} \geq {- {O\hspace{0pt}{(\frac{\gamma}{M})}}}`$. Since by definition $`g_{i}'\hspace{0pt}{(b')}`$ must be the optimal solution and thus we have $`{{{\hat{g}}_{i}\hspace{0pt}{(b')}} - {g_{i}'\hspace{0pt}{(b')}}} \leq 0`$. Thus, we have $`{|{{{\hat{g}}_{i}\hspace{0pt}{(b')}} - {g_{i}'\hspace{0pt}{(b')}}}|} \leq {O\hspace{0pt}{(\frac{\gamma}{M})}}`$. By Lemma 12, the produced solution to problem B.1 is exactly the optimal solution. That is to say, for the generated solution $`{{\hat{\rho}}^{i,\ell}\hspace{0pt}{(\beta_{t_{\ell}^{\ast}})}},{{\hat{\mathbf{\Pi}}}^{i,\ell}\hspace{0pt}{(\beta_{t_{\ell}^{\ast}})}}`$, at most $`\beta_{t_{\ell}^{\ast}}`$ budget might be used. Since the total budget is $`{\sum_{\ell = 1}^{L}\beta_{t_{\ell}^{\ast}}} = {b' - \mathbf{c}_{i}}`$, at most $`b' - \mathbf{c}_{i}`$ budget might be used. Calling the base service requires $`\mathbf{c}_{i}`$ cost, and thus the total cost is at most $`b'`$. As a result, we must have $`{\hat{\mathbb{E}}\hspace{0pt}{\lbrack\gamma^{s\hspace{0pt}{(i,b')}\hspace{0pt}{(x)}}\rbrack}} \leq b'`$, which completes the proof. ∎

Note that by definition, $`s' \triangleq {(\mathbf{p}^{{\lbrack 1\rbrack}'},\mathbf{Q}',\mathbf{P}^{{\lbrack 2\rbrack}'})}`$ is the optimal solution to the empirical accuracy and cost joint optimization problem. ###### Theorem 16.

Suppose $`{\mathbb{E}}\hspace{0pt}{\lbrack{{\left. {r_{i}\hspace{0pt}{(x)}} \middle| D_{s} \right. = 0},{A_{s}^{\lbrack 1\rbrack} = i}}\rbrack}`$ is Lipschitz continuous with constant $`\gamma`$ w.r.t. each element in $`\mathbf{Q}`$. Given $`N`$ i.i.d. samples $`{\{{y\hspace{0pt}{(x_{i})}},{\{{({y_{k}\hspace{0pt}{(x_{i})}},{q_{k}\hspace{0pt}{(x_{i})}})}\}}_{k = 1}^{K}\}}_{i = 1}^{N}`$, the computational cost of Algorithm 1 is $`O\hspace{0pt}\left( {{N\hspace{0pt}M\hspace{0pt}K^{2}} + {K^{3}\hspace{0pt}M^{3}\hspace{0pt}L} + {M^{L}\hspace{0pt}K^{2}}} \right)`$. With probability $`1 - \epsilon`$, the produced strategy $`\hat{s}`$ satisfies $`{{{\mathbb{E}}\hspace{0pt}{\lbrack{r^{\hat{s}}\hspace{0pt}{(x)}}\rbrack}} - {{\mathbb{E}}\hspace{0pt}{\lbrack{r^{s^{\ast}}\hspace{0pt}{(x)}}\rbrack}}} \geq {- {O\hspace{0pt}\left( {\sqrt{\frac{{\log\epsilon} + {\log M} + {\log K} + {\log L}}{N}} + \frac{\gamma\hspace{0pt}L}{M}} \right)}}`$, and $`{{\mathbb{E}}\hspace{0pt}{\lbrack{\gamma^{\lbrack\hat{s}\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}} \leq {b + {O\hspace{0pt}\left( \sqrt{\frac{{\log\epsilon} + {\log M} + {\log K} + {\log L}}{N}} \right)}}`$.

###### Proof.

There are three main parts: (i) the computational complexity, (ii) the accuracy drop, and (iii) the excessive cost. Let us handle them sequentially.

\(i\) Computational Complexity: Lemma 8 directly gives the computational complexity bound.

\(ii\) Accuracy Loss: By Lemma 9, with probability $`1 - \epsilon`$, we have

``` math
\begin{aligned}
{{{\mathbb{E}}\hspace{0pt}{\lbrack\mathbb{1}_{{{\hat{y}}^{\hat{s}}\hspace{0pt}{(x)}} = {y\hspace{0pt}{(x)}}}\rbrack}} - {\hat{\mathbb{E}}\hspace{0pt}{\lbrack\mathbb{1}_{{{\hat{y}}^{\hat{s}}\hspace{0pt}{(x)}} = {y\hspace{0pt}{(x)}}}\rbrack}}} & {\geq {- {O\hspace{0pt}\left( {\sqrt{\frac{{\log\epsilon} + {\log M} + {\log K} + {\log L}}{N}} + \frac{\gamma}{M}} \right)}}} \\
{{\hat{\mathbb{E}}\hspace{0pt}{\lbrack\mathbb{1}_{{{\hat{y}}^{s'}\hspace{0pt}{(x)}} = {y\hspace{0pt}{(x)}}}\rbrack}} - {{\mathbb{E}}\hspace{0pt}{\lbrack\mathbb{1}_{{{\hat{y}}^{s'}\hspace{0pt}{(x)}} = {y\hspace{0pt}{(x)}}}\rbrack}}} & {\geq {- {O\hspace{0pt}\left( \sqrt{\frac{{\log\epsilon} + {\log M} + {\log K} + {\log L}}{N}} \right)}}}
\end{aligned}
```

and also

``` math
\begin{aligned}
{{{\mathbb{E}}\hspace{0pt}{\lbrack\mathbb{1}_{{{\hat{y}}^{s'}\hspace{0pt}{(x)}} = {y\hspace{0pt}{(x)}}}\rbrack}} - {{\mathbb{E}}\hspace{0pt}{\lbrack\mathbb{1}_{{{\hat{y}}^{s^{\ast}}\hspace{0pt}{(x)}} = {y\hspace{0pt}{(x)}}}\rbrack}}} & {\geq {- {O\hspace{0pt}\left( \sqrt{\frac{{\log\epsilon} + {\log M} + {\log K} + {\log L}}{N} + + \frac{\gamma}{M}} \right)}}}
\end{aligned}
```

By Lemma 10, we have

``` math
\begin{aligned}
{{\hat{\mathbb{E}}\hspace{0pt}{\lbrack\mathbb{1}_{{{\hat{y}}^{\hat{s}}\hspace{0pt}{(x)}} = {y\hspace{0pt}{(x)}}}\rbrack}} - {\hat{\mathbb{E}}\hspace{0pt}{\lbrack\mathbb{1}_{{{\hat{y}}^{s'}\hspace{0pt}{(x)}} = {y\hspace{0pt}{(x)}}}\rbrack}}} & {\geq {- {O\hspace{0pt}\left( \frac{\gamma}{M} \right)}}}
\end{aligned}
```

Combining those four inequalities, we have

``` math
\begin{array}{cl}
 & {{{\mathbb{E}}\hspace{0pt}{\lbrack\mathbb{1}_{{{\hat{y}}^{\hat{s}}\hspace{0pt}{(x)}} = {y\hspace{0pt}{(x)}}}\rbrack}} - {{\mathbb{E}}\hspace{0pt}{\lbrack\mathbb{1}_{{{\hat{y}}^{s^{\ast}}\hspace{0pt}{(x)}} = {y\hspace{0pt}{(x)}}}\rbrack}}} \\
 = & {{{{{\mathbb{E}}\hspace{0pt}{\lbrack\mathbb{1}_{{{\hat{y}}^{\hat{s}}\hspace{0pt}{(x)}} = {y\hspace{0pt}{(x)}}}\rbrack}} - {\hat{\mathbb{E}}\hspace{0pt}{\lbrack\mathbb{1}_{{{\hat{y}}^{\hat{s}}\hspace{0pt}{(x)}} = {y\hspace{0pt}{(x)}}}\rbrack}}} + {\hat{\mathbb{E}}\hspace{0pt}{\lbrack\mathbb{1}_{{{\hat{y}}^{\hat{s}}\hspace{0pt}{(x)}} = {y\hspace{0pt}{(x)}}}\rbrack}}} - {\hat{\mathbb{E}}\hspace{0pt}{\lbrack\mathbb{1}_{{{\hat{y}}^{s'}\hspace{0pt}{(x)}} = {y\hspace{0pt}{(x)}}}\rbrack}}} \\
 + & {{{{\hat{\mathbb{E}}\hspace{0pt}{\lbrack\mathbb{1}_{{{\hat{y}}^{s'}\hspace{0pt}{(x)}} = {y\hspace{0pt}{(x)}}}\rbrack}} - {{\mathbb{E}}\hspace{0pt}{\lbrack\mathbb{1}_{{{\hat{y}}^{s'}\hspace{0pt}{(x)}} = {y\hspace{0pt}{(x)}}}\rbrack}}} + {{\mathbb{E}}\hspace{0pt}{\lbrack\mathbb{1}_{{{\hat{y}}^{s'}\hspace{0pt}{(x)}} = {y\hspace{0pt}{(x)}}}\rbrack}}} - {{\mathbb{E}}\hspace{0pt}{\lbrack\mathbb{1}_{{{\hat{y}}^{s^{\ast}}\hspace{0pt}{(x)}} = {y\hspace{0pt}{(x)}}}\rbrack}}} \\
 \geq & {{- {O\hspace{0pt}\left( \sqrt{\frac{{\log\epsilon} + {\log M} + {\log K} + {\log L}}{N}} \right)}} - {O\hspace{0pt}\left( \frac{\gamma\hspace{0pt}L}{M} \right)}} \\
 - & {{O\hspace{0pt}\left( \sqrt{\frac{{\log\epsilon} + {\log M} + {\log K} + {\log L}}{N}} \right)} - {O\hspace{0pt}\left( \sqrt{\frac{{\log\epsilon} + {\log M} + {\log K} + {\log L}}{N}} \right)}} \\
 \geq & {- {O\hspace{0pt}\left( {\sqrt{\frac{{\log\epsilon} + {\log M} + {\log K} + {\log L}}{N}} + \frac{\gamma\hspace{0pt}L}{M}} \right)}}
\end{array}
```

\(iii\) Excessive Cost: Similar to (ii), by Lemma 9, with probability $`1 - \epsilon`$, we have

``` math
\begin{aligned}
{{{\mathbb{E}}\hspace{0pt}{\lbrack{\tau^{\lbrack\hat{s}\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}} - {\hat{\mathbb{E}}\hspace{0pt}{\lbrack{\tau^{\lbrack\hat{s}\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}}} & {\leq {O\hspace{0pt}\left( \sqrt{\frac{{\log\epsilon} + {\log K} + {\log L}}{N}} \right)}} \\
{{\hat{\mathbb{E}}\hspace{0pt}{\lbrack{\tau^{\lbrack s'\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}} - {{\mathbb{E}}\hspace{0pt}{\lbrack{\tau^{\lbrack s'\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}}} & {\leq {O\hspace{0pt}\left( \sqrt{\frac{{\log\epsilon} + {\log K} + {\log L}}{N}} \right)}}
\end{aligned}
```

and also

``` math
\begin{aligned}
{{{\mathbb{E}}\hspace{0pt}{\lbrack{\tau^{\lbrack s'\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}} - {{\mathbb{E}}\hspace{0pt}{\lbrack{\tau^{\lbrack s^{\ast}\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}}} & {\leq {O\hspace{0pt}\left( \sqrt{\frac{{\log\epsilon} + {\log K} + {\log L}}{N}} \right)}}
\end{aligned}
```

By Lemma 10, we have

``` math
\begin{aligned}
{{\hat{\mathbb{E}}\hspace{0pt}{\lbrack{\tau^{\lbrack\hat{s}\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}} - {\hat{\mathbb{E}}\hspace{0pt}{\lbrack{\tau^{\lbrack s'\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}}} & {\leq 0}
\end{aligned}
```

Combining those four inequalities, we have

``` math
\begin{array}{cl}
 & {{{\mathbb{E}}\hspace{0pt}{\lbrack{\tau^{\lbrack\hat{s}\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}} - {{\mathbb{E}}\hspace{0pt}{\lbrack{\tau^{\lbrack s^{\ast}\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}}} \\
 = & {{{{{\mathbb{E}}\hspace{0pt}{\lbrack{\tau^{\lbrack\hat{s}\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}} - {\hat{\mathbb{E}}\hspace{0pt}{\lbrack{\tau^{\lbrack\hat{s}\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}}} + {\hat{\mathbb{E}}\hspace{0pt}{\lbrack{\tau^{\lbrack\hat{s}\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}}} - {\hat{\mathbb{E}}\hspace{0pt}{\lbrack{\tau^{\lbrack s'\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}}} \\
 + & {{{{\hat{\mathbb{E}}\hspace{0pt}{\lbrack{\tau^{\lbrack s'\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}} - {{\mathbb{E}}\hspace{0pt}{\lbrack{\tau^{\lbrack s'\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}}} + {{\mathbb{E}}\hspace{0pt}{\lbrack{\tau^{\lbrack s'\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}}} - {{\mathbb{E}}\hspace{0pt}{\lbrack{\tau^{\lbrack s^{\ast}\rbrack}\hspace{0pt}{(x,\mathbf{c})}}\rbrack}}} \\
 \leq & {{O\hspace{0pt}\left( \sqrt{\frac{{\log\epsilon} + {\log K} + {\log L}}{N}} \right)} + 0} \\
 + & {{O\hspace{0pt}\left( \sqrt{\frac{{\log\epsilon} + {\log K} + {\log L}}{N}} \right)} + {O\hspace{0pt}\left( \sqrt{\frac{{\log\epsilon} + {\log K} + {\log L}}{N}} \right)}} \\
 \leq & {O\hspace{0pt}\left( \sqrt{\frac{{\log\epsilon} + {\log K} + {\log L}}{N}} \right)}
\end{array}
```

which completes the proof. ∎

###### Lemma 17.

Let $`s^{\Delta\hspace{0pt}b} \triangleq {{\arg{\max_{s \in S}{\mathbb{E}}}}\hspace{0pt}{\lbrack{r^{s}\hspace{0pt}{(x)}}\rbrack}\hspace{0pt}\text{~s.t.~}\hspace{0pt}{\mathbb{E}}\hspace{0pt}{\lbrack{\gamma^{\lbrack s\rbrack}\hspace{0pt}{(x)}}\rbrack}} \leq {b - {\Delta\hspace{0pt}b}}`$. If $`{b - {\Delta\hspace{0pt}b}} \geq 0`$, then $`{{{\mathbb{E}}\hspace{0pt}{\lbrack{r^{s^{\Delta\hspace{0pt}b}}\hspace{0pt}{(x)}}\rbrack}} - {{\mathbb{E}}\hspace{0pt}{\lbrack{r^{s^{\ast}}\hspace{0pt}{(x)}}\rbrack}}} \geq {- {O\hspace{0pt}{({\Delta\hspace{0pt}b})}}}`$.

###### Proof.

We simply need to show that $`{\mathbb{E}}\hspace{0pt}{\lbrack{r^{s^{\Delta\hspace{0pt}b}}\hspace{0pt}{(x)}}\rbrack}`$ is Lipschitz continuous in $`\Delta\hspace{0pt}b`$. To see this, let us expand $`s^{\Delta\hspace{0pt}b} = {(\mathbf{p}^{\Delta\hspace{0pt}b},\mathbf{Q}^{\Delta\hspace{0pt}b},\mathbf{P}^{\Delta\hspace{0pt}b})}`$ and consider the following optimization problem

``` math
\begin{array}{r}
{{{{\max\limits_{s = {(\mathbf{p}^{0},\mathbf{Q}^{\Delta\hspace{0pt}b},\mathbf{P})} \in S}{\mathbb{E}}}\hspace{0pt}{\lbrack{r^{s}\hspace{0pt}{(x)}}\rbrack}\hspace{0pt}\text{~s.t.~}\hspace{0pt}{\mathbb{E}}\hspace{0pt}{\lbrack{\gamma^{\lbrack s\rbrack}\hspace{0pt}{(x)}}\rbrack}} \leq a}.}
\end{array}
```

By law of total expectation, we have

``` math
{{\mathbb{E}}\hspace{0pt}{\lbrack{r^{s}\hspace{0pt}{(x)}}\rbrack}} = {\sum\limits_{i = 1}^{K}{{\Pr{\lbrack{A_{s}^{\lbrack 1\rbrack} = i}\rbrack}}\hspace{0pt}{\mathbb{E}}\hspace{0pt}{\lbrack{\left. {r^{s}\hspace{0pt}{(x)}} \middle| A_{s}^{\lbrack 1\rbrack} \right. = i}\rbrack}}}
```

And we can further expand the conditional expectation by

``` math
\begin{array}{cl}
 & {{\mathbb{E}}\hspace{0pt}{\lbrack{\left. {r^{s}\hspace{0pt}{(x)}} \middle| A_{s}^{\lbrack 1\rbrack} \right. = i}\rbrack}} \\
 = & {\sum\limits_{\ell = 1}^{L}{{\Pr{\lbrack{{y_{i}\hspace{0pt}{(x)}} = \ell}\rbrack}}\hspace{0pt}{\mathbb{E}}\hspace{0pt}{\lbrack{{\left. {r^{s}\hspace{0pt}{(x)}} \middle| A_{s}^{\lbrack 1\rbrack} \right. = i},{{y_{i}\hspace{0pt}{(x)}} = \ell}}\rbrack}}} \\
 = & {{\sum\limits_{\ell = 1}^{L}{{\Pr{\lbrack{D_{s} = \left. 0 \middle| A_{s}^{\lbrack 1\rbrack} \right. = i},{{y_{i}\hspace{0pt}{(x)}} = \ell}\rbrack}}\hspace{0pt}{\Pr{\lbrack{{y_{i}\hspace{0pt}{(x)}} = \ell}\rbrack}}\hspace{0pt}{\mathbb{E}}\hspace{0pt}{\lbrack{{\left. {r^{s}\hspace{0pt}{(x)}} \middle| A_{s}^{\lbrack 1\rbrack} \right. = i},{{{y_{i}\hspace{0pt}{(x)}} = \ell},{D_{s} = 0}}}\rbrack}}} +} \\
 & {\sum\limits_{\ell = 1}^{L}{{\Pr{\lbrack{D_{s} = \left. 1 \middle| A_{s}^{\lbrack 1\rbrack} \right. = i},{{y_{i}\hspace{0pt}{(x)}} = \ell}\rbrack}}\hspace{0pt}{\Pr{\lbrack{{y_{i}\hspace{0pt}{(x)}} = \ell}\rbrack}}\hspace{0pt}{\mathbb{E}}\hspace{0pt}{\lbrack{{\left. {r^{s}\hspace{0pt}{(x)}} \middle| A_{s}^{\lbrack 1\rbrack} \right. = i},{{{y_{i}\hspace{0pt}{(x)}} = \ell},{D_{s} = 1}}}\rbrack}}}
\end{array}
```

Note that

``` math
\begin{array}{cl}
 & {{{\mathbb{E}}\hspace{0pt}{\lbrack{{\left. {r^{s}\hspace{0pt}{(x)}} \middle| A_{s}^{\lbrack 1\rbrack} \right. = i},{{{y_{i}\hspace{0pt}{(x)}} = \ell},{D_{s} = 0}}}\rbrack}} = {{\mathbb{E}}\hspace{0pt}{\lbrack{{\left. {r^{i}\hspace{0pt}{(x)}} \middle| A_{s}^{\lbrack 1\rbrack} \right. = i},{{{y_{i}\hspace{0pt}{(x)}} = \ell},{D_{s} = 0}}}\rbrack}}}
\end{array}
```

and

``` math
\begin{array}{cl}
 & {{\mathbb{E}}\hspace{0pt}{\lbrack{{\left. {r^{s}\hspace{0pt}{(x)}} \middle| A_{s}^{\lbrack 1\rbrack} \right. = i},{{{y_{i}\hspace{0pt}{(x)}} = \ell},{D_{s} = 1}}}\rbrack}} \\
 = & {\sum\limits_{j = 1}^{K}{{\Pr{\lbrack{A_{s}^{\lbrack 2\rbrack} = \left. j \middle| A_{s}^{\lbrack 1\rbrack} \right. = i},{{y_{i}\hspace{0pt}{(x)}} = \ell},{D_{s} = 1}\rbrack}}\hspace{0pt}{\mathbb{E}}\hspace{0pt}{\lbrack{{\left. {r^{s}\hspace{0pt}{(x)}} \middle| A_{s}^{\lbrack 1\rbrack} \right. = i},{{{y_{i}\hspace{0pt}{(x)}} = \ell},{{D_{s} = 1},{A_{s}^{\lbrack 2\rbrack} = j}}}}\rbrack}}} \\
 = & {\sum\limits_{j = 1}^{K}{\mathbf{Q}_{i,\ell,j}\hspace{0pt}{\mathbb{E}}\hspace{0pt}{\lbrack{{\left. {r^{s}\hspace{0pt}{(x)}} \middle| A_{s}^{\lbrack 1\rbrack} \right. = i},{{{y_{i}\hspace{0pt}{(x)}} = \ell},{{D_{s} = 1},{A_{s}^{\lbrack 2\rbrack} = j}}}}\rbrack}}}
\end{array}
```

where all qualities are simply by applying the conditional expectation formula. That is to say, conditional on the quality score $`\mathbf{Q}`$, the objective function is a linear function over $`\mathbf{P}`$ where all coefficients are positive. Similarly, we can expand the budget constraint, which turns out to be also linear in $`\mathbf{P}`$ conditional on $`\mathbf{Q}`$.

Thus, problem C.12 is a linear programming in $`\mathbf{P}`$. Therefore, its optimal value, denoted by $`F\hspace{0pt}{(\left. a \middle| \Delta_{b} \right.)}`$, must also be Lipschitz continuous in $`a`$, according to Lemma 5. In other words, we have $`|F{(a_{2}|\Delta_{b})} - F{(a_{1}|\Delta_{b})}| \leq O{(|a_{1} - a_{2}|)}`$ for any $`a_{1},a_{2},{\Delta\hspace{0pt}b}`$. When $`a = {b - {\Delta\hspace{0pt}b}}`$, its optimal value must be $`{\mathbb{E}}\hspace{0pt}{\lbrack{r^{s^{\Delta\hspace{0pt}b}}\hspace{0pt}{(x)}}\rbrack}`$, i,e., $`{{\mathbb{E}}\hspace{0pt}{\lbrack{r^{s^{\Delta\hspace{0pt}b}}\hspace{0pt}{(x)}}\rbrack}} = {F\hspace{0pt}{({b - \left. {\Delta\hspace{0pt}b} \middle| \Delta_{b} \right.})}}`$. On the other hand, note that the optimal solution corresponding to $`F\hspace{0pt}{({b - \left. \Delta_{b} \middle| 0 \right.})}`$ is also a feasible solution to the original optimization without fixing $`{{\mathbf{p}^{=}\hspace{0pt}\mathbf{p}^{0}},\mathbf{Q}} = \mathbf{Q}^{0}`$. Hence, we must have $`{{\mathbb{E}}\hspace{0pt}{\lbrack{r^{s^{\Delta\hspace{0pt}b}}\hspace{0pt}{(x)}}\rbrack}} \geq {F\hspace{0pt}{({b - \left. {\Delta\hspace{0pt}b} \middle| 0 \right.})}}`$ since the former is the optimal solution and the latter is only a feasible solution. Thus, we have

``` math
\begin{array}{cl}
 & {{{\mathbb{E}}\hspace{0pt}{\lbrack{r^{s^{0}}\hspace{0pt}{(x)}}\rbrack}} - {{\mathbb{E}}\hspace{0pt}{\lbrack{r^{s^{\Delta\hspace{0pt}b}}\hspace{0pt}{(x)}}\rbrack}}} \\
 = & {{{{{{{\mathbb{E}}\hspace{0pt}{\lbrack{r^{s^{0}}\hspace{0pt}{(x)}}\rbrack}} - {F\hspace{0pt}{(\left. b \middle| 0 \right.)}}} + {F\hspace{0pt}{(\left. b \middle| 0 \right.)}}} - {F\hspace{0pt}{({b - \left. {\Delta\hspace{0pt}b} \middle| 0 \right.})}}} + {F\hspace{0pt}{({b - \left. {\Delta\hspace{0pt}b} \middle| 0 \right.})}}} - {{\mathbb{E}}\hspace{0pt}{\lbrack{r^{s^{\Delta\hspace{0pt}b}}\hspace{0pt}{(x)}}\rbrack}}} \\
 = & {{{{F\hspace{0pt}{(\left. b \middle| 0 \right.)}} - {F\hspace{0pt}{({b - \left. {\Delta\hspace{0pt}b} \middle| 0 \right.})}}} + {F\hspace{0pt}{({b - \left. {\Delta\hspace{0pt}b} \middle| 0 \right.})}}} - {{\mathbb{E}}\hspace{0pt}{\lbrack{r^{s^{\Delta\hspace{0pt}b}}\hspace{0pt}{(x)}}\rbrack}}} \\
 \leq & {{O\hspace{0pt}{({b - {({b - {\Delta\hspace{0pt}b}})}})}} = {O\hspace{0pt}{({\Delta\hspace{0pt}b})}}}
\end{array}
```

Note that $`{{\mathbb{E}}\hspace{0pt}{\lbrack{r^{s^{0}}\hspace{0pt}{(x)}}\rbrack}} = {{\mathbb{E}}\hspace{0pt}{\lbrack{r^{s^{\ast}}\hspace{0pt}{(x)}}\rbrack}}`$, we have proved the statement. ∎

Now we can relax Theorem 16 to Theorem 3 by slightly modifying the subroutines in Algorithm 1. First, we can compute the excessive part in the cost given in Lemma 9, denoted by $`b_{e}`$. Next, for all the subroutines in Algorithm 1, replace $`b`$ by $`b - b_{e}`$ whenever applicable. Thus, the produced solution with high probability has $`{{\mathbb{E}}\hspace{0pt}{\lbrack{\gamma^{\lbrack s\rbrack}\hspace{0pt}{(x)}}\rbrack}} \leq b`$, since we already remove the $`b_{e}`$ term. By Lemma 9, $`b_{e} = {O\hspace{0pt}{(\sqrt{{({{\log\epsilon} + {\log K} + {\log L}})}/N})}}`$, which is subsumed by the accuracy drop in Theorem 16, which finishes the proof. 17

## Appendix D Experimental Details

We provide missing experimental details here.

#### Experimental Setup.

All experiments were run on a machine with 20 Intel Xeon E5-2660 2.6 GHz cores, 160 GB RAM, and 200GB disk with Ubuntu 16.04 LTS as the OS. Our code is implemented in python 3.7.

#### ML tasks and services.

Recall that We focus on three main ML tasks, namely, facial emotion recognition (FER), sentiment analysis (SA), and speech to text (STT).

FER is a computer vision task, where give a face image, the goal is to give its emotion (such as happy or sad). For FER, we use 3 different ML cloud services, Google Vision \[9\], Microsoft Face (MS Face) \[11\], and Face++\[6\]. We also use a pretrained convolutional neural network (CNN) freely available from github \[13\]. Both Microsoft Face and Face++ APIs provide a numeric value in \[0,1\] as the quality score for their predictions, while Google API gives a value in five categories, namely, “very unlikely”, “unlikely”, “possible”, “likely”, and “very likely”. We transform this categorical value into numerical value by linear interpolation, i.e., the five values correspond to 0.2, 0.4, 0.6, 0.8, 1, respectively.

SA is a natural language processing (NLP) task, where the goal is to predict if the attitude of a given text is positive or negative. For SA, the ML services used in the experiments are Google Natural Language (Google NLP) \[7\], Amazon Comprehend (AMZN Comp) \[2\], and Baidu Natural Language Processing (Baidu NLP) \[3\]. For English datasets, we use Vader \[29\], a rule-based sentiment analysis engine. For Chinese datasets, we use another rule-based sentiment analysis tool Bixin \[4\].

STT is a speech recognition task where the goal is to transform an utterance into its corresponding text. for STT, we use three common APIs: Google Speech \[8\], Microsoft Speech (MS Speech) \[12\], and IBM speech \[10\]. a deepspeech model\[14, 19\] from github is also used. Given the returned text from a API, we determine the API’s predicted label as the label with smallest edit distance to the returned text. For example, if IBM API produces “for” for a sample in AUDIOMNIST, then its label becomes “four”, since all other numbers have larger distance from the predicted text “for”.

#### Datasets.

The experiments were conducted on 12 datasets. The first four datasets, FER+\[20\], RAFDB\[35\], EXPW\[53\], and AFFECTNET\[38\] are FER datasets. The images in FER+ was originally from the FER dataset for the ICML 2013 Workshop on Challenges in Representation, and the label was recreated by crowdsourcing. We only use the testing portion of FER+, since the CNN model from github was pretrained on its training set. For RAFDB and AFFECTNET, we only use the images for basic emotions since commercial APIs cannot work for compound emotions. For EXPW, we use the true bounding box associated with the dataset to create aligned faces first, and only pick the images that are faces with confidence larger than 0.6.

For SA, we use four datasets, YELP \[18\], IMDB \[37\], SHOP \[15\], and WAIMAI \[17\]. YELP and IMDB are both English text datasets. YELP is from the YELP review challenge. Each review is associated with a rating from 1,2,3,4,5. We transform rating 1 and 2 into negative, and rating 4 and 5 into positive. Then we randomly select 10,000 positive and negative reviews, respectively. IMDB is already polarized and partitioned into training and testing parts; we use its testing part which has 25,000 images. SHOP and WAIMAI are two Chinese text datasets. SHOP contains polarized labels for reviews for various purchases (such as fruits, hotels, computers). WAIMAI is a dataset for polarized delivery reviews. We use all samples from SHOP and WAIMAI.

Finally, we use the other four datasets for STT, namely, DIGIT \[5\], AUDIOMNIST\[21\], COMMAND \[47\] and FLUENT \[36\]. Each utterance in DIGIT and AUDIOMNIST is a spoken digit (i.e., 0-9). The sampling rate is 8 kHz for DIGIT and 48 kHz for AUDIOMNIST. Each sample in COMMAND is a spoken command such as “go”, “left”, “right”, “up”, and “down”, with a sampling rate of 16 kHz. In total, there are 30 commands and a few white noise utterances. FLUENT is another recently developed dataset for speech command. The commands in FLUENT are typically a phrase (e.g., “turn on the light” or “turn down the music”). There are in total 248 possible phrases, which are mapped to 31 unique labels. The sampling rate is also 16 kHz.

#### GitHub Model Cost.

We evaluate the inference time of all GitHub models on an Amazon EC2 t2.micro instance, which is \$0.0116 per hour. The CNN model needs at most 0.016 seconds per 480 x 480 grey image, Bixin and Vader require at most 0.005 seconds for each text with less than 300 words, and DeepSpeech takes at most 0.5 seconds for each less than 15 seconds utterance. Hence, their equivalent price is \$0.0005, \$0.00016, and \$0.016 per 10,000 data points. As shown in Figure 6, the services from GitHub are much less expensive than the commercial ML services.

#### Case Study Details.

For comparison purposes, we also evaluate the performance of a mixture of experts, a simple majority vote, and a simple cascade approach on FER+ dataset. For the mixture of experts, we use softmax for the gating network, and linear model on the domain space for the feature generation. This results in a strategy that ends up with always calling the best expert Microsoft. For the simple majority vote, we first transforms each API’s confidence score $`q`$ and predicted label $`\ell`$ into its probability vector $`\mathbf{v} \in {\mathbb{R}}^{L}`$, by $`{\mathbf{v}_{\ell} = q},{{\mathbf{v}_{j} = {{({1 - q})}/{({L - 1})}}},{j \neq \ell}}`$. This can be viewed as that the API gives a distribution of all labels for the input data point. Assuming independence, we simply sum all APIs’ distributions and then produce the label with highest estimated probability. We also use a simple majority vote, where we simply return the label on which most API agrees on. For example, if GitHub (CNN), Google, and Face++ all give a label “surprise”, the no matter what Microsoft produces, we choose “surprise ” as the label. We break ties randomly.

Figure 7: Confusion matrix annotated with overall accuracy and cost on FER+ testing. The y-axis corresponds to the true label and x-axis represents the predicted label. Each entry in a confusion matrix is the likelihood that its corresponding label in x-axis is predicted given the corresponding true label in y-axis. For example, the 0.87 in (i) means that for all surprise images, FrugalML correctly predicts 87% of them as surprise,

Figure 7 shows the confusion matrix of FrugalML, along with all ML services and the other approaches (namely, mixture of experts, simple cascade, (simple majority vote), and majority vote). Among all the four services, we first note that there is an accuracy disparity for different facial emotions. In fact, GitHub (CNN) gives the highest accuracy on anger images (0.73%), fear (0.81%), happy (0.90%) and sad (0.60%), Face++ is best at disgust emotion (0.60%) and surprise (0.85%), while Microsoft is best at neutral (90%). Meanwhile, GitHub (CNN) gives a poor performance for neutral images, Face++ can hardly tell the differences between fear and surprise, and Google has a hard time distinguishing between anger and disgust images. This implies bias (and thus strength and weakness) from each ML API, leading to opportunities for optimization. We would also like to note that such biases may be of independent interest and explored for fairness study in the future.

We notice that the mixture of expert approach has the same confusion matrix as the Microsoft API. This is because the simple mixture of experts simply learns to always use the Microsoft API. Noting that we use a simple linear gating on the raw image space, this probably implies that Microsoft API has the best performance on any subspace in the raw image space produced by any hyperplane. More complicated mixture of experts approaches may lead to better performance, but requires more training complexity. Again, unlike FrugalML, mixture of experts does not allow users to specify their own budget/accuracy constraints.

Simple cascade approach allows accuracy cost trade-offs. As shown in Figure 6(f), while reaching the same accuracy as the best commercial API (Microsoft), it only asks for half of the cost. In fact, simple cascade uses GitHub (CNN) and Microsoft as the base service and add-on service with a fixed threshold for all labels. As a result, compared to Microsoft API, the prediction accuracy of neutral images drops significantly, while the accuracy on all the other labels increases, and thus resulting in the same accuracy.

FrugalML, also with half of the cost of Microsoft API, actually gives an accuracy (84%) even higher than that of Microsoft API (81%). In fact, FrugalML identifies that only a vert small portion of images are disgust, and thus slightly sacrifices the accuracy on disgust images to improve the accuracy on all the other images. Compared to the simple cascade approach in Figure 6 (f), FrugalML, as shown in Figure 6 (i), produces higher accuracy on all classes of images except disgust images. Compared to Microsoft API (Figure 6), FrugalML slightly hurts the accuracy on fear, sad, and neutral images, but significantly improve the accuracy on happy and other images. Note that the strategy learned by FrugalML depends on the data distribution. As shown in Figure 8, most images are neutral and happy, and thus a slight drop on neutral images is worthy in exchange of a large improvement on happy images. Depending on the training data distribution, FrugalML may have learned different strategies as well.

Finally we note that while (simple) majority vote gives a poor accuracy (80% in Figure 7 (g)), the majority vote approach does lead to an accuracy (82%) higher than Microsoft API, although it is still lower than FrugalML’s accuracy (84%). In addition, ensemble methods like majority vote need access to all ML APIs, and thus requires a cost of 30\$, which is 5 times as large as the cost of FrugalML. Hence, they may not help reduce the cost effectively.
