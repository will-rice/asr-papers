# Performance of the Bounded Distance Decoder on the AWGN Channel

Kenneth Andrews and Sam Dolinar¹¹footnotemark: 1 Jet Propulsion
Laboratory, California Institute of Technology, Pasadena, CA, USA  
e-mail: {andrews,sam}@shannon.jpl.nasa.gov

Kenneth Andrews and Sam Dolinar¹¹ 1 © 2012 California Institute of

Jet Propulsion Laboratory, California Institute of Technology, Pasadena,

e-mail: {andrews,sam}@shannon.jpl.nasa.gov

Abstract — In contrast to a maximum-likelihood decoder, it is often
desirable to use an incomplete decoder that can detect its decoding
errors with high probability. One common choice is the bounded distance
decoder. Bounds are derived for the total word error rate, $`P_{w}`$,
and the undetected error rate, $`P_{u}`$. Excellent agreement is found
with simulation results for a small code, and the bounds are shown to be
tractable for a larger code.

I. Introduction

Error correcting codes are used in many settings where it is desirable
to correct errors when it can be done sufficiently reliably, and to
report a decoding failure when it cannot. In spacecraft telecommand, for
example, it is far preferable to discard a command than it is to deliver
one that has a significant probability of being incorrect.

Three classes of incomplete decoders were considered in
\[[1](#bib.bib1)\]: the optimal Bounded Reciprocal Likelihood Ratio
(BRLR) decoder, the Bounded Angle (BA) decoder, and the Bounded Distance
(BD) decoder. The BA decoder was further studied in \[[2](#bib.bib2),
[3](#bib.bib3)\], but the bounds are difficult to use. While the BD
decoder does not perform especially well, it is an important class of
decoders, and practical performance bounds can be derived.

The “amount of incompleteness” of a BD decoder can be set by its
decoding radius $`r_{d}`$. It is commonly agreed that a BD decoder
reports a decoding failure if no codeword lies within $`r_{d}`$ of the
received noisy vector $`\mathbf{y}`$, and if a single codeword lies
within $`r_{d}`$, the decoder returns that result. If
$`r_{d}\geq d_{\min}/2`$, more than one codeword may lie within
$`r_{d}`$, and in this paper, we specify that the BD decoder returns the
closest codeword. Thus, the BD decoder asymptotically becomes the
Maximum Likelihood (ML) decoder as $`r_{d}`$ is made large.

II. Performance Bounds

The BD decoder returns three outcomes: it finds the correct codeword
with probability $`P_{c}`$, it makes an undetected error and returns an
incorrect codeword with probability $`P_{u}`$, and it declares a
decoding failure with probability $`P_{f}`$. Here, we derive upper
bounds for $`P_{u}`$ and for the total word error rate
$`P_{w}=P_{u}+P_{f}`$, each as functions of $`r_{d}`$ and the bit Signal
to Noise Ratio $`E_{b}/N_{0}`$.

Figure 1: Geometry of the Bounded Distance Decoder

We consider an $`(n,k)`$ code with rate $`R=k/n`$. Let the code have
codewords $`\mathbf{x}_{i}`$, $`0\leq i<2^{k}`$. Suppose
$`\mathbf{x}_{0}`$ is transmitted, and is received as
$`\mathbf{y}=\mathbf{x}_{0}+\mathbf{N}`$, where each of the $`n`$
components of $`\mathbf{N}`$ are zero-mean Gaussian variables with
variance $`\sigma^{2}=1/(2RE_{b}/N_{0})`$. The geometry of the BD
decoder is shown in Figure
[1](#S2.F1 "Figure 1 ‣ Performance of the Bounded Distance Decoder on the AWGN Channel"),
where shaded spheres of radius $`r_{d}`$ are shown around codeword
$`x_{0}`$ and another representative codeword $`x_{i}`$. An undetected
error occurs if $`\mathbf{y}`$ lands in a shaded region outside
$`x_{0}`$’s Voronoi cell (shown in bold black lines), and a word error
also occurs if $`\mathbf{y}`$ lands in an unshaded region. That is,

|     |     |     |
| --- | --- | --- |
|     |

       ``` math
       P_{w}=P_{u}^{<}(r_{d})+P_{tot}^{>}(r_{d})
       ```                                        |     |

|     |     |     |
| --- | --- | --- |
|     |

       ``` math
       P_{u}=P_{u}^{<}(r_{d})+P_{u}^{>}(r_{d})
       ```                                      |     |

The constituent probabilities can be computed as integrals of the
surface areas of caps of $`n`$-dimensional spheres (or $`n`$-sphere).
The surface area of an $`n`$-sphere of radius $`r`$ is

|     |     |     |
| --- | --- | --- |
|     |

       ``` math
       S_{n}(r)=\frac{2\pi^{n/2}}{\Gamma(n/2)}r^{n-1}.
       ```                                              |     |

The surface area of the cap of an $`n`$-sphere with polar half-angle
$`\phi`$ and radius $`r`$ is

|     |     |     |
| --- | --- | --- |
|     |

````math
S_{n}(r,\phi)=\frac{1}{2}S_{n}(r)I_{\sin^{2}\phi}\left(\frac{n-1}{2},\frac{1}{2}\right)
``` |  |

where $`I`$ is the regularized incomplete beta function
\[[4](#bib.bib4)\].

The probability density of receiving $`\mathbf{y}`$ when
$`\mathbf{x_{0}}`$ is transmitted is

|  |  |  |
|----|----|----|
|  |
``` math
p(\mathbf{y}|\mathbf{x_{0}})=\frac{1}{(\sigma\sqrt{2\pi})^{n}}e^{-||\mathbf{y}-\mathbf{x_{0}}||^{2}/2\sigma^{2}}.
``` |  |

Hence, the probability density that $`||\mathbf{y}-\mathbf{x}_{0}||=r`$
is

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle p_{0}(r)`$ | $`\displaystyle=`$ | $`\displaystyle S_{n}(r)\sigma^{-n}(2\pi)^{-n/2}e^{-r^{2}/2\sigma^{2}}`$ |  |
|  |  | $`\displaystyle=`$ | $`\displaystyle\frac{2^{1-n/2}}{\Gamma(n/2)}\sigma^{-n}r^{n-1}e^{-r^{2}/2\sigma^{2}}`$ |  |
|  |  | $`\displaystyle=`$ | $`\displaystyle\frac{1}{\sigma}f\left(\frac{r}{\sigma},n\right)`$ |  |

where $`f`$ is the PDF of the $`\chi`$-distribution.

Now we can work out the component probabilities.

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle P_{tot}^{>}(r_{d})`$ | $`\displaystyle=`$ | $`\displaystyle\int_{r_{d}}^{\infty}p_{0}(r)\ dr`$ |  |
|  |  | $`\displaystyle=`$ | $`\displaystyle 1-\frac{1}{\sigma}\int_{0}^{r_{d}}f\left(\frac{r}{\sigma},n\right)\ dr`$ |  |
|  |  | $`\displaystyle=`$ | $`\displaystyle 1-F\left(\frac{r_{d}}{\sigma},n\right)`$ |  |
|  |  | $`\displaystyle=`$ | $`\displaystyle Q\left(\frac{n}{2},\frac{r_{d}^{2}}{2\sigma^{2}}\right)`$ |  |

where $`F`$ is the CDF of the $`\chi`$-distribution and $`Q`$ is the
regularized Gamma function.

By a union bound over all incorrect codewords $`x_{i}`$, we have

|  |  |  |  |
|----|----|----|----|
|  |
``` math
P_{u}^{<}(r_{d})\leq\sum_{i\neq 0}\mathrm{Pr}(r_{i}\leq r_{0}\leq r_{d})
``` |  | (1) |

From Figure
[1](#S2.F1 "Figure 1 ‣ Performance of the Bounded Distance Decoder on the AWGN Channel"),
we have,

|  |  |  |
|----|----|----|
|  |
``` math
\mathrm{Pr}(r_{i}\leq r_{0}\leq r_{d})=\left\{\hskip-3.0pt\begin{array}[]{ll}\displaystyle\int_{\sqrt{w_{i}}}^{r_{d}}p_{0}(r)\frac{S_{n}(r,\phi_{i}(r))}{S_{n}(r)}\ dr&\mbox{if }\sqrt{w_{i}}\leq r_{d}\\
0&\mbox{otherwise}\end{array}\right.
``` |  |

where $`S_{n}(r,\phi_{i}(r))`$ is the surface area of the hyperspherical
cap of radius $`r`$ and half-angle $`\phi_{i}(r)`$. Note that
$`||\mathbf{x_{0}}-\mathbf{x_{i}}||/2=\sqrt{w_{i}}`$, where $`w_{i}`$ is
the Hamming weight of $`\mathbf{x_{i}}`$, and
$`\cos\phi_{i}(r)=\sqrt{w_{i}}/r`$. Substituting into
([1](#S2.E1 "In Performance of the Bounded Distance Decoder on the AWGN Channel")),

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle P_{u}^{<}(r_{d})`$ | $`\displaystyle\leq`$ | $`\displaystyle\sum_{\begin{subarray}{c}i\neq 0\\
\sqrt{w_{i}}\leq r_{d}\end{subarray}}\int_{\sqrt{w_{i}}}^{r_{d}}p_{0}(r)\frac{S_{n}(r,\phi_{i}(r))}{S_{n}(r)}\ dr`$ |  |
|  |  | $`\displaystyle=`$ | $`\displaystyle\sum_{\begin{subarray}{c}i\neq 0\\
w_{i}\leq r_{d}^{2}\end{subarray}}\int_{\sqrt{w_{i}}}^{r_{d}}\frac{1}{2}p_{0}(r)I_{1-w_{i}/r^{2}}\left(\frac{n-1}{2},\frac{1}{2}\right)\ dr`$ |  |
|  |  | $`\displaystyle=`$ | $`\displaystyle\sum_{w=d_{\min}}^{\min(n,r_{d}^{2})}\frac{A_{w}}{2}\int_{\sqrt{w}}^{r_{d}}p_{0}(r)I_{1-w/r^{2}}\left(\frac{n-1}{2},\frac{1}{2}\right)\ dr`$ |  |

where $`A_{d}`$ is the code’s weight enumerator and $`d_{\min}`$ is the
code’s minimum distance.

Likewise, we can compute $`P_{u}^{>}(r_{d})`$ from a union bound over
all incorrect codewords $`x_{i}`$:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
P_{u}^{>}(r_{d})\leq\sum_{i\neq 0}\mathrm{Pr}(r_{i}\leq r_{d}<r_{0})
``` |  | (2) |

For each $`i`$,

|  |  |  |
|----|----|----|
|  |
``` math
\mathrm{Pr}(r_{i}\leq r_{d}<r_{0})=\int_{\max(r_{d},2\sqrt{w_{i}}-r_{d})}^{2\sqrt{w_{i}}+r_{d}}p_{0}(r)\frac{S_{n}(r,\phi_{i}(r))}{S_{n}(r)}\ dr
``` |  |

where in this case the half-angle of the spherical cap is given by the
law of cosines:

|  |  |  |
|----|----|----|
|  |
``` math
r_{d}^{2}=(2\sqrt{w_{i}})^{2}+r^{2}-2(2\sqrt{w_{i}})(r)\cos\phi_{i}(r)
``` |  |

Substituting into
([2](#S2.E2 "In Performance of the Bounded Distance Decoder on the AWGN Channel"))
we have,

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle P_{u}^{>}(r_{d})\leq\sum_{i\neq 0}\int_{\max(r_{d},2\sqrt{w_{i}}-r_{d})}^{2\sqrt{w_{i}}+r_{d}}p_{0}(r)\frac{S_{n}(r,\phi_{i}(r))}{S_{n}(r)}\ dr`$ |  |  |  |
|  |  |  | $`\displaystyle=\sum_{i\neq 0}\int_{\max(r_{d},2\sqrt{w_{i}}-r_{d})}^{2\sqrt{w_{i}}+r_{d}}\frac{1}{2}p_{0}(r)I_{\sin^{2}\phi_{i}(r)}\left(\frac{n-1}{2},\frac{1}{2}\right)\ dr`$ |  |
|  |  |  | $`\displaystyle\hskip-15.0pt=\sum_{w=d_{\min}}^{n}\frac{A_{w}}{2}\int_{\max(r_{d},2\sqrt{w}-r_{d})}^{2\sqrt{w}+r_{d}}p_{0}(r)I_{\sin^{2}\phi_{w}(r)}\left(\frac{n-1}{2},\frac{1}{2}\right)\ dr`$ |  |

where

|  |  |  |
|----|----|----|
|  |
``` math
\sin^{2}\phi_{w}(r)=1-\left(\frac{r^{2}-r_{d}^{2}+4w}{4r\sqrt{w}}\right)^{2}
``` |  |

III. Examples

The (8,4) extended Hamming code has $`n=8`$, $`k=4`$, $`d_{\min}=4`$,
and weight distribution $`A_{w}=\{1,0,0,0,14,0,0,0,1\}`$ for
$`w=\{0,\ldots,8\}`$. The equations in Section Performance of the
Bounded Distance Decoder on the AWGN Channel were evaluated for this
code using Mathematica for $`E_{b}/N_{0}=6.7`$ dB (for which an ML
decoder achieves $`P_{w}\approx 10^{-4}`$), and are plotted as curves in
Figure
[2](#S3.F2 "Figure 2 ‣ Performance of the Bounded Distance Decoder on the AWGN Channel").
Computer simulations were run for $`10^{10}`$ codewords, and the error
rates are plotted as points. The black curve for $`P_{tot}^{>}`$ is
exact; the others are upper bounds that are evidently good except where
$`P_{u}^{>}`$ is small.

Figure 2: Bounds and simulation results for the (8,4) extended Hamming
code

A set of small rate-1/2 LDPC codes was developed for spacecraft
telecommand \[[5](#bib.bib5)\]. For the $`(128,64)`$ code, computer
search shows $`d_{\min}=14`$ and the weight enumerator is approximately
$`A_{w}=\{16,0,512,0,5344,0,\ldots\}`$ for $`w=\{14,15,\ldots\}`$. An
LDPC decoder detects most of its errors, and its incompleteness can be
adjusted by varying the number of iterations performed. While an LDPC
decoder is not a BD decoder, its performance for this code is well
predicted by the equations derived here.
