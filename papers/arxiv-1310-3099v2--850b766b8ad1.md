###### Abstract

This article provides a unifying Bayesian network view on various
approaches for acoustic model adaptation, missing feature, and
uncertainty decoding that are well-known in the literature of robust
automatic speech recognition. The representatives of these classes can
often be deduced from a Bayesian network that extends the conventional
hidden Markov models used in speech recognition. These extensions, in
turn, can in many cases be motivated from an underlying observation
model that relates clean and distorted feature vectors. By converting
the observation models into a Bayesian network representation, we
formulate the corresponding compensation rules leading to a unified view
on known derivations as well as to new formulations for certain
approaches. The generic Bayesian perspective provided in this
contribution thus highlights structural differences and similarities
between the analyzed approaches.

###### Index Terms: 

robust automatic speech recognition, Bayesian network, model adaptation,
missing feature, uncertainty decoding

## I Introduction

Robust Automatic Speech Recognition (ASR) still represents a challenging
research topic. The main obstacle, namely the mismatch of test and
training data, can be tackled by enhancing the observed speech signals
or features in order to meet the training conditions or by compensating
for the distorted test conditions in the acoustic model of the ASR
system.

Methods that modify the acoustic model are in general termed (acoustic)
model-based or model compensation approaches and comprise inter alia the
following sub-categories: So-called model adaptation techniques mostly
update the parameters of the acoustic model, i.e., of the Hidden Markov
Models (HMMs), prior to the decoding of a set of observed feature
vectors. In contrast, decoder-based approaches re-adapt the HMM
parameters for each observed feature vector. The most common
decoder-based approaches are missing feature and uncertainty decoding
that incorporate additional time-varying uncertainty information into
the evaluation of the HMMs’ probability density functions (pdfs).

Various model compensation techniques exhibit two (more or less)
distinct steps that are taken interchangeably: First, the compensation
parameters need to be estimated and, second, the actual compensation
rule is applied to the acoustic model. The compensation rules can often
be motivated based on an observation model that relates the clean and
distorted feature vectors, e.g., in the logarithmic melspectral
(logmelspec) or the Mel Frequency Cepstral Coefficient (MFCC) domain.

In this article, we show how the compensation rules can be deduced from
the Bayesian network representations of the observation models for
several uncertainty decoding \[[1](#bib.bib1), [2](#bib.bib2),
[3](#bib.bib3), [4](#bib.bib4), [5](#bib.bib5)\], missing feature
\[[6](#bib.bib6), [7](#bib.bib7), [8](#bib.bib8), [9](#bib.bib9)\], and
model adaptation techniques \[[10](#bib.bib10), [11](#bib.bib11),
[12](#bib.bib12), [13](#bib.bib13), [14](#bib.bib14), [15](#bib.bib15),
[16](#bib.bib16), [17](#bib.bib17), [18](#bib.bib18),
[19](#bib.bib19)\]. In addition, we give a Bayesian network description
of the generic uncertainty decoding approach of \[[20](#bib.bib20)\], of
the Maximum A Posteriori (MAP) adaptation technique
\[[21](#bib.bib21)\], and of some alternative HMM topologies
\[[22](#bib.bib22), [23](#bib.bib23)\]. While Bayesian networks have
been sporadically employed in this context before \[[4](#bib.bib4),
[20](#bib.bib20), [9](#bib.bib9)\], with this article, we give new
formulations for certain of the considered algorithms in order to fill
some gaps for a unified description.

Throughout the following, feature vectors are denoted by bold-face
letters $`\mathbf{v}_{n}`$ with time index $`n\in\{1,...,N\}`$. Feature
vector sequences are written as
$`\mathbf{v}_{1:N}=(\mathbf{v}_{1},...,\mathbf{v}_{N})`$. Without
distinguishing a random variable from its realization, a pdf over a
random variable $`z_{n}`$ is denoted by $`p(z_{n})`$. For a normally
distributed real-valued random vector $`\mathbf{z}_{n}`$ with mean
vector $`\boldsymbol{\mu}_{\mathbf{z}_{n}}`$ and covariance matrix
$`\mathbf{C}_{\mathbf{z}_{n}}`$, we write
$`\mathbf{z}_{n}\sim\mathcal{N}(\boldsymbol{\mu}_{\mathbf{z}_{n}},\mathbf{C}_{\mathbf{z}_{n}})`$
or

|     |     |     |     |
| --- | --- | --- | --- |
|     |

````math
p(\mathbf{z}_{n})=\mathcal{N}(\mathbf{z}_{n};\boldsymbol{\mu}_{\mathbf{z}_{n}},\mathbf{C}_{\mathbf{z}_{n}}).
``` |  | (1) |

To express that all random vectors of the set
$`\{\mathbf{z}_{1},...,\mathbf{z}_{N}\}`$ share the same statistics, we
write $`p(\mathbf{z}_{n})={\rm const.}`$ or, in the Gaussian case,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
p(\mathbf{z}_{n})=\mathcal{N}(\mathbf{z}_{n};\boldsymbol{\mu}_{\mathbf{z}},\mathbf{C}_{\mathbf{z}})
``` |  | (2) |

with time-invariant mean vector $`\boldsymbol{\mu}_{\mathbf{z}}`$ and
covariance matrix $`\mathbf{C}_{\mathbf{z}}`$. Finally, for a Gaussian
random vector $`\mathbf{z}_{n}`$ conditioned on another random vector
$`\mathbf{w}_{n}`$, we write

|  |  |  |  |
|----|----|----|----|
|  |
``` math
p(\mathbf{z}_{n}|\mathbf{w}_{n})=\mathcal{N}(\mathbf{z}_{n};\boldsymbol{\mu}_{\mathbf{z}|\mathbf{w}_{n}},\mathbf{C}_{\mathbf{z}|\mathbf{w}_{n}}),
``` |  | (3) |

if the statistics of $`\mathbf{z}_{n}`$ depend only on time through
$`\mathbf{w}_{n}`$, i.e., if
$`\boldsymbol{\mu}_{\mathbf{z}|\mathbf{w}_{n}}=\boldsymbol{\mu}_{\mathbf{z}|\mathbf{w}_{m}}`$
and
$`\mathbf{C}_{\mathbf{z}|\mathbf{w}_{n}}=\mathbf{C}_{\mathbf{z}|\mathbf{w}_{m}}`$
for $`\mathbf{w}_{n}=\mathbf{w}_{m}`$ and $`n,m\in\{1,...,N\}`$.

The remainder of the article is organized as follows: After summarizing
the employed Bayesian network view in
Section [II](#S2 "II A Bayesian Network View ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")
and its difference to existing overview articles in
Section [III](#S3 "III Merit of the Bayesian Network View ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"),
this perspective is applied to uncertainty decoding, missing feature
techniques, and other model-based approaches in
Section [IV](#S4 "IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition").
Finally, conclusions are drawn in
Section [V](#S5 "V Summary ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition").

## II A Bayesian Network View

We start by reviewing the Bayesian network perspective on acoustic
model-based techniques that we use in
Section [IV](#S4 "IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")
to compare different algorithms.

Given a sequence of observed feature vectors $`\mathbf{y}_{1:N}`$, the
acoustic score $`p(\mathbf{y}_{1:N}|\mathbf{W})`$ of a sequence
$`\mathbf{W}`$ of conventional HMMs, as depicted in
Figure [1](#S2.F1 "Fig. 1 ‣ II A Bayesian Network View ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(a),
is given by \[[24](#bib.bib24)\]

|  |  |  |  |  |  |
|----|----|----|----|----|----|
|  | $`\displaystyle p(\mathbf{y}_{1:N}|\mathbf{W})\hskip-7.11317pt`$ | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\sum_{q_{1:N}}p(\mathbf{y}_{1:N},q_{1:N})`$ |  | (4) |
|  |  | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\sum_{q_{1:N}}\bigg\{\prod_{n=1}^{N}p(\mathbf{y}_{n}|q_{n})\;p(q_{n}|q_{n-1})\bigg\},`$ |  | (5) |

where $`p(q_{1}|q_{0})=p(q_{1})`$. The summation goes over all possible
state sequences $`q_{1:N}`$ through $`\mathbf{W}`$ superseding the
explicit dependency on $`\mathbf{W}`$ at the right-hand side of
([4](#S2.E4 "In II A Bayesian Network View ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
and
([5](#S2.E5 "In II A Bayesian Network View ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")).
Note that the pdf $`p(\mathbf{y}_{n}|q_{n})`$ can be scaled by
$`p(\mathbf{y}_{n})`$ without influencing the discrimination capability
of the acoustic score w.r.t. changing word sequences $`\mathbf{W}`$. We
thus define
$`\mathring{p}(\mathbf{y}_{n}|q_{n})={p(\mathbf{y}_{n}|q_{n})}/{p(\mathbf{y}_{n})}`$
for later use.

\includegraphics

\[width=\]./HMM_UncDec_small.eps

Fig. 1: Bayesian network representation of (a) a conventional HMM and
(b) an HMM incorporating latent feature vectors. Subfigure (b) is based

The compensation rules of a wide range of model adaptation, missing
feature and uncertainty decoding approaches can be expressed by
modifying the Bayesian network structure of a conventional HMM and
applying the inference rules of Bayesian networks \[[25](#bib.bib25)\] –
potentially followed by suitable approximations to ensure mathematical
tractability. While some approaches postulate a certain Bayesian network
structure, others indirectly define a modified Bayesian network by
assuming an observed feature vector $`\mathbf{y}_{n}`$ to be a distorted
version of an underlying clean feature vector $`\mathbf{x}_{n}`$, which
is introduced as latent variable in the HMM as, e.g., in
Figure [1](#S2.F1 "Fig. 1 ‣ II A Bayesian Network View ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(b).
In the latter case, the relation of $`\mathbf{y}_{n}`$ and
$`\mathbf{x}_{n}`$ can be expressed by an analytical observation model
$`f(\cdot)`$ that incorporates certain compensation parameters
$`\mathbf{b}_{n}`$:

|     |                                                  |     |     |
|-----|--------------------------------------------------|-----|-----|
|     |
       ``` math
       \mathbf{y}_{n}=f(\mathbf{x}_{n},\mathbf{b}_{n}).
       ```                                               |     | (6) |

Note that here it is not distinguished whether $`\mathbf{y}_{n}`$ is the
output of a front-end enhancement process or a noisy or reverberant
observation that is directly fed into the recognizer. By converting the
observation model to a Bayesian network representation, the pdf
$`p(\mathbf{y}_{n}|q_{n})`$ in
([5](#S2.E5 "In II A Bayesian Network View ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
can be derived exploiting the inference rules of Bayesian networks
\[[25](#bib.bib25)\]. For the case of
Figure [1](#S2.F1 "Fig. 1 ‣ II A Bayesian Network View ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(b),
the observation likelihood in
([5](#S2.E5 "In II A Bayesian Network View ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
would, e.g., become:

|  |  |  |  |  |  |
|----|----|----|----|----|----|
|  | $`\displaystyle p(\mathbf{y}_{n}|q_{n})\hskip-7.11317pt`$ | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\int p(\mathbf{x}_{n},\mathbf{y}_{n}|q_{n})d\mathbf{x}_{n}`$ |  | (7) |
|  |  | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\int p(\mathbf{x}_{n}|q_{n})p(\mathbf{y}_{n}|\mathbf{x}_{n})d\mathbf{x}_{n},`$ |  |  |

where the actual functional form of $`p(\mathbf{y}_{n}|\mathbf{x}_{n})`$
depends on the assumptions on $`f(\cdot)`$ and the statistics
$`p(\mathbf{b}_{n})`$ of $`\mathbf{b}_{n}`$.

The abstract perspective taken in this paper reveals a fundamental
difference between model adaptation approaches on the one hand and
missing feature and uncertainty decoding approaches on the other hand:
Model adaptation techniques usually assume $`\mathbf{b}_{n}`$ to have
constant statistics over time \[[4](#bib.bib4), [26](#bib.bib26)\],
i.e.,

|     |                                                             |     |     |
|-----|-------------------------------------------------------------|-----|-----|
|     |
       ``` math
       p(\mathbf{b}_{n})={\rm const.},\mbox{ for }n\in\{1,...,N\}.
       ```                                                          |     | (8) |

or to be a deterministic parameter vector of value $`\mathbf{b}`$, i.e.,

|     |                                                      |     |     |
|-----|------------------------------------------------------|-----|-----|
|     |
       ``` math
       p(\mathbf{b}_{n})=\delta(\mathbf{b}_{n}-\mathbf{b}),
       ```                                                   |     | (9) |

where $`\delta(\cdot)`$ denotes the Dirac distribution. In contrast,
missing feature and uncertainty decoding approaches typically assume
$`p(\mathbf{b}_{n})`$ to be a time-varying pdf \[[4](#bib.bib4),
[26](#bib.bib26)\].

As exemplified in Section
[IV](#S4 "IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"),
the Bayesian network view conveniently illustrates the underlying
statistical dependencies of model-based approaches. If two approaches
share the same Bayesian network, their underlying joint pdfs over all
involved random variables share the same decomposition properties.
However, some crucial aspects are not reflected by a Bayesian network:
The particular functional form of the joint pdf, potential
approximations to arrive at a tractable algorithm, as well as the
estimation procedure for the compensation parameters. While some
approaches estimate these parameters through an acoustic front-end,
others derive them from clean or distorted data. For clarity, we
entirely focus in this article on the compensation rules while ignoring
the parameter estimation step. We also neglect approaches that apply a
modified training method to conventional HMMs without exhibiting a
distinct compensation step, as it is characteristic for, e.g., the case
for discriminative \[[27](#bib.bib27)\], multi-condition
\[[28](#bib.bib28)\] or reverberant training \[[29](#bib.bib29)\].

## III Merit of the Bayesian Network View

In the past decades, a range of survey papers and books have been
published summarizing the state-of-the-art in noise and
reverberation-robust ASR \[[30](#bib.bib30), [31](#bib.bib31),
[32](#bib.bib32), [33](#bib.bib33), [26](#bib.bib26), [34](#bib.bib34),
[35](#bib.bib35)\]. Recently, a comprehensive review of noise-robust ASR
techniques was published in \[[36](#bib.bib36)\] providing a
taxonomy-oriented framework by distinguishing whether, e.g., prior
knowledge, uncertainty processing or an explicit distortion model is
used or not. In contrast to \[[36](#bib.bib36)\] and previous survey
articles, we pursue a threefold goal with this article:

- •
  First of all, we aim at classifying all considered techniques along
  the same dimension by motivating and describing them with the same
  Bayesian network formalism. Consequently, we do not conceptually
  distinguish whether a given method employs a time-varying pdf
  $`p(\mathbf{b}_{n})`$, as in uncertainty decoding, or whether a
  distorted vector $`\mathbf{y}_{n}`$ is a preprocessed or a genuinely
  noisy or reverberant observation. Also the distinction of implicit and
  explicit observation models dissolves in our formalism.
- •
  As a second goal, we aim at closing some gaps by presenting new
  derivations and formulations for some of the considered techniques.
  For instance, the Bayesian network representations of the concepts in
  Subsections
  [C](#S4.SS3 "C Uncertainty Decoding with SPLICE ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"),
  [D](#S4.SS4 "D Joint Uncertainty Decoding ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"),
  [F](#S4.SS6 "F Ion and Haeb-Umbach ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"),
  [M](#S4.SS13 "M CMLLR ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"),
  [N](#S4.SS14 "N MLLR ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"),
  [O](#S4.SS15 "O MAP Adaptation ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"),
  [P](#S4.SS16 "P Bayesian MLLR ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"),
  [S](#S4.SS19 "S Takiguchi et al. ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"),
  and
  [T](#S4.SS20 "T Conditional HMMs [] and Combined-Order HMMs [] ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")
  of Section
  [IV](#S4 "IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")
  have not been presented so far. Moreover, the links to the Bayesian
  network framework via the formulations in
  ([37](#S4.E37 "In I Modified Imputation ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")),
  ([38](#S4.E38 "In J Significance Decoding ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")),
  ([47](#S4.E47 "In M CMLLR ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")),
  ([53](#S4.E53 "In O MAP Adaptation ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")),
  ([57](#S4.E57 "In P Bayesian MLLR ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")),
  ([63](#S4.E63 "In S Takiguchi et al. ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
  are explicitly stated for the first time in this paper.
- •
  The third goal of the Bayesian network description is to provide a
  graphical illustration that allows to easily overview a broad class of
  algorithms and to immediately identify their similarities and
  differences in terms of the underlying statistical assumptions.

By establishing new links between existing concepts, such an abstract
overview should therefore also serve as a basis for revealing and
exploring new directions. Note, however, that the review presented in
this paper does not claim to cover all relevant acoustic model-based
techniques and is rather meant as an inspiration to other researchers.

### A General Example of Uncertainty Decoding

A fundamental example of uncertainty decoding can, e.g., be extracted
from \[[37](#bib.bib37), [1](#bib.bib1), [38](#bib.bib38),
[39](#bib.bib39), [40](#bib.bib40), [41](#bib.bib41),
[42](#bib.bib42)\]. The underlying observation model can be identified
as

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathbf{y}_{n}=\mathbf{x}_{n}+\mathbf{b}_{n}\mbox{ with }\mathbf{b}_{n}\sim\mathcal{N}(\mathbf{0},\mathbf{C}_{\mathbf{b}_{n}}),`$ |  | (10) |

where $`\mathbf{y}_{n}`$ and $`\mathbf{C}_{\mathbf{b}_{n}}`$ often play
the role of an enhanced feature vector, e.g., from a Wiener filtering
front-end \[[40](#bib.bib40)\], and a measure of uncertainty from the
enhancement process, respectively. Thus, the point estimate
$`\mathbf{y}_{n}`$ can be seen as being enriched by the additional
reliability information $`\mathbf{C}_{\mathbf{b}_{n}}`$. The observation
model is representable by the Bayesian network in
Figure [2](#S4.F2 "Fig. 2 ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(a).
Exploiting the conditional independence properties of Bayesian networks
\[[25](#bib.bib25)\], the compensation of the observation likelihood in
([5](#S2.E5 "In II A Bayesian Network View ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
leads to

|  |  |  |  |  |  |
|----|----|----|----|----|----|
|  | $`\displaystyle p(\mathbf{y}_{n}|q_{n})\hskip-7.11317pt`$ | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\int p(\mathbf{x}_{n}|q_{n})p(\mathbf{y}_{n}|\mathbf{x}_{n})d\mathbf{x}_{n}`$ |  | (11) |
|  |  | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\int\mathcal{N}(\mathbf{x}_{n};\boldsymbol{\mu}_{\mathbf{x}|q_{n}},\mathbf{C}_{\mathbf{x}|q_{n}})\,\mathcal{N}(\mathbf{y}_{n};\mathbf{x}_{n},\mathbf{C}_{\mathbf{b}_{n}})d\mathbf{x}_{n}`$ |  |  |
|  |  | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\mathcal{N}(\mathbf{y}_{n};\boldsymbol{\mu}_{\mathbf{x}|q_{n}},\mathbf{C}_{\mathbf{x}|q_{n}}+\mathbf{C}_{\mathbf{b}_{n}}).`$ |  |  |

Without loss of generality, a single Gaussian pdf
$`p(\mathbf{x}_{n}|q_{n})`$ is assumed since, in the case of a Gaussian
Mixture Model (GMM), the linear mismatch function
([10](#S4.E10 "In A General Example of Uncertainty Decoding ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
can be applied to each Gaussian component separately.

### B Dynamic Variance Compensation

The concept of dynamic variance compensation \[[2](#bib.bib2)\] is based
on a reformulation of the log-sum observation model
\[[39](#bib.bib39)\]:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathbf{y}_{n}=\mathbf{x}_{n}+\log(1+\exp(\widehat{\mathbf{r}}_{n}-\mathbf{x}_{n}))+\mathbf{b}_{n}`$ |  | (12) |

with $`\widehat{\mathbf{r}}_{n}`$ being a noise estimate of any noise
tracking algorithm and
$`\mathbf{b}_{n}\sim\mathcal{N}(\mathbf{0},\mathbf{C}_{\mathbf{b}_{n}})`$
a residual error term. Since the analytical derivation of
$`p(\mathbf{y}_{n}|q_{n})`$ is intractable, an approximate pdf is
evaluated based on the assumption of
$`p(\mathbf{x}_{n}|\mathbf{y}_{n})`$ being Gaussian and that the
compensation can be applied to each Gaussian component of the GMM
separately \[[2](#bib.bib2)\] such that the observation likelihood in
([5](#S2.E5 "In II A Bayesian Network View ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
becomes according to
Figure [2](#S4.F2 "Fig. 2 ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(a):

|  |  |  |  |  |  |
|----|----|----|----|----|----|
|  | $`\displaystyle\mathring{p}(\mathbf{y}_{n}|q_{n})\hskip-7.11317pt`$ | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\int p(\mathbf{x}_{n}|q_{n})\frac{p(\mathbf{x}_{n}|\mathbf{y}_{n})}{p(\mathbf{x}_{n})}d\mathbf{x}_{n}`$ |  | (13) |
|  |  | $`\displaystyle\approx`$ | $`\displaystyle\hskip-7.11317pt\int p(\mathbf{x}_{n}|q_{n})p(\mathbf{x}_{n}|\mathbf{y}_{n})d\mathbf{x}_{n}`$ |  |  |
|  |  | $`\displaystyle\approx`$ | $`\displaystyle\hskip-7.11317pt\int\mathcal{N}(\mathbf{x}_{n};\boldsymbol{\mu}_{\mathbf{x}|q_{n}},\mathbf{C}_{\mathbf{x}|q_{n}})`$ |  |  |
|  |  |  | $`\displaystyle\hskip-7.11317pt\mathcal{N}(\mathbf{x}_{n};\boldsymbol{\mu}_{\mathbf{x}|\mathbf{y}_{n}},\mathbf{C}_{\mathbf{x}|\mathbf{y}_{n}})d\mathbf{x}_{n}`$ |  |  |
|  |  | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\mathcal{N}(\boldsymbol{\mu}_{\mathbf{x}|q_{n}};\boldsymbol{\mu}_{\mathbf{x}|\mathbf{y}_{n}},\mathbf{C}_{\mathbf{x}|q_{n}}+\mathbf{C}_{\mathbf{x}|\mathbf{y}_{n}}),`$ |  |  |

### C Uncertainty Decoding with SPLICE

The Stereo Piecewise LInear Compensation for Environment (SPLICE)
approach, first introduced in \[[43](#bib.bib43)\] and further developed
in \[[44](#bib.bib44), [45](#bib.bib45)\], is a popular method for
cepstral feature enhancement based on a mapping learned from stereo
(i.e., clean and noisy) data \[[36](#bib.bib36)\]. While SPLICE can be
used to derive an Minimum Mean Square Error (MMSE) \[[44](#bib.bib44)\]
or MAP \[[43](#bib.bib43)\] estimate that is fed into the recognizer, it
is also applicable in the context of uncertainty decoding
\[[3](#bib.bib3)\], which we focus on in the following. In order to
derive a Bayesian network representation of the uncertainty decoding
version of SPLICE \[[3](#bib.bib3)\], we first note from
\[[3](#bib.bib3)\] that one fundamental assumption is:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle p(\mathbf{x}_{n}|\mathbf{y}_{n},s_{n})=\mathcal{N}(\mathbf{x}_{n};\mathbf{y}_{n}+\mathbf{r}_{s_{n}},\boldsymbol{\Gamma}_{s_{n}}),`$ |  | (14) |

where $`s_{n}`$ denotes a discrete region index. Exploiting the symmetry
of the Gaussian pdf

|  |  |  |  |  |  |
|----|----|----|----|----|----|
|  | $`\displaystyle p(\mathbf{x}_{n}|\mathbf{y}_{n},s_{n})\hskip-7.11317pt`$ | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\mathcal{N}(\mathbf{x}_{n};\mathbf{y}_{n}+\mathbf{r}_{s_{n}},\boldsymbol{\Gamma}_{s_{n}})`$ |  | (15) |
|  |  | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\mathcal{N}(\mathbf{y}_{n}-\mathbf{x}_{n};-\mathbf{r}_{s_{n}},\boldsymbol{\Gamma}_{s_{n}})`$ |  |  |

and defining $`\mathbf{b}_{n}=\mathbf{y}_{n}-\mathbf{x}_{n}`$, we
identify the observation model to be

|     |                                              |     |      |
|-----|----------------------------------------------|-----|------|
|     |
       ``` math
       \mathbf{y}_{n}=\mathbf{x}_{n}+\mathbf{b}_{n}
       ```                                           |     | (16) |

given a certain region index $`s_{n}`$. In the general case of $`s_{n}`$
depending on $`\mathbf{x}_{n}`$, the observation model can be expressed
by the Bayesian network in
Figure [2](#S4.F2 "Fig. 2 ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(b)
with

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle p(\mathbf{b}_{n}|s_{n})=\mathcal{N}(\mathbf{b}_{n};-\mathbf{r}_{s_{n}},\boldsymbol{\Gamma}_{s_{n}}).`$ |  | (17) |

By introducing a separate prior model

|  |  |  |  |  |  |
|----|----|----|----|----|----|
|  | $`\displaystyle p(\mathbf{y}_{n})\hskip-7.11317pt`$ | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\sum_{s_{n}}p(s_{n})\,p(\mathbf{y}_{n}|s_{n})`$ |  | (18) |
|  |  | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\sum_{s_{n}}p(s_{n})\,\mathcal{N}(\mathbf{y}_{n};\boldsymbol{\mu}_{\mathbf{y}|s_{n}},\mathbf{C}_{\mathbf{y}|s_{n}}),`$ |  |  |

for the distorted speech $`\mathbf{y}_{n}`$, the likelihood in
([5](#S2.E5 "In II A Bayesian Network View ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
can be adapted according to

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\hskip 9.10486ptp(\mathbf{y}_{n}|q_{n})=\int p(\mathbf{x}_{n}|q_{n})p(\mathbf{y}_{n}|\mathbf{x}_{n})d\mathbf{x}_{n}`$ |  |

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\int p(\mathbf{x}_{n}|q_{n})\frac{p(\mathbf{x}_{n},\mathbf{y}_{n})}{p(\mathbf{x}_{n})}d\mathbf{x}_{n}`$ |  |
|  |  | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\int p(\mathbf{x}_{n}|q_{n})\frac{\sum_{s_{n}}p(\mathbf{x}_{n}|\mathbf{y}_{n},s_{n})p(\mathbf{y}_{n}|s_{n})p(s_{n})}{\sum_{s_{n}}\int p(\mathbf{x}_{n}|\mathbf{y}_{n},s_{n})p(\mathbf{y}_{n}|s_{n})p(s_{n})d\mathbf{y}_{n}}d\mathbf{x}_{n}.`$ |  |

Although analytically tractable, both the numerator and the denominator
in () are typically approximated for the sake of runtime efficiency

### D Joint Uncertainty Decoding

Model-based joint uncertainty decoding \[[4](#bib.bib4)\] assumes an
affine observation model in the cepstral domain

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathbf{y}_{n}=\mathbf{A}_{k_{n}}\mathbf{x}_{n}+\mathbf{b}_{n}`$ |  | (20) |

with the deterministic matrix $`\mathbf{A}_{k_{n}}`$ and
$`p(\mathbf{b}_{n}|k_{n})=\mathcal{N}(\mathbf{b}_{n};\boldsymbol{\mu}_{\mathbf{b}|k_{n}},\mathbf{C}_{\mathbf{b}|k_{n}})`$
depending on the considered Gaussian component $`k_{n}`$ of the GMM of
the current HMM state $`q_{n}`$:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle p(\mathbf{x}_{n}|q_{n})=\sum_{k_{n}}p(k_{n})p(\mathbf{x}_{n}|k_{n}).`$ |  | (21) |

The Bayesian network is depicted in
Figure [2](#S4.F2 "Fig. 2 ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(c)
implying the following compensation rule:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle p(\mathbf{y}_{n}|k_{n})=\int p(\mathbf{x}_{n}|k_{n})p(\mathbf{y}_{n}|\mathbf{x}_{n},k_{n})d\mathbf{x}_{n},`$ |  | (22) |

which can be analytically derived analogously to
([11](#S4.E11 "In A General Example of Uncertainty Decoding ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")).
In practice, the compensation parameters
$`\mathbf{A}_{k_{n}},\boldsymbol{\mu}_{\mathbf{b}|k_{n}},\mathbf{C}_{\mathbf{b}|k_{n}}`$
are not estimated for each Gaussian component $`k_{n}`$ but for each
regression class comprising a set of Gaussian components
\[[4](#bib.bib4)\].

### E REMOS

\includegraphics

\[width=0.8\]./GraphModel_REMOS_singleBullet.eps

Fig. 3: Bayesian network representation of the REMOS concept
(Subsection [IV](#S4 "IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")-[E](#S4.SS5 "E REMOS ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")).
The figure is based on \[[5](#bib.bib5)\].

As many other techniques, the Reverberation Modeling for Speech
Recognition (REMOS) concept \[[46](#bib.bib46), [5](#bib.bib5)\] assumes
the environmental distortion to be additive in the melspectral domain.
However, REMOS also considers the influence of the $`L`$ previous clean
speech feature vectors $`\mathbf{x}_{n-L:n-1}`$ in order to model the
dispersive effect of reverberation and to relax the conditional
independence assumption of conventional HMMs. The observation model
reads in the logmelspec domain:

|  |  |  |  |  |  |
|----|----|----|----|----|----|
|  | $`\displaystyle\mathbf{y}_{n}\hskip-7.11317pt`$ | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\log\bigg(\exp(\mathbf{c}_{n})+\exp(\mathbf{h}_{n}+\mathbf{x}_{n})`$ |  | (23) |
|  |  |  | $`\displaystyle\hskip-7.11317pt+\exp(\mathbf{a}_{n})\;\sum_{l=1}^{L}{\exp({\boldsymbol{\mu}}_{l}+\mathbf{x}_{n-l})}\bigg),`$ |  |  |

where the normally distributed random variables
$`\mathbf{c}_{n},\mathbf{h}_{n},\mathbf{a}_{n}`$ model the additive
noise components, the early part of the room impulse response (RIR), and
the weighting of the late part of the RIR, respectively, and the
parameters $`{\boldsymbol{\mu}}_{1:L}`$ represent a deterministic
description of the late part of the RIR. The Bayesian network is
depicted in
Figure [3](#S4.F3 "Fig. 3 ‣ E REMOS ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")
with $`\mathbf{b}_{n}=[\mathbf{c}_{n},\mathbf{a}_{n},\mathbf{h}_{n}]`$.
In contrast to most of the other compensation rules discussed in this
article, the REMOS concept necessitates a modification of the Viterbi
decoder due to the introduced cross-connections in
Figure [3](#S4.F3 "Fig. 3 ‣ E REMOS ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition").
In order to arrive at a computationally feasible decoder, the
marginalization over the previous clean speech components
$`\mathbf{x}_{n-L:n-1}`$ is circumvented by employing estimates
$`\widehat{\mathbf{x}}_{n-L:n-1}(q_{n-1})`$ that depend on the best
partial path, i.e., on the previous HMM state $`q_{n-1}`$. The resulting
analytically intractable integral is then approximated by the maximum of
its integrand:

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\hskip 9.10486ptp(\mathbf{y}_{n}|q_{n},\widehat{\mathbf{x}}_{n-L:n-1}(q_{n-1}))=`$ |  |

|  |  |  |  |  |  |
|----|----|----|----|----|----|
|  |  | $`\displaystyle=`$ | $`\displaystyle\int p(\mathbf{y}_{n}|\mathbf{x}_{n},\widehat{\mathbf{x}}_{n-L:n-1}(q_{n-1}))p(\mathbf{x}_{n}|q_{n})d\mathbf{x}_{n}`$ |  | (24) |
|  |  | $`\displaystyle\geq`$ | $`\displaystyle\max_{\mathbf{x}_{n}}\;p(\mathbf{y}_{n}|\mathbf{x}_{n},\widehat{\mathbf{x}}_{n-L:n-1}(q_{n-1}))p(\mathbf{x}_{n}|q_{n}).`$ |  |  |

The determination of a global solution to
([24](#S4.E24 "In E REMOS ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
represents the core of the REMOS concept. The estimates
$`\widehat{\mathbf{x}}_{n-L:n-1}(q_{n-1})`$ in turn are the solutions to
([24](#S4.E24 "In E REMOS ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
at previous time steps. We refer to \[[5](#bib.bib5)\] for a detailed
derivation of the corresponding decoding routine.

### G Feature Vector Imputation

We next turn to missing feature techniques, which can be used to model
feature distortion due to a front-end enhancement process
\[[7](#bib.bib7)\], noise \[[47](#bib.bib47)\] or reverberation
\[[48](#bib.bib48)\]. A major subcategory of missing feature approaches
is called feature vector imputation \[[6](#bib.bib6), [7](#bib.bib7),
[26](#bib.bib26)\] where each feature vector component $`y_{n}^{(d)}`$
is either classified as reliable ($`d\in\mathcal{R}_{n}`$) or unreliable
($`d\in\mathcal{U}_{n}`$), where $`\mathcal{R}_{n}`$ and
$`\mathcal{U}_{n}`$ denote the set of reliable and unreliable components
of the $`n`$-th feature vector, respectively \[[24](#bib.bib24)\]. While
unreliable components are withdrawn and replaced by an estimate
$`\widehat{x}_{n}^{(d)}`$ of the original observation $`y^{(d)}_{n}`$,
reliable components are directly “plugged” into the pdf. The score
calculation in
([5](#S2.E5 "In II A Bayesian Network View ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
therefore becomes

|  |  |  |  |  |  |
|----|----|----|----|----|----|
|  | $`\displaystyle\mathring{p}(\mathbf{y}_{n}|q_{n})\hskip-7.11317pt`$ | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\int p(\mathbf{x}_{n}|q_{n})\frac{p(\mathbf{x}_{n}|\mathbf{y}_{n})}{p(\mathbf{x}_{n})}d\mathbf{x}_{n}`$ |  | (29) |
|  |  | $`\displaystyle\approx`$ | $`\displaystyle\hskip-7.11317pt\int p(\mathbf{x}_{n}|q_{n})p(\mathbf{x}_{n}|\mathbf{y}_{n})d\mathbf{x}_{n}`$ |  |  |

with

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle p(\mathbf{x}_{n}|\mathbf{y}_{n})=\prod_{d=1}^{D}p(x_{n}^{(d)}|y_{n}^{(d)})`$ |  | (30) |

and \[[24](#bib.bib24)\]

|  |  |  |
|----|----|----|
|  | $`\displaystyle p(x_{n}^{(d)}|y_{n}^{(d)})=\left\{\begin{array}[]{l l}\delta(x_{n}^{(d)}-y_{n}^{(d)})&d\in\mathcal{R}\\
\delta(x_{n}^{(d)}-\widehat{x}_{n}^{(d)})&d\in\mathcal{U}\end{array}\right.`$ |  |

with the general Bayesian network in
Figure [5](#S4.F5 "Fig. 5 ‣ J Significance Decoding ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(a).

thus becomes \[[24](#bib.bib24)\]

p(x_{n}^{(d)})&d\in\mathcal{U}\end{array}\right.`$ |  |

with the general Bayesian network in

The approach presented in \[[8](#bib.bib8)\] again implicitly assumes
the basic observation model
$`\mathbf{y}_{n}=\mathbf{x}_{n}+\mathbf{b}_{n}`$, where
$`\mathbf{b}_{n}\sim\mathcal{N}(\mathbf{0},\mathbf{C}_{\mathbf{b}_{n}})`$

Bayesian network is depicted in
Figure [2](#S4.F2 "Fig. 2 ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(a)

|  |  |  |  |  |  |
|----|----|----|----|----|----|

### K Parallel Model Combination

We next investigate several acoustic model adaptation techniques
starting with the fundamental framework of Parallel Model Combination
(PMC) \[[10](#bib.bib10)\]. The observation model of the PMC concept is
based on the log-sum distortion model and reads in the static logmelspec
domain:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathbf{y}_{n}=\log(\alpha\exp(\mathbf{x}_{n})+\exp(\mathbf{b}_{n})),`$ |  | (39) |

where the deterministic parameter $`\alpha`$ accounts for level
differences between the clean speech $`\mathbf{x}_{n}`$ and the
distortion $`\mathbf{b}_{n}`$. Under the assumption of stationary
distortions, i.e.,

|     |                                                   |     |      |
|-----|---------------------------------------------------|-----|------|
|     | $`\displaystyle p(\mathbf{b}_{n})={\rm const.},`$ |     | (40) |

the underlying Bayesian network corresponds to
Figure [2](#S4.F2 "Fig. 2 ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(a).
This explains the name of PMC as
([39](#S4.E39 "In K Parallel Model Combination ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
combines two independent parallel models: the clean-speech HMM and the
distortion model $`p(\mathbf{b}_{n})`$. Since the resulting adapted pdf

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle p(\mathbf{y}_{n}|q_{n})=\int p(\mathbf{x}_{n}|q_{n})p(\mathbf{y}_{n}|\mathbf{x}_{n},\mathbf{b}_{n})p(\mathbf{b}_{n})d(\mathbf{x}_{n},\mathbf{b}_{n})`$ |  | (41) |

cannot be derived in an analytical closed form, a variety of
approximations to the true pdf $`p(\mathbf{y}_{n}|q_{n})`$ have been
investigated \[[10](#bib.bib10)\]. For nonstationary distortions,
\[[10](#bib.bib10)\] proposes to employ a separate HMM for the
distortion $`\mathbf{b}_{n}`$ leading to the Bayesian network
representation of
Figure [2](#S4.F2 "Fig. 2 ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(d).
Marginalizing over the distortion state sequence $`\widetilde{q}_{1:N}`$
as in
([5](#S2.E5 "In II A Bayesian Network View ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
reveals the acoustic score to become

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\hskip 9.10486ptp(\mathbf{y}_{1:N}|\mathbf{W})=\sum_{\begin{subarray}{c}q_{1:N}\\
\widetilde{q}_{1:N}\end{subarray}}p(\mathbf{y}_{1:N},q_{1:N},\widetilde{q}_{1:N})`$ |  |

|  |  |  |  |  |  |
|----|----|----|----|----|----|
|  |  | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\sum_{\begin{subarray}{c}q_{1:N}\\
\widetilde{q}_{1:N}\end{subarray}}\bigg\{\prod_{n=1}^{N}p(\mathbf{y}_{n}|q_{n},\widetilde{q}_{n})\;p(q_{n}|q_{n-1})\;p(\widetilde{q}_{n}|\widetilde{q}_{n-1})\bigg\},`$ |  | (42) |

where

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle p(\mathbf{y}_{n}|q_{n},\widetilde{q}_{n})\hskip-7.11317pt`$ | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\int p(\mathbf{x}_{n}|q_{n})p(\mathbf{y}_{n}|\mathbf{x}_{n},\mathbf{b}_{n})p(\mathbf{b}_{n}|\widetilde{q}_{n})d(\mathbf{x}_{n},\mathbf{b}_{n}).`$ |  |

The overall acoustic score can be approximated by a 3D Viterbi decoder,
which can in turn be mapped onto a conventional 2D Viterbi decoder
\[[10](#bib.bib10)\].

### L Vector Taylor Series

The concept of Vector Taylor Series (VTS) is frequently employed in
practice yielding promising results \[[36](#bib.bib36)\]. Its
fundamental idea is to linearize a nonlinear distortion model by a
Taylor series \[[49](#bib.bib49), [11](#bib.bib11), [50](#bib.bib50)\].
The standard VTS approach \[[49](#bib.bib49)\] is based on the log-sum
observation model:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathbf{y}_{n}=\log(\exp(\mathbf{h}_{n}+\mathbf{x}_{n})+\exp(\mathbf{c}_{n})),`$ |  | (44) |

where
$`p(\mathbf{h}_{n})=\mathcal{N}(\mathbf{h}_{n};\boldsymbol{\mu}_{\mathbf{h}},\mathbf{C}_{\mathbf{h}})`$
captures short convolutive distortion and
$`p(\mathbf{c}_{n})=\mathcal{N}(\mathbf{c}_{n};\boldsymbol{\mu}_{\mathbf{c}},\mathbf{C}_{\mathbf{c}})`$
models additive noise components. The Bayesian network is represented by
Figure [2](#S4.F2 "Fig. 2 ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(a)
with $`\mathbf{b}_{n}=[\mathbf{h}_{n},\mathbf{c}_{n}]`$. Note that in
contrast to uncertainty decoding, $`p(\mathbf{b}_{n})`$ is constant over
time. As the adapted pdf is again of the form of
([41](#S4.E41 "In K Parallel Model Combination ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
and thus analytically intractable, it is assumed that
([44](#S4.E44 "In L Vector Taylor Series ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
can, firstly, be applied to each Gaussian component
$`p(\mathbf{x}_{n}|k_{n})`$ of the GMM

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle p(\mathbf{x}_{n}|q_{n})=\sum_{k_{n}}p(k_{n})p(\mathbf{x}_{n}|k_{n})`$ |  | (45) |

individually and, secondly, be approximated by a Taylor series around
$`[\boldsymbol{\mu}_{\mathbf{x}|k_{n}},\boldsymbol{\mu}_{\mathbf{h}},\boldsymbol{\mu}_{\mathbf{c}}]`$,
where $`\boldsymbol{\mu}_{\mathbf{x}|k_{n}}`$ denotes the mean of the
component $`p(\mathbf{x}_{n}|k_{n})`$. There are various extensions to
the VTS concept that are neglected here. For a more comprehensive review
of VTS, we refer to \[[36](#bib.bib36)\].

### M CMLLR

Constrained Maximum Likelihood Linear Regression (CMLLR)
\[[12](#bib.bib12), [51](#bib.bib51)\] can be seen as the deterministic
counterpart of joint uncertainty decoding
(Subsection [IV](#S4 "IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")-[D](#S4.SS4 "D Joint Uncertainty Decoding ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
with the observation model

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathbf{y}_{n}=\mathbf{A}_{k_{n}}\mathbf{x}_{n}+\mathbf{b}_{k_{n}}`$ |  | (46) |

and deterministic parameters $`\mathbf{A}_{k_{n}},\mathbf{b}_{k_{n}}`$.
The adaptation rule of $`p(\mathbf{y}_{n}|k_{n})`$ has the same form as
([22](#S4.E22 "In D Joint Uncertainty Decoding ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
with

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle p(\mathbf{y}_{n}|\mathbf{x}_{n},k_{n})=\delta(\mathbf{y}_{n}-\mathbf{A}_{k_{n}}\mathbf{x}_{n}-\mathbf{b}_{k_{n}}).`$ |  | (47) |

The Bayesian network corresponds to
Figure [5](#S4.F5 "Fig. 5 ‣ J Significance Decoding ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(b),
where the use of regression classes is again reflected by the dependency
of the observation model parameters on the Gaussian component $`k_{n}`$
(cf.
Subsection [IV](#S4 "IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")-[D](#S4.SS4 "D Joint Uncertainty Decoding ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")).
The affine observation model in
([46](#S4.E46 "In M CMLLR ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
is equivalent to transforming the mean vector
$`\boldsymbol{\mu}_{\mathbf{x}|k_{n}}`$ and covariance matrix
$`\mathbf{C}_{\mathbf{x}|k_{n}}`$ of each Gaussian component of
$`p(\mathbf{x}_{n}|k_{n})`$:

|  |  |  |  |  |  |
|----|----|----|----|----|----|
|  | $`\displaystyle\boldsymbol{\mu}_{\mathbf{y}|k_{n}}\hskip-7.11317pt`$ | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\mathbf{A}_{k_{n}}\boldsymbol{\mu}_{\mathbf{x}|k_{n}}+\mathbf{b}_{k_{n}},`$ |  | (48) |
|  | $`\displaystyle\mathbf{C}_{\mathbf{y}|k_{n}}\hskip-7.11317pt`$ | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\mathbf{A}_{k_{n}}\mathbf{C}_{\mathbf{x}|k_{n}}\mathbf{A}_{k_{n}}^{T}.`$ |  | (49) |

CMLLR represents a very popular adaptation technique in practice due to
its promising results and versatile fields of application, such as
speaker adaptation \[[51](#bib.bib51)\], adaptive training
\[[52](#bib.bib52)\] as well as noise \[[53](#bib.bib53)\] and
reverberation-robust \[[54](#bib.bib54)\] ASR.

### N MLLR

The Maximum Likelihood Linear Regression (MLLR) concept
\[[13](#bib.bib13)\] can be considered as a generalization of CMLLR as
it allows for a separate transform matrix $`\mathbf{B}_{k_{n}}`$ in
([49](#S4.E49 "In M CMLLR ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")):

|  |  |  |  |  |  |
|----|----|----|----|----|----|
|  | $`\displaystyle\boldsymbol{\mu}_{\mathbf{y}|k_{n}}\hskip-7.11317pt`$ | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\mathbf{A}_{k_{n}}\boldsymbol{\mu}_{\mathbf{x}|k_{n}}+\mathbf{b}_{k_{n}},`$ |  | (50) |
|  | $`\displaystyle\mathbf{C}_{\mathbf{y}|k_{n}}\hskip-7.11317pt`$ | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\mathbf{B}_{k_{n}}\mathbf{C}_{\mathbf{x}|k_{n}}\mathbf{B}_{k_{n}}^{T}.`$ |  | (51) |

In practice, however, MLLR is frequently applied to the mean vectors
only \[[55](#bib.bib55), [56](#bib.bib56), [57](#bib.bib57),
[58](#bib.bib58)\] while neglecting the adaptation of the covariance
matrix:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathbf{C}_{\mathbf{y}|k_{n}}=\mathbf{C}_{\mathbf{x}|k_{n}}.`$ |  | (52) |

This principle is also known from other approaches that are applicable
to both means and variances but are often only carried out on the former
(e.g., for the sake of robustness) \[[10](#bib.bib10),
[59](#bib.bib59)\].

If applied to the mean vectors only, MLLR can in turn be considered as a
simplified version of CMLLR, where the observation model
([46](#S4.E46 "In M CMLLR ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
and the Bayesian network in
Figure [5](#S4.F5 "Fig. 5 ‣ J Significance Decoding ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(b)
is assumed while the compensation of the variances is omitted.

The Bayesian network representation in
Figure [5](#S4.F5 "Fig. 5 ‣ J Significance Decoding ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(b)
also underlies the general MLLR adaptation rule
([50](#S4.E50 "In N MLLR ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
and
([51](#S4.E51 "In N MLLR ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")).
In this case, however, it seems impossible to identify a corresponding
analytic observation model representation.

### O MAP Adaptation

We next describe the MAP adaptation applied to any parameters
$`\boldsymbol{\theta}`$ of the pdfs of an HMM. In MAP, these parameters
are considered as Bayesian parameters, i.e., random variables that are
drawn once for all times as depicted in
Figure [5](#S4.F5 "Fig. 5 ‣ J Significance Decoding ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(c)
\[[25](#bib.bib25)\]. As a direct consequence, any two observation
vectors $`\mathbf{y}_{i},\mathbf{y}_{j}`$ are conditionally dependent
given the state sequence. The predictive pdf in
([4](#S2.E4 "In II A Bayesian Network View ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
therefore explicitly depends on the adaptation data that we denote as
$`\mathbf{y}_{M:0}`$, $`M<0`$, and becomes

|  |  |  |  |  |  |
|----|----|----|----|----|----|
|  | $`\displaystyle p(\mathbf{y}_{1:N},q_{1:N}|\mathbf{y}_{M:0})\hskip-7.11317pt`$ | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\int p(\mathbf{y}_{1:N},q_{1:N},\boldsymbol{\theta}|\mathbf{y}_{M:0})d\boldsymbol{\theta}`$ |  | (53) |
|  |  | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\int p(\mathbf{y}_{1:N},q_{1:N}|\boldsymbol{\theta},\mathbf{y}_{M:0})p(\boldsymbol{\theta}|\mathbf{y}_{M:0})d\boldsymbol{\theta}`$ |  |  |
|  |  | $`\displaystyle\approx`$ | $`\displaystyle\hskip-7.11317ptp(\mathbf{y}_{1:N},q_{1:N}|\boldsymbol{\theta}_{\rm MAP},\mathbf{y}_{M:0}),`$ |  |  |

where the posterior $`p(\boldsymbol{\theta}|\mathbf{y}_{M:0})`$ is
approximated as Dirac distribution
$`\delta(\boldsymbol{\theta}-\boldsymbol{\theta}_{\rm MAP})`$ at the
mode $`\boldsymbol{\theta}_{\rm MAP}`$:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\boldsymbol{\theta}_{\rm MAP}=\operatornamewithlimits{argmax}_{\boldsymbol{\theta}}p(\boldsymbol{\theta}|\mathbf{y}_{M:0})=\operatornamewithlimits{argmax}_{\boldsymbol{\theta}}p(\mathbf{y}_{M:0}|\boldsymbol{\theta})p(\boldsymbol{\theta}).
``` |  | (54) |

An iterative (local) solution to
([54](#S4.E54 "In O MAP Adaptation ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
is obtained by the Expectation Maximization (EM) algorithm. Note that
due to the MAP approximation of the posterior
$`p(\boldsymbol{\theta}|\mathbf{y}_{M:0})`$, the conditional
independence assumption is again fulfilled such that a conventional
decoder can be employed.

### P Bayesian MLLR

As mentioned before, uncertainty decoding techniques allow for a
time-varying pdf $`p(\mathbf{b}_{n})`$, while model adaptation
approaches, such as in

mostly set $`p(\mathbf{b}_{n})`$ to be constant over time. In both
cases, however, the “randomized” model parameter $`\mathbf{b}_{n}`$ is
assumed to be redrawn in each time step $`n`$ as in
Figure [6](#S4.F6 "Fig. 6 ‣ O MAP Adaptation ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(a).
In contrast, Bayesian estimation – as mentioned before – usually refers
to inference problems, where the random model parameters are drawn once

Figure [6](#S4.F6 "Fig. 6 ‣ O MAP Adaptation ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(b).

Another example of Bayesian model adaptation, besides MAP, is Bayesian
MLLR \[[14](#bib.bib14)\] applied to the mean vector
$`\boldsymbol{\mu}_{\mathbf{x}|q_{n}}`$ of each pdf
$`p(\mathbf{x}_{n}|q_{n})`$:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\boldsymbol{\mu}_{\mathbf{y}|q_{n}}=\mathbf{A}\boldsymbol{\mu}_{\mathbf{x}|q_{n}}+\mathbf{c}`$ |  | (55) |

with $`\mathbf{b}=[\mathbf{A},\mathbf{c}]`$ being usually drawn from a
Gaussian distribution \[[14](#bib.bib14)\]. Here, we do not consider
different regression classes and assume $`p(\mathbf{x}_{n}|q_{n})`$ to
be a single Gaussian pdf since, in the case of a GMM, the linear
mismatch function
([55](#S4.E55 "In P Bayesian MLLR ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
can be applied to each Gaussian component separately. The likelihood
score in

|  |  | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\sum_{q_{1:N}}\int p(\mathbf{y}_{1:N},q_{1:N}|\mathbf{b})p(\mathbf{b})d\mathbf{b}.`$ |  |  |

This score can, e.g., be approximated by a frame-synchronous Viterbi
search \[[60](#bib.bib60)\]. Another approach is to apply the Bayesian

becomes

|----|----|----|----|----|----|

where the original assumption of $`\mathbf{w}`$ being identical for all

### Q Reverberant VTS

Reverberant VTS \[[15](#bib.bib15)\] is an extension of conventional VTS
(Subsection [IV](#S4 "IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")-[L](#S4.SS12 "L Vector Taylor Series ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
to capture the dispersive effect of reverberation. Its observation model
reads for static features in the logmelspec domain:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathbf{y}_{n}=\log\bigg(\sum_{l=0}^{L}\exp(\mathbf{x}_{n-l}+\boldsymbol{\mu}_{l})+\exp(\mathbf{b}_{n})\bigg)`$ |  | (58) |

with $`\mathbf{b}_{n}`$ being an additive noise component modeled as
normally distributed random variable and $`\boldsymbol{\mu}_{0:L}`$
being a deterministic description of the reverberant distortion. For the
sake of tractability, the observation model is approximated in a similar
manner as in the VTS approach. This concept can be seen as an
alternative to REMOS
(Subsection [IV](#S4 "IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")-[E](#S4.SS5 "E REMOS ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")):
While REMOS tailors the Viterbi decoder to the modified Bayesian
network, reverberant VTS avoids the computationally expensive
marginalization over all previous clean-speech vectors by averaging –
and thus smoothing – the clean-speech statistics over all possible
previous states and Gaussian components. Thus, $`\mathbf{y}_{n}`$ is
assumed to depend on the extended clean-speech vector
$`\overline{\mathbf{x}}_{n}`$ =
$`[\mathbf{x}_{n-L},...,\mathbf{x}_{n}]`$, cf.
Figure [7](#S4.F7 "Fig. 7 ‣ P Bayesian MLLR ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(a)
vs. (b).

### R Convolutive Model Adaptation

Besides the previously mentioned REMOS, reverberant VTS, and reverberant
CMLLR concepts, there are three related approaches employing a
convolutive observation model in order to describe the dispersive effect
of reverberation \[[16](#bib.bib16), [17](#bib.bib17),
[18](#bib.bib18)\]. All three approaches assume the following model in
the logmelspec domain:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathbf{y}_{n}=\log\bigg(\sum_{l=0}^{L}\exp(\mathbf{x}_{n-l}+\boldsymbol{\mu}_{l})\bigg),`$ |  | (59) |

where $`\boldsymbol{\mu}_{0:L}`$ denotes a deterministic description of
the reverberant distortion that is differently determined by the three
approaches. The observation model
([59](#S4.E59 "In R Convolutive Model Adaptation ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
can be represented by the Bayesian network in
Figure [3](#S4.F3 "Fig. 3 ‣ E REMOS ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")
without the random component $`\mathbf{b}_{n}`$. Both
\[[16](#bib.bib16)\] and \[[18](#bib.bib18)\] use the “log-add
approximation” \[[10](#bib.bib10)\] to derive
$`p(\mathbf{y}_{n}|q_{n})`$, i.e.,

|  |  |  |  |  |  |
|----|----|----|----|----|----|
|  | $`\displaystyle\boldsymbol{\mu}_{\mathbf{y}|k_{n}}\hskip-7.11317pt`$ | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\log\bigg(\exp(\boldsymbol{\mu}_{\mathbf{x}|k_{n}}+\boldsymbol{\mu}_{0})`$ |  | (60) |
|  |  |  | $`\displaystyle\hskip-7.11317pt+\sum_{l=1}^{L}\exp(\overline{\boldsymbol{\mu}}_{\mathbf{x}|q_{n-l}}+\boldsymbol{\mu}_{l})\bigg),`$ |  |  |

where $`\boldsymbol{\mu}_{\mathbf{y}|k_{n}}`$ and
$`\boldsymbol{\mu}_{\mathbf{x}|k_{n}}`$ denote the mean of the
$`k_{n}`$-th Gaussian component of $`p(\mathbf{y}_{n}|q_{n})`$ and
$`p(\mathbf{x}_{n}|q_{n})`$, respectively. The previous means
$`\overline{\boldsymbol{\mu}}_{\mathbf{x}|q_{n-l}}`$, $`l>0`$, are
averaged over all means of the corresponding GMM
$`p(\mathbf{x}_{n-l}|q_{n-l})`$. On the other hand, \[[17](#bib.bib17)\]
employs the “log-normal approximation” \[[10](#bib.bib10)\] to adapt
$`p(\mathbf{y}_{n}|q_{n})`$ according to
([59](#S4.E59 "In R Convolutive Model Adaptation ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")).
While \[[16](#bib.bib16)\] and \[[17](#bib.bib17)\] perform the
adaptation once prior to recognition and then use a standard decoder,
the concept proposed in \[[18](#bib.bib18)\] performs an online
adaptation based on the best partial path \[[15](#bib.bib15)\].

It should be pointed out here that there is a variety of other
approximations to the statistics of the log-sum of (mixtures of)
Gaussian random variables (as seen in
Subsections [B](#S4.SS2 "B Dynamic Variance Compensation ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"),
[E](#S4.SS5 "E REMOS ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"),

### T Conditional HMMs \[[22](#bib.bib22)\] and Combined-Order HMMs \[[23](#bib.bib23)\]

We close this section by turning to two model-based approaches that
cannot be classified as “model adaptation” as they postulate different
HMM topologies rather than adapting a conventional HMM. Both approaches
aim at relaxing the conditional independence assumption of conventional
HMMs in order to improve the modeling of the inter-frame correlation.

The concept of conditional HMMs \[[22](#bib.bib22)\] models the
observation $`\mathbf{y}_{n}`$ as depending on the previous observations
at time shifts
$`\boldsymbol{\psi}=(\psi_{1},...,\psi_{P})\in\mathbb{N}^{P}`$. Each
summand in
([4](#S2.E4 "In II A Bayesian Network View ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"))
therefore becomes

|  |  |  |  |  |  |
|----|----|----|----|----|----|
|  | $`\displaystyle p(\mathbf{y}_{1:N},q_{1:N})\hskip-7.11317pt`$ | $`\displaystyle=`$ | $`\displaystyle\hskip-7.11317pt\prod_{n=1}^{N}p(\mathbf{y}_{n}|\mathbf{y}_{n-\psi_{1}},...,\mathbf{y}_{n-\psi_{P}},q_{n})`$ |  | (64) |
|  |  |  | $`\displaystyle\hskip-7.11317pt\cdot\;p(q_{n}|q_{n-1})`$ |  |  |

according to
Figure [9](#S4.F9 "Fig. 9 ‣ T Conditional HMMs [] and Combined-Order HMMs [] ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(a).
Such HMMs are also known as autoregressive HMMs \[[25](#bib.bib25)\].

In contrast to conditional HMMs, combined-order HMMs
\[[23](#bib.bib23)\] assume the current observation $`\mathbf{y}_{n}`$
to depend on the previous HMM state $`q_{n-1}`$ in addition to state
$`q_{n}`$:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
p(\mathbf{y}_{1:N},q_{1:N})=\prod_{n=1}^{N}p(\mathbf{y}_{n}|q_{n},q_{n-1})p(q_{n}|q_{n-1})
``` |  | (65) |

according to
Figure [9](#S4.F9 "Fig. 9 ‣ T Conditional HMMs [] and Combined-Order HMMs [] ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(b).

aspects related to the considered concepts: Most importantly, neither
the particular functional form of the joint pdf, nor potential
approximations to arrive at a tractable algorithm nor the provenance of
(i.e., the estimation procedure for) the compensation parameters are
reflected.

On the other hand, the Bayesian network description provides a
convenient language to immediately and clearly identify some major
properties:

- •
  The cross-connections depicted in
  Figures [3](#S4.F3 "Fig. 3 ‣ E REMOS ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"),
  [4](#S4.F4 "Fig. 4 ‣ F Ion and Haeb-Umbach ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"),

  [8](#S4.F8 "Fig. 8 ‣ R Convolutive Model Adaptation ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"),
  [9](#S4.F9 "Fig. 9 ‣ T Conditional HMMs [] and Combined-Order HMMs [] ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")
  show that the underlying concept aims at improving the modeling of the
  inter-frame correlation, e.g., to increase the robustness of the
  acoustic model against reverberation. If applied in a straightforward
  way, such cross-connections would entail a costly modification of the
  Viterbi decoder. In this paper, we summarized some important
  approximations that allow for a more efficient decoding of the
  extended Bayesian network, cf.
  Subsections [IV](#S4 "IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")-[E](#S4.SS5 "E REMOS ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"),
  [IV](#S4 "IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")-[F](#S4.SS6 "F Ion and Haeb-Umbach ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"),
  [IV](#S4 "IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")-[Q](#S4.SS17 "Q Reverberant VTS ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"),
  [IV](#S4 "IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")-[R](#S4.SS18 "R Convolutive Model Adaptation ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition").
  Some of these typically empirically motivated or just intuitive
  approximations, especially neglected statistical dependencies, become
  obvious from a Bayesian network, as shown in
  Figures [4](#S4.F4 "Fig. 4 ‣ F Ion and Haeb-Umbach ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")
  and
  [7](#S4.F7 "Fig. 7 ‣ P Bayesian MLLR ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition").
- •
  The approaches introducing instantaneous (here: purely vertical)
  extensions to the Bayesian network, as in
  Figures [2](#S4.F2 "Fig. 2 ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(a)-(c)
  and
  [5](#S4.F5 "Fig. 5 ‣ J Significance Decoding ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(c),
  usually aim at compensating for nondispersive distortions, such as
  additive or short convolutive noise.
- •
  The arcs in
  Figures [2](#S4.F2 "Fig. 2 ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(c)
  and
  [5](#S4.F5 "Fig. 5 ‣ J Significance Decoding ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(b)
  illustrate that the observed vector $`\mathbf{y}_{n}`$ does not only
  depend on the state $`q_{n}`$ (or mixture component $`k_{n}`$) through
  $`\mathbf{x}_{n}`$. As a consequence, one can deduce that the
  compensation parameters do depend on the phonetic content, as in
  Subsections [IV](#S4 "IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")-[D](#S4.SS4 "D Joint Uncertainty Decoding ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition"),

  and
  [IV](#S4 "IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")-[N](#S4.SS14 "N MLLR ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition").
- •
  The graphical model representation also succinctly highlights whether

  Figures [5](#S4.F5 "Fig. 5 ‣ J Significance Decoding ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(c)
  and

  or not, as in
  Figures [5](#S4.F5 "Fig. 5 ‣ J Significance Decoding ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(a)
  and (b).
- •
  The existence of the additional latent variable $`\mathbf{x}_{n}`$ in
  most of the presented Bayesian network representations expresses that
  an explicit observation model or an implicit statistical model between
  the clean and the corrupted features is employed. In contrast, the
  graphical representations in
  Figures [5](#S4.F5 "Fig. 5 ‣ J Significance Decoding ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")(c)
  and
  [9](#S4.F9 "Fig. 9 ‣ T Conditional HMMs [] and Combined-Order HMMs [] ‣ IV Examples ‣ A Bayesian Network View onAcoustic Model-Based Techniques forRobust Speech Recognition")
  show that – instead of a distinct compensation step – a modified HMM
  topology is used.

In summary, the condensed description of the various concepts from the
same Bayesian network perspective shall offer other researchers the
possibility to more easily exploit or combine existing techniques and to
link their own algorithms to the presented ones. This seems all the more
important as the recent acoustic modeling approaches based on Deep
Neural Networks (DNNs) raise new challenges for the conventional
robustness techniques \[[36](#bib.bib36)\]. As pointed out in
\[[36](#bib.bib36)\], a possible solution for exploiting the traditional
GMM-based robustness approaches – such as the ones reviewed here –
within the deep learning paradigm could be the use of DNN-derived
bottleneck features in a GMM-HMM, which offers various possibilities for
further research.
````
