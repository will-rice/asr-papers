Language Model Integration based on Memory Control for\
Sequence to sequence Speech Recognition
=======================================================

###### Abstract

In this paper, we explore several new schemes to train a seq2seq model to integrate a pre-trained LM. Our proposed fusion methods focus on the memory cell state and the hidden state in the seq2seq decoder long short-term memory (LSTM), and the memory cell state is updated by the LM unlike the prior studies. This means the memory retained by the main seq2seq would be adjusted by the external LM. These fusion methods have several variants depending on the architecture of this memory cell update and the use of memory cell and hidden states which directly affects the final label inference. We performed the experiments to show the effectiveness of the proposed methods in a mono-lingual ASR setup on the Librispeech corpus and in a transfer learning setup from a multilingual ASR (MLASR) base model to a low-resourced language. In Librispeech, our best model improved WER by 3.7%, 2.4% for test clean, test other relatively to the shallow fusion baseline, with multi-level decoding. In transfer learning from an MLASR base model to the IARPA Babel Swahili model, the best scheme improved the transferred model on eval set by 9.9%, 9.8% in CER, WER relatively to the 2-stage transfer baseline.

Index Terms: Automatic speech recognition (ASR), sequence to sequence, language model, shallow fusion, deep fusion, cold fusion

## 1 introduction

As deep learning prospers in most research fields, systems based on it keep improving, and become the state-of-the-art in most of the scenarios. The sequence to sequence (seq2seq) model is one of the kind that heavily depends on deep learning techniques, and it is used in many sequence mapping problems such as automatic speech recognition (ASR) \[[1](https://arxiv.org/html/1811.02162v2#bib.bib1), [2](https://arxiv.org/html/1811.02162v2#bib.bib2), [3](https://arxiv.org/html/1811.02162v2#bib.bib3), [4](https://arxiv.org/html/1811.02162v2#bib.bib4)\] and machine translation \[[5](https://arxiv.org/html/1811.02162v2#bib.bib5), [6](https://arxiv.org/html/1811.02162v2#bib.bib6), [7](https://arxiv.org/html/1811.02162v2#bib.bib7)\]. In \[[4](https://arxiv.org/html/1811.02162v2#bib.bib4)\], a seq2seq model with attention mechanism is introduced in ASR. Though the performance lagged behind highly-optimized conventional systems, e.g. CLDNN HMM system \[[8](https://arxiv.org/html/1811.02162v2#bib.bib8)\], it enabled to map a sequence of feature vectors to a sequence of characters, with a single neural network, in an end-to-end manner. In \[[9](https://arxiv.org/html/1811.02162v2#bib.bib9)\], the authors apply a multi-task learning scheme to train an attentional seq2seq model with connectionist temporal classification (CTC) objective function \[[1](https://arxiv.org/html/1811.02162v2#bib.bib1), [10](https://arxiv.org/html/1811.02162v2#bib.bib10)\] as auxiliary loss. Adding the CTC loss to train the model reduces the burden of the attention model to learn monotonic attention.

In the seq2seq ASR setup, the language model (LM) takes an important role as it is already shown in hybrid ASR systems \[[11](https://arxiv.org/html/1811.02162v2#bib.bib11), [12](https://arxiv.org/html/1811.02162v2#bib.bib12)\]. However, compared to the conventional ASR, there have been only a few studies on ways to integrate an LM into seq2seq ASR \[[13](https://arxiv.org/html/1811.02162v2#bib.bib13), [14](https://arxiv.org/html/1811.02162v2#bib.bib14), [15](https://arxiv.org/html/1811.02162v2#bib.bib15)\]. In this direction, the authors in \[[5](https://arxiv.org/html/1811.02162v2#bib.bib5)\] introduce two methods integrating an LM into a decoder of the end-to-end neural machine translation (NMT) system. First method was shallow fusion where the model decodes based on a simple weighted sum of NMT model and recurrent neural network LM \[[16](https://arxiv.org/html/1811.02162v2#bib.bib16)\] (RNNLM) scores. The next one was called deep fusion where they combine a mono-lingual RNNLM with a NMT model by learning parameters that connect hidden states of a separately trained NMT model and RNNLM. While the parameters connecting the hidden states are trained, parameters in NMT and RNNLM are frozen. Recently in ASR research, a scheme called cold fusion was introduced, which trains a seq2seq model from scratch in assistance with a pre-trained RNNLM \[[17](https://arxiv.org/html/1811.02162v2#bib.bib17)\]. In contrast to the previous methods, the parameters of the seq2seq model are not frozen during training although pre-trained RNNLM parameters are still kept frozen. The results showed the model trained this way outperforms deep fusion in decoding as well as reducing the amount of data in domain adaptation. Later, more experiments were done comparing all three methods \[[18](https://arxiv.org/html/1811.02162v2#bib.bib18)\]. In the paper, they observe that cold fusion works best among all three methods in the second pass re-scoring with a large and production-scale LM. The previous research has shown the potential of training a seq2seq model utilizing a pre-trained LM. However, it seems only effective to limited scenarios such as domain adaptation and second-pass re-scoring. Thus, studies on better ways of integrating both models need to be explored.

In this paper, we explored several new fusion schemes to train a seq2seq model jointly with a pre-trained LM. Among them, we found one method that works consistently better than other fusion methods over more general scenarios. The proposed methods focus on updating the memory cell state as well as the hidden state of the seq2seq decoder long short-term memory (LSTM) \[[19](https://arxiv.org/html/1811.02162v2#bib.bib19)\], given the LM logit or hidden state. This means that the memory retained by the main seq2seq model will be adjusted by the external LM for better prediction. The fusion methods have several variants according to the architecture of this memory cell update and the use of memory cell and hidden states, which directly affects the final label inference. Note that we used LSTM networks for RNNs throughout whole explanations and experiments. The proposed methods, however, can be applied to different variant RNNs such as gated recurrent unit (GRU) \[[20](https://arxiv.org/html/1811.02162v2#bib.bib20)\] only with minimal modification.

The organization of this paper is as follows. First, we describe previous fusion methods as a background in Section [2](https://arxiv.org/html/1811.02162v2#S2 "2 Background: Shallow fusion, Deep fusion, and Cold fusion in ASR ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition"). Then, in Section [3](https://arxiv.org/html/1811.02162v2#S3 "3 Proposed methods ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition"), we explain our proposed methods in detail. Experiments with previous and proposed methods are presented in Section [4](https://arxiv.org/html/1811.02162v2#S4 "4 Experiments ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition"). Lastly, we conclude the paper in Section [5](https://arxiv.org/html/1811.02162v2#S5 "5 Conclusion ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition").

## 2 Background: Shallow fusion, Deep fusion, and Cold fusion in ASR

### 2.1 Shallow fusion

In this paper, we denotes as shallow fusion a decoding method based on the following convex score combination of a seq2seq model and LM during beam search,

``` math
\hat{y} = {\underset{y}{argmax}\left( {{{\log p}\left( y \middle| x \right)} + {\gamma{\log p}(y)}} \right)}
```

where $`x`$ is an input acoustic frame sequence while $`\hat{y}`$ is the predicted label sequence selected among all possible $`y`$. The predicted label sequence can be a sequence of characters, sub-words, or words, and this paper deals with character-level sequences. $`{\log p}\left( y \middle| x \right)`$ is calculated from the seq2seq model and $`{\log p}(y)`$ is calculated from the RNNLM. Both models are separately trained but their scores are combined in a decoding phase. $`\gamma`$ is a scaling factor between 0 and 1 that needs to be tuned manually.

### 2.2 Deep fusion

In deep fusion, the seq2seq model and RNNLM are combined with learnable parameters. Two models are first trained separately as in shallow fusion, and then both are frozen while the connecting linear transformation parameters, i.e. $`\mathbf{v}`$, $`b`$, $`\mathbf{W}`$, and $`\mathbf{b}`$ below, are trained.

``` math
g_{t} = {\sigma\left( {{{\mathbf{v}}^{\text{T}}{\mathbf{s}}_{t}^{\text{LM}}} + b} \right)}
```
``` math
{\mathbf{s}}_{t}^{\text{DF}} = \left\lbrack {\mathbf{s}}_{t};{g_{t}{\mathbf{s}}_{t}^{\text{LM}}} \right\rbrack
```
``` math
{\hat{p}\left( y_{t} \middle| {y_{< t},x} \right)} = {\text{softmax}\left( {{{\mathbf{W}}{\mathbf{s}}_{t}^{\text{DF}}} + {\mathbf{b}}} \right)}
```

$`{\mathbf{s}}_{t}^{\text{LM}}`$ and $`{\mathbf{s}}_{t}`$ are hidden states at time $`t`$ from an RNNLM and a decoder of the seq2seq model, respectively. $`\sigma( \cdot )`$ in Eq. ([2a](https://arxiv.org/html/1811.02162v2#S2.E2.1 "In 2 ‣ 2.2 Deep fusion ‣ 2 Background: Shallow fusion, Deep fusion, and Cold fusion in ASR ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition")) is the sigmoid function to generate $`g_{t}`$, which acts as a scalar gating function in Eq. ([2b](https://arxiv.org/html/1811.02162v2#S2.E2.2 "In 2 ‣ 2.2 Deep fusion ‣ 2 Background: Shallow fusion, Deep fusion, and Cold fusion in ASR ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition")) to control the contribution of $`{\mathbf{s}}_{t}^{\text{LM}}`$ to the final inference.

### 2.3 Cold fusion

In contrast to the two previous methods, cold fusion uses the RNNLM in a seq2seq model training phase. The seq2seq model is trained from scratch with the pre-trained RNNLM model whose parameters are frozen and learnable parameters $`{\mathbf{W}}_{k}`$ and $`{\mathbf{b}}_{k}`$, where $`k = {1,2,3}`$. The equation follows

``` math
{\mathbf{h}}_{t}^{\text{LM}} = {{{\mathbf{W}}_{1}{\mathbf{l}}_{t}^{\text{LM}}} + {\mathbf{b}}_{1}}
```
``` math
{\mathbf{g}}_{t} = {\sigma\left( {{{\mathbf{W}}_{2}\left\lbrack {\mathbf{s}}_{t};{\mathbf{h}}_{t}^{\text{LM}} \right\rbrack} + {\mathbf{b}}_{2}} \right)}
```
``` math
{\mathbf{s}}_{t}^{\text{CF}} = \left\lbrack {\mathbf{s}}_{t};{{\mathbf{g}}_{t} \odot {\mathbf{h}}_{t}^{\text{LM}}} \right\rbrack
```
``` math
{\hat{p}\left( y_{t} \middle| {y_{< t},x} \right)} = {\text{softmax}\left( {\text{ReLU}\left( {{{\mathbf{W}}_{3}{\mathbf{s}}_{t}^{\text{CF}}} + {\mathbf{b}}_{3}} \right)} \right)}
```

where $`{\mathbf{l}}_{t}^{\text{LM}}`$ is the logit at time step $`t`$ from the RNNLM. As opposed to a scalar $`g_{t}`$ in Eq. ([2b](https://arxiv.org/html/1811.02162v2#S2.E2.2 "In 2 ‣ 2.2 Deep fusion ‣ 2 Background: Shallow fusion, Deep fusion, and Cold fusion in ASR ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition")) of deep fusion, it is now a vector $`{\mathbf{g}}_{t}`$ in cold fusion, meaning the gating function is applied element-wise, where $`\odot`$ means element-wise multiplication. $`\text{ReLU}( \cdot )`$ is a rectified linear function applied element-wise. Applying it before $`\text{softmax}( \cdot )`$ was shown to be helpful empirically in \[[17](https://arxiv.org/html/1811.02162v2#bib.bib17)\].

## 3 Proposed methods

In this paper, we propose several fusion schemes to train a seq2seq model well integrated with a pre-trained RNNLM. We mainly focus on updating hidden/memory cell states in the seq2seq LSTM decoder given the LM logit/hidden state. The first proposed method uses the LM information to adjust the memory cell state of the seq2seq decoder. Then, the updated cell state replaces the original input cell state of the LSTM decoder to calculate states at the next time step. This fusion scheme is inspired by cold fusion, but they differ in that the new method directly affects the memory cell maintaining mechanism in the LSTM decoder to consider the linguistic context obtained from the LM. Then, we further extend this idea with multiple schemes that use the LM information not only for updating the memory cell states but also hidden states in the seq2seq LSTM decoder, which further affect the final inference and attention calculation directly. Figure [1](https://arxiv.org/html/1811.02162v2#S2.F1 "Figure 1 ‣ 2.3 Cold fusion ‣ 2 Background: Shallow fusion, Deep fusion, and Cold fusion in ASR ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition") visualizes the schemes in high-level to help understanding.

### 3.1 LM fusion by controlling memory cell state

In Eq. ([3c](https://arxiv.org/html/1811.02162v2#S2.E3.3 "In 3 ‣ 2.3 Cold fusion ‣ 2 Background: Shallow fusion, Deep fusion, and Cold fusion in ASR ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition")) at cold fusion, the gated RNNLM information, $`{\mathbf{g}}_{t} \odot {\mathbf{h}}_{t}^{\text{LM}}`$, is concatenated with the decoder hidden state, $`{\mathbf{s}}_{t}`$. Then, the fused state, $`{\mathbf{s}}_{t}^{\text{CF}}`$ is used to predict the distribution of the next character. However, the gated RNNLM information can be used in a different way to update the cell state in the seq2seq decoder, as in Eq. ([4c](https://arxiv.org/html/1811.02162v2#S3.E4.3 "In 4 ‣ 3.1 LM fusion by controlling memory cell state ‣ 3 Proposed methods ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition")).

``` math
{\mathbf{h}}_{t}^{\text{LM}} = {\tanh\left( {{{\mathbf{W}}_{1}{\mathbf{l}}_{t}^{\text{LM}}} + {\mathbf{b}}_{1}} \right)}
```
``` math
{\mathbf{g}}_{t} = {\sigma\left( {{{\mathbf{W}}_{2}\left\lbrack {\mathbf{c}}_{t};{\mathbf{h}}_{t}^{\text{LM}} \right\rbrack} + {\mathbf{b}}_{2}} \right)}
```
``` math
{\mathbf{c}}_{t}^{\text{CCF}} = {{\mathbf{c}}_{t} + {{\mathbf{g}}_{t} \odot {\mathbf{h}}_{t}^{\text{LM}}}}
```
``` math
{{\mathbf{s}}_{t + 1},{\mathbf{c}}_{t + 1}} = {\text{LSTM}\left( \text{input},{\mathbf{s}}_{t},{\mathbf{c}}_{t}^{\text{CCF}} \right)}
```
``` math
{{\hat{p}\left( y_{t} \middle| {y_{< t},x} \right)} = {\text{softmax}\left( {{{\mathbf{W}}_{3}{\mathbf{s}}_{t}} + {\mathbf{b}}_{3}} \right)}}.
```

In this method, we add the gated RNNLM information to the original cell state, $`{\mathbf{c}}_{t}`$. $`\text{LSTM}( \cdot )`$ in Eq. ([4d](https://arxiv.org/html/1811.02162v2#S3.E4.4 "In 4 ‣ 3.1 LM fusion by controlling memory cell state ‣ 3 Proposed methods ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition")) is the standard LSTM function, which takes previous cell and hidden states and an input came from an attention context vector, and updates the cell and hidden states for the next time step. In our case, when the LSTM decoder updates its cell state, it uses $`{\mathbf{c}}_{t}^{\text{CCF}}`$ instead of $`{\mathbf{c}}_{t}`$, which contains additional linguistic context obtained from an external LM. We call this fusion as cell control fusion 1 throughout the paper. Here, this method does not include $`\text{ReLU}( \cdot )`$ before $`\text{softmax}( \cdot )`$ in Eq. ([4e](https://arxiv.org/html/1811.02162v2#S3.E4.5 "In 4 ‣ 3.1 LM fusion by controlling memory cell state ‣ 3 Proposed methods ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition")) since it did not show any benefit empirically unlike in other methods.

### 3.2 LM fusion by updating both hidden and memory cell states

In cold fusion, the update of the hidden state output from the LSTM decoder in Eq. ([3c](https://arxiv.org/html/1811.02162v2#S2.E3.3 "In 3 ‣ 2.3 Cold fusion ‣ 2 Background: Shallow fusion, Deep fusion, and Cold fusion in ASR ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition")) directly affects the final inference unlike *cell control fusion 1*. Therefore, this section combines the concepts of the cold fusion and *cell control fusion 1* and further proposes variants of novel fusion methods by extending the cell control fusion 1 with the above hidden state consideration.

First, we simply combine cell control fusion 1 in Section [3.1](https://arxiv.org/html/1811.02162v2#S3.SS1 "3.1 LM fusion by controlling memory cell state ‣ 3 Proposed methods ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition") with cold fusion. We call this scheme as cell control fusion 2. The detailed equations are

``` math
{\mathbf{h}}_{t}^{\text{LM}} = {{{\mathbf{W}}_{1}{\mathbf{l}}_{t}^{\text{LM}}} + {\mathbf{b}}_{1}}
```
``` math
{\mathbf{g}}_{t}^{\text{cell}} = {\sigma\left( {{{\mathbf{W}}_{2}\left\lbrack {\mathbf{c}}_{t};{\mathbf{h}}_{t}^{\text{LM}} \right\rbrack} + {\mathbf{b}}_{2}} \right)}
```
``` math
{\mathbf{c}}_{t}^{\text{CCF2}} = {{\mathbf{c}}_{t} + {{\mathbf{g}}_{t}^{\text{cell}} \odot {\mathbf{h}}_{t}^{\text{LM}}}}
```
``` math
{{\mathbf{s}}_{t + 1},{\mathbf{c}}_{t + 1}} = {\text{LSTM}\left( \text{input},{\mathbf{s}}_{t},{\mathbf{c}}_{t}^{\text{CCF2}} \right)}
```
``` math
{\mathbf{g}}_{t}^{\text{state}} = {\sigma\left( {{{\mathbf{W}}_{3}\left\lbrack {\mathbf{s}}_{t};{\mathbf{h}}_{t}^{\text{LM}} \right\rbrack} + {\mathbf{b}}_{3}} \right)}
```
``` math
{\mathbf{s}}_{t}^{\text{CCF2}} = \left\lbrack {\mathbf{s}}_{t};{{\mathbf{g}}_{t}^{\text{state}} \odot {\mathbf{h}}_{t}^{\text{LM}}} \right\rbrack
```
``` math
{{\hat{p}\left( y_{t} \middle| {y_{< t},x} \right)} = {\text{softmax}\left( {\text{ReLU}\left( {{{\mathbf{W}}_{4}{\mathbf{s}}_{t}^{\text{CCF2}}} + {\mathbf{b}}_{4}} \right)} \right)}}.
```

Note the calculations of Eq. ([5a](https://arxiv.org/html/1811.02162v2#S3.E5.1 "In 5 ‣ 3.2 LM fusion by updating both hidden and memory cell states ‣ 3 Proposed methods ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition")), ([5e](https://arxiv.org/html/1811.02162v2#S3.E5.5 "In 5 ‣ 3.2 LM fusion by updating both hidden and memory cell states ‣ 3 Proposed methods ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition"))-([5g](https://arxiv.org/html/1811.02162v2#S3.E5.7 "In 5 ‣ 3.2 LM fusion by updating both hidden and memory cell states ‣ 3 Proposed methods ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition")) are exactly same as of Eq. ([3](https://arxiv.org/html/1811.02162v2#S2.E3 "In 2.3 Cold fusion ‣ 2 Background: Shallow fusion, Deep fusion, and Cold fusion in ASR ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition")), and calculations of Eq. ([5a](https://arxiv.org/html/1811.02162v2#S3.E5.1 "In 5 ‣ 3.2 LM fusion by updating both hidden and memory cell states ‣ 3 Proposed methods ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition"))-([5d](https://arxiv.org/html/1811.02162v2#S3.E5.4 "In 5 ‣ 3.2 LM fusion by updating both hidden and memory cell states ‣ 3 Proposed methods ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition")) are same as of Eq. ([4a](https://arxiv.org/html/1811.02162v2#S3.E4.1 "In 4 ‣ 3.1 LM fusion by controlling memory cell state ‣ 3 Proposed methods ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition"))-([4d](https://arxiv.org/html/1811.02162v2#S3.E4.4 "In 4 ‣ 3.1 LM fusion by controlling memory cell state ‣ 3 Proposed methods ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition")) other than $`\text{tanh}( \cdot )`$ used in Eq. ([4a](https://arxiv.org/html/1811.02162v2#S3.E4.1 "In 4 ‣ 3.1 LM fusion by controlling memory cell state ‣ 3 Proposed methods ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition")), which shows some effectiveness on our preliminary investigation. However, this straightforward extension does not outperform both cell control fusion 1 and cold fusion.

As a next variant, we apply a similar cell control update mechanism (Eq. ([5d](https://arxiv.org/html/1811.02162v2#S3.E5.4 "In 5 ‣ 3.2 LM fusion by updating both hidden and memory cell states ‣ 3 Proposed methods ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition"))) to the seq2seq decoder hidden state $`{\mathbf{s}}_{t}`$ as well. That is, the original hidden state, $`{\mathbf{s}}_{t}`$, is replaced by $`{\mathbf{s}}_{t}^{\text{CCF3}}`$ in the LSTM update Eq. ([6f](https://arxiv.org/html/1811.02162v2#S3.E6.6 "In 6 ‣ 3.2 LM fusion by updating both hidden and memory cell states ‣ 3 Proposed methods ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition")), which is transformed from the fused state in cold fusion to match dimension. $`{\mathbf{s}}_{t}^{\text{CCF3}}`$ is expected to have more information since it contains additional linguistic context obtained from an external LM. The Eq. ([6](https://arxiv.org/html/1811.02162v2#S3.E6 "In 3.2 LM fusion by updating both hidden and memory cell states ‣ 3 Proposed methods ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition")) explains this fusion method more in detail. We call this type of fusion cell control fusion 3 in this paper.

``` math
{\mathbf{h}}_{t}^{\text{LM}} = {\tanh\left( {{{\mathbf{W}}_{1}{\mathbf{l}}_{t}^{\text{LM}}} + {\mathbf{b}}_{1}} \right)}
```
``` math
{\mathbf{g}}_{t}^{\text{state}} = {\sigma\left( {{{\mathbf{W}}_{2}\left\lbrack {\mathbf{s}}_{t};{\mathbf{h}}_{t}^{\text{LM}} \right\rbrack} + {\mathbf{b}}_{2}} \right)}
```
``` math
{\mathbf{g}}_{t}^{\text{cell}} = {\sigma\left( {{{\mathbf{W}}_{3}\left\lbrack {\mathbf{c}}_{t};{\mathbf{h}}_{t}^{\text{LM}} \right\rbrack} + b_{3}} \right)}
```
``` math
{\mathbf{s}}_{t}^{\text{CCF3}} = {{{\mathbf{W}}_{4}\left\lbrack {\mathbf{s}}_{t};{{\mathbf{g}}_{t}^{\text{state}} \odot {\mathbf{h}}_{t}^{\text{LM}}} \right\rbrack} + {\mathbf{b}}_{4}}
```
``` math
{\mathbf{c}}_{t}^{\text{CCF3}} = {\text{CellUpdate}\left( {\mathbf{c}}_{t},{{\mathbf{g}}_{t}^{\text{cell}} \odot {\mathbf{h}}_{t}^{\text{LM}}} \right)}
```
``` math
{{\mathbf{s}}_{t + 1},{\mathbf{c}}_{t + 1}} = {\text{LSTM}\left( \text{input},{\mathbf{s}}_{t}^{\text{CCF3}},{\mathbf{c}}_{t}^{\text{CCF3}} \right)}
```
``` math
{\hat{p}\left( y_{t} \middle| {x,y_{< t}} \right)} = {\text{softmax}\left( {\text{ReLU}\left( {{{\mathbf{W}}_{5}{\mathbf{s}}_{t}^{\text{CCF3}}} + {\mathbf{b}}_{5}} \right)} \right)}
```

For CellUpdate function in Eq. ([6e](https://arxiv.org/html/1811.02162v2#S3.E6.5 "In 6 ‣ 3.2 LM fusion by updating both hidden and memory cell states ‣ 3 Proposed methods ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition")), we compared two different calculations:

``` math
{\mathbf{c}}_{t} + {{\mathbf{g}}_{t}^{\text{cell}} \odot {\mathbf{h}}_{t}^{\text{LM}}}
```
``` math
{{\mathbf{W}}_{0}\left\lbrack {\mathbf{c}}_{t};{{\mathbf{g}}_{t}^{\text{cell}} \odot {\mathbf{h}}_{t}^{\text{LM}}} \right\rbrack} + {\mathbf{b}}_{0}
```

In the case of Eq. ([8](https://arxiv.org/html/1811.02162v2#S3.E8 "In 3.2 LM fusion by updating both hidden and memory cell states ‣ 3 Proposed methods ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition")), the affine transformation of $`\left\lbrack {\mathbf{c}}_{t};{{\mathbf{g}}_{t}^{\text{cell}} \odot {\mathbf{h}}_{t}^{\text{LM}}} \right\rbrack`$ would cause gradient vanishing problem in theory. However, we found that in practice, the method works best among all proposed methods.

## 4 Experiments

We first compared all our proposed methods described in Section [3](https://arxiv.org/html/1811.02162v2#S3 "3 Proposed methods ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition") with shallow fusion, deep fusion, and cold fusion on the 100hrs subset of the Librispeech corpus \[[21](https://arxiv.org/html/1811.02162v2#bib.bib21)\] as a preliminary experiment. Then, we further investigate some selected methods with two other experiments: mono-lingual ASR setup on the Librispeech 960hrs corpus and a transfer learning setup from a multilingual ASR (MLASR) base model to a low-resourced language, Swahili in IARPA Babel \[[22](https://arxiv.org/html/1811.02162v2#bib.bib22)\].

We used shallow fusion all the time in decoding phase for every trained model. For example, we can additionally use shallow fusion decoding for the seq2seq model trained with a cold/cell-control fusion scheme. We refer to \[[18](https://arxiv.org/html/1811.02162v2#bib.bib18)\] to justify the comparison between the baseline seq2seq model with shallow/deep fusion decoding and the seq2seq model trained using cold/cell-control fusion with shallow fusion decoding. The baseline seq2seq model above means a seq2seq model trained without any fusion method.

All models are trained with joint CTC-attention objective as proposed in \[[9](https://arxiv.org/html/1811.02162v2#bib.bib9)\],

``` math
L_{\text{MTL}} = {{\alpha L_{\text{CTC}}} + {\left( {1 - \alpha} \right)L_{\text{Attention}}}}
```

where $`L_{\text{CTC}}`$ and $`L_{\text{Attention}}`$ are the losses for CTC and attention repectively, and $`\alpha`$ ranges between 0 and 1 inclusively. In decoding, we did attention/CTC joint decoding with RNNLM \[[23](https://arxiv.org/html/1811.02162v2#bib.bib23)\]. In all the experiments, we represented each frame of 25ms windowed audio having 10ms shift by a vector of 83 dimensions, which consists of 80 Mel-filter bank coefficients and 3 pitch features. The features were normalized by the mean and the variance of the whole training set. All experiments were done based on ESPnet toolkit \[[24](https://arxiv.org/html/1811.02162v2#bib.bib24)\].

For Librispeech, training and decoding configurations of the seq2seq model are shown in Table [1](https://arxiv.org/html/1811.02162v2#S4.T1 "Table 1 ‣ 4 Experiments ‣ Language Model Integration based on Memory Control for Sequence to sequence Speech Recognition"). We trained both character-level and word-level RNNLMs on 10% of the text publicly available for Librispeech¹¹1http://www.openslr.org/11/, which is roughly 10 times the 960 hours of the transcriptions in terms of the data size.

In the MLASR transfer learning scenario, the base MLASR model was trained exactly same as in  \[[25](https://arxiv.org/html/1811.02162v2#bib.bib25)\]. The base model was trained using 10 selected Babel languages, which are roughly 640 hours of data: Cantonese, Bengali, Pashto, Turkish, Vietnamese, Haitian, Tamil, Kurmanji, Tokpisin, and Georgian. The model parameters were then fine-tuned using all Swahili corpus in Babel, which is about 40 hours. During the transfer process, we used the same MLASR base model with three different ways: 2-stage transfer (see  \[[25](https://arxiv.org/html/1811.02162v2#bib.bib25)\] for more details), cold fusion, and cell control fusion 3 (affine). We included cold fusion in this comparison since cold fusion showed its effectiveness in domain adaptation in \[[17](https://arxiv.org/html/1811.02162v2#bib.bib17)\]. The character-level RNNLM was trained on all transcriptions available for Swahili in IARPA Babel.

## 5 Conclusion

In this paper, several methods were proposed to integrate a pre-trained RNNLM during a seq2seq model training. First, we used information from the LM output to update the memory cell in the seq2seq model decoder, which performed similar to cold fusion. Then, we extended this model to additionally update the seq2seq model hidden state given the LM output. For the scheme, Several formulas were compared. Among the proposed methods, cell control fusion 3 (affine) showed the best performance consistently on all experiments. In Librispeech, our best model improved WER by 3.7%, 2.4% for test clean, test other relatively to the shallow fusion baseline, with multi-level decoding. For the transfer learning setup from a MLASR base model to the IARPA Babel Swahili model, the best scheme improved the transferred model performance on eval set by 9.9%, 9.8% in CER, WER relatively to the 2-stage transfer baseline. In the future, we will explore how the best method performs by the amount of additional text data used for RNNLM training.
