# Experiments

In this section, we compare the performance of the proposed system to existing method for lip synchronisation and a related audio-visual application.

## Audio-to-video synchronisation

Audio-to-video synchronisation can be seen as a cross-modal retrieval task, where the temporal offset is found by selecting an audio segment from a set, given a video segment. This is done by computing the distance between a learnt video feature (from a 5-frame window) and a set of audio features. We assume that the two streams are synchronised when the distances between features are minimised. However as suggests, one visual feature might not be enough to determine the correct offset, since not all samples contain discriminative information – for instance, there may be some 5-frame video segments in which nothing is said. Therefore, we also conduct experiments with the context window of more than 5 video frames, in which case we average the distances across multiple video samples (with a temporal stride of 1 frame).\

<figure id="fig:acc_N" data-latex-placement="t">

<figcaption>Synchronisation accuracy according to <span><em>N</em></span></figcaption>
</figure>

**Dataset.** The network is trained on the pre-train set of the Lip Reading Sentences 2 (LRS2)  dataset. The LRS2 dataset contains 96,318 clips for training, and 1,243 for test. There is a trade-off between the number of classes (or candidate audio features) $`N`$ and the number of available video clips for training, since longer video clips are required to train networks with larger $`N`$ (the candidate audio clips are sampled without overlap). We run experiments with different values of $`N`$ in order to find the optimal value, and report the accuracy and the number of available video clips in Figure <a href="#fig:acc_N" data-reference-type="ref" data-reference="fig:acc_N">1</a>.\
**Evaluation protocol.** The task is to determine the correct synchronisation within a $`\pm`$<!-- -->15 frame window, and the synchronisation is determined to be correct if the predicted offset is within 1 video frame of the ground truth. A random prediction would therefore yield 9.7% accuracy. Since there are non-informative frames, we also compute the sync offset over various numbers of input visual frames, using the average distances between features for input length $`K>5`$.\

**Results.** The results of experiments are given using the network trained with $`N=40`$ in Table <a href="#table:result_sync" data-reference-type="ref" data-reference="table:result_sync">1</a>. The performance of the proposed method far exceeds the baseline trained with a pair-wise objectives. In particular, for \# frames = 5 (_i.e._ no context beyond the receptive field), there is a significant increase in synchronisation performance from 75.8% to 89.5%.

## Visual speech recognition

<figure id="fig:arc_lr" data-latex-placement="t">
<img src="fig5_tc_5.png" style="width:60.0%" />
<figcaption>Architecture of the <span><strong>TC-5</strong></span> lip reading network.</figcaption>
</figure>

The network learns a powerful embedding of the visual information contained in the input video. The objective of this experiment is to show that the embeddings learnt by the matching network are effective for other applications, in this case, visual speech recognition. This is demonstrated on a word-level recognition task, and we compare the performance using the embeddings learnt by the proposed self-supervised method to networks trained end-to-end with full supervision.\
**Dataset.** We train and evaluate the models on the Lip Reading in the Wild (LRW) dataset, which consists of word-level speech and video segments extracted from the British television. The dataset has a vocabulary size of 500, and contains over 500,000 utterances, of which 25,000 are reserved for testing.\
**Architecture.** The front-end architecture is taken from the visual stream of the network described in Section <a href="#subsec:trunkarc" data-reference-type="ref" data-reference="subsec:trunkarc">[subsec:trunkarc]</a>. We propose a 2-layer temporal convolution back-end, followed by a 500-way softmax classification layer. This network structure is summarised in Figure <a href="#fig:arc_lr" data-reference-type="ref" data-reference="fig:arc_lr">2</a> and is referred to as **TC-5** in Table <a href="#table:result_lr" data-reference-type="ref" data-reference="table:result_lr">2</a>. The **‘5’** refers to the receptive field of the feature extractor in the temporal dimension, in line with the naming convention of the networks in . The performance of the **TC-5** model exceeds the network designs proposed in  when trained end-to-end (E2E). The visual features are extracted in advance for the ‘pre-trained’ experiments (PT), and only the back-end layers are trained for the 500-way classification task – the feature extractor is not fine-tuned with full supervision.\

The results are compared to existing lip reading networks based on the VGG-M base architecture, and also to a model with the identical **TC-5** architecture trained end-to-end on the large-scale LRW dataset in a full supervision. It is noteworthy that the performance of the feature extractor trained with the self-supervised method matches that of the end-to-end trained network without any fine-tuning.
