# Conflict of Interest

The author maintains the following publicly available fine-tuned Pashto ASR models that are evaluated in Section <a href="#sec:asr-finetuned" data-reference-type="ref" data-reference="sec:asr-finetuned">[sec:asr-finetuned]</a>: `ihanif/ps_base_l1`, `ihanif/pashto-asr-v3`, `ihanif/pashto-asr-base`, `ihanif/wav2vec2-xls-r-300m-pashto`, and `ihanif/w2v-bert2-pashto-augmented`. The author also created and contributed the Mozilla Common Voice Pashto corpus  that constitutes a substantial part of the CV24 test set used in this benchmark. All evaluation code and results are publicly available; the benchmark protocol is applied identically to all models regardless of authorship.
