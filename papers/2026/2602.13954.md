In this section, we present the prompt templates used in the DataFlux pipeline, including those for query generation and answer verification.

\# TASK SPECIFICATION\
\*\*STEP 1: VERIFICATION\*\*\
Analyze the provided ‘Audio Caption‘ against the ‘Category Hierarchy‘ (L0-L3).\

- Determine if the event described in the caption logically falls under the specific Sub-Task/Category provided.\
- \*\*Mismatch Example:\*\* Category is "Animal Sounds \> Dog" but Caption describes "A car engine revving". (Result: ‘is_success‘: false)\
- \*\*Match Example:\*\* Category is "Animal Sounds \> Dog" and Caption describes "A large dog barking aggressively". (Result: ‘is_success‘: true)\

  If the caption is consistent, generate \*\*5 distinct Multiple Choice Questions (MCQs)\*\* that a user would answer by \*\*LISTENING to the audio\*\*.\

- \*\*Distractors:\*\* Wrong options must be plausible audio events relevant to the context, not obviously ridiculous.\

## Prompts for Dense Audio Captioning Evaluation

In this section, we provide the prompts used in the dense audio captioning evaluation. Specifically, we include two types of prompts: (1) a caption generation prompt that instructs the model to produce comprehensive and semantically rich dense audio descriptions, and (2) a question answering prompt that takes the generated caption together with a downstream question as input to produce the final answer. The complete prompt formulations are presented to ensure transparency and reproducibility of the evaluation procedure.

<div class="tcolorbox">

Please provide a comprehensive description of the input audio, covering all details.

</div>

<div class="tcolorbox">

\### System Role\
You are an intelligent \*\*Audio-Based Question Answering Assistant\*\*.\
You will receive a textual \*\*\[Audio Caption\]\*\* generated by a specialized audio analysis model that provides comprehensive details about the audio content.\
\### Core Instructions\

1.  \*\*Source Reliability\*\*: The \[Audio Caption\] is your \*\*sole source of truth\*\*. It provides a detailed analysis of the audio, including speech content, speaker characteristics, background sounds, and emotional context.\
2.  \*\*Mapping Task\*\*: Your goal is to answer the \[User Question\] by extracting relevant evidence from the caption.\
3.  \*\*Handling Limitations\*\*: If the question asks for specific details that are not present in the caption, explicitly state that the information is not available in the audio analysis.\
    \### Thinking Process\
    Before answering:\
4.  \*\*Analyze\*\*: Carefully read the caption to understand all audio elements described.\
5.  \*\*Verify\*\*: Check if the caption contains sufficient evidence to support your answer.\
6.  \*\*Reason\*\*: Connect the observed audio elements to answer the question logically.\
    \### Input Data

        [Audio Caption]: "{caption}"
        [User Question]: "{question}"

\### Output Format\
Provide a direct and concise answer based on the audio caption. If the answer involves multiple-choice options, select the most appropriate one based on the evidence.\

</div>

## Decoding Throughput Comparison

#### Hardware Setup.

All experiments are conducted on a server equipped with dual Intel Xeon Platinum 8468V processors and NVIDIA H100 GPUs interconnected via NVSwitch. Throughput results are measured using 8x H100 GPU.

#### Evaluation Protocol.

We evaluate decoding throughput on 200 audio samples with a maximum generation length of 2,000 tokens. Throughput is computed as the average number of decoded tokens per second. Figure <a href="#fig:speed_comp" data-reference-type="ref" data-reference="fig:speed_comp">1</a> compares the decode throughput across different model sizes. Eureka-Audio-Instruct (1.7B) achieves the highest throughput of 269.7 tokens/sec, which is 1.2$`\times`$ faster than Qwen2.5-Omni-3B, 1.9$`\times`$ faster than Qwen2.5-Omni-7B, and 3.7$`\times`$ faster than Qwen3-Omni-30B-A3B. With only 1.7B parameters, 17$`\times`$ smaller than the largest baseline—our model delivers superior inference speed, making it well-suited for on-device deployment on mobile phones and edge devices.

Eureka-Audio achieves the highest decoding throughput among all compared models, demonstrating strong inference efficiency despite its compact parameter scale.
