# Polar codes for classical-quantum channels

Mark M. Wilde    Saikat Guha ^(†)^(†)thanks: Mark M. Wilde is with the
School of Computer Science, McGill University, Montreal, Quebec H3A 2A7,
Canada. Saikat Guha is with the Quantum Information Processing Group,
Raytheon BBN Technologies, Cambridge, Massachusetts, USA 02138. (E-mail:
mark.wilde@mcgill.ca; sguha@bbn.com)

###### Abstract

Holevo, Schumacher, and Westmoreland’s coding theorem guarantees the
existence of codes that are capacity-achieving for the task of sending
classical data over a channel with classical inputs and quantum outputs.
Although they demonstrated the existence of such codes, their proof does
not provide an explicit construction of codes for this task. The aim of
the present paper is to fill this gap by constructing near-explicit
“polar” codes that are capacity-achieving. The codes exploit the channel
polarization phenomenon observed by Arikan for the case of classical
channels. Channel polarization is an effect in which one can synthesize
a set of channels, by “channel combining” and “channel splitting,” in
which a fraction of the synthesized channels are perfect for data
transmission while the other fraction are completely useless for data
transmission, with the good fraction equal to the capacity of the
channel. The channel polarization effect then leads to a simple scheme
for data transmission: send the information bits through the perfect
channels and “frozen” bits through the useless ones. The main technical
contributions of the present paper are threefold. First, we leverage
several known results from the quantum information literature to
demonstrate that the channel polarization effect occurs for channels
with classical inputs and quantum outputs. We then construct linear
polar codes based on this effect, and the encoding complexity is
$`O(N\log N)`$, where $`N`$ is the blocklength of the code. We also
demonstrate that a quantum successive cancellation decoder works well,
in the sense that the word error rate decays exponentially with the
blocklength of the code. For this last result, we exploit Sen’s recent
“non-commutative union bound” that holds for a sequence of projectors
applied to a quantum state.

## I Introduction

Shannon’s fundamental contribution was to establish the capacity of a
noisy channel as the highest rate at which a sender can reliably
transmit data to a receiver \[[1](#bib.bib1)\]. His method of proof
exploited the probabilistic method and was thus non-constructive. Ever
since Shannon’s contribution, researchers have attempted to construct
error-correcting codes that can reach the capacity of a given channel.
Some of the most successful schemes for error correction are turbo codes
and low-density parity-check codes \[[2](#bib.bib2)\], with numerical
results demonstrating that these codes perform well for a variety of
channels. In spite of the success of these codes, there is no proof that
they are capacity achieving for channels other than the erasure channel
\[[3](#bib.bib3)\].

Recently, Arikan constructed polar codes and proved that they are
capacity achieving for a wide variety of channels \[[4](#bib.bib4)\].
Polar codes exploit the phenomenon of channel polarization, in which a
simple, recursive encoding synthesizes a set of channels that polarize,
in the sense that a fraction of them become perfect for transmission
while the other fraction are completely noisy and thus useless for
transmission. The fraction of the channels that become perfect for
transmission is equal to the capacity of the channel. In addition, the
complexity of both the encoding and decoding scales as
$`O\mathopen{}\left(N\log N\right)\mathclose{}`$, where $`N`$ is the
blocklength of the code. Arikan developed polar codes after studying how
the techniques of channel combining and channel splitting affect the
rate and reliability of a channel \[[5](#bib.bib5)\]. Arikan and others
have now extended the methods of polar coding to many different
settings, including arbitrary discrete memoryless channels
\[[6](#bib.bib6)\], source coding \[[7](#bib.bib7)\], lossy source
coding \[[3](#bib.bib3), [8](#bib.bib8)\], and the multiple access
channel with two senders and one receiver \[[9](#bib.bib9)\].

All of the above results are important for determining both the limits
on data transmission and methods for achieving these limits on classical
channels. The description of a classical channel $`p_{Y|X}`$ arises from
modeling the signaling alphabet, the physical transmission medium, and
the receiver measurement. If we are interested in accurately evaluating
and reaching the true data-transmission limits of the physical channels,
with an unspecified receiver measurement, and whose information carriers
require a quantum-mechanical description, then it becomes necessary to
invoke the laws of quantum mechanics. Examples of such channels include
deep-space optical channels and ultra-low-temperature
quantum-noise-limited RF channels. Achieving the classical communication
capacity for such (quantum) channels often requires making collective
measurements at the receiver, an action for which no classical
description or implementation exists. The quantum-mechanical approach to
information theory \[[10](#bib.bib10), [11](#bib.bib11)\] is not merely
a formality or technicality—encoding classical information with quantum
states and decoding with collective measurements on the channel outputs
\[[12](#bib.bib12), [13](#bib.bib13)\] can dramatically improve data
transmission rates, for example if the sender and receiver are operating
in a low-power regime for a pure-loss optical channel (which is a
practically relevant regime for long haul free-space terrestrial and
deep-space optical communication) \[[14](#bib.bib14),
[15](#bib.bib15)\]. Also, encoding with entangled inputs to the channels
can increase capacity for certain channels \[[16](#bib.bib16)\], a
superadditive effect which simply does not occur for classical channels.

The proof of one of the most important theorems of quantum information
theory is due to Holevo \[[12](#bib.bib12)\], Schumacher, and
Westmoreland \[[13](#bib.bib13)\] (HSW). They showed that the Holevo
information of a quantum channel is an achievable rate for classical
communication over it. Their proof of the HSW theorem bears some
similarities with Shannon’s technique (including the use of random
coding), but their main contribution was the construction of a quantum
measurement at the receiving end that allows for reliable decoding at
the Holevo information rate. Since the proof of the HSW theorem, several
researchers have improved the proof’s error analysis
\[[17](#bib.bib17)\], and others have demonstrated different techniques
for achieving the Holevo information \[[18](#bib.bib18),
[19](#bib.bib19), [20](#bib.bib20), [21](#bib.bib21),
[22](#bib.bib22)\]. Very recently, Giovannetti et al. proved that a
sequential decoding approach can achieve the Holevo information
\[[23](#bib.bib23)\]. The sequential decoding approach has the receiver
ask, through a series of dichotomic quantum measurements, whether the
output of the channel was the first codeword, the second codeword,
etc. (this approach is similar in spirit to a classical
“jointly-typical” decoder \[[24](#bib.bib24)\]). As long as the rate of
the code is less than the Holevo information, then this sequential
decoder will correctly identify the transmitted codeword with
asymptotically negligible error probability. Sen recently simplified the
error analysis of this sequential decoding approach (rather
significantly) by introducing a “non-commutative union bound” in order
to bound the error probability of quantum sequential decoding
\[[25](#bib.bib25)\].

In spite of the large amount of effort placed on proving that the Holevo
information is achievable, there has been relatively little work on
devising explicit codes that approach the Holevo information rate.¹¹ 1
This is likely due to the large amount of effort that the quantum
information community has put towards quantum error
correction \[[26](#bib.bib26)\], which is important for the task of
transmitting quantum bits over a noisy quantum channel or for building a
fault-tolerant quantum computer. Also, there might be a general belief
that classical coding strategies would extend easily for sending
classical information over quantum channels, but this is not the case
given that collective measurements on channel outputs are required to
achieve the Holevo information rate and the classical strategies do not
incorporate these collective measurements. The aim of the present paper
is to fill this gap by generalizing the polar coding approach to quantum
channels. In doing so, we construct the first explicit class of linear
codes that approach the Holevo information rate with asymptotically
small error probability.

The main technical contributions of the present paper are as follows:

1.  1.  We characterize rate with the symmetric Holevo information
        \[[27](#bib.bib27), [12](#bib.bib12), [10](#bib.bib10),
        [11](#bib.bib11)\] and reliability with the fidelity
        \[[28](#bib.bib28), [29](#bib.bib29), [10](#bib.bib10),
        [11](#bib.bib11)\] between channel outputs corresponding to
        different classical inputs. These parameters generalize the
        symmetric Shannon capacity and the Bhattacharya
        parameter \[[4](#bib.bib4)\], respectively, to the quantum case. We
        demonstrate that the symmetric Holevo information and the fidelity
        polarize under a recursive channel transformation similar to
        Arikan’s \[[4](#bib.bib4)\], by exploiting Arikan’s proof ideas
        \[[4](#bib.bib4)\] and several tools from the quantum information
        literature \[[30](#bib.bib30), [31](#bib.bib31), [32](#bib.bib32),
        [10](#bib.bib10), [33](#bib.bib33), [11](#bib.bib11)\].
2.  2.  The second contribution of ours is the generalization of Arikan’s
        successive cancellation decoder \[[4](#bib.bib4)\] to the quantum
        case. We exploit ideas from quantum hypothesis testing
        \[[34](#bib.bib34), [35](#bib.bib35), [36](#bib.bib36),
        [37](#bib.bib37), [38](#bib.bib38)\] in order to construct the
        quantum successive cancellation decoder, and we use Sen’s recent
        “non-commutative union bound” \[[25](#bib.bib25)\] in order to
        demonstrate that the decoder performs reliably in the limit of many
        channel uses, while achieving the symmetric Holevo information rate.

The complexity of the encoding part of our polar coding scheme is
$`O\mathopen{}\left(N\log N\right)\mathclose{}`$ where $`N`$ is the
blocklength of the code (the argument for this follows directly from
Arikan’s \[[4](#bib.bib4)\]). However, we have not yet been able to show
that the complexity of the decoding part is
$`O\mathopen{}\left(N\log N\right)\mathclose{}`$ (as is the case with
Arikan’s decoder \[[4](#bib.bib4)\]). Determining how to simplify the
complexity of the decoding part is the subject of ongoing research. For
now, we should regard our contribution in this paper as a more explicit
method for achieving the Holevo information rate (as compared to those
from prior work \[[12](#bib.bib12), [13](#bib.bib13), [18](#bib.bib18),
[19](#bib.bib19), [20](#bib.bib20), [21](#bib.bib21)\]).

One might naively think from a casual glance at our paper that Arikan’s
results \[[4](#bib.bib4)\] directly apply to our quantum scenario here,
but this is not the case. If one were to impose single-symbol detection
on the outputs of the quantum channels,²² 2 For instance, all known
conventional optical receivers are single-symbol detectors. They detect
each modulated pulse individually, followed by classical postprocessing.
such a procedure would induce a classical channel from input to output.
In this case, Arikan’s results do apply in that they can attain the
Shannon capacity of this induced classical channel.

However, the Shannon capacity of the best single-symbol detection
strategy may be far below the Holevo limit \[[14](#bib.bib14),
[15](#bib.bib15)\]. Attaining the Holevo information rate generally
requires the receiver to perform collective measurements (physical
detection of the quantum state of the entire codeword that may not be
realizable by detecting single symbols one at a time). We should stress
that what we are doing in this paper is different from a naive
application of Arikan’s results. First, our polar coding rule depends on
a quantum parameter, the fidelity, rather than the Bhattacharya distance
(a classical parameter). The polar coding rule is then different from
Arikan’s, and we would thus expect a larger fraction of the channels to
be “good” channels than if one were to impose a single-symbol
measurement and exploit Arikan’s polar coding rule with the Bhattacharya
distance. Second, the quantum measurements in our quantum successive
cancellation decoder are collective measurements performed on all of the
channel outputs. Were it not so, then our polar coding scheme would not
achieve the Holevo information rate in general.

Section [III](#S3 "III Recursive Channel Transformations ‣ Polar codes for classical-quantum channels")

in

## II Overview of Results

Our setting involves a classical-quantum channel $`W`$ with a classical
input $`x`$ and a quantum output $`\rho_{x}`$:

|     |     |     |
| --- | --- | --- |
|     |

       ``` math
       W:x\rightarrow\rho_{x},
       ```                      |     |

where $`x\in\mathopen{}\left\{0,1\right\}\mathclose{}`$ and $`\rho_{x}`$
is a unit trace, positive operator called a density operator. We can
associate a probability distribution and a classical label with the
states $`\rho_{0}`$ and $`\rho_{1}`$ by writing the following
classical-quantum state \[[11](#bib.bib11)\]:

|     |     |     |
| --- | --- | --- |
|     |

````math
\rho^{XB}\equiv\frac{1}{2}\mathopen{}\left|0\right\rangle\mathclose{}\mathopen{}\left\langle 0\right|\mathclose{}^{X}\otimes\rho_{0}^{B}+\frac{1}{2}\mathopen{}\left|1\right\rangle\mathclose{}\mathopen{}\left\langle 1\right|\mathclose{}^{X}\otimes\rho_{1}^{B}.
``` |  |

Two important parameters for characterizing any classical-quantum
channel are its rate and reliability.³³ 3 We are using the same
terminology as Arikan \[[4](#bib.bib4)\]. We define the rate in terms of
the channel’s symmetric Holevo information
$`I\mathopen{}\left(W\right)\mathclose{}`$ where

|  |  |  |
|----|----|----|
|  |
``` math
I\mathopen{}\left(W\right)\mathclose{}\equiv I\mathopen{}\left(X;B\right)\mathclose{}_{\rho}.
``` |  |

$`I\mathopen{}\left(X;B\right)\mathclose{}_{\rho}`$ is the quantum
mutual information of the state $`\rho^{XB}`$, defined as

|  |  |  |
|----|----|----|
|  |
``` math
I\mathopen{}\left(X;B\right)\mathclose{}_{\rho}\equiv H\mathopen{}\left(X\right)\mathclose{}_{\rho}+H\mathopen{}\left(B\right)\mathclose{}_{\rho}-H\mathopen{}\left(XB\right)\mathclose{}_{\rho},
``` |  |

and the von Neumann entropy
$`H\mathopen{}\left(\sigma\right)\mathclose{}`$ of any density operator
$`\sigma`$ is defined as

|  |  |  |
|----|----|----|
|  |
``` math
H\mathopen{}\left(\sigma\right)\mathclose{}\equiv-\text{Tr}\mathopen{}\left\{\sigma\log_{2}\sigma\right\}\mathclose{}.
``` |  |

(Observe that the von Neumann entropy of $`\sigma`$ is equal to the
Shannon entropy of its eigenvalues.) It is also straightforward to
verify that

|  |  |  |
|----|----|----|
|  |
``` math
I\mathopen{}\left(W\right)\mathclose{}=H((\rho_{0}^{B}+\rho_{1}^{B})/2)-H(\rho_{0}^{B})/2-H(\rho_{1}^{B})/2.
``` |  |

The symmetric Holevo information is non-negative by concavity of von
Neumann entropy, and it can never exceed one if the system $`X`$ is a
classical binary system (as is the case for the classical-quantum state
$`\rho^{XB}`$). Additionally, the symmetric Holevo information is equal
to zero if there is no correlation between $`X`$ and $`B`$. It is equal
to the capacity of the channel $`W`$ for transmitting classical bits
over it if the input prior distribution is restricted to be uniform
\[[12](#bib.bib12), [13](#bib.bib13)\]. It also generalizes the
symmetric capacity \[[4](#bib.bib4)\] to the quantum setting given
above.

We define the reliability of the channel $`W`$ as the fidelity between
the states $`\rho_{0}`$ and $`\rho_{1}`$ \[[28](#bib.bib28),
[29](#bib.bib29), [10](#bib.bib10), [11](#bib.bib11)\]:

|  |  |  |
|----|----|----|
|  |
``` math
F\mathopen{}\left(\rho_{0},\rho_{1}\right)\mathclose{}\equiv\mathopen{}\left\|\sqrt{\rho_{0}}\sqrt{\rho_{1}}\right\|\mathclose{}_{1}^{2},
``` |  |

where $`\mathopen{}\left\|A\right\|\mathclose{}_{1}`$ is the nuclear
norm of the operator $`A`$:

|  |  |  |
|----|----|----|
|  |
``` math
\mathopen{}\left\|A\right\|\mathclose{}_{1}=\text{Tr}\mathopen{}\left\{\sqrt{A^{{\dagger}}A}\right\}\mathclose{}.
``` |  |

Let $`F\mathopen{}\left(W\right)\mathclose{}`$ denote the reliability of
the channel $`W`$:

|  |  |  |
|----|----|----|
|  |
``` math
F\mathopen{}\left(W\right)\mathclose{}\equiv F\mathopen{}\left(\rho_{0},\rho_{1}\right)\mathclose{}.
``` |  |

The fidelity is equal to a number between zero and one, and it
characterizes how “close” two quantum states are to one another. It is
equal to zero if and only if there exists a quantum measurement that can
perfectly distinguish the states, and it is equal to one if the states
are indistinguishable by any measurement \[[10](#bib.bib10),
[11](#bib.bib11)\]. The fidelity generalizes the Bhattacharya parameter
used in the classical setting \[[4](#bib.bib4)\]. Naturally, we would
expect the channel $`W`$ to be perfectly reliable if
$`F\mathopen{}\left(W\right)\mathclose{}=0`$ and completely unreliable
if $`F\mathopen{}\left(W\right)\mathclose{}=1`$. The fidelity also
serves as a coarse bound on the probability of error in discriminating
the states $`\rho_{0}`$ and $`\rho_{1}`$ \[[37](#bib.bib37),
[39](#bib.bib39)\].

We would expect the symmetric Holevo information
$`I\mathopen{}\left(W\right)\mathclose{}\approx 1`$ if and only if the
channel’s fidelity $`F\mathopen{}\left(W\right)\mathclose{}\approx 0`$
and vice versa:
$`I\mathopen{}\left(W\right)\mathclose{}\approx 0\Leftrightarrow F\mathopen{}\left(W\right)\mathclose{}\approx 1`$.
The following proposition makes this intuition rigorous, and it serves
as a generalization of Arikan’s first proposition regarding the
relationship between rate and reliability. We provide its proof in the
appendix.

###### Proposition 1

For any binary input classical-quantum channel of the above form, the
following bounds hold

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle I\mathopen{}\left(W\right)\mathclose{}`$ | $`\displaystyle\geq\log_{2}\mathopen{}\left(\frac{2}{1+\sqrt{F\mathopen{}\left(W\right)\mathclose{}}}\right)\mathclose{},`$ |  | (1) |
|  | $`\displaystyle I\mathopen{}\left(W\right)\mathclose{}`$ | $`\displaystyle\leq\sqrt{1-F\mathopen{}\left(W\right)\mathclose{}}.`$ |  | (2) |

### II-A Channel Polarization

The channel polarization phenomenon occurs after synthesizing a set of
$`N`$ classical-quantum channels
$`\{W_{N}^{\mathopen{}\left(i\right)\mathclose{}}:1\leq i\leq N\}`$ from
$`N`$ independent copies of the classical-quantum channel $`W`$. The
effect is known as “polarization” because a fraction of the channels
$`W_{N}^{\mathopen{}\left(i\right)\mathclose{}}`$ become perfect for
data transmission,⁴⁴ 4 One cannot expect to transmit more than one
classical bit over a perfect qubit channel due to Holevo’s bound
\[[27](#bib.bib27)\]. in the sense that
$`I(W_{N}^{\mathopen{}\left(i\right)\mathclose{}})\approx 1`$ for the
channels in this fraction, while the channels in the complementary
fraction become completely useless in the sense that
$`I(W_{N}^{\mathopen{}\left(i\right)\mathclose{}})\approx 0`$ in the
limit as $`N`$ becomes large. Also, the fraction of channels that do not
exhibit polarization vanishes as $`N`$ becomes large. One can induce the
polarization effect by means of channel combining and channel splitting.

``` |  |

so that

W_{4}^{B_{1}B_{2}B_{3}B_{4}}\mathopen{}\left(u_{1},u_{2},u_{3},u_{4}\right)\mathclose{}\\
=\rho_{u_{1}\oplus u_{2}\oplus u_{3}\oplus u_{4}}^{B_{1}}\otimes\rho_{u_{3}\oplus u_{4}}^{B_{2}}\otimes\rho_{u_{2}\oplus u_{4}}^{B_{3}}\otimes\rho_{u_{4}}^{B_{4}}.

The general recursion at the $`n^{\text{th}}`$ level is to take two
copies of $`W_{N/2}`$ and synthesize a channel $`W_{N}`$ from them. The
first part is to transform the input sequence $`u^{N}`$ according to the
following rule for all
$`i\in\mathopen{}\left\{1,\ldots,N/2\right\}\mathclose{}`$:

|     |                            |                                          |     |
|-----|----------------------------|------------------------------------------|-----|
|     | $`\displaystyle s_{2i-1}`$ | $`\displaystyle=u_{2i-1}\oplus u_{2i},`$ |     |
|     | $`\displaystyle s_{2i}`$   | $`\displaystyle=u_{2i}.`$                |     |

The next part of the transformation is a “reverse shuffle” $`R_{N}`$
that performs the transformation:

|  |  |  |
|----|----|----|
|  |
``` math
\mathopen{}\left(s_{1},s_{2},s_{3},s_{4},\ldots,s_{N-1},s_{N}\right)\mathclose{}\\
\rightarrow\mathopen{}\left(s_{1},s_{3},\ldots,s_{N-1},s_{2},s_{4},\ldots,s_{N}\right)\mathclose{}.
``` |  |

The resulting bit sequence is the input to the two copies of
$`W_{N/2}`$.

The overall transformation on the input sequence $`u^{N}`$ is a linear
transformation given by $`x^{N}=u^{N}G_{N}`$ where

|     |                           |     |     |
|-----|---------------------------|-----|-----|
|     |
       ``` math
       G_{N}=B_{N}F^{\otimes n},
       ```                        |     | (5) |

where

|     |                             |     |
|-----|-----------------------------|-----|
|     |
       ``` math
       F\equiv\begin{bmatrix}1&0\\
       1&1\end{bmatrix},
       ```                          |     |

and $`B_{N}`$ is a permutation matrix known as a “bit-reversal”
operation \[[4](#bib.bib4)\].

#### II-A2 Channel Splitting

The channel splitting phase consists of taking the channels $`W_{N}`$
induced by the transformation $`G_{N}`$ and defining new channels
$`W_{N}^{\mathopen{}\left(i\right)\mathclose{}}`$ from them. Let
$`\rho_{u^{N}}`$ denote the output of the channel $`W_{N}`$ when
inputting the bit sequence $`u^{N}`$. We define the $`i^{\text{th}}`$
split channel $`W_{N}^{\mathopen{}\left(i\right)\mathclose{}}`$ as
follows:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
W_{N}^{\mathopen{}\left(i\right)\mathclose{}}:u_{i}\rightarrow\rho_{\mathopen{}\left(i\right)\mathclose{},u_{i}}^{U_{1}^{i-1}B^{N}},
``` |  | (6) |

where

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\rho_{\mathopen{}\left(i\right)\mathclose{},u_{i}}^{U_{1}^{i-1}B^{N}}`$ | $`\displaystyle\equiv\sum_{u_{1}^{i-1}}\frac{1}{2^{i-1}}\mathopen{}\left|u_{1}^{i-1}\right\rangle\mathclose{}\mathopen{}\left\langle u_{1}^{i-1}\right|\mathclose{}^{U_{1}^{i-1}}\otimes\overline{\rho}_{u_{1}^{i}}^{B^{N}},`$ |  | (7) |
|  | $`\displaystyle\overline{\rho}_{u_{1}^{i}}^{B^{N}}`$ | $`\displaystyle\equiv\sum_{u_{i+1}^{N}}\frac{1}{2^{N-i}}\rho_{u^{N}}^{B^{N}}.`$ |  | (8) |

We can also write as an alternate notation

|  |  |  |
|----|----|----|
|  |
``` math
W_{N}^{\mathopen{}\left(i\right)\mathclose{}}(u_{i})=\rho_{\mathopen{}\left(i\right)\mathclose{},u_{i}}^{U_{1}^{i-1}B^{N}}.
``` |  |

These channels have the same interpretation as Arikan’s split channels
\[[4](#bib.bib4)\]—they are the channels induced by a “genie-aided”
quantum successive cancellation decoder, in which the $`i^{\text{th}}`$
decision measurement estimates $`u_{i}`$ given that the channel output
$`\rho_{u^{N}}^{B^{N}}`$ is available, after observing the previous bits
$`u_{1}^{i-1}`$ correctly, and if the distribution over $`u_{i+1}^{N}`$
is uniform. These split channels arise in our analysis of the error
probability for quantum successive cancellation decoding.

#### II-A3 Channel Polarization

Our channel polarization theorem below is similar to Arikan’s Theorem 1
\[[4](#bib.bib4)\], though ours applies for classical-quantum channels
with binary inputs and quantum outputs:

###### Theorem 2 (Channel Polarization)

The classical-quantum channels
$`W_{N}^{\mathopen{}\left(i\right)\mathclose{}}`$ synthesized from the
channel $`W^{\otimes N}`$ polarize, in the sense that the fraction of
indices $`i\in\mathopen{}\left\{1,\ldots,N\right\}\mathclose{}`$ for
which
$`I(W_{N}^{\mathopen{}\left(i\right)\mathclose{}})\in(1-\delta,1]`$ goes
to the symmetric Holevo information
$`I\mathopen{}\left(W\right)\mathclose{}`$ and the fraction for which
$`I(W_{N}^{\mathopen{}\left(i\right)\mathclose{}})\in[0,\delta)`$ goes
to $`1-I\mathopen{}\left(W\right)\mathclose{}`$ for any
$`\delta\in\mathopen{}\left(0,1\right)\mathclose{}`$ as $`N`$ goes to
infinity through powers of two.

The proof of the above theorem is identical to Arikan’s proof with a
martingale approach \[[4](#bib.bib4)\]. For completeness, we provide a
brief proof in
Section [IV](#S4 "IV Channel Polarization ‣ Polar codes for classical-quantum channels").

#### II-A4 Rate of Polarization

It is important to characterize the speed with which the polarization
phenomenon comes into play for the purpose of proving this paper’s polar
coding theorem. We exploit the fidelity
$`F(W^{\mathopen{}\left(i\right)\mathclose{}})`$ of the split channels
in order to characterize the rate of polarization:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
F(W_{N}^{\mathopen{}\left(i\right)\mathclose{}})\equiv F(\rho_{\mathopen{}\left(i\right)\mathclose{},0}^{U_{1}^{i-1}B^{N}},\rho_{\mathopen{}\left(i\right)\mathclose{},1}^{U_{1}^{i-1}B^{N}}).
``` |  | (9) |

The theorem below exploits the exponential convergence results of Arikan
and Telatar \[[40](#bib.bib40)\], which improved upon Arikan’s original
convergence results \[[4](#bib.bib4)\] (note that we could also use the
more general results in Ref. \[[41](#bib.bib41)\]):

###### Theorem 3 (Rate of Polarization)

Given any classical-quantum channel $`W`$ with
$`I\mathopen{}\left(W\right)\mathclose{}>0`$, any
$`R<I\mathopen{}\left(W\right)\mathclose{}`$, and any constant
$`\beta<1/2`$, there exists a sequence of sets
$`\mathcal{A}_{N}\subset\mathopen{}\left\{1,\ldots,N\right\}\mathclose{}`$
with $`\mathopen{}\left|\mathcal{A}_{N}\right|\mathclose{}\geq NR`$ such
that

|  |  |  |
|----|----|----|
|  |
``` math
\sum_{i\in\mathcal{A}_{N}}\sqrt{F(W_{N}^{\mathopen{}\left(i\right)\mathclose{}})}=o(2^{-N^{\beta}}).
``` |  |

Conversely, suppose that $`R>0`$ and $`\beta>1/2`$. Then for any
sequence of sets
$`\mathcal{A}_{N}\subset\mathopen{}\left\{1,\ldots,N\right\}\mathclose{}`$
with $`\mathopen{}\left|\mathcal{A}_{N}\right|\mathclose{}\geq NR`$, the
following result holds

|  |  |  |
|----|----|----|
|  |
``` math
\max\mathopen{}\left\{\sqrt{F(W_{N}^{\mathopen{}\left(i\right)\mathclose{}})}:i\in\mathcal{A}_{N}\right\}\mathclose{}=\omega(2^{-N^{\beta}}).
``` |  |

The proof of this theorem exploits our results in
Section [III](#S3 "III Recursive Channel Transformations ‣ Polar codes for classical-quantum channels")
and Theorem 1 of Ref. \[[40](#bib.bib40)\].

### II-B Polar Coding

The idea behind polar coding is to exploit the polarization effect for
the construction of a capacity-achieving code. The sender should
transmit the information bits only through the split channels
$`W_{N}^{\mathopen{}\left(i\right)\mathclose{}}`$ for which the
reliability parameter
$`F(W_{N}^{\mathopen{}\left(i\right)\mathclose{}})`$ is close to zero.
In doing so, the sender and receiver can achieve the symmetric Holevo
information $`I\mathopen{}\left(W\right)\mathclose{}`$ of the channel
$`W`$.

#### II-B1 Coset Codes

Polar codes arise from a special class of codes that Arikan calls
“$`G_{N}`$-coset codes” \[[4](#bib.bib4)\]. These $`G_{N}`$-coset codes
are given by the following mapping from the input sequence $`u^{N}`$ to
the channel input sequence $`x^{N}`$:

|     |                   |     |
|-----|-------------------|-----|
|     |
       ``` math
       x^{N}=u^{N}G_{N},
       ```                |     |

where $`G_{N}`$ is the encoding matrix defined in
([5](#S2.E5 "In II-A1 Channel Combining ‣ II-A Channel Polarization ‣ II Overview of Results ‣ Polar codes for classical-quantum channels")).
Suppose that $`\mathcal{A}`$ is some subset of
$`\mathopen{}\left\{1,\ldots,N\right\}\mathclose{}`$. Then we can write
the above transformation as follows:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
x^{N}=u_{\mathcal{A}}G_{N}\mathopen{}\left(\mathcal{A}\right)\mathclose{}\oplus u_{\mathcal{A}^{c}}G_{N}\mathopen{}\left(\mathcal{A}^{c}\right)\mathclose{},
``` |  | (10) |

where $`G_{N}\mathopen{}\left(\mathcal{A}\right)\mathclose{}`$ denotes
the submatrix of $`G_{N}`$ constructed from the rows of $`G_{N}`$ with
indices in $`\mathcal{A}`$ and $`\oplus`$ denotes vector binary
addition.

Suppose that we fix the set $`\mathcal{A}`$ and the bit sequence
$`u_{\mathcal{A}^{c}}`$. The mapping in
([10](#S2.E10 "In II-B1 Coset Codes ‣ II-B Polar Coding ‣ II Overview of Results ‣ Polar codes for classical-quantum channels"))
then specifies a transformation from the bit sequence
$`u_{\mathcal{A}}`$ to the channel input sequence $`x^{N}`$. This
mapping is equivalent to a linear encoding for a code that Arikan calls
a $`G_{N}`$-coset code where the sequence
$`u_{\mathcal{A}^{c}}G_{N}\mathopen{}\left(\mathcal{A}^{c}\right)\mathclose{}`$
identifies the coset. We can fully specify a coset code by the parameter
vector
$`\mathopen{}\left(N,K,\mathcal{A},u_{\mathcal{A}^{c}}\right)\mathclose{}`$
where $`N`$ is the length of the code,
$`K=\mathopen{}\left|\mathcal{A}\right|\mathclose{}`$ is the number of
information bits, $`\mathcal{A}`$ is a set that identifies the indices
for the information bits, and $`u_{\mathcal{A}^{c}}`$ is the vector of
frozen bits. The polar coding rule specifies a way to choose the indices
for the information bits based on the channel over which the sender is
transmitting data.

#### II-B2 A Quantum Successive Cancellation Decoder

The specification of the quantum successive cancellation decoder is what
mainly distinguishes Arikan’s polar codes for classical channels from
ours developed here for classical-quantum channels. Let us begin with a
$`G_{N}`$-coset code with parameter vector
$`\mathopen{}\left(N,K,\mathcal{A},u_{\mathcal{A}^{c}}\right)\mathclose{}`$.
The sender encodes the information bit vector $`u_{\mathcal{A}}`$ along
with the frozen vector $`u_{\mathcal{A}^{c}}`$ according to the
transformation in
([10](#S2.E10 "In II-B1 Coset Codes ‣ II-B Polar Coding ‣ II Overview of Results ‣ Polar codes for classical-quantum channels")).
The sender then transmits the encoded sequence $`x^{N}`$ through the
classical-quantum channel, leading to a state
$`\rho_{x_{1}}\otimes\cdots\otimes\rho_{x_{N}}`$, which is equivalent to
a state $`\rho_{u^{N}}`$ up to the transformation $`G_{N}`$. It is then
the goal of the receiver to perform a sequence of quantum measurements
on the state $`\rho_{u^{N}}`$ in order to determine the bit sequence
$`u^{N}`$. We are assuming that the receiver has full knowledge of the
frozen vector $`u_{\mathcal{A}^{c}}`$ so that he does not make mistakes
when decoding these bits.

Corresponding to the split channels
$`W_{N}^{\mathopen{}\left(i\right)\mathclose{}}`$ in
([6](#S2.E6 "In II-A2 Channel Splitting ‣ II-A Channel Polarization ‣ II Overview of Results ‣ Polar codes for classical-quantum channels"))
are the following projectors that can attempt to decide whether the
input of the $`i^{\text{th}}`$ split channel is zero or one:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\Pi_{\mathopen{}\left(i\right)\mathclose{},0}^{U_{1}^{i-1}B^{N}}`$ | $`\displaystyle\equiv\mathopen{}\left\{\sqrt{\rho_{\mathopen{}\left(i\right)\mathclose{},0}^{U_{1}^{i-1}B^{N}}}-\sqrt{\rho_{\mathopen{}\left(i\right)\mathclose{},1}^{U_{1}^{i-1}B^{N}}}\geq 0\right\}\mathclose{},`$ |  |
|  | $`\displaystyle\Pi_{\mathopen{}\left(i\right)\mathclose{},1}^{U_{1}^{i-1}B^{N}}`$ | $`\displaystyle\equiv I-\Pi_{\mathopen{}\left(i\right)\mathclose{},0}^{U_{1}^{i-1}B^{N}}`$ |  |
|  |  | $`\displaystyle=\mathopen{}\left\{\sqrt{\rho_{\mathopen{}\left(i\right)\mathclose{},0}^{U_{1}^{i-1}B^{N}}}-\sqrt{\rho_{\mathopen{}\left(i\right)\mathclose{},1}^{U_{1}^{i-1}B^{N}}}<0\right\}\mathclose{},`$ |  |

where $`\sqrt{A}`$ denotes the square root of a positive operator $`A`$,
$`\mathopen{}\left\{B\geq 0\right\}\mathclose{}`$ denotes the projector
onto the positive eigenspace of a Hermitian operator $`B`$, and
$`\mathopen{}\left\{B<0\right\}\mathclose{}`$ denotes the projection
onto the negative eigenspace of $`B`$. After some calculations, we can
readily see that

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\Pi_{\mathopen{}\left(i\right)\mathclose{},0}^{U_{1}^{i-1}B^{N}}`$ | $`\displaystyle=\sum_{u_{1}^{i-1}}\mathopen{}\left|u_{1}^{i-1}\right\rangle\mathclose{}\mathopen{}\left\langle u_{1}^{i-1}\right|\mathclose{}^{U_{1}^{i-1}}\otimes\Pi_{\mathopen{}\left(i\right)\mathclose{},u_{1}^{i-1}0}^{B^{N}},`$ |  | (11) |
|  | $`\displaystyle\Pi_{\mathopen{}\left(i\right)\mathclose{},1}^{U_{1}^{i-1}B^{N}}`$ | $`\displaystyle=\sum_{u_{1}^{i-1}}\mathopen{}\left|u_{1}^{i-1}\right\rangle\mathclose{}\mathopen{}\left\langle u_{1}^{i-1}\right|\mathclose{}^{U_{1}^{i-1}}\otimes\Pi_{\mathopen{}\left(i\right)\mathclose{},u_{1}^{i-1}1}^{B^{N}},`$ |  | (12) |

where

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\Pi_{\mathopen{}\left(i\right)\mathclose{},u_{1}^{i-1}0}^{B^{N}}`$ | $`\displaystyle\equiv\mathopen{}\left\{\sqrt{\overline{\rho}_{u_{1}^{i-1}0}^{B^{N}}}-\sqrt{\overline{\rho}_{u_{1}^{i-1}1}^{B^{N}}}\geq 0\right\}\mathclose{},`$ |  |
|  | $`\displaystyle\Pi_{\mathopen{}\left(i\right)\mathclose{},u_{1}^{i-1}1}^{B^{N}}`$ | $`\displaystyle\equiv\mathopen{}\left\{\sqrt{\overline{\rho}_{u_{1}^{i-1}0}^{B^{N}}}-\sqrt{\overline{\rho}_{u_{1}^{i-1}1}^{B^{N}}}<0\right\}\mathclose{}.`$ |  |

The above observations lead to a method for a successive cancellation
decoder similar to Arikan’s \[[4](#bib.bib4)\], with the following
decoding rule:

|  |  |  |
|----|----|----|
|  |
``` math
\hat{u}_{i}=\mathopen{}\left\{\begin{array}[c]{cc}u_{i}&\text{if }i\in\mathcal{A}^{c}\\
h\mathopen{}\left(\hat{u}_{1}^{i-1}\right)\mathclose{}&\text{if }i\in\mathcal{A}\end{array}\right.\mathclose{},
``` |  |

where $`h\mathopen{}\left(\hat{u}_{1}^{i-1}\right)\mathclose{}`$ is the
outcome of the following $`i^{\text{th}}`$ measurement on the output of
the channel (after $`i-1`$ measurements have already been performed):

|  |  |  |
|----|----|----|
|  |
``` math
\mathopen{}\left\{\Pi_{\mathopen{}\left(i\right)\mathclose{},\hat{u}_{1}^{i-1}0}^{B^{N}},\Pi_{\mathopen{}\left(i\right)\mathclose{},\hat{u}_{1}^{i-1}1}^{B^{N}}\right\}\mathclose{}.
``` |  |

We are assuming that the measurement device outputs “0” if the outcome
$`\Pi_{\mathopen{}\left(i\right)\mathclose{},\hat{u}_{1}^{i-1}0}^{B^{N}}`$
occurs and it outputs “1” otherwise. (Note that we can set
$`\Pi_{\mathopen{}\left(i\right)\mathclose{},\hat{u}_{1}^{i-1}u_{i}}^{B^{N}}=I`$
if the bit $`u_{i}`$ is a frozen bit.) The above sequence of
measurements for the whole bit stream $`u^{N}`$ corresponds to a
positive operator-valued measure
(POVM) $`\mathopen{}\left\{\Lambda_{u^{N}}\right\}\mathclose{}`$ where

|  |  |  |
|----|----|----|
|  |
``` math
\Lambda_{u^{N}}\equiv\Pi_{\mathopen{}\left(1\right)\mathclose{},u_{1}}^{B^{N}}\cdots\Pi_{\mathopen{}\left(i\right)\mathclose{},u_{1}^{i-1}u_{i}}^{B^{N}}\cdots\\
\cdots\Pi_{\mathopen{}\left(N\right)\mathclose{},u_{1}^{N-1}u_{N}}^{B^{N}}\cdots\Pi_{\mathopen{}\left(i\right)\mathclose{},u_{1}^{i-1}u_{i}}^{B^{N}}\cdots\Pi_{\mathopen{}\left(1\right)\mathclose{},u_{1}}^{B^{N}},
``` |  |

|     |                                                  |     |
|-----|--------------------------------------------------|-----|
|     |
       ``` math
       \sum_{u_{\mathcal{A}}}\Lambda_{u^{N}}=I^{B^{N}}.
       ```                                               |     |

The above decoding strategy is suboptimal in two regards. First, the
decoder assumes that the future bits are unknown (and random) even if
the receiver has full knowledge of the future frozen bits (this
suboptimality is similar to the suboptimality of Arikan’s
decoder \[[4](#bib.bib4)\]). Second, the measurement operators for
making a decision are suboptimal as well because we choose them to be
projectors onto the positive eigenspace of the difference of the square
roots of two density operators. The optimal bitwise decision rule is to
choose these operators to be the Helstrom-Holevo projector onto the
positive eigenspace of the difference of two density operators
\[[34](#bib.bib34), [35](#bib.bib35)\]. Having our quantum successive
cancellation decoder operate in these two different suboptimal ways
allows for us to analyze its performance easily (though, note that we
could just as well have used Helstrom-Holevo measurements to obtain
bounds on the error probability). This suboptimality is asymptotically
negligible because the symmetric Holevo information is still an
achievable rate for data transmission even for the above choice of
measurement operators.

#### II-B3 Polar Code Performance

The probability of error
$`P_{e}\mathopen{}\left(N,K,\mathcal{A},u_{\mathcal{A}^{c}}\right)\mathclose{}`$
for code length $`N`$, number $`K`$ of information bits, set
$`\mathcal{A}`$ of information bits, and choice $`u_{\mathcal{A}^{c}}`$
for the frozen bits is as follows:

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle P_{e}\mathopen{}\left(N,K,\mathcal{A},u_{\mathcal{A}^{c}}\right)\mathclose{}`$ |  |
|  |  | $`\displaystyle=\frac{1}{2^{K}}\sum_{u_{\mathcal{A}}}\text{Tr}\mathopen{}\left\{\mathopen{}\left(I-\Lambda_{u^{N}}\right)\mathclose{}\rho_{u^{N}}\right\}\mathclose{}`$ |  |
|  |  | $`\displaystyle=1-\frac{1}{2^{K}}\sum_{u_{\mathcal{A}}}\text{Tr}\mathopen{}\left\{\Lambda_{u^{N}}\rho_{u^{N}}\right\}\mathclose{}`$ |  |
|  |  | $`\displaystyle=1-\frac{1}{2^{K}}\sum_{u_{\mathcal{A}}}\text{Tr}\bigg\{\Pi_{\mathopen{}\left(N\right)\mathclose{},u_{1}^{N-1}u_{N}}^{B^{N}}\cdots\Pi_{\mathopen{}\left(i\right)\mathclose{},u_{1}^{i-1}u_{i}}^{B^{N}}\cdots`$ |  |
|  |  | $`\displaystyle\ \ \ \cdots\Pi_{\mathopen{}\left(1\right)\mathclose{},u_{1}}^{B^{N}}\ \rho_{u^{N}}\ \Pi_{\mathopen{}\left(1\right)\mathclose{},u_{1}}^{B^{N}}\cdots\Pi_{\mathopen{}\left(i\right)\mathclose{},u_{1}^{i-1}u_{i}}^{B^{N}}\cdots\Pi_{\mathopen{}\left(N\right)\mathclose{},u_{1}^{N-1}u_{N}}^{B^{N}}\bigg\},`$ |  |

where we are assuming a particular choice of the bits
$`u_{\mathcal{A}^{c}}`$ in the sequence of projectors
$`\Pi_{\mathopen{}\left(N\right)\mathclose{},u_{1}^{N-1}u_{N}}^{B^{N}}`$
$`\cdots`$
$`\Pi_{\mathopen{}\left(i\right)\mathclose{},u_{1}^{i-1}u_{i}}^{B^{N}}`$
$`\cdots`$ $`\Pi_{\mathopen{}\left(1\right)\mathclose{},u_{1}}^{B^{N}}`$
and the convention mentioned before that
$`\Pi_{\mathopen{}\left(i\right)\mathclose{},u_{1}^{i-1}u_{i}}^{B^{N}}=I`$
if $`u_{i}`$ is a frozen bit. We are also assuming that the sender
transmits the information sequence $`u_{\mathcal{A}}`$ with uniform
probability $`2^{-K}`$. The probability of error
$`P_{e}\mathopen{}\left(N,K,\mathcal{A}\right)\mathclose{}`$ averaged
over all choices of the frozen bits is then

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle P_{e}\mathopen{}\left(N,K,\mathcal{A}\right)\mathclose{}`$ |  |  |
|  |  | $`\displaystyle=\frac{1}{2^{N-K}}\sum_{u_{\mathcal{A}^{c}}}P_{e}\mathopen{}\left(N,K,\mathcal{A},u_{\mathcal{A}^{c}}\right)\mathclose{}`$ |  |  |
|  |  | $`\displaystyle=1-\frac{1}{2^{N}}\sum_{u^{N}}\text{Tr}\bigg\{\Pi_{\mathopen{}\left(N\right)\mathclose{},u_{1}^{N-1}u_{N}}^{B^{N}}\cdots\Pi_{\mathopen{}\left(i\right)\mathclose{},u_{1}^{i-1}u_{i}}^{B^{N}}\cdots`$ |  |  |
|  |  | $`\displaystyle\ \ \ \ \cdots\Pi_{\mathopen{}\left(1\right)\mathclose{},u_{1}}^{B^{N}}\ \rho_{u^{N}}\ \Pi_{\mathopen{}\left(1\right)\mathclose{},u_{1}}^{B^{N}}\cdots\Pi_{\mathopen{}\left(i\right)\mathclose{},u_{1}^{i-1}u_{i}}^{B^{N}}\cdots\Pi_{\mathopen{}\left(N\right)\mathclose{},u_{1}^{N-1}u_{N}}^{B^{N}}\bigg\}.`$ |  | (13) |

One of the main contributions of this paper is the following proposition
regarding the average ensemble performance of polar codes with a quantum
successive cancellation decoder:

###### Proposition 4

For any classical-quantum channel $`W`$ with binary inputs and quantum
outputs and any choice of
$`\mathopen{}\left(N,K,\mathcal{A}\right)\mathclose{}`$, the following
bound holds

|  |  |  |
|----|----|----|
|  |
``` math
P_{e}\mathopen{}\left(N,K,\mathcal{A}\right)\mathclose{}\leq 2\sqrt{\sum_{i\in\mathcal{A}}\frac{1}{2}\sqrt{F(W_{N}^{\mathopen{}\left(i\right)\mathclose{}})}}.
``` |  |

Thus, there exists a frozen vector $`u_{\mathcal{A}^{c}}`$ for each
$`\mathopen{}\left(N,K,\mathcal{A}\right)\mathclose{}`$ such that

|  |  |  |
|----|----|----|
|  |
``` math
P_{e}\mathopen{}\left(N,K,\mathcal{A},u_{\mathcal{A}^{c}}\right)\mathclose{}\leq 2\sqrt{\sum_{i\in\mathcal{A}}\frac{1}{2}\sqrt{F(W_{N}^{\mathopen{}\left(i\right)\mathclose{}})}}.
``` |  |

#### II-B4 Polar Coding Theorem

Proposition [4](#Thmtheorem4 "Proposition 4 ‣ II-B3 Polar Code Performance ‣ II-B Polar Coding ‣ II Overview of Results ‣ Polar codes for classical-quantum channels")
immediately leads to the definition of polar codes for classical-quantum
channels:

###### Definition 5 (Polar Code)

A polar code for $`W`$ is a $`G_{N}`$-coset code with parameters
$`\mathopen{}\left(N,K,\mathcal{A},u_{\mathcal{A}^{c}}\right)\mathclose{}`$
where the information set $`\mathcal{A}`$ is such that
$`\mathopen{}\left|\mathcal{A}\right|\mathclose{}=K`$ and

|  |  |  |
|----|----|----|
|  |
``` math
F(W_{N}^{\mathopen{}\left(i\right)\mathclose{}})\leq F(W_{N}^{\mathopen{}\left(j\right)\mathclose{}})\text{ for all
}i\in\mathcal{A}\text{ and }j\in\mathcal{A}^{c}.
``` |  |

We can finally state the polar coding theorem for classical-quantum
channels. Consider a classical-quantum channel $`W`$ and a real number
$`R\geq 0`$. Let

|  |  |  |
|----|----|----|
|  |
``` math
P_{e}\mathopen{}\left(N,R\right)\mathclose{}=P_{e}\mathopen{}\left(N,\mathopen{}\left\lfloor NR\right\rfloor\mathclose{},\mathcal{A}\right)\mathclose{},
``` |  |

with the information bit set chosen according to the polar coding rule
in
Definition [5](#Thmtheorem5 "Definition 5 (Polar Code) ‣ II-B4 Polar Coding Theorem ‣ II-B Polar Coding ‣ II Overview of Results ‣ Polar codes for classical-quantum channels").
So $`P_{e}\mathopen{}\left(N,\mathcal{A}\right)\mathclose{}`$ is the
block error probability for polar coding over $`W`$ with blocklength
$`N`$, rate $`R`$, and quantum successive cancellation decoding averaged
uniformly over the frozen bits $`u_{\mathcal{A}^{c}}`$.

###### Theorem 6 (Polar Coding Theorem)

For any classical-quantum channel $`W`$ with binary inputs and quantum
outputs, a fixed $`R<I\mathopen{}\left(W\right)\mathclose{}`$, and
$`\beta<1/2`$, the block error probability
$`P_{e}\mathopen{}\left(N,R\right)\mathclose{}`$ satisfies the following
bound:

|  |  |  |
|----|----|----|
|  |
``` math
P_{e}\mathopen{}\left(N,R\right)\mathclose{}=o(2^{-\frac{1}{2}N^{\beta}}).
``` |  |

The polar coding theorem above follows as a straightforward corollary of
Theorem [3](#Thmtheorem3 "Theorem 3 (Rate of Polarization) ‣ II-A4 Rate of Polarization ‣ II-A Channel Polarization ‣ II Overview of Results ‣ Polar codes for classical-quantum channels")
and
Proposition [4](#Thmtheorem4 "Proposition 4 ‣ II-B3 Polar Code Performance ‣ II-B Polar Coding ‣ II Overview of Results ‣ Polar codes for classical-quantum channels").

## III Recursive Channel Transformations

This section delves into more detail regarding recursive channel
combining and channel splitting. Recall the channel combining in
([3](#S2.E3 "In II-A1 Channel Combining ‣ II-A Channel Polarization ‣ II Overview of Results ‣ Polar codes for classical-quantum channels")-[5](#S2.E5 "In II-A1 Channel Combining ‣ II-A Channel Polarization ‣ II Overview of Results ‣ Polar codes for classical-quantum channels"))
and the channel splitting in
([6](#S2.E6 "In II-A2 Channel Splitting ‣ II-A Channel Polarization ‣ II Overview of Results ‣ Polar codes for classical-quantum channels")).
These allowed for us to take $`N`$ independent copies of a
classical-quantum channel $`W^{\otimes N}`$ and transform them into the
$`N`$ split channels $`W_{N}^{\mathopen{}\left(1\right)\mathclose{}}`$,
…, $`W_{N}^{\mathopen{}\left(N\right)\mathclose{}}`$. We show here how
to break the channel transformation into a series of single-step
transformations. Much of the discussion here parallels Arikan’s
discussion in Sections II and III of Ref. \[[4](#bib.bib4)\].

We obtain a pair of channels $`W^{-}`$ and $`W^{+}`$ from two
independent copies of a channel $`W:x\rightarrow\rho_{x}`$ by a
single-step transformation if it holds that

|     |                                         |     |
|-----|-----------------------------------------|-----|
|     |
       ``` math
       W^{-}:u_{1}\rightarrow\rho_{u_{1}}^{-},
       ```                                      |     |

where

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\rho_{u_{1}}^{-}\equiv\sum_{u_{2}}\frac{1}{2}\rho_{u_{2}\oplus u_{1}}^{B_{1}}\otimes\rho_{u_{2}}^{B_{2}}.
``` |  | (14) |

Also, it should hold that

|     |                                         |     |
|-----|-----------------------------------------|-----|
|     |
       ``` math
       W^{+}:u_{2}\rightarrow\rho_{u_{2}}^{+},
       ```                                      |     |

where

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\rho_{u_{2}}^{+}`$ | $`\displaystyle\equiv\sum_{u_{1}}\frac{1}{2}\mathopen{}\left|u_{1}\right\rangle\mathclose{}\mathopen{}\left\langle u_{1}\right|\mathclose{}^{U_{1}}\otimes\rho_{u_{2}\oplus u_{1}}^{B_{1}}\otimes\rho_{u_{2}}^{B_{2}}`$ |  | (15) |
|  |  | $`\displaystyle=\mathopen{}\left(\sum_{u_{1}}\frac{1}{2}\mathopen{}\left|u_{1}\right\rangle\mathclose{}\mathopen{}\left\langle u_{1}\right|\mathclose{}^{U_{1}}\otimes\rho_{u_{2}\oplus u_{1}}^{B_{1}}\right)\mathclose{}\otimes\rho_{u_{2}}^{B_{2}}.`$ |  |  |

We use the following notation to denote such a transformation:

|  |  |  |
|----|----|----|
|  |
``` math
\mathopen{}\left(W,W\right)\mathclose{}\rightarrow\mathopen{}\left(W^{-},W^{+}\right)\mathclose{}.
``` |  |

Additionally, we choose the notation $`W^{-}`$ and $`W^{+}`$ so that
$`W^{-}`$ denotes the worse channel and $`W^{+}`$ denotes the better
channel.

## IV Channel Polarization

We are now in a position to prove
Theorem [2](#Thmtheorem2 "Theorem 2 (Channel Polarization) ‣ II-A3 Channel Polarization ‣ II-A Channel Polarization ‣ II Overview of Results ‣ Polar codes for classical-quantum channels")
on channel polarization. The idea behind the proof of this theorem is
identical to Arikan’s proof of his Theorem 1 in
Ref. \[[4](#bib.bib4)\]—with the relationships in
Propositions [8](#Thmtheorem8 "Proposition 8 ‣ III-A Transformation of Rate and Reliability ‣ III Recursive Channel Transformations ‣ Polar codes for classical-quantum channels")
and
[9](#Thmtheorem9 "Proposition 9 ‣ III-A Transformation of Rate and Reliability ‣ III Recursive Channel Transformations ‣ Polar codes for classical-quantum channels")
already established, we can readily exploit the martingale proof
technique. Thus, we only provide a brief summary of the proof of
Theorem [2](#Thmtheorem2 "Theorem 2 (Channel Polarization) ‣ II-A3 Channel Polarization ‣ II-A Channel Polarization ‣ II Overview of Results ‣ Polar codes for classical-quantum channels")
by following the presentation in Chapter 2 of Ref. \[[3](#bib.bib3)\].

Consider the channel $`W_{N}^{\mathopen{}\left(i\right)\mathclose{}}`$.
Let $`b_{1}\cdots b_{n}`$ denote an $`n`$-bit binary expansion of the
channel index $`i`$ and let
$`W_{\mathopen{}\left(b_{1}\cdots b_{n}\right)\mathclose{}}=W_{N}^{\mathopen{}\left(i\right)\mathclose{}}`$.
Then we can construct the channel
$`W_{\mathopen{}\left(b_{1}\cdots b_{k}\right)\mathclose{}}`$ by
combining two copies of
$`W_{\mathopen{}\left(b_{1}\cdots b_{k-1}\right)\mathclose{}}`$
according to
([17](#S3.E17 "In Proposition 7 ‣ III Recursive Channel Transformations ‣ Polar codes for classical-quantum channels"))
if $`b_{k}=0`$ or by combining two copies of
$`W_{\mathopen{}\left(b_{1}\cdots b_{k-1}\right)\mathclose{}}`$
according to
([18](#S3.E18 "In Proposition 7 ‣ III Recursive Channel Transformations ‣ Polar codes for classical-quantum channels"))
if $`b_{k}=1`$. We repeatedly construct all the way from $`b_{1}`$ until
$`b_{n}`$ with the above rule.

Arikan’s idea was to represent the channel construction as a random
birth process in order to analyze its limiting behavior. In order to do
so, we let $`\mathopen{}\left\{B_{n}:n\geq 1\right\}\mathclose{}`$ be a
sequence of IID uniform Bernoulli random variables, where we define each
over a probability space $`(\Omega,\mathcal{F},P)`$. Let
$`\mathcal{F}_{0}`$ denote the trivial $`\sigma`$-field. Also, let
$`\mathopen{}\left\{\mathcal{F}_{n}:n\geq 1\right\}\mathclose{}`$ denote
the $`\sigma`$-fields that the random variables
$`\mathopen{}\left(B_{1},\ldots,B_{n}\right)\mathclose{}`$ generate. We
also assume that
$`\mathcal{F}_{0}\subseteq\mathcal{F}_{1}\subseteq\mathcal{\cdots}\subseteq\mathcal{F}_{n}`$.
Let $`W_{0}=W`$ and let
$`\mathopen{}\left\{W_{n}:n\geq 0\right\}\mathclose{}`$ denote a
sequence of operator-valued random variables that forms a tree process
where $`W_{n+1}`$ is constructed from two copies of $`W_{n}`$ according
to
([17](#S3.E17 "In Proposition 7 ‣ III Recursive Channel Transformations ‣ Polar codes for classical-quantum channels"))
if $`B_{n}=0`$ and according to
([18](#S3.E18 "In Proposition 7 ‣ III Recursive Channel Transformations ‣ Polar codes for classical-quantum channels"))
if $`B_{n}=1`$. The output space of the operator-valued random variable
$`W_{n}`$ is equal to
$`\{W_{2^{n}}^{\mathopen{}\left(i\right)\mathclose{}}\}_{i=1}^{2^{n}}`$.
We are not really concerned with the channel process
$`\mathopen{}\left\{W_{n}:n\geq 0\right\}\mathclose{}`$ but more so with
the fidelities $`\{F(W_{N}^{\mathopen{}\left(i\right)\mathclose{}})\}`$
and Holevo informations
$`\{I(W_{N}^{\mathopen{}\left(i\right)\mathclose{}})\}`$. Thus, we can
simply analyze the limiting behavior of the two random processes
$`\{F_{n}:n\geq 0\}\equiv\{\sqrt{F(W_{n})}:n\geq 0\}`$ and
$`\{I_{n}:n\geq 0\}\equiv\{I(W_{n}):n\geq 0\}`$. By the definitions of
the random variables $`F_{n}`$ and $`I_{n}`$, it follows that

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\Pr\mathopen{}\left\{I_{n}\in\mathopen{}\left(a,b\right)\mathclose{}\right\}\mathclose{}`$ | $`\displaystyle=\frac{1}{2^{n}}|\{i:I(W_{2^{n}}^{\mathopen{}\left(i\right)\mathclose{}})\in\mathopen{}\left(a,b\right)\mathclose{}\}|,`$ |  |
|  | $`\displaystyle\Pr\mathopen{}\left\{F_{n}\in\mathopen{}\left(a,b\right)\mathclose{}\right\}\mathclose{}`$ | $`\displaystyle=\frac{1}{2^{n}}|\{i:F(W_{2^{n}}^{\mathopen{}\left(i\right)\mathclose{}})\in\mathopen{}\left(a,b\right)\mathclose{}\}|.`$ |  |

We then have the following lemma.

###### Lemma 11

The sequence
$`\{\mathopen{}\left(F_{n},\mathcal{F}_{n}\right)\mathclose{}:n\geq 0\}`$
is a bounded super-martingale, and the sequence
$`\{\mathopen{}\left(I_{n},\mathcal{F}_{n}\right)\mathclose{}:n\geq 0\}`$
is a bounded martingale.

###### Proof:

Let $`b_{1}\cdots b_{n}`$ be a particular realization of the random
sequence $`B_{1}\cdots B_{n}`$. Then the conditional expectation
satisfies

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\mathbb{E}\mathopen{}\left\{I_{n+1}\ |\ B_{1}=b_{1},\ldots,B_{n}=b_{n}\right\}\mathclose{}`$ |  |
|  |  | $`\displaystyle=\frac{1}{2}I\mathopen{}\left(W_{\mathopen{}\left(b_{1},\ldots,b_{n},0\right)\mathclose{}}\right)\mathclose{}+\frac{1}{2}I\mathopen{}\left(W_{\mathopen{}\left(b_{1},\ldots,b_{n},1\right)\mathclose{}}\right)\mathclose{}`$ |  |
|  |  | $`\displaystyle=I\mathopen{}\left(W_{\mathopen{}\left(b_{1},\ldots,b_{n}\right)\mathclose{}}\right)\mathclose{}`$ |  |
|  |  | $`\displaystyle=I_{n},`$ |  |

where the second equality follows from the definition of
$`W_{\mathopen{}\left(b_{1},\ldots,b_{n},0\right)\mathclose{}}`$ and
$`W_{\mathopen{}\left(b_{1},\ldots,b_{n},1\right)\mathclose{}}`$ and
Proposition [10](#Thmtheorem10 "Proposition 10 ‣ III-A Transformation of Rate and Reliability ‣ III Recursive Channel Transformations ‣ Polar codes for classical-quantum channels").
The proof for $`\mathopen{}\left\{F_{n}\right\}\mathclose{}`$ similarly
follows from the definitions and
Proposition [10](#Thmtheorem10 "Proposition 10 ‣ III-A Transformation of Rate and Reliability ‣ III Recursive Channel Transformations ‣ Polar codes for classical-quantum channels").
The boundedness condition follows because
$`0\leq I\mathopen{}\left(W\right)\mathclose{},F\mathopen{}\left(W\right)\mathclose{}\leq 1`$
for any classical-quantum channel $`W`$ with binary inputs and quantum
outputs. ∎

We can now finally prove
Theorem [2](#Thmtheorem2 "Theorem 2 (Channel Polarization) ‣ II-A3 Channel Polarization ‣ II-A Channel Polarization ‣ II Overview of Results ‣ Polar codes for classical-quantum channels")
regarding channel polarization. Given that
$`\mathopen{}\left\{I_{n}\right\}\mathclose{}`$ is a bounded martingale
and $`\mathopen{}\left\{F_{n}\right\}\mathclose{}`$ is a bounded
super-martingale, the limits $`\lim_{n\rightarrow\infty}I_{n}`$ and
$`\lim_{n\rightarrow\infty}F_{n}`$ converge almost surely and in
$`\mathcal{L}_{1}`$ to the random variables $`I_{\infty}`$ and
$`F_{\infty}`$. The convergence implies that
$`\mathbb{E}\mathopen{}\left\{\mathopen{}\left|F_{n+1}-F_{n}\right|\mathclose{}\right\}\mathclose{}\rightarrow 0`$
as $`n\rightarrow\infty`$. By the definition of the process
$`\mathopen{}\left\{F_{n}\right\}\mathclose{}`$, it holds that
$`F_{n+1}=F_{n}^{2}`$ with probability $`\frac{1}{2}`$, so that

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}\mathopen{}\left\{\mathopen{}\left|F_{n+1}-F_{n}\right|\mathclose{}\right\}\mathclose{}\geq\frac{1}{2}\mathbb{E}\mathopen{}\left\{\mathopen{}\left|F_{n}\mathopen{}\left(1-F_{n}\right)\mathclose{}\right|\mathclose{}\right\}\mathclose{}\geq 0.
``` |  |

It then follows that
$`\mathbb{E}\mathopen{}\left\{\mathopen{}\left|F_{n}\mathopen{}\left(1-F_{n}\right)\mathclose{}\right|\mathclose{}\right\}\mathclose{}\rightarrow 0`$
as $`n\rightarrow\infty`$, which in turn implies that
$`\mathbb{E}\mathopen{}\left\{\mathopen{}\left|F_{\infty}\mathopen{}\left(1-F_{\infty}\right)\mathclose{}\right|\mathclose{}\right\}\mathclose{}=0`$.
We conclude that
$`F_{\infty}\in\mathopen{}\left\{0,1\right\}\mathclose{}`$ almost
surely. Combining this result with
Proposition [1](#Thmtheorem1 "Proposition 1 ‣ II Overview of Results ‣ Polar codes for classical-quantum channels")
proves that $`I_{\infty}\in\mathopen{}\left\{0,1\right\}\mathclose{}`$
almost surely. Finally, we have that
$`\Pr\mathopen{}\left\{I_{\infty}=1\right\}\mathclose{}=\mathbb{E}\mathopen{}\left\{I_{\infty}\right\}\mathclose{}=\mathbb{E}\mathopen{}\left\{I_{0}\right\}\mathclose{}=I\mathopen{}\left(W\right)\mathclose{}`$
because $`I_{n}`$ is a martingale.

## V Performance of Polar Coding

We can now analyze the performance under the above successive
cancellation decoding scheme and provide a proof of
Proposition [4](#Thmtheorem4 "Proposition 4 ‣ II-B3 Polar Code Performance ‣ II-B Polar Coding ‣ II Overview of Results ‣ Polar codes for classical-quantum channels").
The proof of
Theorem [6](#Thmtheorem6 "Theorem 6 (Polar Coding Theorem) ‣ II-B4 Polar Coding Theorem ‣ II-B Polar Coding ‣ II Overview of Results ‣ Polar codes for classical-quantum channels")
readily follows by applying
Proposition [4](#Thmtheorem4 "Proposition 4 ‣ II-B3 Polar Code Performance ‣ II-B Polar Coding ‣ II Overview of Results ‣ Polar codes for classical-quantum channels")
and
Theorem [3](#Thmtheorem3 "Theorem 3 (Rate of Polarization) ‣ II-A4 Rate of Polarization ‣ II-A Channel Polarization ‣ II Overview of Results ‣ Polar codes for classical-quantum channels").

First recall the following “non-commutative union bound” of Sen (Lemma 3
in Ref. \[[25](#bib.bib25)\]):

|  |  |  |  |
|----|----|----|----|
|  |
``` math
1-\text{Tr}\mathopen{}\left\{\Pi_{N}\cdots\Pi_{1}\rho\Pi_{1}\cdots\Pi_{N}\right\}\mathclose{}\leq 2\sqrt{\sum_{i=1}^{N}\text{Tr}\mathopen{}\left\{\mathopen{}\left(I-\Pi_{i}\right)\mathclose{}\rho\right\}\mathclose{}},

which holds for projectors $`\Pi_{1}`$, …, $`\Pi_{N}`$ and a density

## VI Conclusion

We have shown how to construct polar codes for channels with classical
binary inputs and quantum outputs, and we showed that they can achieve
the symmetric Holevo information rate for classical communication. In
fact, for a quantum channel with binary pure state outputs, such as a
binary-phase-shift-keyed (BPSK) coherent-state optical communication
alphabet, the symmetric Holevo information rate is the ultimate channel
capacity \[[15](#bib.bib15)\], which is therefore achieved by our polar
code \[[42](#bib.bib42)\]. The general idea behind the construction is
similar to Arikan’s \[[4](#bib.bib4)\], but we required several
technical advances in order to demonstrate both channel polarization at
the symmetric Holevo information rate and the operation of the quantum
successive cancellation decoder. To prove that channel polarization
takes hold, we could exploit several results in the quantum information
literature \[[30](#bib.bib30), [31](#bib.bib31), [32](#bib.bib32),
[10](#bib.bib10), [33](#bib.bib33), [11](#bib.bib11)\] and some of
Arikan’s tools. To prove that the quantum successive cancellation
decoder works well, we exploited some ideas from quantum hypothesis
testing \[[34](#bib.bib34), [35](#bib.bib35), [36](#bib.bib36),
[37](#bib.bib37), [38](#bib.bib38)\] and Sen’s recent “non-commutative
union bound” \[[25](#bib.bib25)\]. The result is a near-explicit code
construction that achieves the symmetric Holevo information rate for
channels with classical inputs and quantum outputs. (When we say
“near-explicit,” we mean that it still remains open in the quantum case
to determine which synthesized channels are good or bad.) Also, several
works have now appeared on polar coding for private classical
communication and quantum communication \[[43](#bib.bib43),
[44](#bib.bib44), [43](#bib.bib43), [45](#bib.bib45), [46](#bib.bib46),
[47](#bib.bib47)\], most of which use the results developed in this
paper.

One of the main open problems going forward from here is to simplify the
quantum successive cancellation decoder. Arikan could show how to
calculate later estimates by exploiting the results of earlier estimates
in an “FFT-like” fashion, and this observation reduced the complexity of
the decoding to $`O(N\log N)`$. It is not clear to us yet how to reduce
the complexity of the quantum successive cancellation decoder because it
is not merely a matter of computing formulas, but rather a sequence of
physical operations (measurements) that the receiver needs to perform on
the channel output systems. If there were some way to perform the
measurements on smaller systems and then adaptively perform other
measurements based on earlier results, then this would be helpful in
demonstrating a reduced complexity.

Another important open question is to devise an efficient construction
of the polar codes, something that remains an open problem even for
classical polar codes. However, there has been recent work on efficient
suboptimal classical polar code constructions \[[48](#bib.bib48)\],
which one might try to extend to polar codes for the classical-quantum
channel. Finally, extending our code and decoder construction to a
classical-quantum channel with a non-binary (M-ary) alphabet remains a
good open line for investigation.

|  |
``` math
F\mathopen{}\left(\rho_{0},\rho_{1}\right)\mathclose{}=\min_{\mathopen{}\left\{\Lambda_{m}\right\}\mathclose{}}\mathopen{}\left(\sum_{m}\sqrt{\text{Tr}\mathopen{}\left\{\Lambda_{m}\rho_{0}\right\}\mathclose{}\text{Tr}\mathopen{}\left\{\Lambda_{m}\rho_{1}\right\}\mathclose{}}\right)\mathclose{}^{2}.
``` |  |

So

|  |  |  |
|----|----|----|
|  |
``` math
\sqrt{F\mathopen{}\left(W^{-}\right)\mathclose{}}=\min_{\mathopen{}\left\{\Gamma_{m}^{B_{1}B_{2}}\right\}\mathclose{}}\sum_{m}\sqrt{\text{Tr}\mathopen{}\left\{\Gamma_{m}^{B_{1}B_{2}}\rho_{0}^{-}\right\}\mathclose{}\text{Tr}\mathopen{}\left\{\Gamma_{m}^{B_{1}B_{2}}\rho_{1}^{-}\right\}\mathclose{}}
``` |  |

Let $`\Lambda_{m}`$ denote the POVM that achieves the minimum for
$`\sqrt{F\mathopen{}\left(W\right)\mathclose{}}`$:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\sqrt{F\mathopen{}\left(W\right)\mathclose{}}`$ | $`\displaystyle=\sqrt{F\mathopen{}\left(\rho_{0},\rho_{1}\right)\mathclose{}}`$ |  |
|  |  | $`\displaystyle=\min_{\mathopen{}\left\{\Lambda_{m}\right\}\mathclose{}}\sum_{m}\sqrt{\text{Tr}\mathopen{}\left\{\Lambda_{m}\rho_{0}\right\}\mathclose{}\text{Tr}\mathopen{}\left\{\Lambda_{m}\rho_{1}\right\}\mathclose{}}.`$ |  |

Then the POVM
$`\mathopen{}\left\{\Lambda_{l}\otimes\Lambda_{m}\right\}\mathclose{}`$
is a particular POVM that can try to distinguish the states
$`\rho_{0}^{-}`$ and $`\rho_{1}^{-}`$. We then have

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\sqrt{F\mathopen{}\left(W^{-}\right)\mathclose{}}`$ |  |
|  |  | $`\displaystyle\leq\sum_{l,m}\sqrt{\text{Tr}\mathopen{}\left\{\mathopen{}\left(\Lambda_{l}\otimes\Lambda_{m}\right)\mathclose{}\mathopen{}\left(\rho_{0}^{-}\right)\mathclose{}\right\}\mathclose{}\text{Tr}\mathopen{}\left\{\mathopen{}\left(\Lambda_{l}\otimes\Lambda_{m}\right)\mathclose{}\mathopen{}\left(\rho_{1}^{-}\right)\mathclose{}\right\}\mathclose{}}`$ |  |
|  |  | $`\displaystyle=\sum_{l,m}\sqrt{\text{Tr}\mathopen{}\left\{\mathopen{}\left(\Lambda_{l}\otimes\Lambda_{m}\right)\mathclose{}\frac{1}{2}\mathopen{}\left(\rho_{0}^{B_{1}}\otimes\rho_{0}^{B_{2}}+\rho_{1}^{B_{1}}\otimes\rho_{1}^{B_{2}}\right)\mathclose{}\right\}\mathclose{}}`$ |  |
|  |  | $`\displaystyle\ \ \ \ \ \times\sqrt{\text{Tr}\mathopen{}\left\{\mathopen{}\left(\Lambda_{l}\otimes\Lambda_{m}\right)\mathclose{}\frac{1}{2}\mathopen{}\left(\rho_{1}^{B_{1}}\otimes\rho_{0}^{B_{2}}+\rho_{0}^{B_{1}}\otimes\rho_{1}^{B_{2}}\right)\mathclose{}\right\}\mathclose{}}`$ |  |

|  |  |  |
|----|----|----|
|  |
``` math
=\frac{1}{2}\sum_{l,m}\bigg[\bigg(\text{Tr}\mathopen{}\left\{\Lambda_{l}\rho_{0}^{B_{1}}\right\}\mathclose{}\text{Tr}\mathopen{}\left\{\Lambda_{m}\rho_{0}^{B_{2}}\right\}\mathclose{}+\\
\ \ \ \ \ \text{Tr}\mathopen{}\left\{\Lambda_{l}\rho_{1}^{B_{1}}\right\}\mathclose{}\text{Tr}\mathopen{}\left\{\Lambda_{m}\rho_{1}^{B_{2}}\right\}\mathclose{}\bigg)\bigg(\text{Tr}\mathopen{}\left\{\Lambda_{l}\rho_{1}^{B_{1}}\right\}\mathclose{}\text{Tr}\mathopen{}\left\{\Lambda_{m}\rho_{0}^{B_{2}}\right\}\mathclose{}+\\
\ \ \ \ \ \ \text{Tr}\mathopen{}\left\{\Lambda_{l}\rho_{0}^{B_{1}}\right\}\mathclose{}\text{Tr}\mathopen{}\left\{\Lambda_{m}\rho_{1}^{B_{2}}\right\}\mathclose{}\bigg)\bigg]^{1/2}
``` |  |

Making the assignments

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\alpha_{m}`$ | $`\displaystyle\equiv\text{Tr}\mathopen{}\left\{\Lambda_{m}\rho_{0}^{B_{2}}\right\}\mathclose{},`$ |  |
|  | $`\displaystyle\beta_{l}`$ | $`\displaystyle\equiv\text{Tr}\mathopen{}\left\{\Lambda_{l}\rho_{0}^{B_{1}}\right\}\mathclose{},`$ |  |
|  | $`\displaystyle\gamma_{l}`$ | $`\displaystyle\equiv\text{Tr}\mathopen{}\left\{\Lambda_{l}\rho_{1}^{B_{1}}\right\}\mathclose{},`$ |  |
|  | $`\displaystyle\delta_{m}`$ | $`\displaystyle\equiv\text{Tr}\mathopen{}\left\{\Lambda_{m}\rho_{1}^{B_{2}}\right\}\mathclose{},`$ |  |

the above expression is equal to

|  |  |  |
|----|----|----|
|  |
``` math
\sum_{l,m}\frac{1}{2}\sqrt{\beta_{l}\alpha_{m}+\gamma_{l}\delta_{m}}\sqrt{\gamma_{l}\alpha_{m}+\beta_{l}\delta_{m}}
``` |  |

We can then exploit Arikan’s inequality in Appendix D of
Ref. \[[4](#bib.bib4)\] to have

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\sum_{l,m}\frac{1}{2}\sqrt{\beta_{l}\alpha_{m}+\gamma_{l}\delta_{m}}\sqrt{\gamma_{l}\alpha_{m}+\beta_{l}\delta_{m}}`$ |  |
|  |  | $`\displaystyle\leq\sum_{l,m}\frac{1}{2}\mathopen{}\left(\sqrt{\beta_{l}\alpha_{m}}+\sqrt{\gamma_{l}\delta_{m}}\right)\mathclose{}\mathopen{}\left(\sqrt{\gamma_{l}\alpha_{m}}+\sqrt{\beta_{l}\delta_{m}}\right)\mathclose{}`$ |  |
|  |  | $`\displaystyle\ \ \ \ \ \ \ -\sum_{l,m}\sqrt{\beta_{l}\alpha_{m}\gamma_{l}\delta_{m}}`$ |  |
|  |  | $`\displaystyle=\sum_{l,m}\frac{1}{2}\mathopen{}\left(\alpha_{m}\sqrt{\beta_{l}\gamma_{l}}+\gamma_{l}\sqrt{\delta_{m}\alpha_{m}}+\beta_{l}\sqrt{\alpha_{m}\delta_{m}}+\delta_{m}\sqrt{\gamma_{l}\beta_{l}}\right)\mathclose{}`$ |  |
|  |  | $`\displaystyle\ \ \ \ \ \ \ -\sum_{l}\sqrt{\beta_{l}\gamma_{l}}\sum_{m}\sqrt{\alpha_{m}\delta_{m}}`$ |  |
|  |  | $`\displaystyle=\sum_{l}\sqrt{\beta_{l}\gamma_{l}}+\sum_{m}\sqrt{\delta_{m}\alpha_{m}}-\sum_{l}\sqrt{\beta_{l}\gamma_{l}}\sum_{m}\sqrt{\alpha_{m}\delta_{m}}`$ |  |
|  |  | $`\displaystyle=2\sqrt{F\mathopen{}\left(W\right)\mathclose{}}-F\mathopen{}\left(W\right)\mathclose{}.`$ |  |

The inequality
$`F\mathopen{}\left(W^{-}\right)\mathclose{}\geq F\mathopen{}\left(W\right)\mathclose{}`$
follows from concavity of fidelity and its multiplicativity under tensor
products \[[10](#bib.bib10), [11](#bib.bib11)\]:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle F\mathopen{}\left(W^{-}\right)\mathclose{}`$ | $`\displaystyle=F\mathopen{}\left(\rho_{0}^{-},\rho_{1}^{-}\right)\mathclose{}`$ |  |
|  |  | $`\displaystyle\geq\frac{1}{2}F\mathopen{}\left(\rho_{0}^{B_{1}}\otimes\rho_{0}^{B_{2}},\rho_{1}^{B_{1}}\otimes\rho_{0}^{B_{2}}\right)\mathclose{}`$ |  |
|  |  | $`\displaystyle\ \ \ \ \ +\frac{1}{2}F\mathopen{}\left(\rho_{1}^{B_{1}}\otimes\rho_{1}^{B_{2}},\rho_{0}^{B_{1}}\otimes\rho_{1}^{B_{2}}\right)\mathclose{}`$ |  |
|  |  | $`\displaystyle=\frac{1}{2}F\mathopen{}\left(\rho_{0}^{B_{1}},\rho_{1}^{B_{1}}\right)\mathclose{}F\mathopen{}\left(\rho_{0}^{B_{2}},\rho_{0}^{B_{2}}\right)\mathclose{}`$ |  |
|  |  | $`\displaystyle\ \ \ \ \ +\frac{1}{2}F\mathopen{}\left(\rho_{1}^{B_{1}},\rho_{0}^{B_{1}}\right)\mathclose{}F\mathopen{}\left(\rho_{1}^{B_{2}},\rho_{1}^{B_{2}}\right)\mathclose{}`$ |  |
|  |  | $`\displaystyle=\frac{1}{2}F\mathopen{}\left(\rho_{0}^{B_{1}},\rho_{1}^{B_{1}}\right)\mathclose{}+\frac{1}{2}F\mathopen{}\left(\rho_{1}^{B_{1}},\rho_{0}^{B_{1}}\right)\mathclose{}`$ |  |
|  |  | $`\displaystyle=F\mathopen{}\left(W\right)\mathclose{}`$ |  |

The inequality
$`F\mathopen{}\left(W\right)\mathclose{}\geq F\mathopen{}\left(W^{+}\right)\mathclose{}`$
follows from the relation
$`\sqrt{F\mathopen{}\left(W^{+}\right)\mathclose{}}=F\mathopen{}\left(W\right)\mathclose{}`$
and the fact that $`0\leq F\leq 1`$. ∎
