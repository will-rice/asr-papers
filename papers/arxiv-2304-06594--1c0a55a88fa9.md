# Solving Tensor Low Cycle Rank Approximation

Yichuan Deng ycdeng@cs.washington.edu. The University of Washington.    Yeqi Gao a916755226@gmail.com. The University of Washington.    Zhao Song zsong@adobe.com. Adobe Research.

Large language models have become ubiquitous in modern life, finding applications in various domains such as natural language processing, language translation, and speech recognition. Recently, a breakthrough work \[Zhao, Panigrahi, Ge, and Arora Arxiv 2023\] explains the attention model from probabilistic context-free grammar (PCFG). One of the central computation task for computing probability in PCFG is formulating a particular tensor low rank approximation problem, we can call it tensor cycle rank. Given an $`n \times n \times n`$ third order tensor $`A`$, we say that $`A`$ has cycle rank-$`k`$ if there exists three $`n \times k^{2}`$ size matrices $`U,V`$, and $`W`$ such that for each entry in each

$`A_{a,b,c} = {\sum\limits_{i = 1}^{k}{\sum\limits_{j = 1}^{k}{\sum\limits_{l = 1}^{k}{U_{a,{i + {k\hspace{0pt}{({j - 1})}}}} \otimes V_{b,{j + {k\hspace{0pt}{({l - 1})}}}} \otimes W_{c,{l + {k\hspace{0pt}{({i - 1})}}}}}}}}`$

for all $`{a \in {\lbrack n\rbrack}},{{b \in {\lbrack n\rbrack}},{c \in {\lbrack n\rbrack}}}`$. For the tensor classical rank, tucker rank and train rank, it has been well studied in \[Song, Woodruff, Zhong SODA 2019\]. In this paper, we generalize the previous “rotation and sketch” technique in page 186 of \[Song, Woodruff, Zhong SODA 2019\] and show an input sparsity time algorithm for cycle rank.

## 1 Introduction

Large Language Models (LLMs) are a type of artificial intelligence model that is designed to process and understand human language. These models are built using deep learning techniques and can be trained on massive amounts of data, allowing them to learn patterns and relationships in language that enable them to generate text, answer questions and complete other tasks that are related to language. Some of the most well-known LLMs include OPT \[72\], PaLM \[18\], GPT-3 \[6\], Transformer \[63\] and BERT \[20\], which have been used for a wide range of applications such as language translation \[53, 25, 33\], and content generation \[63, 20, 6, 18\]. Large language models are becoming increasingly sophisticated and powerful, and are expected to play a major role in shaping the future of human-computer interaction and natural language processing \[64, 49, 46, 37\].

As one of the large language models, the Transformer \[63\] has drawn the most attention in recent years. Recently, a beautiful and breakthrough work by Zhao, Panigrahi, Ge and Arora \[71\] explore an interesting problem regarding whether the Transformer is capable of true parsing while attempting masked word prediction.

For solving the problem above, they first focus a Probabilistic Context-Free Grammar (PCFG) \[67\] and parsing algorithm based on it. As a type of formal grammar, Probabilistic Context-Free Grammar (PCFG) is widely used in natural language processing \[64, 46\] and computational linguistics \[38, 5\]. With $`\mathcal{N}`$ as the set of all the non-terminal symbols of the language grammar, $`\mathcal{P} \subset \mathcal{N}`$ as the set of pre-terminals, $`\mathcal{I} \subset \mathcal{N}`$ as the finite set of in-terminals and $`\lbrack n\rbrack`$ as the set of all possible words and $`p`$ is the relating probability for grammar parsing, a $`5`$-tuple $`\mathcal{G}:={(\mathcal{N},\mathcal{P},\mathcal{I},p,n)}`$ defines it.

In a PCFG, every grammar rule of the language is defined to be connected with a probability that represents how likely it is to be used in generating a sentence. These probabilities can be learned from a large corpus of text data using machine learning techniques such as the expectation-maximization algorithm. PCFGs have been widely used in various applications of natural language processing, including part-of-speech tagging \[16, 62, 47\], syntactic parsing \[15, 32, 44\], and text generation \[34\].

A well-known approach for discovering the (unlabeled) parse tree of a sentence $`w`$ using the PCFG model is the Labelled-Recall algorithm, which was introduced by \[27\]. The algorithm aims to identify the tree $`T = {(i,j)}`$ that maximizes the sum of scores, where the score of a span $`v_{i}\hspace{0pt}v_{i + 1}\hspace{0pt}\cdots\hspace{0pt}v_{j}`$ under a non-terminal $`a`$ is defined as the marginal probability $`\mu\hspace{0pt}{(i,j,a)}`$ calculated as follows: $`{\mu\hspace{0pt}{(i,j,a)}} = {\max_{a \in \mathcal{N}}{\Pr{\lbrack{a\rightarrow{v_{i}\hspace{0pt}v_{i + 1}\hspace{0pt}\cdots\hspace{0pt}v_{j}}},{{\mathsf{r}\mathsf{o}\mathsf{o}\mathsf{t}}\rightarrow\left. w \middle| \mathcal{G} \right.}\rbrack}}}`$.

The marginal probabilities mentioned above can be computed using the Inside-Outside algorithm \[39, 4\]. In a recent study, \[71\] attempted to explain the Transformer architecture from the perspective of Probabilistic Context-Free Grammar (PCFG) \[40\].

With the aid of dynamic programming, the Inside-Outside algorithm can determine two types of probability terms. The inside type of probability is defined as

$`{p_{in}\hspace{0pt}{(i,j,a)}}:={\Pr{\lbrack{a\rightarrow\left. {v_{i}\hspace{0pt}v_{i + 1}\hspace{0pt}\ldots\hspace{0pt}v_{j}} \middle| \mathcal{G} \right.}\rbrack}}`$

while the outside type of probability is defined as

$`{p_{out}\hspace{0pt}{(i,j,a)}} = {\Pr{\lbrack{{\mathsf{r}\mathsf{o}\mathsf{o}\mathsf{t}}\rightarrow\left. {v_{1}\hspace{0pt}v_{2}\hspace{0pt}\ldots\hspace{0pt}v_{i - 1}\hspace{0pt}a\hspace{0pt}v_{j + 1}\hspace{0pt}\ldots\hspace{0pt}v_{L}} \middle| \mathcal{G} \right.}\rbrack}}`$

for all ordered pairs $`(i,j)`$ where $`1 \leq i \leq j \leq L`$ and $`a \in \mathcal{N}`$. To be precise, the probabilities can be defined with the following recursive form,

$`{p_{in}\hspace{0pt}(i,j,a)} = {\sum\limits_{b,c}{\sum\limits_{k = i}^{j - 1}{p_{in}\hspace{0pt}(i,k,b)\hspace{0pt}p_{in}\hspace{0pt}\left( {k + 1},j,c \right)\hspace{0pt}{\Pr\left\lbrack {a\rightarrow{b\hspace{0pt}c}} \right\rbrack}}}}`$

and

$`{p_{out}\hspace{0pt}{(i,j,a)}} =`$$`\sum\limits_{b,c}{\sum\limits_{k = 1}^{i - 1}{p_{in}\hspace{0pt}{(k,{i - 1},c)}\hspace{0pt}p_{out}\hspace{0pt}{(k,j,b)}\hspace{0pt}{\Pr{\lbrack{b\rightarrow{c\hspace{0pt}a}}\rbrack}}}}`$$`+`$$`\sum\limits_{b,c}{\sum\limits_{k = {j + 1}}^{L}{p_{in}\hspace{0pt}{({j + 1},k,c)}\hspace{0pt}p_{out}\hspace{0pt}{(i,k,b)}\hspace{0pt}{\Pr{\lbrack{b\rightarrow{a\hspace{0pt}c}}\rbrack}}}}`$

given that for all $`a,i`$, $`{p_{in}\hspace{0pt}{(i,i,a)}} = {\Pr{\lbrack{a\rightarrow v_{i}}\rbrack}}`$ and for all $`a`$, $`{p_{out}\hspace{0pt}{(1,L,{\mathsf{r}\mathsf{o}\mathsf{o}\mathsf{t}})}} = 1`$. We can obtain the marginal probabilities using the following expressions

$`{\mu\hspace{0pt}{(i,j,a)}} =`$$`\Pr{\lbrack{a\Rightarrow{v_{i}\hspace{0pt}v_{i + 1}\hspace{0pt}\ldots\hspace{0pt}v_{j}}},{{\mathsf{r}\mathsf{o}\mathsf{o}\mathsf{t}}\Rightarrow\left. w \middle| \mathcal{G} \right.}\rbrack}`$$`=`$$`{\Pr{\lbrack{{\mathsf{r}\mathsf{o}\mathsf{o}\mathsf{t}}\rightarrow\left. {v_{1}\hspace{0pt}v_{2}\hspace{0pt}\ldots\hspace{0pt}v_{i - 1}\hspace{0pt}a\hspace{0pt}v_{j + 1}\hspace{0pt}\ldots\hspace{0pt}v_{L}} \middle| \mathcal{G} \right.}\rbrack}} \cdot {\Pr{\lbrack{a\rightarrow\left. {v_{i}\hspace{0pt}v_{i + 1}\hspace{0pt}\ldots\hspace{0pt}v_{j}} \middle| \mathcal{G} \right.}\rbrack}}`$$`=`$$`{{{p_{in}\hspace{0pt}{(i,j,a)}} \cdot p_{out}}\hspace{0pt}{(i,j,a)}}.`$

In our paper, we will focus on the analysis of $`p_{in}\hspace{0pt}{(i,j,a)}`$ and investigate $`p_{in}\hspace{0pt}{(i,j,b)}`$, $`p_{in}\hspace{0pt}{({k + 1},j,c)}`$ and $`\Pr{\lbrack{a\rightarrow{b\hspace{0pt}c}}\rbrack}`$ from a tensor perspective. By treating $`b,c,k`$ as the cycle index and $`a,i,j`$ as the tensor index transformed from $`p_{in}\hspace{0pt}{(i,j,a)}`$, we can restructure the function in a new format. Drawing inspiration from the computation of $`p_{in}\hspace{0pt}{(i,j,a)}`$, we define the cycle rank of a tensor for low-rank approximation as follows.

###### Definition 1.1 (Tensor Cycle-rank).

Considering $`\overline{U}`$, $`\overline{V}`$, and $`\overline{W}`$, which are $`n`$-by-$`k`$-by-$`k`$ tensors with real-valued entries, are the tensorizations of matrices $`U \in {\mathbb{R}}^{n \times k^{2}}`$, $`V \in {\mathbb{R}}^{n \times k^{2}}`$, and $`W \in {\mathbb{R}}^{n \times k^{2}}`$, we say $`a`$ has cycle-rank provided that matrices $`{U,V},`$ and $`W`$ belong to $`{\mathbb{R}}^{n \times k^{2}}`$ satisfying the following condition:

$`A_{i,j,l} = {\sum\limits_{a = 1}^{k}{\sum\limits_{b = 1}^{k}{\sum\limits_{c = 1}^{k}{U_{i,{a + {k\hspace{0pt}{({b - 1})}}}}\hspace{0pt}V_{j,{b + {k\hspace{0pt}{({c - 1})}}}}\hspace{0pt}v_{l,{c + {k\hspace{0pt}{({a - 1})}}}}}}}}`$

Alternatively, we can state that

$`A_{i,j,l} = {\sum\limits_{a = 1}^{k}{\sum\limits_{b = 1}^{k}{\sum\limits_{c = 1}^{k}{{\overline{U}}_{i,a,b}\hspace{0pt}{\overline{V}}_{j,b,c}\hspace{0pt}{\overline{W}}_{l,c,a}}}}}`$

We remark that there are other tensor ranks such as classical tensor rank, tensor train rank, and tensor tucker rank. Those ranks have been studied by \[58\], however tensor cycle rank is not studied. We provide more detailed definition of other tensor ranks in Section 4.2.

### 1.1 Our Result

We present our main result as follows:

###### Theorem 1.2 (Cycle rank, informal version of Theorem 5.1. ‣ 5 Tensor Cycle Rank ‣ Solving Tensor Low Cycle Rank Approximation")).

For any $`k \geq 1`$, $`\epsilon \in {(0,1)}`$, and a third-order tensor $`a \in {\mathbb{R}}^{n \times n \times n}`$, there is an algorithm that operates in

$`{O\hspace{0pt}{({{nnz}{(A)}})}} + {n\hspace{0pt}{{poly}{(k,{1/\epsilon})}}} + {\exp{({O\hspace{0pt}{({{{poly}{(k)}}/\epsilon})}})}}`$

time and produces $`U`$, $`V`$, and $`W`$ which are tensors of dimension $`n \times k \times k`$ satisfying the following condition:

$`{\|{{\sum\limits_{i = 1}^{k}{\sum\limits_{j = 1}^{k}{\sum\limits_{l = 1}^{k}{U_{\ast ,i,j} \otimes V_{\ast ,j,l} \otimes v_{\ast ,l,i}}}}} - A}\|}_{F} \leq {{({1 + \epsilon})}\hspace{0pt}\min\limits_{{{cycle}\hspace{0pt}{rank}}-{k\hspace{0pt}A_{k}}}\hspace{0pt}{\|{A_{k} - A}\|}_{F}^{2}}`$

## 2 Related Work

### 2.1 Transformer Theory

#### Optimization and Convergence

In the realm of optimization, \[60\] concentrated on investigating the behavior of a single-head attention mechanism to emulate the process of learning a Seq2Seq model, while adaptive methods have been emphasized for attention models by \[70\]. \[26\] have recently become interested in the over-parametrization problem associated with exponential activation functions. The exponential activation function is the focus of study in \[26\], where the convergence of an over-parameterized two-layer neural network is examined. The authors determine the minimum number of neurons required for convergence. Furthermore, \[36\] have addressed the issue of regularized exponential regression and proposed an algorithm running in input sparsity time. \[35\] provides a comprehensive explanation of how transformers learn “semantic structure”, which is in regard to their proficiency in capturing word co-occurrence patterns.

#### Fast Attention Computation

The work of \[69\] and \[2\] primarily focus on the static version of attention computation. In particular, on the positive side, \[2\] provides an algorithm, and on the negative side, \[2\] prove a hardness by assuming (strong) exponential time hypothesis. \[11\] define and investigate the dynamic version of the problem, presenting both positive and negative results. The algorithmic result of \[11\] is built on lazy update techniques in solving linear programming \[17, 10\]. The hardness result of \[11\] is built on Hinted MV conjecture \[7\]. \[22\] consider the case where feature dimension is much larger than the length of sentence in attention computation, and they provide both randomized algorithm and deterministic algorithm to sparsify the feature dimension.

#### Learning in-context

In a recent work \[3\], it is shown that, in-context learners based on transformers can perform conventional learning algorithms in an implicit manner by encoding smaller models within their activations and continuously updating these models as new examples are presented within the context. Concentrating on the clearly defined task of training a model under in-context conditions to learn a class of functions, such as linear functions, \[28\] aim to gain a deeper insight into in-context learning. Their research aims to determine if a model, when provided with data derived from some functions within a class, are able to be trained to learn the ”majority” of functions in this class. \[42\] gave an explanation of the mechanisms of Transformers as in-context learners. They showed that the training process of the Transformers in in-context tasks have similarity of some meta-learning formulations based on gradient descent.

#### Privacy.

Considering the potential negative influence of the abuse of the LLMs, \[31\] propose a method for watermarking proprietary language models without adversely affecting text quality. A novel algorithm for detecting watermarks in language models without requiring access to the model’s parameters or API is introduced by \[31\].

### 2.2 Numerical Linear Algebra

#### Low-rank Approximation

Many variants of low-rank approximation problems have been studied, for example low-rank approximation with Frobenious norm \[19, 41\], matrix CUR decomposition \[12, 55, 58\], weighted low rank approximation \[50\], entrywise $`\ell_{1}`$ norm low-rank approximation \[55, 56\], general norm column subset selection \[57\], tensor low-rank approximation \[58\], and tensor regression \[23, 21, 51, 54\]. Low-rank approximation also has many applications in other problems such as cutting plane method \[29\], integral minimization \[30\], training neural network \[9, 61, 68\].

#### Input Sparsity Algorithms

For several years, there have been many works focused on designing input-sparsity time algorithms \[19, 41, 66, 13, 50, 55, 58, 59, 24\]. For the problems of matrix low-rank approximation and linear regression, \[19\] gave the first input sparsity time. With a sparse embedding matrix $`S`$, one can compute its product with any input matrix $`A`$ in the input-sparsity $`{nnz}{(A)}`$ time. Another work \[41\] later gave some sketching matrices called Oblivious Sparse Norm Approximating Projections (OSNAPs), which improve the former dimension of sketch in \[19\]. \[50\] gives an input sparsity time algorithm for weighted low-rank approximation. \[55\] generalize the Frobenius low rank approximation problem \[19, 41\] to entry-wise $`\ell_{1}`$ low rank approximation problem. \[58\] studied the tensor low rank approximation problem. Recently, \[59\] gave an algorithm for structured John Ellipsoid computation. It improves the previous work \[14\] to input sparsity time. Another recent work \[24\] gave a novel algorithm which can minimizing the discrepancy in input sparsity time.

## 3 Technique Overview

With $`U^{\ast} \in {\mathbb{R}}^{n^{2} \times k^{2}}`$, $`V^{\ast} \in {\mathbb{R}}^{n^{2} \times k^{2}}`$ and $`W^{\ast} \in {\mathbb{R}}^{n^{2} \times k^{2}}`$, we can rewrite $`A_{k}`$ as follows

$`A_{k} = {\sum\limits_{i = 1}^{k}{\sum\limits_{j = 1}^{k}{\sum\limits_{l = 1}^{k}{U_{i + {k\hspace{0pt}{({j - 1})}}}^{\ast} \otimes V_{j + {k\hspace{0pt}{({l - 1})}}}^{\ast} \otimes W_{l + {k\hspace{0pt}{({i - 1})}}}^{\ast}}}}}`$

The main idea in our proof is to first establish the existence of a matrix decomposition for $`A`$, and then use a corresponding algorithm to confidently locate the desired matrix.

#### Rotate and Sketch Step 1.

In the first step, we consider the hypothetical regression problem $`\min_{U \in {\mathbb{R}}^{n \times k^{2}}}{\|{A_{1} - {U\hspace{0pt}Z_{1}}}\|}_{F}^{2}`$. With $`r = {O\hspace{0pt}{({k^{2}/\epsilon})}}`$ and $`S_{1} \in {\mathbb{R}}^{n^{2} \times r}`$ with i.i.d. normal random variables denoted $`N\hspace{0pt}{(0,{1/r})}`$, and $`\hat{U} = {\text{argmin}_{U \in {\mathbb{R}}^{n \times k^{2}}}\hspace{0pt}{\|{{U\hspace{0pt}Z_{1}\hspace{0pt}S_{1}} - {A_{1}\hspace{0pt}S_{1}}}\|}_{F}^{2}}`$, we have

$`{{\|{A_{1} - {\hat{U}\hspace{0pt}Z_{1}}}\|}_{F}^{2} \leq {{({1 + \epsilon})}\hspace{0pt}{\min\limits_{U \in {\mathbb{R}}^{n \times k^{2}}}{\|{A_{1} - {U\hspace{0pt}Z_{1}}}\|}_{F}^{2}}}}.`$

By choosing $`\hat{U} = {A_{1}\hspace{0pt}S_{1}\hspace{0pt}{({Z_{1}\hspace{0pt}S_{1}})}^{\dagger}}`$, we can prove that at least a matrix $`\hat{U}`$ can be found to satisfy the equation above.

#### Rotate and Sketch Step 2.

According to the first step, we can create a rank-$`k`$ tensor, defined as follows

$`B:={\sum\limits_{i = 1}^{k}{\sum\limits_{j = 1}^{k}{\sum\limits_{l = 1}^{k}{{\hat{U}}_{i + {k\hspace{0pt}{({j - 1})}}} \otimes V_{j + {k\hspace{0pt}{({l - 1})}}}^{\ast} \otimes W_{j + {k\hspace{0pt}{({i - 1})}}}^{\ast}}}}}`$

from the matrix $`\hat{U}\hspace{0pt}Z_{1}`$.

Since $`\hat{U}`$ is in the column span of $`A_{1}\hspace{0pt}S_{1}`$, the set of rank-$`1`$ tensors $`{\{{{({A_{1}\hspace{0pt}S_{1}})}_{a + {k\hspace{0pt}{({b - 1})}}} \otimes V_{b + {k\hspace{0pt}{({c - 1})}}}^{\ast} \otimes W_{c + {k\hspace{0pt}{({a - 1})}}}^{\ast}}\}}_{{a \in {{\lbrack r\rbrack},b}},{c \in {\lbrack k\rbrack}}}`$ spans the space that contains $`B`$. It is possible to express a proper rank-$`k`$ tensor $`B`$ as a linear combination of rank-$`1`$ tensors of the form $`{\{{U_{a + k{(b - 1)})}^{\ast} \otimes {({A_{2}\hspace{0pt}S_{2}})}_{b + {k\hspace{0pt}{({c - 1})}}} \otimes W_{c + {k\hspace{0pt}{({a - 1})}}}^{\ast}}\}}_{{{a,c} \in {\lbrack k\rbrack}},{b \in {\lbrack r\rbrack}}}`$ and the set of rank-$`1`$ tensors $`{\{{U_{a + {k\hspace{0pt}{({b - 1})}}}^{\ast} \otimes V_{b + {k\hspace{0pt}{({c - 1})}}}^{\ast} \otimes {({A_{3}\hspace{0pt}S_{3}})}_{c + {k\hspace{0pt}{({a - 1})}}}}\}}_{{{a,b} \in {\lbrack k\rbrack}},{c \in {\lbrack r\rbrack}}}`$ spans a subspace that contains a proper rank-$`k`$ tensor $`B`$.

We first compute $`A_{1}\hspace{0pt}S_{1}`$, and write $`\hat{U} = {A_{1}\hspace{0pt}S_{1}\hspace{0pt}{({Z_{1}\hspace{0pt}S_{1}})}^{\dagger}}`$. Now, we redefine $`Z_{2}`$ with respect to $`\hat{U}`$, which implies that, the rows of $`Z_{2}`$ is vectors where the $`(j,l)`$-th row is $`{vec}{({\sum_{i = 1}^{k}{{\hat{U}}_{i + {k\hspace{0pt}{({j - 1})}}} \otimes W_{l + {k\hspace{0pt}{({i - 1})}}}^{\ast}}})}`$ for each $`j \in {\lbrack k\rbrack}`$ and $`l \in {\lbrack k\rbrack}`$. And we consider the regression problem in the following form,

$`{\min\limits_{V}{\|{{V\hspace{0pt}Z_{2}} - A_{2}}\|}_{F}^{2}}.`$

If $`S_{2} \in {\mathbb{R}}^{n^{2} \times r}`$ as a matrix of i.i.d. Gaussian entries, we have $`\hat{V} = {A_{2}\hspace{0pt}S_{2}\hspace{0pt}{({Z_{2}\hspace{0pt}S_{2}})}^{\dagger}}`$ satisfies

$`{{\|{{\hat{V}\hspace{0pt}Z_{2}} - A_{2}}\|}_{F}^{2} \leq {{({1 + \epsilon})}^{2}\hspace{0pt}{\|{A_{k} - A}\|}_{F}^{2}}}.`$

The matrix $`B`$ can be obtained by retensorizing $`\hat{V}\hspace{0pt}Z_{2}`$ and then we will have

$`{{\|{B - A}\|}_{F}^{2} = {\|{{\hat{V}\hspace{0pt}Z_{2}} - A_{2}}\|}_{F}^{2} \leq {{({1 + \epsilon})}^{2}\hspace{0pt}{\|{A_{k} - A}\|}_{F}^{2}}}.`$

#### Rotate and Sketch Step 3.

Recall that, the columns of $`\hat{V}`$ are all in the row span of $`A_{2}\hspace{0pt}S_{2}`$, and the rows of $`Z_{2}`$ are defined to be $`{vec}{({\sum_{i = 1}^{k}{{\hat{U}}_{i + {k\hspace{0pt}{({j - 1})}}} \otimes W_{l + {k\hspace{0pt}{({i - 1})}}}^{\ast}}})}`$ for each $`j \in {\lbrack k\rbrack}`$ and $`l \in {\lbrack k\rbrack}`$, where the columns of $`\hat{U}`$ are in the row span of the matrix $`A_{1}\hspace{0pt}S_{1}`$, we have that, $`B`$ is in the span of the set of rank-$`1`$ tensors

$`{\{{{({A_{1}\hspace{0pt}S_{1}})}_{a + {k\hspace{0pt}{({b - 1})}}} \otimes {({A_{2}\hspace{0pt}S_{2}})}_{b + {k\hspace{0pt}{({c - 1})}}} \otimes {\hat{V}}_{c + {k\hspace{0pt}{({a - 1})}}}}\}}_{{{a,b} \in {\lbrack r\rbrack}},{c \in {\lbrack k\rbrack}}}.`$

Given that $`Z_{3} \in {\mathbb{R}}^{r^{2} \times n^{2}}`$ as an matrix with rows $`{vec}{({{({A_{1}\hspace{0pt}S_{1}})}_{a + {k\hspace{0pt}{({b - 1})}}} \otimes {({A_{2}\hspace{0pt}S_{2}})}_{b + {k\hspace{0pt}{({c - 1})}}}})}`$ for all pairs $`{a,b} \in {\lbrack r\rbrack}`$, we will focus on the following regression problem

$`{\min\limits_{W}{\|{{W\hspace{0pt}Z_{3}} - A_{3}}\|}_{F}^{2}}.`$

By solving another regression problem, $`W \in {\mathbb{R}}^{n \times r^{2}}`$ can be solved in polynomial time. After retensorizing $`W\hspace{0pt}Z_{3}`$ to a new tensor $`B`$, we can find a rank-$`r^{2} = {O\hspace{0pt}{({k^{2}/\epsilon^{2}})}}`$ tensor $`B`$ such that

$`{{\|{B - A}\|}_{F}^{2} \leq {{({1 + \epsilon})}^{2}\hspace{0pt}{\|{A_{k} - A}\|}_{F}^{2}} = {{({1 + {O\hspace{0pt}{(\epsilon)}}})}\hspace{0pt}{\|{A_{k} - A}\|}_{F}^{2}}}.`$

#### Input sparsity reduction.

To obtain the input-sparsity running time guarantee of $`{n\hspace{0pt}{{poly}{({k/\epsilon})}}} + {{nnz}{(A)}}`$ for Theorem 4.15. ‣ 4.6 Tensor Low-rank Approximation ‣ 4 Preliminary ‣ Solving Tensor Low Cycle Rank Approximation"), while we can replace $`S_{1}`$ and $`S_{2}`$ using a sparse CountSketch matrix together with a Gaussian matrix, which enables us to compute $`A_{1}\hspace{0pt}S_{1}`$ and $`A_{2}\hspace{0pt}S_{2}`$ in the desired $`{{nnz}{(A)}} + {n\hspace{0pt}{{poly}{({k/\epsilon})}}}`$ time.

For the next steps of solving $`\min_{W}{\|{A_{3} - {W\hspace{0pt}Z_{3}}}\|}_{F}^{2}`$ quickly and writing matrix $`Z_{3}`$ without spending $`r^{2}\hspace{0pt}n^{2}`$ time, a technique of TensorSketch is used, which is introduced in \[43, 45\]. But as shown in \[1\], we need show some stronger properties of approximate matrix product (AMP) and subspace embedding (SE) to make it stand. When the AMP and SE is satisfied, we can solve the “sketched version” regression problem, in the form of

$`{\min\limits_{W}{\|{{A_{3}\hspace{0pt}S_{3}} - {W\hspace{0pt}Z_{3}\hspace{0pt}S_{3}}}\|}_{F}^{2}}.`$

The point of this sketch is, matrix products $`A_{3}\hspace{0pt}S_{3}`$ and $`Z_{3}\hspace{0pt}S_{3}`$ can be computed in the sparsity time of $`{{nnz}{(A)}} + {n\hspace{0pt}{{poly}{({k/\epsilon})}}}`$. Combining them together, we can solve the problem in $`n\hspace{0pt}{{poly}{({k/\epsilon})}}`$ time.

In order to get the sparsity time of $`A`$, we use CounSketch matrices to boost the algorithm. To be specific, we choose three CountSketch matrices $`T_{1},T_{2},T_{3}`$ with sketching dimension of $`t = {n \cdot {{poly}{(k,{1/\epsilon})}}}`$.

We define

$`{D:={\sum\limits_{i = 1}^{k}{\sum\limits_{j = 1}^{k}{\sum\limits_{l = 1}^{k}{{({T_{1}\hspace{0pt}A_{1}\hspace{0pt}S_{1}\hspace{0pt}X_{1}})}_{a,{i + {k\hspace{0pt}{({j - 1})}}}} \cdot {({T_{2}\hspace{0pt}A_{2}\hspace{0pt}S_{2}\hspace{0pt}X_{2}})}_{b,{j + {k\hspace{0pt}{({l - 1})}}}} \cdot {({T_{3}\hspace{0pt}A_{3}\hspace{0pt}S_{3}\hspace{0pt}X_{3}})}_{c,{l + {k\hspace{0pt}{({i - 1})}}}}}}}}}.`$

Applying them to the iterative argument described above, now we try to minimize the following target polynomial function

$`\sum\limits_{{a,b,c} \in {\lbrack t\rbrack}}{({D - {({A\hspace{0pt}{(T_{1},T_{2},T_{3})}})}_{a,b,c}})}^{2}`$

by choosing $`{3\hspace{0pt}r\hspace{0pt}k} = {O\hspace{0pt}{({k^{2}/\epsilon})}}`$ indeterminates $`X_{1},X_{2},X_{3}`$.

#### Solving small problem via polynomial system solver.

With $`X_{1},X_{2}`$, and $`X_{3}`$ as $`r \times k^{2}`$ matrices of indeterminates, we can re-express $`\hat{U}`$ as $`A_{1}\hspace{0pt}S_{1}\hspace{0pt}X_{1}`$, $`\hat{V}`$ as $`A_{2}\hspace{0pt}S_{2}\hspace{0pt}X_{2}`$, and $`\hat{W}`$ as $`A_{3}\hspace{0pt}S_{3}\hspace{0pt}X_{3}`$. We let the rows of $`Z_{1}`$ be $`{vec}{({V_{j + {k\hspace{0pt}{({l - 1})}}}^{\ast} \otimes W_{l + {k\hspace{0pt}{({i - 1})}}}^{\ast}})}`$, the rows of $`Z_{2}`$ be $`{vec}{({{\hat{U}}_{i + {k\hspace{0pt}{({j - 1})}}} \otimes W_{j + {k\hspace{0pt}{({l - 1})}}}^{\ast}})}`$, and the rows of $`Z_{3}`$ be $`{vec}{({{\hat{U}}_{i + {k\hspace{0pt}{({j - 1})}}} \otimes V_{j + {k\hspace{0pt}{({l - 1})}}}})}`$.

It follows that the rank-$`k`$ tensor

$`B = {\sum\limits_{i = 1}^{k}{\sum\limits_{j = 1}^{k}{\sum\limits_{l = 1}^{k}{{({A_{1}\hspace{0pt}S_{1}\hspace{0pt}X_{1}})}_{i + {k\hspace{0pt}{({j - 1})}}} \otimes {({A_{2}\hspace{0pt}S_{2}\hspace{0pt}X_{2}})}_{j + {k\hspace{0pt}{({l - 1})}}} \otimes {({A_{3}\hspace{0pt}S_{3}\hspace{0pt}X_{3}})}_{l + {k\hspace{0pt}{({i - 1})}}}}}}}`$

where $`{\|{A - B}\|}_{F}^{2} \leq {{({1 + \epsilon})}^{3}\hspace{0pt}{\|{A - A_{k}}\|}_{F}^{2}}`$.

The minimization task can be achieved by minimizing the degree-$`6`$ polynomial as follows

$`\sum\limits_{{a,b,c} \in {\lbrack n\rbrack}}{({{\sum\limits_{i = 1}^{k}{\sum\limits_{j = 1}^{k}{\sum\limits_{l = 1}^{k}{{({A_{1}\hspace{0pt}S_{1}\hspace{0pt}X_{1}})}_{a,{i + {k\hspace{0pt}{({j - 1})}}}} \cdot {({A_{2}\hspace{0pt}S_{2}\hspace{0pt}X_{2}})}_{b,{j + {k\hspace{0pt}{({l - 1})}}}} \cdot {({A_{3}\hspace{0pt}S_{3}\hspace{0pt}X_{3}})}_{c,{l + {k\hspace{0pt}{({i - 1})}}}}}}}} - A_{a,b,c}})}^{2}`$

by choosing $`{3\hspace{0pt}r\hspace{0pt}k} = {O\hspace{0pt}{({k^{2}/\epsilon})}}`$ indeterminates $`X_{1},X_{2},X_{3}`$. We can get $`X_{1},X_{2},X_{3}`$ such that the solution is at least $`({1 + {O\hspace{0pt}{(\epsilon)}}})`$-approximate.

Assuming that the entries of matrices $`U^{\ast},V^{\ast},W^{\ast}`$ are all bounded by $`2^{{poly}{(n)}}`$, as stated in Theorem 4.17. ‣ 4.8 Solving Small Problems ‣ 4 Preliminary ‣ Solving Tensor Low Cycle Rank Approximation"), the polynomial can be minimized up to an additive error of $`2^{- {{poly}{(n)}}}`$ in $`{poly}{(n)}`$ time \[48, 8\]. Similar approaches can also be used to obtain a relative error approximation of the ground truth value of $`OPT`$, and to deal with situations where $`A_{k}`$ does not exist.

### 4.1 Notations

We use the notation $`\lbrack n\rbrack`$ to denote the set $`1,2,\cdots,n`$ for any positive integer $`n`$. We denote the Moore-Penrose pseudoinverse matrix $`A`$ as $`A^{\dagger} \in {\mathbb{R}}^{k \times n}`$, i.e., $`A^{\dagger} = {N\hspace{0pt}\Sigma^{- 1}\hspace{0pt}M^{\top}}`$.

We define the following two definitions of the $`\otimes`$ product.

### 4.2 Tensor Ranks

In this section, we define the following kinds of ranks for tensor.

###### Definition 4.4 (Classical rank).

We say tensor $`U \in {\mathbb{R}}^{n \times n \times n}`$ has a classical rank of $`k`$ if $`k \in \mathbb{Z}_{\geq 0}`$ is the smallest positive integer for which there exist three matrices $`{A,B,C} \in {\mathbb{R}}^{n \times k}`$ such that

$`U_{i,j,l} = {\sum\limits_{a = 1}^{k}{\sum\limits_{b = 1}^{k}{\sum\limits_{c = 1}^{k}{A_{i,a}\hspace{0pt}B_{j,b}\hspace{0pt}C_{l,c}}}}}`$

We define Tucker rank as follows:

###### Definition 4.5 (Tucker rank).

We say tensor $`U \in {\mathbb{R}}^{n \times n \times n}`$ has a tucker rank of $`k`$ if $`k \in \mathbb{Z}_{\geq 0}`$ is the smallest positive integer such that there exist three matrices $`{A \in {\mathbb{R}}^{n \times k}},{{B \in {\mathbb{R}}^{n \times k}},{C \in {\mathbb{R}}^{n \times k}}}`$, and a (smaller) tensor $`D \in {\mathbb{R}}^{k \times k \times k}`$ such that $`{\forall{(i,j,l)}} \in {{\lbrack n\rbrack} \times {\lbrack n\rbrack} \times {\lbrack n\rbrack}}`$, we have

$`{U_{i,j,l} = {\sum\limits_{i' = 1}^{k}{\sum\limits_{j' = 1}^{k}{\sum\limits_{l' = 1}^{k}{D_{i',j',l'}\hspace{0pt}A_{i,i'}\hspace{0pt}B_{j,j'}\hspace{0pt}C_{l,l'}}}}}}.`$

Then, we define train rank,

###### Definition 4.6 (Train rank).

We say tensor $`U \in {\mathbb{R}}^{n \times n \times n}`$ has a train rank of $`k`$ if $`k \in \mathbb{Z}_{\geq 0}`$ is the smallest positive integer such that there exist three matrices $`A \in {\mathbb{R}}^{1 \times n \times k}`$, $`B \in {\mathbb{R}}^{k \times n \times k}`$, $`C \in {\mathbb{R}}^{k \times n \times 1}`$ such that $`{{\forall i},j,l} \in {{\lbrack n\rbrack} \times {\lbrack n\rbrack} \times {\lbrack n\rbrack}}`$ we have,

$`U_{i,j,l} = {\sum\limits_{i_{1} = 1}^{1}{\sum\limits_{i_{2} = 1}^{k}{\sum\limits_{i_{3} = 1}^{k}{\sum\limits_{i_{4} = 1}^{1}{A_{i_{1},i,i_{2}}\hspace{0pt}B_{i_{2},j,i_{3}}\hspace{0pt}C_{i_{3},l,i_{4}}}}}}}`$

### 4.3 Tensor Cycle Definitions

We give the formal definition of tensor cycle rank as follows.

###### Definition 4.7 (Cycle-rank).

We say $`U \in {\mathbb{R}}^{n \times n \times n}`$ has cycle-rank $`k`$ if there are three matrices $`{A,B,C} \in {\mathbb{R}}^{n \times k^{2}}`$ such that

$`U_{i,j,l} = {\sum\limits_{a = 1}^{k}{\sum\limits_{b = 1}^{k}{\sum\limits_{c = 1}^{k}{A_{i,{a + {k\hspace{0pt}{({b - 1})}}}}\hspace{0pt}B_{j,{b + {k\hspace{0pt}{({c - 1})}}}}\hspace{0pt}C_{l,{c + {k\hspace{0pt}{({a - 1})}}}}}}}}`$

or

$`A_{i,j,l} = {\sum\limits_{a = 1}^{k}{\sum\limits_{b = 1}^{k}{\sum\limits_{c = 1}^{k}{{\overline{U}}_{i,a,b}\hspace{0pt}{\overline{V}}_{j,b,c}\hspace{0pt}{\overline{W}}_{l,c,a}}}}}`$

where $`\overline{U} \in {\mathbb{R}}^{n \times k \times k}`$ is tensorization of $`U \in {\mathbb{R}}^{n \times k^{2}}`$, $`\overline{V} \in {\mathbb{R}}^{n \times k \times k}`$ is tensorization of $`V \in {\mathbb{R}}^{n \times k^{2}}`$, $`\overline{W} \in {\mathbb{R}}^{n \times k \times k}`$ is tensorization of $`W \in {\mathbb{R}}^{n \times k^{2}}`$.

### 4.4 Approximate Matrix Product and Subspace Embeddings

We define subspace embedding \[52\] as follows.

###### Definition 4.8 (Subspace Embedding \[52\]).

For a matrix $`A \in {\mathbb{R}}^{n \times d}`$, we say matrix $`S`$ is a Subspace Embedding $`{\mathsf{S}\mathsf{E}}\hspace{0pt}{(n,d,\epsilon,\delta)}`$ of $`A`$ if

###### Definition 4.9 (Frobenius Approximate Matrix Product).
