# T-NGA: Temporal Network Grafting Algorithm for Learning to Process Spiking Audio Sensor Events

###### Abstract

Spiking silicon cochlea sensors encode sound as an asynchronous stream of spikes from different frequency channels. The lack of labeled training datasets for spiking cochleas makes it difficult to train deep neural networks on the outputs of these sensors. This work proposes a self-supervised method called Temporal Network Grafting Algorithm (T-NGA), which grafts a recurrent network pretrained on spectrogram features so that the network works with the cochlea event features. T-NGA training requires only temporally aligned audio spectrograms and event features. Our experiments show that the accuracy of the grafted network was similar to the accuracy of a supervised network trained from scratch on a speech recognition task using events from a software spiking cochlea model. Despite the circuit non-idealities of the spiking silicon cochlea, the grafted network accuracy on the silicon cochlea spike recordings was only about 5% lower than the supervised network accuracy using the N-TIDIGITS18 dataset. T-NGA can train networks to process spiking audio sensor events in the absence of large labeled spike datasets.

Index Terms—  spiking silicon cochlea sensor, event-driven audio processing, deep neural network, self-supervised learning, speech recognition

## 1 Introduction

With the increasing use of speech command interfaces on mobile devices, finding lightweight networks for edge audio tasks, *e.g.*, Voice Activity Detection (VAD), Speaker Verification (SV), and Keyword Spotting (KWS), has become a fast growing research area \[1\]. Recent methods to produce low-memory footprint or low-compute networks include the use of delta activation update \[2\] and Neural Architectural Search \[3\] methods.

![Refer to caption](https://ar5iv.labs.arxiv.org/html/2202.03204/assets/x1.png)

Fig. 1: Temporal Network Grafting Algorithm (T-NGA). “GN” stands for grafted network.

The inputs to these networks are typically spectrogram features extracted from the audio samples, *e.g.*, Mel-Frequency Cepstral Coefficients (MFCCs) and Log-Mel spectrograms. On the other hand, spiking silicon cochlea sensors, which implement a simple model of the biological cochlea, encode audio as an asynchronous stream of output spikes from a set of frequency channels. The spiking Dynamic Audio Sensor (DAS) incorporates filter circuits that model the frequency selectivity of the basilar membrane, the rectification of inner hair cells, and the spike generation of the auditory nerve fibers \[4, 5\]. The DAS output events have been used to drive low-latency localization solutions together with the separation of the spike streams produced by competing talkers \[6\]. These studies show that it is possible to simultaneously localize multiple speakers, to separate their spike streams, and to estimate the speech envelope of an individual speaker from the separated spike streams. The DAS output has been used for edge audio tasks such as SV \[7\] and digit recognition \[2\] where the low-power and low-latency properties of an edge audio device are needed. Other methods use front-end software models that produce audio events, which are then processed by a spiking neural network  \[8, 9, 10\]. Custom edge Application-Specific Integrated Circuit (ASIC) designs that include the VAD chip by \[11\] use a spiking cochlea front-end together with a multilayer binary perceptron, and demonstrate a low power consumption of 1 $`\mu`$W.

Training deep neural networks for audio processing often requires large labeled datasets such as LibriSpeech which contains over 960 hours of transcribed audio \[12\]. There is a lack of large labeled spike datasets for event-driven sensors, thereby preventing the more extensive use of deep networks for processing spiking cochlea output events. To mitigate the expensive costs for labeling spiking audio datasets, we propose a self-supervised Temporal Network Grafting Algorithm (T-NGA), which requires only temporally aligned audio waveforms and spike recordings for training. In other words, T-NGA training does not require labeled DAS recordings. In this work, we show how T-NGA can exploit a pretrained network that processes audio spectrogram features to produce a *grafted network* (GN) that processes event features via Transfer Learning. T-NGA extends the Network Grafting Algorithm (NGA) \[13\] which was originally proposed for vision modalities to temporal audio sequences.

We studied and validated T-NGA using a Recurrent Neural Network (RNN) on a simple Automatic Speech Recognition (ASR) task (Section 3), first using spike recordings generated from an ideal software spiking cochlea model and then from the DAS recordings in the N-TIDIGITS18 dataset \[14\]. We investigated whether the accuracy of the GN obtained from T-NGA training could achieve the accuracy of a network trained from scratch using the labeled spiking cochlea recordings; and how the silicon circuit non-idealities and recording non-idealities affect the accuracy of GN. The contributions of this work can be summarized as follows:

- •
  We propose a self-supervised training method, T-NGA, which avoids the need of expensive labeling when training on novel spiking cochlea events for an acoustic task such as ASR.
- •
  T-NGA, to our knowledge, is the first algorithm that utilizes temporally aligned audio spectrogram and event features for training a network that uses spiking cochlea events for an ASR task.

## 2 Methods

### 2.1 Temporal Network Grafting Algorithm (T-NGA)

Fig. 1 illustrates the working principle of T-NGA. An RNN $`\mathcal{F}\hspace{0pt}( \cdot )`$ is pretrained on spectrogram features extracted from the audio waveform samples. The pretrained network $`\mathcal{F}\hspace{0pt}( \cdot )`$ consists of two parts: a front end $`\mathcal{F}_{\text{front}}`$ and trunk layers $`\mathcal{F}_{\text{trunk}}`$ (Fig. 1 (A)). The weights of the pretrained network are frozen during the T-NGA training. After training, a newly-trained grafted front end $`\mathcal{G}_{\text{front}}\hspace{0pt}( \cdot )`$ together with the pretrained trunk layers $`\mathcal{F}_{\text{trunk}}`$ form a *grafted network* (GN) that processes event features computed from the spiking cochlea events (Fig. 1 (B)).

Let $`\left\{ \left( \mathbf{a}_{i},t_{i}^{a} \right) \right\}_{i = 1}^{T^{a}}`$ and $`\left\{ \left( \mathbf{s}_{t},t_{i}^{s} \right) \right\}_{i = 1}^{T^{s}}`$ be the temporally aligned spectrogram and event features where $`t_{i}^{a}`$ and $`t_{i}^{s}`$ are timestamps of $`\mathbf{a}_{i}`$ and $`\mathbf{s}_{i}`$ respectively. Note that $`T^{a}`$ may not be equal to $`T^{s}`$ depending on the choice of feature configuration (see Section 2.3).

$`\mathcal{F}\hspace{0pt}( \cdot )`$ processes the spectrogram features $`\left\{ \left( \mathbf{a}_{i},t_{i}^{a} \right) \right\}_{i = 1}^{T^{a}}`$ and returns the prediction $`\left\{ y_{l} \right\}_{l = 1}^{L^{a}}`$:

$`{\left\{ \mathbf{h}_{i} \right\} = {\mathcal{F}_{\text{front}}\hspace{0pt}\left( \left\{ \mathbf{a}_{i} \right\} \right)}},{\left\{ y_{l} \right\} = {\mathcal{F}_{\text{trunk}}\hspace{0pt}\left( \left\{ \mathbf{h}_{i} \right\} \right)}}`$

where $`\left\{ \left( \mathbf{h}_{i},t_{i}^{a} \right) \right\}_{i = 1}^{T^{a}}`$ are the pretrained states, *i.e.*, hidden states of $`\mathcal{F}_{\text{front}}`$. Similarly, GN processes event features $`\left\{ \left( \mathbf{s}_{t},t_{i}^{s} \right) \right\}_{i = 1}^{T^{s}}`$ and outputs prediction $`\left\{ y_{l}^{s} \right\}_{l = 1}^{L^{s}}`$:

``` math
{\left\{ \mathbf{g}_{i} \right\} = {\mathcal{G}_{\text{front}}\hspace{0pt}\left( \left\{ \mathbf{s}_{i} \right\} \right)}},{\left\{ y_{l}^{s} \right\} = {\mathcal{F}_{\text{trunk}}\hspace{0pt}\left( \left\{ \mathbf{g}_{i} \right\} \right)}}
```

where $`\left\{ \left( \mathbf{g}_{i},t_{i}^{s} \right) \right\}_{i = 1}^{T^{s}}`$ are the grafted states, *i.e.*, hidden states of $`\mathcal{G}_{\text{front}}`$. The dimension of $`\mathbf{g}_{i}`$ is the same as the dimension of $`\mathbf{h}_{i}`$.

T-NGA training maximizes the similarity between $`\left\{ \mathbf{h}_{i} \right\}`$ and $`\left\{ \mathbf{g}_{i} \right\}`$. When $`T^{a} \neq T^{s}`$, we select $`T`$ features from both $`\left\{ \mathbf{h}_{i} \right\}`$ and $`\left\{ \mathbf{g}_{i} \right\}`$ where $`T \leq {\min\left( T^{a},T^{s} \right)}`$ and timestamps of the corresponding states $`t_{i}^{a}`$ and $`t_{i}^{s}`$ are the closest in time. T-NGA training optimizes the following loss function:

$`\mathcal{L}`$$`= {{\text{NCS}\hspace{0pt}\left( \left\{ \mathbf{h}_{i} \right\},\left\{ \mathbf{g}_{i} \right\} \right)} + {\text{MAE}\hspace{0pt}\left( \left\{ \mathbf{h}_{i} \right\},\left\{ \mathbf{g}_{i} \right\} \right)}}`$$`= {1 + {\frac{1}{T}\hspace{0pt}{\sum\limits_{i = 1}^{T}\frac{\mathbf{h}_{i} \cdot \mathbf{g}_{i}}{\left\| \mathbf{h}_{i} \right\| \cdot \left\| \mathbf{g}_{\mathbf{i}} \right\|}}} + {\frac{1}{T}\hspace{0pt}{\sum\limits_{i = 1}^{T}\left| {\mathbf{h}_{i} - \mathbf{g}_{i}} \right|}}}`$

where $`\text{NCS}\hspace{0pt}( \cdot , \cdot )`$ and $`\text{MAE}\hspace{0pt}( \cdot , \cdot )`$ compute the negative cosine similarity and the mean absolute error between aligned states, respectively. When the training is completed, the grafted front end $`\mathcal{G}_{\text{front}}`$ encodes the event features into a set of grafted states that can be directly used by the pretrained trunk layers $`\mathcal{F}_{\text{trunk}}`$.

### 2.2 Spiking Cochlea

The Dynamic Audio Sensor (DAS) has two independent 64-stage cascaded filter banks driven by two microphone inputs. The frequency selectivity of the cochlea channels ranges roughly from 50 Hz to 20 kHz on a log spacing across the channels. The DAS has been captured in several cochlea designs \[5, 4, 15\]. The spiking cochlea designed in \[15\] was used to generate the spike recordings of the TIDIGITS dataset to create a spiking cochlea dataset called N-TIDIGITS18. Details of this spiking dataset are given in Sec 2.5.

In this work, we also use a software model of a frequency channel which includes a second-order filter, a half-wave rectifier, and a linear leak integrate-and-fire neuron model used in the design reported in \[15\]. The transfer function of the $`n`$-th filter in a cascaded set of second-order filters is given by

``` math
{H_{n}\hspace{0pt}(s)} = {\prod\limits_{i = 1}^{n}\left( \frac{\tau_{i}\hspace{0pt}s}{{\tau_{i}^{2}\hspace{0pt}s^{2}} + \left. {\tau_{i}\hspace{0pt}s}/Q \right. + 1} \right)}
```

where $`\tau_{i} = \frac{1}{2 \cdot \pi \cdot f_{i}}`$, $`f_{i}`$ is the center frequency of the $`i`$-th channel, and $`Q`$ is the filter quality factor. The half-wave rectification is described as:

``` math
v_{r} = {\max\left( 0,{V_{n} - V_{\text{ref}}} \right)}
```

where $`v_{r}`$ is the rectifier output used to drive the neuron, $`V_{n}`$ is the filter output of the channel and $`V_{\text{ref}}`$ is a constant. The parameters of the model are set so that the spike responses of the channels are similar to those of the hardware spiking cochlea.

An example of the spikes generated from the software spiking cochlea model and the spikes recorded with the hardware spiking cochlea in response to the sample “8z1” (8Z1A.WAV from speaker AE in TIDIGITS) is shown in Fig. 2 ‣ 2 Methods ‣ T-NGA: Temporal Network Grafting Algorithm for Learning to Process Spiking Audio Sensor Events").

### 2.3 Feature Extraction

Features are extracted from both the audio and spike samples. For audio samples, we computed the Log-Mel spectrogram features using a 25 ms window, 10 ms stride, and 40 filter bank channels as shown in Fig. 3 (A). For the spike recordings, we used the time-binned spike count (TBSC) method \[14\] to convert spikes into event features. Assume that the spike stream consists of $`N`$ spikes $`\left\{ {e_{i} = \left( t_{i},f_{i} \right)} \right\}_{i = 1}^{N}`$ where timestamps $`t_{i}`$ are in ascending order. The TBSC feature for a time window $`\Delta\hspace{0pt}W`$ is then defined as $`\mathbf{s}_{j}^{(f)} = {\text{card}\hspace{0pt}\left( \left\{ e_{i} \middle| {{t_{i} \in {j\hspace{0pt}\text{-th window}}},{f_{i} = f}} \right\} \right)}`$ where $`\mathbf{s}_{j}^{(f)}`$ represents TBSC feature value at $`j`$-th window for channel frequency $`f`$; $`\text{card}\hspace{0pt}( \cdot )`$ is the cardinality of selected events. $`\Delta\hspace{0pt}W`$ is 10 ms or 25 ms and the stride is 10 ms for the TBSC features used in the study. Examples of TBSC features with $`\Delta\hspace{0pt}W`$= 25 ms are shown in Fig. 3 (B) and (C). For convenience, feature configurations are coded as window/stride, *e.g.*, 25w/10s means 25 ms window and 10 ms stride.

### 2.4 Network Architecture

The RNN used in this work consists of two Gated Recurrent Unit (GRU) \[16\] layers with 256 units each followed by a fully connected layer of 200 units with a LeakyReLU activation \[17\], and a final classification layer of 12 output units. The network has a total of 677 K parameters.

### 2.5 Datasets

We used the men and women speaker recordings in the TIDIGITS dataset \[18\] to match the spike recordings in the N-TIDIGITS18 dataset \[14\]. N-TIDIGITS18 consists of 8,623 training samples and 8,700 testing samples. Each sample consists of a single digit or multiple spoken digits. In total, there are 11 digits (“o”, “zero” and “1” to “9”).

For T-NGA training, the N-TIDIGITS18 recordings and the corresponding audio samples were aligned temporally using the Dynamic Time Warping (DTW) algorithm \[19\] before feature extraction. The spike recordings generated by the software spiking cochlea model are already aligned with the corresponding audio samples.

## 3 Results

We conducted experiments on a speech recognition task using the datasets described in Section 2.5. All networks in this section were trained for 50 epochs using the Adam optimizer \[20\]. For the supervised training experiments, we used a learning rate of 3e-4 and the Connectionist Temporal Classification (CTC) loss function \[21\]. For T-NGA, we used a learning rate of 1e-3 and the T-NGA loss function in Eq. 4 ‣ 2 Methods ‣ T-NGA: Temporal Network Grafting Algorithm for Learning to Process Spiking Audio Sensor Events"). Reported results show the mean and standard deviation of the word error rate (WER) for 5 runs of each experiment.

### 3.1 T-NGA experiments

We first trained a network PT-25 on TIDIGITS using spectrogram features as shown in Table 1(A). The PT-25 model was subsequently used as the pretrained model for T-NGA training to obtain grafted networks (GNs). For comparison, we also trained supervised networks (SNs) through standard supervised training on spiking cochlea datasets using event features.

Table 1(B) shows the results of using the event features created from ideal software spiking cochlea recordings. The GNs BGN-25, BGN-10 reached similar or better WERs than the SNs B-25, B-10. These result show that T-NGA training could be advantageous as it does not require a labeled event dataset and still produces a network that shows equivalent accuracy.

Results on N-TIDIGITS18 presented in Table 1(C) show that the SNs S-25, S-10 achieved $`\sim`$10% WER while the GNs GN-25, GN-10 reached $`\sim`$15% WER. The higher WER of the GNs compared to the corresponding SNs is because the hardware spiking cochlea includes circuit non-idealites that affect the distribution of the output cochlea spikes, and the temporal mismatch between the audio samples and event sample still exists after DTW alignment. In Section 3.2, we show that the WER of GN increased when training on spike recordings generated by the same software cochlea model which includes circuit non-idealities.

Table 1 also shows that both GNs and SNs perform better when using a 10w/10s event feature configuration, *i.e.*, 10w/10s characterizes the spike recordings better than 25w/10s. T-NGA training for BGN-10 and GN-10 models used 25w/10s Log-Mel spectrogram features and 10w/10s TBSC features. The results show that T-NGA can maximize the similarity between temporally aligned grafted states and pretrained states successfully while the feature configurations for the two modalities are different.

### 3.2 Analysis

We present two additional experiments to better understand the results obtained from T-NGA training and the resulting GN.

We first investigated quantitatively whether the circuit non-idealities of a spiking cochlea affect the performance of GN and SN. We generated another event dataset using the same software spiking cochlea model that includes circuit non-idealities from the the neuron spiking threshold, and filter quality factor variation. As a result, the WER of the GN was $`\sim`$3% higher than the SN as shown in Table 2. This result reveals that these non-idealities in the hardware spiking cochlea contributed to the gap in WER between GNs and SNs as observed in Table 1(C).

## 4 Conclusion

We propose a self-supervised method called Temporal Network Grafting Algorithm (T-NGA) which exploits a RNN trained on audio spectrogram features to process event features through a newly trained grafted front end. This algorithm mitigates the need for labeled spike recordings and only requires temporally aligned audio and spike samples.

We demonstrate T-NGA on a speech recognition task using TIDIGITS and N-TIDIGITS18 datasets; and show that the accuracy of the GN is equivalent to that of a network trained from scratch on the labeled software spiking cochlea recordings. When validated on real DAS recordings, the accuracy of the GN was only $`\sim`$5% lower than the accuracy of the SN despite the silicon circuit non-idealities reflected in the DAS recordings. The T-NGA works well even when the feature configuration of the Log-Mel spectrogram is different from that of the event features as shown in Section 3. Through self-supervised training, GN produces grafted states that are similar to the pretrained states as shown by the decoded spectrogram features.

Future work includes testing on a DAS dataset, which already includes the synchronized audio and spike recordings, and testing on datasets used for edge audio tasks such as keyword spotting.
