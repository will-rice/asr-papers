# A Neural Network Architecture Combining Gated Recurrent Unit (GRU) and Support Vector Machine (SVM) for Intrusion Detection in Network Traffic Data

Abien Fred M. Agarap <abienfred.agarap@gmail.com>

\(2018\)

###### Abstract.

Gated Recurrent Unit (GRU) is a recently-developed variation of the long short-term memory (LSTM) unit, both of which are variants of recurrent neural network (RNN). Through empirical evidence, both models have been proven to be effective in a wide variety of machine learning tasks such as natural language processing(Wen et al., 2015), speech recognition(Chorowski et al., 2015), and text classification(Yang et al., 2016). Conventionally, like most neural networks, both of the aforementioned RNN variants employ the Softmax function as its final output layer for its prediction, and the cross-entropy function for computing its loss. In this paper, we present an amendment to this norm by introducing linear support vector machine (SVM) as the replacement for Softmax in the final output layer of a GRU model. Furthermore, the cross-entropy function shall be replaced with a margin-based function. While there have been similar studies(Alalshekmubarak and Smith, 2013; Tang, 2013), this proposal is primarily intended for binary classification on intrusion detection using the 2013 network traffic data from the honeypot systems of Kyoto University. Results show that the GRU-SVM model performs relatively higher than the conventional GRU-Softmax model. The proposed model reached a training accuracy of $`\approx`$81.54% and a testing accuracy of $`\approx`$84.15%, while the latter was able to reach a training accuracy of $`\approx`$63.07% and a testing accuracy of $`\approx`$70.75%. In addition, the juxtaposition of these two final output layers indicate that the SVM would outperform Softmax in prediction time - a theoretical implication which was supported by the actual training and testing time in the study.

## 1. Introduction

By 2019, the cost to the global economy due to cybercrime is projected to reach \$2 trillion(Juniper, 2015). Among the contributory felonies to cybercrime is intrusions, which is defined as illegal or unauthorized use of a network or a system by attackers(Ghosh et al., 1999). An intrusion detection system (IDS) is used to identify the said malicious activity(Ghosh et al., 1999). The most common method used for uncovering intrusions is the analysis of user activities(Ghosh et al., 1999; Kumar and Spafford, 1994; Mukkamala et al., 2002). However, the aforementioned method is laborious when done manually, since the data of user activities is massive in nature(Frank, 1994; Laboratory, 1999). To simplify the problem, automation through machine learning must be done.\
A study by Mukkamala, Janoski, & Sung (2002)(Mukkamala et al., 2002) shows how support vector machine (SVM) and artificial neural network (ANN) can be used to accomplish the said task. In machine learning, SVM separates two classes of data points using a hyperplane(Cortes and Vapnik, 1995). On the other hand, an ANN is a computational model that represents the human brain, and shows information is passed from a neuron to another(Negnevitsky, 2011).\
An approach combining ANN and SVM was proposed by Alalshekmubarak & Smith(Alalshekmubarak and Smith, 2013), for time-series classification. Specifically, they combined echo state network (ESN, a variant of recurrent neural network or RNN) and SVM. This research presents a modified version of the aforementioned proposal, and use it for intrusion detection. The proposed model will use recurrent neural network (RNNs) with gated recurrent units (GRUs) in place of ESN. RNNs are used for analyzing and/or predicting sequential data, making it a viable candidate for intrusion detection(Negnevitsky, 2011), since network traffic data is sequential in nature.

## 2. Methodology

### 2.1. Machine Intelligence Library

Google TensorFlow(Abadi et al., 2015) was used to implement the neural network models in this study – both the proposed and its comparator.

### 2.2. The Dataset

The 2013 Kyoto University honeypot systems’ network traffic data(Song et al., 2006) was used in this study. It has 24 statistical features(Song et al., 2006); (1) 14 features from the KDD Cup 1999 dataset(Stolfo et al., 2000), and (2) 10 additional features, which according to Song, Takakura, & Okabe (2006)(Song et al., 2006), might be pivotal in a more effective investigation on intrusion detection. Only 22 dataset features were used in the study.

### 2.3. Data Preprocessing

For the experiment, only 25% of the whole 16.2 GB network traffic dataset was used, i.e. $`\approx`$4.1 GB of data (from January 1, 2013 to June 1, 2013). Before using the dataset for the experiment, it was normalized first – standardization (for continuous data, see Eq. 1 and Support Vector Machine (SVM) for Intrusion Detection in Network Traffic Data")) and indexing (for categorical data), then it was binned (discretized).

```math
z = \frac{X - \mu}{\sigma}
```

where $`X`$ is the feature value to be standardized, $`\mu`$ is the mean value of the given feature, and $`\sigma`$ is its standard deviation. But for efficiency, the StandardScaler().fit_transform() function of Scikit-learn(Pedregosa et al., 2011) was used for the data standardization in this study.\
For indexing, the categories were mapped to $`\lbrack 0,{n - 1}\rbrack`$ using the LabelEncoder().fit_transform() function of Scikit-learn(Pedregosa et al., 2011). After dataset normalization, the continuous features were binned (decile binning, a discretization/quantization technique). This was done by getting the $`10^{t\hspace{0pt}h}`$, $`20^{t\hspace{0pt}h}`$, …, $`90^{t\hspace{0pt}h}`$, and $`100^{t\hspace{0pt}h}`$ quantile of the features, and their indices served as their bin number. This process was done using the qcut() function of pandas(McKinney, 2010). Binning reduces the required computational cost, and improves the classification performance on the dataset(Lustgarten et al., 2008). Lastly, the features were one-hot encoded, making it ready for use by the models.

### 2.4. The GRU-SVM Neural Network Architecture

Similar to the work of Alalshekmubarak & Smith (2013)(Alalshekmubarak and Smith, 2013) and Tang (2013)(Tang, 2013), the present paper proposes to use SVM as the classifier in a neural network architecture. Specifically, a Gated Recurrent Unit (GRU) RNN (see Figure 1 and Support Vector Machine (SVM) for Intrusion Detection in Network Traffic Data")).

For this study, there were 21 features used as the model input. Then, the parameters are learned through the gating mechanism of GRU(Cho et al., 2014) (Equations 2 and Support Vector Machine (SVM) for Intrusion Detection in Network Traffic Data") to 5 and Support Vector Machine (SVM) for Intrusion Detection in Network Traffic Data")).

```math

```

```math
r = {\sigma\hspace{0pt}{({\mathbf{W}_{r} \cdot {\lbrack h_{t - 1},x_{t}\rbrack}})}}
```

```math
{\overset{\sim}{h}}_{t} = {t\hspace{0pt}a\hspace{0pt}n\hspace{0pt}h\hspace{0pt}{({\mathbf{W} \cdot {\lbrack{r_{t} \ast h_{t - 1}},x_{t}\rbrack}})}}
```

```math
h_{t} = {{{({1 - z_{t}})} \ast h_{t - 1}} + {z_{t} \ast {\overset{\sim}{h}}_{t}}}
```

But with the introduction of SVM as its final layer, the parameters are also learned by optimizing the objective function of SVM (see Eq. 6 and Support Vector Machine (SVM) for Intrusion Detection in Network Traffic Data")). Then, instead of measuring the network loss using cross-entropy function, the GRU-SVM model will use the loss function of SVM (Eq. 6 and Support Vector Machine (SVM) for Intrusion Detection in Network Traffic Data")).

```math
{m\hspace{0pt}i\hspace{0pt}n\hspace{0pt}\frac{1}{2}\hspace{0pt}{\|\mathbf{w}\|}_{1}^{2}} + {C\hspace{0pt}{\sum\limits_{i = 1}^{n}{m\hspace{0pt}a\hspace{0pt}x\hspace{0pt}{(0,{1 - {y_{i}'\hspace{0pt}{({{\mathbf{w}^{T}\hspace{0pt}\mathbf{x}_{i}} + b_{i}})}}})}}}}
```

Eq. 6 and Support Vector Machine (SVM) for Intrusion Detection in Network Traffic Data") is known as the unconstrained optimization problem of L1-SVM. However, it is not differentiable. On the contrary, its variation, known as the L2-SVM is differentiable and is more stable(Tang, 2013) than the L1-SVM:

```math
{m\hspace{0pt}i\hspace{0pt}n\hspace{0pt}\frac{1}{2}\hspace{0pt}{\|\mathbf{w}\|}_{2}^{2}} + {C\hspace{0pt}{\sum\limits_{i = 1}^{n}{m\hspace{0pt}a\hspace{0pt}x\hspace{0pt}{(0,{1 - {y_{i}'\hspace{0pt}{({{\mathbf{w}^{T}\hspace{0pt}\mathbf{x}_{i}} + b_{i}})}}})}^{2}}}}
```

The L2-SVM was used for the proposed GRU-SVM architecture. As for the prediction, the decision function $`{f\hspace{0pt}{(x)}} = {s\hspace{0pt}i\hspace{0pt}g\hspace{0pt}n\hspace{0pt}{({{\mathbf{w}\mathbf{x}} + b})}}`$ produces a score vector for each classes. So, to get the predicted class label $`y`$ of a data $`x`$, the $`a\hspace{0pt}r\hspace{0pt}g\hspace{0pt}m\hspace{0pt}a\hspace{0pt}x`$ function is used:

$`p\hspace{0pt}r\hspace{0pt}e\hspace{0pt}d\hspace{0pt}i\hspace{0pt}c\hspace{0pt}t\hspace{0pt}e\hspace{0pt}d\hspace{0pt}\_\hspace{0pt}c\hspace{0pt}l\hspace{0pt}a\hspace{0pt}s\hspace{0pt}s`$$`= {a\hspace{0pt}r\hspace{0pt}g\hspace{0pt}m\hspace{0pt}a\hspace{0pt}x\hspace{0pt}{({s\hspace{0pt}i\hspace{0pt}g\hspace{0pt}n\hspace{0pt}{({{\mathbf{w}\mathbf{x}} + b})}})}}`$

The $`a\hspace{0pt}r\hspace{0pt}g\hspace{0pt}m\hspace{0pt}a\hspace{0pt}x`$ function will return the index of the highest score across the vector of the predicted classes.\
The proposed GRU-SVM model may be summarized as follows:

1.  (1)
    Input the dataset features $`\left. \{\mathbf{x}_{i} \middle| {\mathbf{x}_{i} \in {\mathbb{R}}^{m}}\} \right.`$ to the GRU model.
2.  (2)
    Initialize the learning parameters weights and biases with arbitrary values (they will be adjusted through training).
3.  (3)
    The cell states of GRU are computed based on the input features $`\mathbf{x}_{i}`$, and its learning parameters values.
4.  (4)
    At the last time step, the prediction of the model is computed using the decision function of SVM: $`{f\hspace{0pt}{(x)}} = {s\hspace{0pt}i\hspace{0pt}g\hspace{0pt}n\hspace{0pt}{({{\mathbf{w}\mathbf{x}} + b})}}`$.
5.  (5)
    The loss of the neural network is computed using Eq. 7 and Support Vector Machine (SVM) for Intrusion Detection in Network Traffic Data").
6.  (6)
    An optimization algorithm is used for loss minimization (for this study, the Adam(Kingma and Ba, 2014) optimizer was used). Optimization adjusts the weights and biases based on the computed loss.
7.  (7)
    This process is repeated until the neural network reaches the desired accuracy or the highest accuracy possible. Afterwards, the trained model can be used for binary classification on a given data.

The program implementation of the proposed GRU-SVM model is available at https://github.com/AFAgarap/gru-svm.

### 2.5. Data Analysis

The effectiveness of the proposed GRU-SVM model was measured through the two phases of the experiment: (1) training phase, and (2) test phase. Along with the proposed model, the conventional GRU-Softmax was also trained and tested on the same dataset.\
The first phase of the experiment utilized 80% of total data points ($`\approx`$3.2 GB, or 14, 856, 316 lines of network traffic log) from the 25% of the dataset. After normalization and binning, it was revealed through a high-level inspection that a duplication occurred. Using the DataFrame.drop_duplicates() of pandas(McKinney, 2010), the 14, 856, 316-line data dropped down to 1, 898, 322 lines ($`\approx`$40MB).\
The second phase of the experiment was the evaluation of the two trained models using 20% of total data points from the 25% of the dataset. The testing dataset also experienced a drastic shrinkage in size – from 3, 714, 078 lines to 420, 759 lines ($`\approx`$9 MB).\
The parameters for the experiments are the following: (1) Accuracy, (2) Epochs, (3) Loss, (4) Run time, (5) Number of data points, (6) Number of false positives, (7) Number of false negatives. These parameters are based on the ones considered by Mukkamala, Janoski, & Sung (2002)(Mukkamala et al., 2002) in their study where they compared SVM and a feed-forward neural network for intrusion detection. Lastly, the statistical measures for binary classification were measured (true positive rate, true negative rate, false positive rate, and false negative rate).

## 4. Discussion

The empirical evidence presented in this paper suggests that SVM outperforms Softmax function in terms of prediction accuracy, when used as the final output layer in a neural network. This finding corroborates the claims by Alalshekmubarak & Smith (2013)(Alalshekmubarak and Smith, 2013) and Tang (2013)(Tang, 2013), and supports the claim that SVM is a more practical approach than Softmax for binary classification. Not only did the GRU-SVM model outperform the GRU-Softmax in terms of prediction accuracy, but it also outperformed the conventional model in terms of training time and testing time. Thus, supporting the theoretical implication as per the respective algorithm complexities of each classifier.\
The reported training accuracy of $`\approx`$81.54% and testing accuracy of $`\approx`$84.15% posits that the GRU-SVM model has a relatively stronger predictive performance than the GRU-Softmax model (with training accuracy of $`\approx`$63.07% and testing accuracy of $`\approx`$70.75%). Hence, we propose a theory to explain the relatively lower performance of Softmax compared to SVM in this particular scenario. First, SVM was designed primarily for binary classification(Cortes and Vapnik, 1995), while Softmax is best-fit for multinomial classification(Karpathy, [\[n. d.\]](#bib.bib12)). Building on the premise, SVM does not care about the individual scores of the classes it predicts, it only requires its margins to be satisfied(Karpathy, [\[n. d.\]](#bib.bib12)). On the contrary, the Softmax function will always find a way to improve its predicted probability distribution by ensuring that the correct class has the higher/highest probability, and the incorrect classes have the lower probability. This behavior of the Softmax function is exemplary, but excessive for a problem like binary classification. Given that the sigmoid $`\sigma`$ function is a special case of Softmax (see Eq. 8 and Support Vector Machine (SVM) for Intrusion Detection in Network Traffic Data")-9 and Support Vector Machine (SVM) for Intrusion Detection in Network Traffic Data")), we can refer to its graph as to how it classifies a network output.

$`\sigma\hspace{0pt}{(y)}`$$`= \frac{1}{1 + e^{- y}} = \frac{1}{1 + \frac{1}{e^{y}}} = \frac{1}{\frac{e^{y} + 1}{e^{y}}} = \frac{e^{y}}{1 + e^{y}} = \frac{e^{y}}{e^{0} + e^{y}}`$ $`s\hspace{0pt}o\hspace{0pt}f\hspace{0pt}t\hspace{0pt}m\hspace{0pt}a\hspace{0pt}x\hspace{0pt}{(y)}`$$`= \frac{e^{y_{i}}}{\sum_{i = 0}^{n = 1}e^{y_{i}}} = \frac{e^{y_{i}}}{e^{y_{0}} + e^{y_{1}}}`$

![Refer to caption](https://ar5iv.labs.arxiv.org/html/1709.03082/assets/sigmoid.png)

Figure 4. Image from ((https://stackoverflow.com/users/7672928/yohan grember), [\[n. d.\]](#bib.bib10)). Graph of a sigmoid $`\sigma`$ function.

It can be inferred from the graph of sigmoid $`\sigma`$ function (see Figure 4 and Support Vector Machine (SVM) for Intrusion Detection in Network Traffic Data")) that $`y`$ values tend to respond less to changes in $`x`$. In other words, the gradients would be small, which gives rise to the “vanishing gradients” problem. Indeed, one of the problems being solved by LSTM, and consequently, by its variants such as GRU(Cho et al., 2014; Hochreiter and Schmidhuber, 1997). This behavior defeats the purpose of GRU and LSTM solving the problems of a traditional RNN. We posit that this is the cause of misclassifications by the GRU-Softmax model.\
The said erroneous manner of the GRU-Softmax model reflects as a favor for the GRU-SVM model. But the comparison of the exhibited predictive accuracies of both models is not the only reason for the practicality in choosing SVM over Softmax in this case. The amount of training time and testing time were also considered. As their computational complexities suggest, SVM has the upper hand over Softmax. This is because the algorithm complexity of the predictor function in SVM is only $`O\hspace{0pt}{(1)}`$. On the other hand, the predictor function of Softmax has an algorithm complexity of $`O\hspace{0pt}{(n)}`$. As results have shown, the GRU-SVM model also outperformed the GRU-Softmax model in both training time and testing time. Thus, it corroborates the respective algorithm complexities of the classifiers.\

## 5. Conclusion and Recommendation

We proposed an amendment to the architecture of GRU RNN by using SVM as its final output layer in a binary/non-probabilistic classification task. This amendment was seen as viable for the fast prediction time of SVM compared to Softmax. To test the model, we conducted an experiment comparing it with the established GRU-Softmax model. Consequently, the empirical data attests to the effectiveness of the proposed GRU-SVM model over its comparator in terms of predictive accuracy, and training and testing time.\
Further work must be done to validate the effectiveness of the proposed GRU-SVM model in other binary classification tasks. Extended study on the proposed model for a faster multinomial classification would prove to be prolific as well. Lastly, the theory presented to explain the relatively low performance of the Softmax function as a binary classifier might be a pre-cursor to further studies.
