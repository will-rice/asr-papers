# USM RNN-T model weights binarization

###### Abstract

Large-scale universal speech models (USM) are already used in production. However, as the model size grows, the serving cost grows too. Serving cost of large models is dominated by model size that is why model size reduction is an important research topic. In this work we are focused on model size reduction using weights only quantization. We present the weights binarization of USM Recurrent Neural Network Transducer (RNN-T) and show that its model size can be reduced by 15.9x times at cost of word error rate (WER) increase by only 1.9% in comparison to the float32 model. It makes it attractive for practical applications.

###### keywords:

speech recognition, model quantization, low-bit quantization, model binarization

## 1 Introduction

In the last several years the size of automatic speech recognition (ASR) models increased by more than 10x: from hundreds of millions \[[1](https://arxiv.org/html/2406.02887v2#bib.bib1), [2](https://arxiv.org/html/2406.02887v2#bib.bib2)\] to several billions parameters \[[3](https://arxiv.org/html/2406.02887v2#bib.bib3), [4](https://arxiv.org/html/2406.02887v2#bib.bib4), [5](https://arxiv.org/html/2406.02887v2#bib.bib5)\]. Serving cost goes up with model size increase, that is why ASR models compression is a hot research topic. Sparse network pruning \[[6](https://arxiv.org/html/2406.02887v2#bib.bib6), [7](https://arxiv.org/html/2406.02887v2#bib.bib7), [8](https://arxiv.org/html/2406.02887v2#bib.bib8), [9](https://arxiv.org/html/2406.02887v2#bib.bib9), [10](https://arxiv.org/html/2406.02887v2#bib.bib10)\] as well as quantization  \[[11](https://arxiv.org/html/2406.02887v2#bib.bib11), [12](https://arxiv.org/html/2406.02887v2#bib.bib12), [13](https://arxiv.org/html/2406.02887v2#bib.bib13), [14](https://arxiv.org/html/2406.02887v2#bib.bib14), [15](https://arxiv.org/html/2406.02887v2#bib.bib15)\] are successfully applied on end-to-end ASR. In \[[13](https://arxiv.org/html/2406.02887v2#bib.bib13), [14](https://arxiv.org/html/2406.02887v2#bib.bib14)\] authors show that it is possible to quantize 160M parameters model (trained on  900 hours of Librispeech data \[[16](https://arxiv.org/html/2406.02887v2#bib.bib16)\]) with 4 bits and 2 bits with no accuracy loss. But at the same time they show that a 160M parameters model quantized on a production data set (with millions of hours of speech) has 1.4% (absolute) WER degradation for 2 bits quantization \[[14](https://arxiv.org/html/2406.02887v2#bib.bib14)\]. Accuracy reduction can be even higher, e.g. in \[[17](https://arxiv.org/html/2406.02887v2#bib.bib17), [15](https://arxiv.org/html/2406.02887v2#bib.bib15)\] for 2 bits weights only quantization WER is increased by several times. To address this issue, authors in \[[15](https://arxiv.org/html/2406.02887v2#bib.bib15)\] explored the combination of quantization with sparsity. Based on these observation we can conclude that 4 bits weights quantization can be quality neutral on most of ASR models, 2 bits quantization works on some set of models (it depends on both model and data size and can require more experiments) and as expected 1 bit quantization (aka binarization) is the most challenging (e.g. authors of \[[17](https://arxiv.org/html/2406.02887v2#bib.bib17)\] reported  3x accuracy degradation), so it motivates us to investigate quantization aware weights binarization.

Models binarization is popular topic, e.g. it is explored for computer vision \[[18](https://arxiv.org/html/2406.02887v2#bib.bib18), [19](https://arxiv.org/html/2406.02887v2#bib.bib19), [20](https://arxiv.org/html/2406.02887v2#bib.bib20), [21](https://arxiv.org/html/2406.02887v2#bib.bib21)\], language \[[22](https://arxiv.org/html/2406.02887v2#bib.bib22), [23](https://arxiv.org/html/2406.02887v2#bib.bib23), [24](https://arxiv.org/html/2406.02887v2#bib.bib24)\] and speech recognition \[[25](https://arxiv.org/html/2406.02887v2#bib.bib25), [26](https://arxiv.org/html/2406.02887v2#bib.bib26), [17](https://arxiv.org/html/2406.02887v2#bib.bib17)\] applications. Standard weights binarization \[[18](https://arxiv.org/html/2406.02887v2#bib.bib18), [19](https://arxiv.org/html/2406.02887v2#bib.bib19), [25](https://arxiv.org/html/2406.02887v2#bib.bib25)\] is based on sign function to binarize weights to {-1, 1}. It uses Straight-Through Estimator to overcome non-differentiability of the sign function. There can be stochastic or deterministic sign function \[[18](https://arxiv.org/html/2406.02887v2#bib.bib18)\]. It can be combined with batch normalization \[[18](https://arxiv.org/html/2406.02887v2#bib.bib18)\] and *hard tanh* \[[25](https://arxiv.org/html/2406.02887v2#bib.bib25)\] to deal with the gradient. The output of the binarized weight can be scaled by absmean \[[19](https://arxiv.org/html/2406.02887v2#bib.bib19), [23](https://arxiv.org/html/2406.02887v2#bib.bib23)\]. As shown in \[[19](https://arxiv.org/html/2406.02887v2#bib.bib19)\] absmean is an optimal scaler for binarization problem. Group Quantization \[[23](https://arxiv.org/html/2406.02887v2#bib.bib23)\] or sub-channel quantization \[[14](https://arxiv.org/html/2406.02887v2#bib.bib14)\] can be applied to parallelize weights quantization (and it also can reduce quantization error). In this work we propose a combination of sub-channel quantization (also called block-wise \[[27](https://arxiv.org/html/2406.02887v2#bib.bib27)\]) with binarization based on absmean \[[19](https://arxiv.org/html/2406.02887v2#bib.bib19), [23](https://arxiv.org/html/2406.02887v2#bib.bib23), [22](https://arxiv.org/html/2406.02887v2#bib.bib22)\]. As in \[[22](https://arxiv.org/html/2406.02887v2#bib.bib22), [23](https://arxiv.org/html/2406.02887v2#bib.bib23)\] we use absmean binarization but without weights centralization. It simplifies model quantization and does not impact model accuracy in comparison to quantization with weights centralization.

Our main contributions are outlined as below:

- •
  We simplify USM-CTC model training by switching to USM-RNNT model and reducing the number of training procedures from 4 to 2 with no accuracy loss (in comparison to baseline USM-CTC model). We show that with a reduced number of training procedures USM-RNNT is more friendly for quantization. With 2bits weights quantization USM-RNNT has only 1.4% WER increase in comparison to 3x WER degradation in the USM-CTC model.
- •
  We develop a new approach of USM-RNNT model binarization. It combines sub-channel quantization with absmean binarization. It is open sourced at \[[28](https://arxiv.org/html/2406.02887v2#bib.bib28)\].
- •
  We benchmark proposed binarization approach on USM RNN-T 1 Billion model trained on millions of hours of speech data and show that model size can be reduced by 15.9x times at cost of 1.9% (absolute) WER increase in comparison to the float32 baseline model.

The rest of the paper is organized as follows. In Section [2](https://arxiv.org/html/2406.02887v2#S2 "2 Model and Data ‣ USM RNN-T model weights binarization"), we describe the baseline model, the RNN-T model we use for quantization, and the datasets. In Section [3](https://arxiv.org/html/2406.02887v2#S3 "3 Quantization approaches ‣ USM RNN-T model weights binarization"), we present our quantization approaches. We report and discuss our experimental results in Section [4](https://arxiv.org/html/2406.02887v2#S4 "4 Experiments ‣ USM RNN-T model weights binarization"). Finally, we review related work in Section [5](https://arxiv.org/html/2406.02887v2#S5 "5 Related work ‣ USM RNN-T model weights binarization") and conclude in Section [6](https://arxiv.org/html/2406.02887v2#S6 "6 Conclusion ‣ USM RNN-T model weights binarization").

## 2 Model and Data

### 2.1 CTC-based Universal Speech Model

We base our work on Google Universal Speech Model (USM \[[5](https://arxiv.org/html/2406.02887v2#bib.bib5)\]). This is a single large model which performs ASR on a multitude of languages. This model uses a conformer encoder \[[2](https://arxiv.org/html/2406.02887v2#bib.bib2)\] and a CTC loss \[[29](https://arxiv.org/html/2406.02887v2#bib.bib29)\]. The USM uses a complex training procedure, therefore below we outline only the most important components.

The USM-CTC model consists of a conformer encoder which requires the 128-dimensional filter-bank features as input. A trainable language embedding is injected as a first token to the encoder. This allows the model to work with about $`300`$ languages. The encoder features are fed into the CTC decoder.

The model is trained in a 4-step procedure:

1.  1.  First, a 600M parameter CTC model is trained on a small supervised set. This model is used as a teacher for the Noisy Student Training \[[30](https://arxiv.org/html/2406.02887v2#bib.bib30)\] procedure. Both supervised and unsupervised sets are relabeled with this model to produce pseudo labels.
2.  2.  Then, the encoder is pre-trained with BEST-RQ \[[31](https://arxiv.org/html/2406.02887v2#bib.bib31)\].
3.  3.  Then, the full model is pre-trained with the supervised relabeled subset obtained in Step 1.
4.  4.  Finally, the model is fine-tuned with task-specific data.

### 2.2 RNN-T-based Universal Speech Model

We expand the USM-CTC model and simplify its training.

We use the RNN-T loss \[[32](https://arxiv.org/html/2406.02887v2#bib.bib32), [33](https://arxiv.org/html/2406.02887v2#bib.bib33)\] which is known to have higher performance. In particular, we use a linear joint network and a 3-layer LSTM decoder. A downside of using the RNN-T instead of CTC is that the training may be less stable. We address this issue by using the Adafactor \[[34](https://arxiv.org/html/2406.02887v2#bib.bib34)\] optimizer. Furthermore, Adafactor allowed us to reduce the memory footprint of the model during training.

Using a stronger loss allowed us to exclude the BEST-RQ pre-training and the fine-tuning steps. Therefore, our approach has two steps:

1.  1.  Similarly to the USM-CTC, we use a 600M CTC model trained on a supervised set to relabel supervised and unsupervised speech datasets.
2.  2.  Then we simply train the RNN-T USM on the mix of all the supervised and semi-supervised data obtained in Step 1.

In this paper we use a USM RNN-T model with 893 million parameters, we call it the USM RNN-T 1B model. It has a good ratio of performance to number of parameters. The USM RNN-T model is composed of a mel spectrogram followed by a feature extractor followed by 16 conformer layers with a decoder. Mel spectrogram returns frames with 128 features (where every frame is generated per every 40ms with 20ms step). The feature extractor is composed of a convolution layer with kernel size (3, 3) channel size (128, 32) and stride (2, 2), followed by a normalization layer with ReLU activation function. These layers are repeated two times so that the input signal is subsampled by 4x in time dimension. After that output features are projected to 1536 dimensions and it is augmented with positional embedding. Output of the feature extractor is processed by sequence of conformer layers. Conformer layer parameters are: the model hidden size is equal to the input size (1536); the kernel size of convolution is 5; local self attention uses left and right context equal 129 and 128 accordingly; number of heads in the attention is 12. Conformer layer is open sourced at \[[28](https://arxiv.org/html/2406.02887v2#bib.bib28)\]. Output of the conformer layers is processed by a standard RNN-T decoder, which has a joint network and predictor. Where the predictor has 3 LSTM layers with 640 hidden units. The joint network also has 640 units. Decoder vocabulary size is 16,384.

In Table [1](https://arxiv.org/html/2406.02887v2#S2.T1 "Table 1 ‣ 2.2 RNN-T-based Universal Speech Model ‣ 2 Model and Data ‣ USM RNN-T model weights binarization") we verify that our model is comparable to the previously published results. We conclude RNN-T simplified training produces results comparable to the baseline USM-CTC model.

### 2.3 Data

We used two datasets for training and one dataset for testing:

1.  1.  Semi-supervised: this is a large dataset extracted from YouTube videos. We extracted segments of lengths 30 seconds. We ensured that the extracted segments contain speech with high probability. This dataset contains videos of varying quality and a mix of formal and informal speech. The set contains 75 languages and its total length is about 4.2 million hours. We produce pseudo-labels for this set described in the procedure described in Section [2.1](https://arxiv.org/html/2406.02887v2#S2.SS1 "2.1 CTC-based Universal Speech Model ‣ 2 Model and Data ‣ USM RNN-T model weights binarization")
2.  2.  Supervised: is a smaller dataset also extracted from YouTube videos. Similarly to the semi-supervised set, we extracted the segments and ensured that they contain speech. In contrast to the semi-supervised set, we used a heuristic approach to include only high quality videos. This dataset was labeled by the human transcribers. Then, we used it to train a teacher model (see Section [2.1](https://arxiv.org/html/2406.02887v2#S2.SS1 "2.1 CTC-based Universal Speech Model ‣ 2 Model and Data ‣ USM RNN-T model weights binarization")). Finally, we produced the pseudo-labels labels for this set. We call the result a supervised-relabeled set. This set contains 56 languages and its total length is about 680,000 hours.
3.  3.  YouTube test set: the test set contains a combination of various topics for each given language. The human transcribers labeled this dataset.

## 3 Quantization approaches

We apply quantization-aware training on USM RNNT 1B model by quantizing weights of linear and projection attention layers in the Conformer encoder, during training of this model. Note that we keep convolution layers and 3 decoder RNN layers in float format because their size is negligible in comparison to the size of the encoder.

### 3.1 2bits quantization

Several methods of 2 bits weights quantization are presented in \[[14](https://arxiv.org/html/2406.02887v2#bib.bib14)\] (they are based on absmax quantization). Here we explore two methods from \[[14](https://arxiv.org/html/2406.02887v2#bib.bib14)\]:

1.  1.  Asymmetric per channel quantization. It uses scale backpropagation \[[35](https://arxiv.org/html/2406.02887v2#bib.bib35)\]. In \[[14](https://arxiv.org/html/2406.02887v2#bib.bib14)\] it is labeled as I2WasymSc, here we tagged it as Exp1
2.  2.  Asymmetric per channel quantization with scale backpropagation, clipping and sub channel split. We use subchannel quantization with block size equal 64. In \[[14](https://arxiv.org/html/2406.02887v2#bib.bib14)\] it is labeled as I2WasymScSubchClip. Here we labeled it as Exp2.

Please refer to \[[14](https://arxiv.org/html/2406.02887v2#bib.bib14)\] for more details about the above approaches.

### 3.2 1bit quantization

We explore several methods of model binarization. The first one is based on absmax asymmetric quantization, labeled as I2WasymSc in \[[14](https://arxiv.org/html/2406.02887v2#bib.bib14)\]. In this work we set the number of bits equal to 1 and apply static clipping, we label it as Exp3.

Another method of binarization is based on absmean \[[23](https://arxiv.org/html/2406.02887v2#bib.bib23), [22](https://arxiv.org/html/2406.02887v2#bib.bib22)\]. It is shown on Figure [1](https://arxiv.org/html/2406.02887v2#S3.F1 "Figure 1 ‣ 3.2 1bit quantization ‣ 3 Quantization approaches ‣ USM RNN-T model weights binarization"): input weights x can be centralized by subtracting per channel mean value (in line 10 on Figure [1](https://arxiv.org/html/2406.02887v2#S3.F1 "Figure 1 ‣ 3.2 1bit quantization ‣ 3 Quantization approaches ‣ USM RNN-T model weights binarization") we disable it). Then weights x are binarized (in line 15) and the dequantization scale is estimated as per channel absmean (in line 14), that is why it is called absmean binarization. Note that we make all zeros equal to small epsilon number (in line 11), so that sign function returns only 1 and -1 (as shown on Figure [2](https://arxiv.org/html/2406.02887v2#S3.F2 "Figure 2 ‣ 3.2 1bit quantization ‣ 3 Quantization approaches ‣ USM RNN-T model weights binarization") output of absmean_binarize has only 1 and -1 values). To deal with the gradient of a sign function we use straight-through estimator based on function ste, shown in line 18 in Figure [1](https://arxiv.org/html/2406.02887v2#S3.F1 "Figure 1 ‣ 3.2 1bit quantization ‣ 3 Quantization approaches ‣ USM RNN-T model weights binarization"). Note that we do not apply weights centralization as in \[[22](https://arxiv.org/html/2406.02887v2#bib.bib22), [23](https://arxiv.org/html/2406.02887v2#bib.bib23)\], because there was no accuracy difference and it simplifies model quantization. We labeled this approach as Exp4.

We combine Exp4 binarization technique with sub channel quantization \[[14](https://arxiv.org/html/2406.02887v2#bib.bib14), [36](https://arxiv.org/html/2406.02887v2#bib.bib36)\], which has a predefined block size equal 64. We labeled this approach as Exp5. It is explained in Figure [2](https://arxiv.org/html/2406.02887v2#S3.F2 "Figure 2 ‣ 3.2 1bit quantization ‣ 3 Quantization approaches ‣ USM RNN-T model weights binarization"), where input weights have shape \[2x6\]. We increase the number of channels in the input weights by splitting weights into sub-channels with block size equal 3 (it is selected for illustration purpose). After that weight shape becomes \[4x3\]. These weights are quantized using absmean binarization approach \[[23](https://arxiv.org/html/2406.02887v2#bib.bib23), [22](https://arxiv.org/html/2406.02887v2#bib.bib22)\] as shown on Figure [1](https://arxiv.org/html/2406.02887v2#S3.F1 "Figure 1 ‣ 3.2 1bit quantization ‣ 3 Quantization approaches ‣ USM RNN-T model weights binarization"). We use fake quantization aware training, so binarized weights are dequantized by multiplying them with scale, as shown on Figure [2](https://arxiv.org/html/2406.02887v2#S3.F2 "Figure 2 ‣ 3.2 1bit quantization ‣ 3 Quantization approaches ‣ USM RNN-T model weights binarization"). Then the dequantized weights are reshaped back to the original weight shape: \[2x6\]. The last step is einsum, which is computed over input activation with dequantized weights. Note that during the inference dequantization step (multiplication by scale) is done on einsum output, also input activation will be reshaped to match the shape of binarized weights (its shape \[4x3\] as shown on Figure [2](https://arxiv.org/html/2406.02887v2#S3.F2 "Figure 2 ‣ 3.2 1bit quantization ‣ 3 Quantization approaches ‣ USM RNN-T model weights binarization")).

## 4 Experiments

### 4.1 Baseline USM RNN-T 1B model

USM RNNT 1 Billion model described in Section [2.2](https://arxiv.org/html/2406.02887v2#S2.SS2 "2.2 RNN-T-based Universal Speech Model ‣ 2 Model and Data ‣ USM RNN-T model weights binarization") is trained on 256 TPU v4 \[[37](https://arxiv.org/html/2406.02887v2#bib.bib37)\] for 1.2 days. It takes 200,000 training iterations to converge. The model is trained on about 5 millions of hours of speech as described in section [2.3](https://arxiv.org/html/2406.02887v2#S2.SS3 "2.3 Data ‣ 2 Model and Data ‣ USM RNN-T model weights binarization"). Its mean WER is equal to 25.3% (computed over 61 languages) and model size in bits are presented in Table [2](https://arxiv.org/html/2406.02887v2#S4.T2 "Table 2 ‣ 4.3 USM RNN-T 1B model with binarized weights ‣ 4 Experiments ‣ USM RNN-T model weights binarization"). This experiment is labeled as Exp0 in Table [2](https://arxiv.org/html/2406.02887v2#S4.T2 "Table 2 ‣ 4.3 USM RNN-T 1B model with binarized weights ‣ 4 Experiments ‣ USM RNN-T model weights binarization").

### 4.2 USM RNN-T 1B model with 2bits weights quantization

We run quantization-aware training of Exp1 and Exp2 (described in section [3.1](https://arxiv.org/html/2406.02887v2#S3.SS1 "3.1 2bits quantization ‣ 3 Quantization approaches ‣ USM RNN-T model weights binarization")) on 256 TPU v5 for 270,000 training iterations (it takes 1.7 days).

Results of USM RNN-T 1B with 2bits quantization approaches Exp1 and Exp2 are presented in Table [2](https://arxiv.org/html/2406.02887v2#S4.T2 "Table 2 ‣ 4.3 USM RNN-T 1B model with binarized weights ‣ 4 Experiments ‣ USM RNN-T model weights binarization"). Exp1 has mean WER 26.7% and it is only 1.4 points worse than its float baseline. In contrast, USM CTC \[[15](https://arxiv.org/html/2406.02887v2#bib.bib15)\] has 3x WER degradation with 2bits weights quantization. We hypothesize that quantization difficulties of the USM CTC model can be due to multi-stage training procedures, described in section [2.1](https://arxiv.org/html/2406.02887v2#S2.SS1 "2.1 CTC-based Universal Speech Model ‣ 2 Model and Data ‣ USM RNN-T model weights binarization")  \[[15](https://arxiv.org/html/2406.02887v2#bib.bib15)\], and differences in data sets. The model size of Exp1 (in bits and estimated model size reduction) is presented in Table [2](https://arxiv.org/html/2406.02887v2#S4.T2 "Table 2 ‣ 4.3 USM RNN-T 1B model with binarized weights ‣ 4 Experiments ‣ USM RNN-T model weights binarization"). With 2bits weights quantization Exp1, we reduce model size by 11.4x times. As expected Exp2 with sub-channel quantization (block size 64) has a larger quantized model size (due to additional meta data) in comparison to Exp1.

### 4.3 USM RNN-T 1B model with binarized weights

Training binarized models Exp3, Exp4 and Exp5 (described in section [3.2](https://arxiv.org/html/2406.02887v2#S3.SS2 "3.2 1bit quantization ‣ 3 Quantization approaches ‣ USM RNN-T model weights binarization")) takes 3.4 days (446,000 training iterations) on 256 TPU v5 \[[38](https://arxiv.org/html/2406.02887v2#bib.bib38)\]. Method Exp3 diverged and has 100% WER. But methods Exp4 and Exp5 converged and have WER 27.5% and 27.2% accordingly. We hypothesize that method Exp3 diverged because it is based on absmax quantization. Its quantization scale coefficient is defined by max value of abs weights and normalization by max value can be less stable in comparison to normalization by mean abs value. Both Exp4 and Exp5 are based on absmean quantization (scale coefficient is defined by mean value of abs weights). We observe that a model binarized with Exp5 can reduce model size by 15.9x times at the cost of increasing mean WER by 1.9% in comparison to float32 baseline.

The WER comparison of float baseline model Exp0 vs binarized model Exp5 over 61 languages is shown on Figure [3](https://arxiv.org/html/2406.02887v2#S4.F3 "Figure 3 ‣ 4.3 USM RNN-T 1B model with binarized weights ‣ 4 Experiments ‣ USM RNN-T model weights binarization"). We can see that some languages have WER \>50%, we explain it by data quality of such languages.

Limitations of the binarization approach presented in this paper: there still is an accuracy gap between binarized and float baseline models; model binarization can take at least 2x times longer because it needs more time to converge.

## 5 Related work

In this section we review the prior literature on ASR model quantization, compare and contrast it to our approach.

As in \[[14](https://arxiv.org/html/2406.02887v2#bib.bib14)\] we explore quantization of RNN-T model (with 118M parameters) and train it on Librispeech data. We binarize weights of this model using best quantization method (from \[[14](https://arxiv.org/html/2406.02887v2#bib.bib14)\], based on absmax) and get only 0.1% WER increase on Librispeech test clean and 0.3% WER increase on test other accordingly. Note that we have to train this model two times longer in comparison to float baseline. But as we can see in Table [2](https://arxiv.org/html/2406.02887v2#S4.T2 "Table 2 ‣ 4.3 USM RNN-T 1B model with binarized weights ‣ 4 Experiments ‣ USM RNN-T model weights binarization"), binarization method Exp3 based on absmax, does not converge on a large model (USM RNN-T, with 1B parameters), trained on a large data set(5 million hours of speech). That is why in this work we are focused on large model binarization trained on large data.

Recent studies are focused on the Universal Speech Model (USM, \[[3](https://arxiv.org/html/2406.02887v2#bib.bib3), [39](https://arxiv.org/html/2406.02887v2#bib.bib39), [40](https://arxiv.org/html/2406.02887v2#bib.bib40), [41](https://arxiv.org/html/2406.02887v2#bib.bib41), [42](https://arxiv.org/html/2406.02887v2#bib.bib42), [5](https://arxiv.org/html/2406.02887v2#bib.bib5)\]) which can recognize multiple languages. We base our work on \[[5](https://arxiv.org/html/2406.02887v2#bib.bib5)\]. These models show state of the art results with large model size (\>1B parameters). As a result it increases serving cost. A standard approach of speech model serving cost reduction is model compression based on weights quantization \[[25](https://arxiv.org/html/2406.02887v2#bib.bib25), [26](https://arxiv.org/html/2406.02887v2#bib.bib26), [17](https://arxiv.org/html/2406.02887v2#bib.bib17), [11](https://arxiv.org/html/2406.02887v2#bib.bib11), [12](https://arxiv.org/html/2406.02887v2#bib.bib12), [13](https://arxiv.org/html/2406.02887v2#bib.bib13), [14](https://arxiv.org/html/2406.02887v2#bib.bib14), [15](https://arxiv.org/html/2406.02887v2#bib.bib15)\]. In \[[15](https://arxiv.org/html/2406.02887v2#bib.bib15)\] authors quantize weights of USM-CTC model with 2bits but accuracy drops by 3x. So they addressed it by combining quantization with sparsity. In our paper we replace USM CTC by USM RNN-T and simplify training step procedures as a result we can quantize USM RNN-T model (Exp1 in Table [2](https://arxiv.org/html/2406.02887v2#S4.T2 "Table 2 ‣ 4.3 USM RNN-T 1B model with binarized weights ‣ 4 Experiments ‣ USM RNN-T model weights binarization")) with 2bits at a cost of 1.4% WER increase (instead of 3x increase in USM CTC). We explore 2bits quantization approach based on \[[14](https://arxiv.org/html/2406.02887v2#bib.bib14)\]. In addition to 2bits quantization we explore USM RNN-T binarization, which has not been investigated in previous studies. Standard weights binarization is based on absmean \[[19](https://arxiv.org/html/2406.02887v2#bib.bib19), [23](https://arxiv.org/html/2406.02887v2#bib.bib23), [22](https://arxiv.org/html/2406.02887v2#bib.bib22)\]. As in \[[22](https://arxiv.org/html/2406.02887v2#bib.bib22), [23](https://arxiv.org/html/2406.02887v2#bib.bib23)\] we use absmean binarization but without weights centralization. It simplifies model quantization and does not impact model accuracy (on USM model) in comparison to quantization with weights centralization. We combine absmean binarization with sub-channel quantization \[[14](https://arxiv.org/html/2406.02887v2#bib.bib14)\] and show that it is possible to binarize USM RNN-T 1B model and reduce its model size by 15.9x times at a cost of 1.9% WER increase in comparison to baseline float32 model.

## 6 Conclusion

We simplified USM-CTC 1B model model training by replacing it with USM RNNT 1B model and reducing the number of training step procedures. As a result, the quantized USM RNNT 1B model with 2 bits weights quantization has reduced model size by 11.4x times at cost of only 1.4% (absolute) WER increase vs 3x WER increase of 2bits weights quantization in USM-CTC 1B. We presented a new weights binarization for the USM RNNT 1B model and showed that model size can be reduced by 13x or 15.9x (if double quantization is applied) at a cost of 1.9% WER increase in comparison to baseline float32 model. It makes it attractive for real applications.
