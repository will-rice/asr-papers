# Semantic Communications for Speech Recognition

Zhenzi Weng1, Zhijin Qin1, and Geoffrey Ye Li2\
1 Queen Mary University of London, London, UK\
2 Imperial College London, London, UK\
{zhenzi.weng, z.qin}@qmul.ac.uk, geoffrey.li@imperial.ac.uk

###### Abstract

The traditional communications transmit all the source data represented by bits, regardless of the content of source and the semantic information required by the receiver. However, in some applications, the receiver only needs part of the source data that represents critical semantic information, which prompts to transmit the application-related information, especially when bandwidth resources are limited. In this paper, we consider a semantic communication system for speech recognition by designing the transceiver as an end-to-end (E2E) system. Particularly, a deep learning (DL)-enabled semantic communication system, named DeepSC-SR, is developed to learn and extract text-related semantic features at the transmitter, which motivates the system to transmit much less than the source speech data without performance degradation. Moreover, in order to facilitate the proposed DeepSC-SR for dynamic channel environments, we investigate a robust model to cope with various channel environments without requiring retraining. The simulation results demonstrate that our proposed DeepSC-SR outperforms the traditional communication systems in terms of the speech recognition metrics, such as character-error-rate and word-error-rate, and is more robust to channel variations, especially in the low signal-to-noise (SNR) regime.

###### Index Terms:

Deep learning, end-to-end communication, semantic communication, speech recognition.

## I Introduction

Due to the breakthroughs of deep learning (DL) in various fields, the intelligent communications have been investigated and considered as a cutting-edge technique to solve the bottlenecks of the traditional communication systems\[[1](https://arxiv.org/html/2107.11190v3#bib.bib1)\]. Particularly, the DL-enabled intelligent communications have achieved lots of successes in physical layer communications\[[2](https://arxiv.org/html/2107.11190v3#bib.bib2), [3](https://arxiv.org/html/2107.11190v3#bib.bib3)\] and wireless resource allocations\[[4](https://arxiv.org/html/2107.11190v3#bib.bib4), [5](https://arxiv.org/html/2107.11190v3#bib.bib5)\].

The communication systems utilizing DL techniques are typically designed to transmit digital bit sequences and optimized by minimizing the bit-error rate (BER) or symbol-error rate (SER), which achieves the first level communications according to the categorization by Shannon and Weaver\[[6](https://arxiv.org/html/2107.11190v3#bib.bib6)\]. Inspired by potentially higher performance and efficiency of the second level communications, the DL-enabled semantic communications have been investigated recently and have shown great potentials to break though the existing technique problems in the traditional communications systems.

Semantic information is relevant to the transmission goal at the receiver, which could be either source massage recovery or more intelligent tasks. In the cases of intelligent tasks, the semantic information only contains the task-related features while the other irrelative features will not be extracted or transmitted. As a result, the transmission bandwidth is reduced significantly. Moreover, the transmitted features can be recovered via minimizing the semantic error instead of BER or SER. The mechanism behind this is that semantic information takes into account the meaning and veracity of source data because they can be both informative and factual\[[7](https://arxiv.org/html/2107.11190v3#bib.bib7)\], besides, the semantic data can be compressed to a proper size by employing a lossless method\[[8](https://arxiv.org/html/2107.11190v3#bib.bib8)\]. However, it is very challenging to define the semantic information or to represent semantic features by a precise mathematical formula.

Inspired by the end-to-end (E2E) communication systems developed to address the challenges in traditional block-wise commutation systems\[[9](https://arxiv.org/html/2107.11190v3#bib.bib9), [10](https://arxiv.org/html/2107.11190v3#bib.bib10)\], different types of sources have been considered on E2E semantic communication systems. Particularly, an initial research on semantic communication systems for text information has been developed in\[[11](https://arxiv.org/html/2107.11190v3#bib.bib11)\], which directly mitigates the semantic error when achieving Nash equilibrium. However, such a text-based semantic communication system only measures the performance at the word level instead of the sentence level. Thus, a further investigation about semantic communications for text transmission, named DeepSC, has been carried out in\[[12](https://arxiv.org/html/2107.11190v3#bib.bib12)\] to deal with the semantic error at the sentence level with various length. Moreover, a lite distributed semantic communication system for text transmission, named L-DeepSC, has been proposed in\[[13](https://arxiv.org/html/2107.11190v3#bib.bib13)\] to address the challenge of IoT to perform the intelligent tasks.

Recently, there are also investigations on semantic communications for other transmission contents, such as image and speech. A DL-enabled semantic communication system for image transmission, named JSCC, has been developed in\[[14](https://arxiv.org/html/2107.11190v3#bib.bib14)\]. Based on JSCC, an image transmission system, integrating channel output feedback, can improve image reconstruction\[[15](https://arxiv.org/html/2107.11190v3#bib.bib15)\]. Similar to text transmission, IoT applications for image transmission have been carried out. Particularly, a joint image transmission-recognition system has been developed in\[[16](https://arxiv.org/html/2107.11190v3#bib.bib16)\] to achieve high recognition accuracy. A deep joint source-channel coding architecture, name DeepJSCC, has been investigated in\[[17](https://arxiv.org/html/2107.11190v3#bib.bib17)\] to process image with low computation complexity.

Regarding the semantic commutations for speech information, our previous work developed an attention mechanism-based semantic communication system to restore the source message, i.e., reconstruct the speech signals\[[18](https://arxiv.org/html/2107.11190v3#bib.bib18)\]. However, in this paper, we consider an intelligent task at the receiver to recover the text information of the input speech signals. Particularly, we propose a DL-enabled semantic communication system for speech recognition, named DeepSC-SR, by learning and extracting the text-related semantic features from the readable speech signals, then recovering the text transcription at the receiver. The main contributions of this article can be summarized as threefold:

- •
  A novel semantic communication system for speech recognition, named DeepSC-SR, is first proposed, which designs joint semantic and channel coding as an integrated neural network (NN).
- •
  Particularly, the convolution neural network (CNN) is employed to compress the source data and recurrent neural network (RNN) is utilized for feature learning and extracting from the input speech signals. By doing so, DeepSC-SR can recover the text transcription at the receiver by only transmitting text-related features.
- •
  Moreover, a trained model with high robustness to channel variations is obtained by training DeepSC-SR under a fixed channel condition, and then facilitating it with good performance when coping with different testing channel environments.

The rest of this article is structured as follows. Section II introduces the model of semantic communication system for speech recognition and performance metrics. In Section III, the details of the proposed DeepSC-SR is presented. Simulation results are discussed in Section IV and Section V draws conclusions.

## II System Model

The semantic communication system for speech recognition aims to transmit and recover the information-related semantic features. In this section, we introduce the details of the considered system model and the adopted performance metrics are presented.

### II-A Input Spectrum and Transcription

The original speech sample sequence is converted into a spectrum before feeding into the transmitter. Particularly, the input sample sequence, $`\mathbf{m}`$, is first divided into $`N`$ frames by slicing it into $`N`$ time-slices. Then, the $`N`$ frames are converted into a spectrum via a series of operations, i.e., Hamming window, fast Fourier transform (FFT), logarithm, and normalization. The spectrum includes $`N`$ vectors, $`{\mathbf{s}} = \left\lbrack {\mathbf{s}}_{1},{\mathbf{s}}_{2},\ldots,{\mathbf{s}}_{N} \right\rbrack`$, and each vector, $`{\mathbf{s}}_{n}`$, $`n \in \lbrack 1,\;2,\ldots,N\rbrack`$, represents the characteristics of its corresponding frame.

Moreover, here we introduce the transcription of a single speech sample sequence as $`{\mathbf{t}} = \left\lbrack t_{1},t_{2},\ldots,t_{K} \right\rbrack`$, each token $`t_{k}`$, $`k \in \lbrack 1,\;2,\ldots,K\rbrack`$, represent a character in the alphabet or a word boundary. In this paper, the considered language is English, there are 26 characters in the alphabet, besides, we add $`apostrophe`$, $`space`$, and $`blank`$ as three word boundaries, then we have 29 tokens, i.e., $`t_{k} \in \overline{\mathbf{t}}`$, $`\overline{\mathbf{t}} = \left\lbrack a,b,c,\ldots,z,{apostrophe},{space},{blank} \right\rbrack`$.

### II-B Transmitter

Based on the spectrum and transcription of the original speech sample sequence, the proposed system model is shown in Fig. [1](https://arxiv.org/html/2107.11190v3#S2.F1 "Figure 1 ‣ II-B Transmitter ‣ II System Model ‣ Semantic Communications for Speech Recognition"). From the figure, the transmitter consists of two individual components: the *semantic encoder* and the *channel encoder*, each component is implemented by an independent NN. At the transmitter, the input spectrum is converted into the text features, $`\mathbf{p}`$, by the *semantic encoder*, then the text features are mapped into symbols, $`\mathbf{x}`$, by the *channel encoder* to be transmitted over physical channels. Denote the NN parameters of the *semantic encoder* and the *channel encoder* as $`\mathbf{α}`$ and $`\mathbf{β}`$, respectively, the encoded symbol sequence, $`\mathbf{x}`$, can be expressed as

``` math
{{\mathbf{x}} = {\mathbf{T}_{\mathbf{β}}^{\mathcal{C}}{({\mathbf{T}_{\mathbf{α}}^{\mathcal{S}}{({\mathbf{s}})}})}}},
```

where $`\mathbf{T}_{\mathbf{α}}^{\mathcal{S}}{( \cdot )}`$ and $`\mathbf{T}_{\mathbf{β}}^{\mathcal{C}}{( \cdot )}`$ indicate the *semantic encoder* and the *channel encoder* with respect to (w.r.t.) parameters $`\mathbf{α}`$ and $`\mathbf{β}`$, respectively. Here we denote the NN parameters of the transmitter as $`{\mathbf{θ}}^{\mathcal{T}} = {({\mathbf{α}},{\mathbf{β}})}`$.

![Refer to caption]()

Figure 1: Model structure of DL-enabled semantic communication system for speech recognition.

The mapped symbols, $`\mathbf{x}`$, are transmitted over a physical channel. Note that the normalization on transmitted symbols $`\mathbf{x}`$ is required to ensure the transmission power constraint $`{{\mathbb{E}}\left\| {\mathbf{x}} \right\|^{2}} = 1`$.

The whole transceiver in Fig. [1](https://arxiv.org/html/2107.11190v3#S2.F1 "Figure 1 ‣ II-B Transmitter ‣ II System Model ‣ Semantic Communications for Speech Recognition") is designed for a single communication link, in which the wireless channel, represented by $`p_{h}\left( {\mathbf{y}} \middle| {\mathbf{x}} \right)`$, takes $`\mathbf{x}`$ as the input and produces the output as received signal, $`\mathbf{y}`$. Denote the coefficients of a linear channel as $`\mathbf{h}`$, then the transmission process from the transmitter to the receiver can be modeled as

``` math
{{\mathbf{y}} = {{{\mathbf{h}} \ast {\mathbf{x}}} + {\mathbf{w}}}},
```

where $`{\mathbf{w}} \sim {\mathcal{C}\mathcal{N}{(0,{\sigma^{2}\mathbf{I}})}}`$ indicates independent and identically distributed (i.i.d.) Gaussian noise, $`\sigma^{2}`$ is noise variance for each channel and $`\mathbf{I}`$ is the identity matrix.

### II-C Receiver

The receiver also consists of two cascaded parts, including the *channel decoder* and the *feature decoder*, which commits to recover the text-related semantic features and convert them into the transcription as close as to the original transcription. Firstly, the received signal, $`\mathbf{y}`$, is mapped into the text-related semantic features, $`\hat{\mathbf{p}}`$, by the NN-based *channel decoder*. $`\hat{\mathbf{p}} = \left\lbrack {\hat{\mathbf{p}}}_{1},{\hat{\mathbf{p}}}_{2},\ldots,{\hat{\mathbf{p}}}_{L} \right\rbrack`$ denotes a probability matrix, in which each probability vector $`{\hat{\mathbf{p}}}_{l} = \left\lbrack {\hat{p}}_{l}^{1},{\hat{p}}_{l}^{2},\ldots,{\hat{p}}_{l}^{29} \right\rbrack`$, $`l \in \lbrack 1,\;2,\ldots,L\rbrack`$, consists of 29 probabilities and each probability represents that the $`l`$th token in $`{\hat{\mathbf{p}}}_{l}`$ is the corresponding token in $`\overline{\mathbf{t}}`$. Denote the NN parameters of the *channel decoder* as $`\mathbf{δ}`$, then the recovered text features, $`\hat{\mathbf{p}}`$, can be obtained from the received signal, $`\mathbf{y}`$, by

``` math
{\hat{\mathbf{p}} = {\mathbf{R}_{\mathbf{δ}}^{\mathcal{S}}{({\mathbf{y}})}}},
```

where $`\mathbf{R}_{\mathbf{δ}}^{\mathcal{S}}{( \cdot )}`$ indicate the *channel decoder* w.r.t. parameters $`\mathbf{δ}`$. Denote the NN parameters of the receiver as $`{\mathbf{θ}}^{\mathcal{R}} = {\mathbf{δ}}`$.

Secondly, the text-related semantic features, $`\hat{\mathbf{p}}`$, are decoded into the transcription, $`\hat{\mathbf{t}}`$, by the *feature decoder*, denoted as

``` math
{\hat{\mathbf{t}} = {\mathbf{R}^{\mathcal{F}}{(\hat{\mathbf{p}})}}},
```

where $`\mathbf{R}^{\mathcal{F}}{( \cdot )}`$ represents the *feature decoder*.

Note that the process to map the probabilities into the transcription by the *feature decoder* is unable to be implemented by the NN due to the non-differentiability. Moreover, the decoded transcription, $`\hat{\mathbf{t}} = \left\lbrack {\hat{t}}_{1},{\hat{t}}_{2},\ldots,{\hat{t}}_{K'} \right\rbrack`$, includes $`K'`$ tokens, which may be greater than, smaller than, or equal to $`K`$ tokens in the original transcription $`\mathbf{t}`$.

The objective of the semantic communication system for speech recognition is to recover the text information of the original speech signals, which is equivalent to maximize the posterior probability $`p\left( {\mathbf{t}} \middle| {\mathbf{s}} \right)`$. Besides, by introducing connectionist temporal classification (CTC)\[[19](https://arxiv.org/html/2107.11190v3#bib.bib19)\], the posterior probability $`p\left( {\mathbf{t}} \middle| {\mathbf{s}} \right)`$ can be expressed as

``` math
{{p\left( {\mathbf{t}} \middle| {\mathbf{s}} \right)} = {\sum\limits_{A \in {{\mathfrak{A}}{({\mathbf{s}},{\mathbf{t}})}}}\left( {\prod\limits_{l = 1}^{L}{{\hat{p}}_{l}\left( a_{l} \middle| {\mathbf{s}} \right)}} \right)}},
```

where $`{\mathfrak{A}}{({\mathbf{s}},{\mathbf{t}})}`$ represents the set of all possible valid alignments of transcription $`\mathbf{t}`$ to spectrum $`\mathbf{s}`$, and $`a_{l}`$ indicates the token under the valid alignments. For example, assume the transcription $`{\mathbf{t}} = \lbrack t,a,s,t,e\rbrack`$, the valid alignments could be $`\left\lbrack {blank},t,{blank},a,s,{blank},t,e \right\rbrack`$, $`\left\lbrack t,{blank},a,s,{blank},{blank},t,e \right\rbrack`$, etc. Note that the number of tokens in every valid alignment is $`L`$. Let a valid alignment be $`\left\lbrack {blank},t,{blank},a,s,{blank},t,e \right\rbrack`$, the first token is $`blank`$, i.e., $`a_{1} = {blank}`$, then we have

``` math
{{{{\hat{p}}_{l}\left( a_{l} \middle| {\mathbf{s}} \right)} = {{\hat{p}}_{l}\left( {blank} \middle| {\mathbf{s}} \right)} = {\hat{p}}_{l}^{29}},{l = 1}},
```

where $`{\hat{p}}_{l}^{29}`$ is one of the probabilities in probability vector $`{\hat{\mathbf{p}}}_{l}`$ and number 29 represents $`blank`$ is the 29th token in $`\overline{\mathbf{t}}`$.

Thus, for the sake of maximizing the posterior probability $`p\left( {\mathbf{t}} \middle| {\mathbf{s}} \right)`$, the CTC loss is adopted as the loss function in our system, which can be expressed as

``` math
{{\mathcal{L}_{CTC}{({\mathbf{θ}})}} = {- {\ln\left( {\sum\limits_{A \in {{\mathfrak{A}}{({\mathbf{s}},{\mathbf{t}})}}}\left( {\prod\limits_{l = 1}^{L}{{\hat{p}}_{l}\left( a_{l} \middle| {{\mathbf{s}},{\mathbf{θ}}} \right)}} \right)} \right)}}},
```

where $`\mathbf{θ}`$ denotes the NN parameters of the transmitter and the receiver, $`{\mathbf{θ}} = {({\mathbf{θ}}^{\mathcal{T}},{\mathbf{θ}}^{\mathcal{R}})}`$.

Moreover, given prior channel state information (CSI), the NN parameters, $`\mathbf{θ}`$, can be updated by stochastic gradient descent (SGD) algorithm as follows:

``` math
{{\mathbf{θ}}^{({i + 1})}\leftarrow{{\mathbf{θ}}^{(i)} - {\eta{\nabla_{{\mathbf{θ}}^{(i)}}\mathcal{L}_{CTC}}{({\mathbf{θ}})}}}},
```

where $`\eta > 0`$ is a learning rate and $`\nabla`$ indicates the differential operator.

### II-D Performance Metrics

In order to measure the similarity of the original and recovered text transcription, we adopt character-error-rate (CER) and word-error-rate (WER) in our model as the performance metrics. Based on the decoded transcription, $`\hat{\mathbf{t}}`$, the substitution, deletion, and insertion operations are utilized to restore the original transcription, $`\mathbf{t}`$. Therefore, the calculation of CER can be denoted as

``` math
{{CER} = \frac{S_{C} + D_{C} + I_{C}}{N_{C}}},
```

where $`S_{C}`$, $`D_{C}`$, and $`I_{C}`$ represent the numbers of character substations, character deletions, and character insertions, respectively. $`N_{C}`$ indicates the number of characters in $`\mathbf{t}`$.

Similarly, the WER can be calculated by

``` math
{{WER} = \frac{S_{W} + D_{W} + I_{W}}{N_{W}}},
```

where $`S_{W}`$, $`D_{W}`$, and $`I_{W}`$ denote the numbers of word substations, word deletions, and word insertions, respectively. $`N_{W}`$ represents the number of words in $`\mathbf{t}`$.

Note that the values of CER and WER may exceed 1 in some cases. Moreover, to evaluate the recognition accuracy for the same sentence, CER is typically lower than WER and it is generally acknowledged that the recognized sentence is readable when CER is lower than around 0.15.

## III Semantic Communication System for Speech Recognition

In this section, we present the details of the developed DeepSC-SR. Specifically, CNN and RNN are adopted for the semantic encoding, dense layer is employed for the channel encoding and decoding.

### III-A Model Description

Let $`\mathbf{M}`$ be the set of speech sample sequences drawn from the speech dataset, which is converted in to a set of spectrums, $`\mathbf{S}`$. In addition, $`{\mathbf{T}} \in \Re^{B \times \overset{\sim}{K}}`$ is the set of text transcriptions corresponding to $`{\mathbf{M}} \in \Re^{B \times Q}`$, where $`B`$ is the batch size, $`Q`$ is the number of samples in a sample sequence, and $`\overset{\sim}{K}`$ indicates the number of tokens, $`K`$, in different batch of transcription is dynamic. The proposed DeepSC-SR is shown in Fig .[2](https://arxiv.org/html/2107.11190v3#S3.F2 "Figure 2 ‣ III-A Model Description ‣ III Semantic Communication System for Speech Recognition ‣ Semantic Communications for Speech Recognition"). From the figure, the input of the proposed DeepSC-SR is spectrums, $`{\mathbf{S}} \in \Re^{B \times N \times F}`$, where $`N`$ denotes the number of frames and $`F`$ indicates the number of frequency bins corresponding to each speech frame. The spectrums, $`\mathbf{S}`$, are fed into the *semantic encoder* to learn and extract the text-related semantic features and to output the features $`{\mathbf{P}} \in \Re^{B \times L \times 29}`$. The details of the *semantic encoder* are presented in part B of this section. Afterwards, the *channel encoder*, denoted as two dense layers, converts $`\mathbf{P}`$ into $`{\mathbf{U}} \in \Re^{{B \times L \times 2}Z}`$. In order to transmit $`\mathbf{U}`$ into a physical channel, it is reshaped into symbol sequences, $`{\mathbf{X}} \in \Re^{{{B \times L}Z} \times 2}`$, via a reshape layer.

![Refer to caption]()

Figure 2: The proposed system architecture for semantic communication system for speech recognition.

The received symbol sequences, $`\mathbf{Y}`$, are reshaped into $`{\mathbf{V}} \in \Re^{{B \times F \times 2}N}`$ before feeding into the *channel decoder*, represented by three dense layers. The output of the *channel decoder* is the recovered text-related semantic features, $`\hat{\mathbf{P}} \in \Re^{B \times L \times 29}`$. Afterwards, the *greedy decoder*, i.e., the *feature decoder*, decodes $`\hat{\mathbf{P}}`$ into the text transcriptions, $`\hat{\mathbf{T}} \in \Re^{B \times \overset{\sim}{K^{^{\prime}}}}`$. Note that the number of tokens in different transcriptions is typically different. The details of the *greedy decoder* are presented in part C of this section. The CTC loss is calculated at the end of the *channel decoder* and backpropagated to the transmitter, thus, the trainable parameters in the whole system can be updated simultaneously.

### III-B Semantic Encoder

The *semantic encoder* is constructed by the CNN and the gated recurrent unit (GRU)-based bidirectional recurrent neural network (BRNN)\[[20](https://arxiv.org/html/2107.11190v3#bib.bib20)\] modules. As shown in Fig. [2](https://arxiv.org/html/2107.11190v3#S3.F2 "Figure 2 ‣ III-A Model Description ‣ III Semantic Communication System for Speech Recognition ‣ Semantic Communications for Speech Recognition"), firstly, the input $`\mathbf{S}`$ is converted into the intermediate features via several CNN modules. Particularly, the number of *filters* in each CNN module is $`E_{p}`$, $`p \in \lbrack 1,\;2,\ldots,P\rbrack`$, and the output of the last CNN module is $`{\mathbf{b}} \in \Re^{B \times C_{P} \times D_{P} \times E_{P}}`$. Secondly, $`\mathbf{b}`$ is fed into $`Q`$ BRNN modules, successively, and produces $`{\mathbf{d}} \in \Re^{B \times G_{Q} \times H_{Q}}`$, where the number of GRU units in each BRNN modules, $`H_{q}`$, $`q \in \lbrack 1,\;2,\ldots,Q\rbrack`$, is consistent. Finally, the text-related semantic features, $`\mathbf{P}`$, are obtained from $`\mathbf{d}`$ by passing through the cascaded dense layer and softmax layer.

### III-C Greedy Decoder

As aforementioned that the recovered text features, $`\hat{\mathbf{P}}`$, are decoded into the text transcriptions, $`\hat{\mathbf{T}}`$, via the *greedy decoder*. An example to obtain the transcription by the *greedy decoder* is shown in Fig. [3](https://arxiv.org/html/2107.11190v3#S3.F3 "Figure 3 ‣ III-C Greedy Decoder ‣ III Semantic Communication System for Speech Recognition ‣ Semantic Communications for Speech Recognition"). During the decoding process, in each step $`l`$, the maximum probability in the probability vector, $`{\hat{\mathbf{p}}}_{l}`$, is indexed and the token corresponding to this probability is employed to construct the final transcription $`\hat{\mathbf{t}}`$.

## IV Experiment and Numerical Results

In this section, we compare to the performance between the proposed DeepSC-SR and the traditional communication systems under the AWGN channels and the Rayleigh channels, where the accurate CSI is assumed at the receiver. The traditional communication systems include *benchmark 1* and *benchmark 2*, which are introduced in the part A of this section. The experiment is conducted on the LibriSpeech dataset, which is a corpus of English speech with sampling rate of 16 kHz. Besides, the simulation environment adopted in our work is Tensorflow 2.3.

### IV-A Neural Network Setting and Benchmarks

In the proposed DeepSC-S, the numbers of CNN modules and BRNN modules in the *semantic encoder* are 2 and 6, respectively. For each CNN module, the number of *filters* is 32, and for each BRNN module, the number of GRU units is 800. Moreover, two dense layers are utilized in the *channel encoder* with units 40 and 40, respectively, and three dense layers are utilized in the *channel decoder* with units 40, 40, and 29, respectively. The batch size is $`B = 16`$ and learning rate is $`\eta = 0.0005`$. The parameter settings of the proposed DeepSC-SR are summarized in Table [IV-A2](https://arxiv.org/html/2107.11190v3#S4.SS1.SSS2 "IV-A2 Benchmark 2 ‣ IV-A Neural Network Setting and Benchmarks ‣ IV Experiment and Numerical Results ‣ Semantic Communications for Speech Recognition"). For performance comparison, we provide the following two benchmarks.

#### IV-A1 Benchmark 1

The first benchmark is a traditional communication system to transmit speech signals, named speech transceiver. Particularly, the input of the system is the speech signals, which is restored at the receiver. Moreover, the transcription is obtained from the recovered speech signals after passing through an automatic speech recognition (ASR) module. For the system, the adaptive multi-rate wideband (AMR-WB)\[[21](https://arxiv.org/html/2107.11190v3#bib.bib21)\] is used for speech source coding and 64-QAM is utilized for modulation. Polar codes with successive cancellation list (SCL) decoding algorithm\[[22](https://arxiv.org/html/2107.11190v3#bib.bib22)\] is employed for channel coding, in which the block length is 512 and the list size is 4. Moreover, the ASR module aims to recover the text transcript accurately, which is realized by employing Deep Speech 2\[[23](https://arxiv.org/html/2107.11190v3#bib.bib23)\] model.

#### IV-A2 Benchmark 2

The second benchmark is a traditional communication system to transmit text signals, named text transceiver. Particularly, the speech signals are converted into the text signals by the ASR model before feeding into the traditional system and the text transcription is recovered at the receiver. For the system, the Huffman coding\[[24](https://arxiv.org/html/2107.11190v3#bib.bib24)\] is employed for text source coding, the settings of channel coding and modulation are same as that in *benchmark 1*. In addition, Deep Speech 2 model is utilized to implement efficient speech recognition in the ASR module.

## V Conclusions

In this article, we have investigated a DL-enabled semantic communication system for speech recognition, named DeepSC-SR, which aims to restore the text transcription by utilizing the text-related semantic features. Particularly, we jointly design the semantic and channel coding to learn and extract the features and mitigate the channel effects. Moreover, in order to facilitate DeepSC-SR adapting well over various physical channels, a model with strong robustness to channel variations has been investigated. Simulation results demonstrated that DeepSC-SR outperforms the traditional communication systems, especially in the low SNR regime. Hence, our proposed DeepSC-SR is a promising candidate for semantic communication systems for speech recognition.
