Different from , which combine the context vectors, in our project the additional reliability indicators are extracted and used to get a better models fusion performance.

Often, stream weighting proved to be an effective method to combine audio and video information in hybrid model. As in , separate models are then trained for each of the modalities, and possibly, for each of the feature streams per modality. Stream weighting is realized through a weighted combination of the DNN state posteriors of each modality
``` math
\begin{equation}
 \label{statefusion}
\textnormal{log }\widetilde{p}(s |\textbf{o}_t)=\sum_{i}^{}\lambda_t^i\cdot \textrm{log }{p}(s |\textbf{o}_t^{i}),
\end{equation}
```
where $`\textrm{log }{p}(s |\textbf{\textrm{o}}_t^{i})`$ is the log-posterior of state $`s`$ in stream $`i`$ and $`\textnormal{log}\,\widetilde{p}(s |\textbf{\textrm{o}}_t)`$ is its estimated combined log-posterior. The stream weights $`\lambda_t^i`$ are typically predicted by appropriate reliability measures. In this paper, we propose a new way to use stream weighting on TM-CTC based AVSR model.

The probabilities are fused via

``` math
\begin{equation}
 \label{TMstatefusion}
\textnormal{log }\widetilde{p}_{s2s}(s |\textbf{o}_m)=\lambda^{a}_{m}\cdot \textrm{log }{p_{s2s}}(s |\textbf{o}_m^{a}) + \lambda^{v}_{m}\cdot \textrm{log }{p_{s2s}}(s |\textbf{o}_m^{v})
\end{equation}
```
and
``` math
\begin{equation}
 \label{CTCstatefusion}
\textnormal{log }\widetilde{p}_{ctc}(s |\textbf{o}_n)=\gamma^{a}_{n}\cdot \textrm{log }{p_{ctc}}(s |\textbf{o}_n^{a}) + \gamma^{v}_{n}\cdot \textrm{log }{p_{ctc}}(s |\textbf{o}_n^{v}).
\end{equation}
```

Then we use a weightnet predict the weights for each model. The weightnet has 2 hidden layers, with 128, 64 units, respectively. Each using ReLU activation functions, the output is the predicted weight for each stream $`\lambda^{i}_{m}`$. A sigmoid function is used to limite the weights to value between 0 and 1.
``` math
\begin{equation}
 \label{tmpred}
\lambda^{i} = \textrm{sigmoid}(\textrm{weightnet}(R_i)).
\end{equation}
```
Finally, we normalize the fused multi-modal S2S probabilities to one for each character.

The CTC weights estimation is much easier, since the $`rms^{i}_{out}`$ and $`P_{ctc}`$ have the same length.
``` math
\begin{equation}
 \label{ctcpred}
\gamma^{i} = \textrm{sigmoid}(\textrm{weightnet}(rms^{i}_{out})).
\end{equation}
```

``` math
\begin{equation}
 \label{atrans1}
\textbf{T}_a = \textrm{softmax}(\frac{(\textbf{W}_a^Q\textbf{Q}_a^T)\cdot (\textbf{W}_a^K\textbf{K}_a^{T})^T}{\sqrt{d_k}}),
\end{equation}
```

``` math
\begin{equation}
 \label{atrans2}
\textbf{T}_v = \textrm{softmax}(\frac{(\textbf{W}_v^Q\textbf{Q}_v^T)\cdot (\textbf{W}_v^K\textbf{K}_v^{T})^T}{\sqrt{d_k}}),
\end{equation}
```
where $`\textbf{Q}_a`$ and $`\textbf{K}_a`$ are the queries and keys from the audio attention block and $`\textbf{Q}_v`$ and $`\textbf{K}_v`$ are from video attention block.

## Audio-based reliability measures

The low order MFCC coefficients are related to the audio quality. It has also reported that MFCC coefficients are help for voice activity detection . Here the first 7 MFCC coefficients are used.

The audio-visual model baseline (in Sec. <a href="#avbaseline" data-reference-type="ref" data-reference="avbaseline">[avbaseline]</a>) was trained for 100 epochs and took around 9 days.

In addition, we also create reverb noise for some audio signals by convolutions with measured impose responses. These impulse responses also come from the MUSAN corpus.

As described in Sec. <a href="#decoder" data-reference-type="ref" data-reference="decoder">[decoder]</a>, $`\textbf{Q}`$ comes from the $`\textbf{C}`$ with size nToken $`\times`$ 256, where nToken is the length of the transcription. $`\textbf{K}`$ and $`\textbf{V}`$ are from $`\textbf{Enc}_{out}^i`$ and have a size $`(\textrm{nFrames}/4)\times 256`$ (since the subsampling layer and Bresnham’s algorithm). In Eq. <a href="#dotatt" data-reference-type="ref" data-reference="dotatt">[dotatt]</a>, $`\textbf{T}_j`$ converts $`\textbf{V}`$ from size $`(\textrm{nFrames}/4)\times 256`$ to nToken $`\times`$ 256. The attention transform matrix $`\textbf{T}_j`$ shows how important the current features for the current transcription.

In Fig. <a href="#fig:decoders" data-reference-type="ref" data-reference="fig:decoders">[fig:decoders]</a>, in the transformer decoder, there are 6 multi-head attention blocks, each of them has an attention transform matrix, we use the transform matrix from the last block to convert $`\textbf{rms}_{out}`$ from size $`(\textrm{nFrames}/4)\times 256`$ to nToken $`\times`$ 256. Because in the last block, $`\textbf{Q}`$ attends better to $`\textbf{K}`$. In each head, the audio reliability indicators ($`\textbf{rms}^{a}_{out}`$) and the video reliability indicators ($`\textbf{rms}^{v}_{out}`$) are converted via
``` math
\begin{equation}
 \label{convert}
\textbf{R}_j^a = \textbf{T}_j^a \cdot (\textbf{W}_j^{arms}\textbf{rms}^{a}_{out})^T,\textbf{R}_j^v = \textbf{T}_j^v \cdot (\textbf{W}_j^{vrms}\textbf{rms}^{v}_{out}).
\end{equation}
```
$`\textbf{R}^i`$ is the concatenated output of each head ($`\textbf{R}_j^i`$) and projected by a feed-forward layer.
