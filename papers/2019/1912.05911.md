###### Abstract

State-of-the-art solutions in the areas of “Language Modelling & Generating Text”, “Speech Recognition”, “Generating Image Descriptions” or “Video Tagging” have been using Recurrent Neural Networks as the foundation for their approaches. Understanding the underlying concepts is therefore of tremendous importance if we want to keep up with recent or upcoming publications in those areas. In this work we give a short overview over some of the most important concepts in the realm of Recurrent Neural Networks which enables readers to easily understand the fundamentals such as but not limited to “Backpropagation through Time” or “Long Short-Term Memory Units” as well as some of the more recent advances like the “Attention Mechanism” or “Pointer Networks”. We also give recommendations for further reading regarding more complex topics where it is necessary.

## 1 Introduction & Notation

Recurrent Neural Networks (RNNs) are a type of neural network architecture which is mainly used to detect patterns in a sequence of data. Such data can be handwriting, genomes, text or numerical time series which are often produced in industry settings (e.g. stock markets or sensors) chung2015gated (7, 12). However, they are also applicable to images if these get respectively decomposed into a series of patches and treated as a sequence bworld (12). On a higher level, RNNs find applications in Language Modelling & Generating Text, Speech Recognition, Generating Image Descriptions or Video Tagging. What differentiates Recurrent Neural Networks from Feedforward Neural Networks also known as Multi-Layer Perceptrons (MLPs) is how information gets passed through the network. While Feedforward Networks pass information through the network without cycles, the RNN has cycles and transmits information back into itself. This enables them to extend the functionality of Feedforward Networks to also take into account previous inputs $`\mathbf{X}_{0:{t - 1}}`$ and not only the current input $`\mathbf{X}_{t}`$. This difference is visualised on a high level in Figure 1: A gentle Introduction and Overview"). Note, that here the option of having multiple hidden layers is aggregated to one Hidden Layer block $`\mathbf{H}`$. This block can obviously be extended to multiple hidden layers.

![Refer to caption](https://ar5iv.labs.arxiv.org/html/1912.05911/assets/x1.png)

Figure 1: Visualisation of differences between Feedfoward NNs und Recurrent NNs

We can describe this process of passing information from the previous iteration to the hidden layer with the mathematical notation proposed in zhang2019dive (24). For that, we denote the hidden state and the input at time step $`t`$ respecively as $`\mathbf{H}_{t} \in {\mathbb{R}}^{n \times h}`$ and $`\mathbf{X}_{t} \in {\mathbb{R}}^{n \times d}`$ where $`n`$ is number of samples, $`d`$ is the number of inputs of each sample and $`h`$ is the number of hidden units. Further, we use a weight matrix $`\mathbf{W}_{x\hspace{0pt}h} \in {\mathbb{R}}^{d \times h}`$, hidden-state-to-hidden-state matrix $`\mathbf{W}_{h\hspace{0pt}h} \in {\mathbb{R}}^{h \times h}`$ and a bias parameter $`\mathbf{b}_{h} \in {\mathbb{R}}^{1 \times h}`$. Lastly, all these informations get passed to a activation function $`\phi`$ which is usually a logistic sigmoid or tanh function to prepair the gradients for usage in backpropagation. Putting all these notations together yields Equation 1: A gentle Introduction and Overview") as the hidden variable and Equation 2: A gentle Introduction and Overview") as the output variable.

``` math
\mathbf{H}_{t} = {\phi_{h}\hspace{0pt}\left( {{\mathbf{X}_{t}\hspace{0pt}\mathbf{W}_{x\hspace{0pt}h}} + {\mathbf{H}_{t - 1}\hspace{0pt}\mathbf{W}_{h\hspace{0pt}h}} + \mathbf{b}_{h}} \right)}
```
``` math
\mathbf{O}_{t} = {\phi_{o}\hspace{0pt}\left( {{\mathbf{H}_{t}\hspace{0pt}\mathbf{W}_{h\hspace{0pt}o}} + \mathbf{b}_{o}} \right)}
```

Since $`\mathbf{H}_{t}`$ recursively includes $`\mathbf{H}_{t - 1}`$ and this process occurs for every time step the RNN includes traces of all hidden states that preceded $`\mathbf{H}_{t - 1}`$ as well as $`\mathbf{H}_{t - 1}`$ itself.

If we compare that notation for RNNs with similar notation for Feedforward Neural Networks we can clearly see the difference we described earlier. In Equation 3: A gentle Introduction and Overview") we can see the computation for the hidden variable while Equation 4: A gentle Introduction and Overview") shows the output variable.

``` math
\mathbf{H} = {\phi_{h}\hspace{0pt}\left( {{\mathbf{X}\mathbf{W}}_{x\hspace{0pt}h} + \mathbf{b}_{h}} \right)}
```
``` math
\mathbf{O} = {\phi_{o}\hspace{0pt}\left( {{\mathbf{H}\mathbf{W}}_{h\hspace{0pt}o} + \mathbf{b}_{o}} \right)}
```

If you are familiar with training techniques for Feedforward Neural Networks such as backpropagation one question which might arise is how to properly backpropagate the error through a RNN. Here, a technique called Backpropagation Through Time (BPTT) is used which gets described in detail in the next section.

## 2 Backpropagation Through Time (BPTT) & Truncated BPTT

Backpropagation Through Time (BPTT) is the adaption of the backpropagation algorithm for RNNs zhang2019dive (24). In theory, this unfolds the RNN to construct a traditional Feedfoward Neural Network where we can apply backpropagation. For that, we use the same notations for the RNN as proposed before.

When we forward pass our input $`\mathbf{X}_{t}`$ through the network we compute the hidden state $`\mathbf{H}_{t}`$ and the output state $`\mathbf{O}_{t}`$ one step at a time. We can then define a loss function $`\mathcal{L}\hspace{0pt}(\mathbf{O},\mathbf{Y})`$ to describe the difference between all outputs $`\mathbf{O}_{t}`$ and target values $`\mathbf{Y}_{t}`$ as shown in Equation 5 & Truncated BPTT ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview"). This basically sums up every loss term $`\ell_{t}`$ of each update step so far. This loss term $`\ell_{t}`$ can have different definitions based on the specific problem (e.g. Mean Squared Error, Hinge Loss, Cross Entropy Loss, etc.).

``` math
{\mathcal{L}\hspace{0pt}(\mathbf{O},\mathbf{Y})} = {\sum\limits_{t = 1}^{T}{\ell_{t}\hspace{0pt}\left( \mathbf{O}_{t},\mathbf{Y}_{t} \right)}}
```

Since we have three weight matrices $`\mathbf{W}_{x\hspace{0pt}h}`$, $`\mathbf{W}_{h\hspace{0pt}h}`$ and $`\mathbf{W}_{h\hspace{0pt}o}`$ we need to compute the partial derivative w.r.t. to each of these weight matrices. With the chain rule which is also used in normal backpropagation we get to the result for $`\mathbf{W}_{h\hspace{0pt}o}`$ shown in Equation 6 & Truncated BPTT ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview").

``` math
\frac{\partial\mathcal{L}}{\partial\mathbf{W}_{h\hspace{0pt}o}} = {\sum\limits_{t = 1}^{T}{\frac{\partial\ell_{t}}{\partial\mathbf{O}_{t}} \cdot \frac{\partial\mathbf{O}_{t}}{\partial\phi_{o}} \cdot \frac{\partial\phi_{o}}{\mathbf{W}_{h\hspace{0pt}o}}}} = {\sum\limits_{t = 1}^{T}{\frac{\partial\ell_{t}}{\partial\mathbf{O}_{t}} \cdot \frac{\partial\mathbf{O}_{t}}{\partial\phi_{o}} \cdot \mathbf{H}_{\mathbf{t}}}}
```

For the partial derivative with respect to $`\mathbf{W}_{h\hspace{0pt}h}`$ we get the result shown in Equation 7 & Truncated BPTT ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview").

``` math
\frac{\partial\mathcal{L}}{\partial\mathbf{W}_{h\hspace{0pt}h}} = {\sum\limits_{t = 1}^{T}{\frac{\partial\ell_{t}}{\partial\mathbf{O}_{t}} \cdot \frac{\partial\mathbf{O}_{t}}{\partial\phi_{o}} \cdot \frac{\partial\phi_{o}}{\partial\mathbf{H}_{t}} \cdot \frac{\partial\mathbf{H}_{t}}{\partial\phi_{h}} \cdot \frac{\partial\phi_{h}}{\partial\mathbf{W}_{h\hspace{0pt}h}}}} = {\sum\limits_{t = 1}^{T}{\frac{\partial\ell_{t}}{\partial\mathbf{O}_{t}} \cdot \frac{\partial\mathbf{O}_{t}}{\partial\phi_{o}} \cdot \mathbf{W}_{h\hspace{0pt}o} \cdot \frac{\partial\mathbf{H}_{t}}{\partial\phi_{h}} \cdot \frac{\partial\phi_{h}}{\partial\mathbf{W}_{h\hspace{0pt}h}}}}
```

For the partial derivative with respect to $`\mathbf{W}_{x\hspace{0pt}h}`$ we get the result shown in Equation 8 & Truncated BPTT ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview").

``` math
\frac{\partial\mathcal{L}}{\partial\mathbf{W}_{x\hspace{0pt}h}} = {\sum\limits_{t = 1}^{T}{\frac{\partial\ell_{t}}{\partial\mathbf{O}_{t}} \cdot \frac{\partial\mathbf{O}_{t}}{\partial\phi_{o}} \cdot \frac{\partial\phi_{o}}{\partial\mathbf{H}_{t}} \cdot \frac{\partial\mathbf{H}_{t}}{\partial\phi_{h}} \cdot \frac{\partial\phi_{h}}{\partial\mathbf{W}_{x\hspace{0pt}h}}}} = {\sum\limits_{t = 1}^{T}{\frac{\partial\ell_{t}}{\partial\mathbf{O}_{t}} \cdot \frac{\partial\mathbf{O}_{t}}{\partial\phi_{o}} \cdot \mathbf{W}_{h\hspace{0pt}o} \cdot \frac{\partial\mathbf{H}_{t}}{\partial\phi_{h}} \cdot \frac{\partial\phi_{h}}{\partial\mathbf{W}_{x\hspace{0pt}h}}}}
```

Since each $`\mathbf{H}_{t}`$ depends on the previous time step we can substitute the last part from above equations to get Equation 9 & Truncated BPTT ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview") and Equation 10 & Truncated BPTT ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview").

``` math
\frac{\partial\mathcal{L}}{\partial\mathbf{W}_{h\hspace{0pt}h}} = {\sum\limits_{t = 1}^{T}{{\frac{\partial\ell_{t}}{\partial\mathbf{O}_{t}} \cdot \frac{\partial\mathbf{O}_{t}}{\partial\phi_{o}} \cdot \mathbf{W}_{h\hspace{0pt}o}}\hspace{0pt}{\sum\limits_{k = 1}^{t}{\frac{\partial\mathbf{H}_{t}}{\partial\mathbf{H}_{k}} \cdot \frac{\partial\mathbf{H}_{k}}{\partial\mathbf{W}_{h\hspace{0pt}h}}}}}}
```
``` math
\frac{\partial\mathcal{L}}{\partial\mathbf{W}_{x\hspace{0pt}h}} = {\sum\limits_{t = 1}^{T}{{\frac{\partial\ell_{t}}{\partial\mathbf{O}_{t}} \cdot \frac{\partial\mathbf{O}_{t}}{\partial\phi_{o}} \cdot \mathbf{W}_{h\hspace{0pt}o}}\hspace{0pt}{\sum\limits_{k = 1}^{t}{\frac{\partial\mathbf{H}_{t}}{\partial\mathbf{H}_{k}} \cdot \frac{\partial\mathbf{H}_{k}}{\partial\mathbf{W}_{x\hspace{0pt}h}}}}}}
```

The adapted part can then further be written as shown in Equation 11 & Truncated BPTT ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview") and Equation 12 & Truncated BPTT ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview").

``` math
\frac{\partial\mathcal{L}}{\partial\mathbf{W}_{h\hspace{0pt}h}} = {\sum\limits_{t = 1}^{T}{{\frac{\partial\ell_{t}}{\partial\mathbf{O}_{t}} \cdot \frac{\partial\mathbf{O}_{t}}{\partial\phi_{o}} \cdot \mathbf{W}_{h\hspace{0pt}o}}\hspace{0pt}{\sum\limits_{k = 1}^{t}{\left( \mathbf{W}_{h\hspace{0pt}h}^{\top} \right)^{t - k} \cdot \mathbf{H}_{k}}}}}
```
``` math
\frac{\partial\mathcal{L}}{\partial\mathbf{W}_{x\hspace{0pt}h}} = {\sum\limits_{t = 1}^{T}{{\frac{\partial\ell_{t}}{\partial\mathbf{O}_{t}} \cdot \frac{\partial\mathbf{O}_{t}}{\partial\phi_{o}} \cdot \mathbf{W}_{h\hspace{0pt}o}}\hspace{0pt}{\sum\limits_{k = 1}^{t}{\left( \mathbf{W}_{h\hspace{0pt}h}^{\top} \right)^{t - k} \cdot \mathbf{X}_{k}}}}}
```

From here, we can see that we need to store powers of $`\mathbf{W}_{h\hspace{0pt}h}^{k}`$ as we proceed through each loss term $`\ell_{t}`$ of the overall loss function $`\mathcal{L}`$ which can become very large. For these large values this method becomes numerically unstable since eigenvalues smaller than $`1`$ vanish and eigenvalues larger than $`1`$ diverge longterm (5). One method of solving this problem is truncate the sum at a computationally convenient size zhang2019dive (24). When you do this, you’re using Truncated BPTT trunc (22). This basically establishes an upper bound for the number of time steps the gradient can flow back to Sutskever:2013:TRN:2604780 (15). One can think of this upper bound as a moving window of past time steps which the RNN considers. Anything before the cut-off time step doesn’t get taken into account. Since BPTT basically unfolds the RNN to create a new layer for each time step we can also think of this procedure as limiting the number of hidden layers.

## 3 Problems of RNNs: Vanishing & Exploding Gradients

As in most neural networks, vanishing or exploding gradients is a key problem of RNNs bworld (12). In Equation 9 & Truncated BPTT ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview") and Equation 10 & Truncated BPTT ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview") we can see $`\frac{\partial\mathbf{H}_{t}}{\partial\mathbf{H}_{k}}`$ which basically introduces matrix multiplication over the (potentially very long) sequence, if there are small values ($`< 1`$) in the matrix multiplication this causes the gradient to decrease with each layer (or time step) and finally vanish chen2016gentle (6). This basically stops the contribution of states that happened far earlier than the current time step towards the current time step chen2016gentle (6). Similarly, this can happen in the opposite direction if we have large values ($`> 1`$) during matrix multiplication causing an exploding gradient which in result values each weight too much and changes it heavily chen2016gentle (6).

This problem motivated the introduction of the long short term memory units (LSTMs) to particularly handle the vanishing gradient problem. This approach was able to outperform traditional RNNs on a variety of tasks chen2016gentle (6). In the next section we want to go deeper on the proposed structure of LSTMs.

## 4 Long Short-Term Memory Units (LSTMs)

Long Short-Term Memory Units (LSTMs) lstms (9) were designed to properly handle the vanishing gradient problem. Since they use a more constant error, they allow RNNs to learn over a lot more time steps (way over $`1000`$) bworld (12). To achieve that, LSTMs store more information outside of the traditional neural network flow in structures called gated cells chen2016gentle (6, 12). To make things work in an LSTM we use an output gate $`\mathbf{O}_{t}`$ to read entries of the cell, an input gate $`\mathbf{I}_{t}`$ to read data into the cell and a forget gate $`\mathbf{F}_{t}`$ to reset the content of the cell. The computations for these gates are shown in Equation 13 ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview"), Equation 14 ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview") and Equation 15 ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview"). For a more visual approach please see Figure 8: A gentle Introduction and Overview") in Appendix A: A gentle Introduction and Overview").

``` math
\mathbf{O}_{t} = {\sigma\hspace{0pt}\left( {{\mathbf{X}_{t}\hspace{0pt}\mathbf{W}_{x\hspace{0pt}o}} + {\mathbf{H}_{t - 1}\hspace{0pt}\mathbf{W}_{h\hspace{0pt}o}} + \mathbf{b}_{o}} \right)}
```
``` math
\mathbf{I}_{t} = {\sigma\hspace{0pt}\left( {{\mathbf{X}_{t}\hspace{0pt}\mathbf{W}_{x\hspace{0pt}i}} + {\mathbf{H}_{t - 1}\hspace{0pt}\mathbf{W}_{h\hspace{0pt}i}} + \mathbf{b}_{i}} \right)}
```
``` math
\mathbf{F}_{t} = {\sigma\hspace{0pt}\left( {{\mathbf{X}_{t}\hspace{0pt}\mathbf{W}_{x\hspace{0pt}f}} + {\mathbf{H}_{t - 1}\hspace{0pt}\mathbf{W}_{h\hspace{0pt}f}} + \mathbf{b}_{f}} \right)}
```

The shown equations use $`{\mathbf{W}_{x\hspace{0pt}i},\mathbf{W}_{x\hspace{0pt}f},\mathbf{W}_{x\hspace{0pt}o}} \in {\mathbb{R}}^{d \times h}`$ and $`{\mathbf{W}_{h\hspace{0pt}i},\mathbf{W}_{h\hspace{0pt}f},\mathbf{W}_{h\hspace{0pt}o}} \in {\mathbb{R}}^{h \times h}`$ as weight matrices while $`{\mathbf{b}_{i},\mathbf{b}_{f},\mathbf{b}_{o}} \in {\mathbb{R}}^{1 \times h}`$ are their respective biases. Further, they use the sigmoid activation function $`\sigma`$ to transform the output $`\in {(0,1)}`$ which each results in a vector with entries $`\in {(0,1)}`$.

Next, we need a candidate memory cell $`{\overset{\sim}{\mathbf{C}}}_{t} \in {\mathbb{R}}^{n \times h}`$ which has a similar computation as the previously mentioned gates but instead uses a tanh activation function to have an output $`\in {({- 1},1)}`$. Further, it again has its own weights $`\mathbf{W}_{x\hspace{0pt}c} \in {\mathbb{R}}^{d \times h}`$, $`\mathbf{W}_{h\hspace{0pt}c} \in {\mathbb{R}}^{h \times h}`$ and biases $`\mathbf{b}_{c} \in {\mathbb{R}}^{1 \times h}`$. The respective computation is shown in Equation 16 ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview"). See Figure 9: A gentle Introduction and Overview") in Appendix A: A gentle Introduction and Overview") for a visualisation of this enhancement.

``` math
{\overset{\sim}{\mathbf{C}}}_{t} = {\tanh\left( {{\mathbf{X}_{t}\hspace{0pt}\mathbf{W}_{x\hspace{0pt}c}} + {\mathbf{H}_{t - 1}\hspace{0pt}\mathbf{W}_{h\hspace{0pt}c}} + \mathbf{b}_{c}} \right)}
```

To plug some things together we introduce old memory content $`\mathbf{C}_{t - 1} \in {\mathbb{R}}^{n \times h}`$ which together with the introduced gates controls how much of the old memory content we want to preserve to get to the new memory content $`\mathbf{C}_{t}`$. This is shown in Equation 17 ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview") where $`\odot`$ denotes element-wise multiplication. The structure so far can be seen in Figure 10: A gentle Introduction and Overview") in Appendix A: A gentle Introduction and Overview").

``` math
\mathbf{C}_{t} = {{\mathbf{F}_{t} \odot \mathbf{C}_{t - 1}} + {\mathbf{I}_{t} \odot {\overset{\sim}{\mathbf{C}}}_{t}}}
```

The last step is to introduce the computation for the hidden states $`\mathbf{H}_{t} \in {\mathbb{R}}^{n \times h}`$ into the framework. This can be seen in Equation 18 ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview").

``` math
\mathbf{H}_{t} = {\mathbf{O}_{t} \odot {\tanh\left( \mathbf{C}_{t} \right)}}
```

With the tanh function we ensure that each element of $`\mathbf{H}_{t}`$ is $`\in {({- 1},1)}`$. The full LSTM framework can be seen in Figure 11: A gentle Introduction and Overview") in Appendix A: A gentle Introduction and Overview").

## 5 Deep Recurrent Neural Networks (DRNNs)

Deep Recurrent Neural Networks (DRNNs) are in theory a really easy concept. To construct a deep RNN with $`L`$ hidden layers we simply stack ordinary RNNs of any type on top of each other. Each hidden state $`\mathbf{H}_{t}^{(\ell)} \in {\mathbb{R}}^{n \times h}`$ is passed to the next time step of the current layer $`\mathbf{H}_{t + 1}^{(\ell)}`$ as well as the current time step of the next layer $`\mathbf{H}_{t}^{({\ell + 1})}`$. For the first layer we compute the hidden state as proposed in the previous models shown shown in Equation 19 ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview") while for the subsequent layer we use Equation 20 ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview") where the hidden state from the previous layer is treated as input.

``` math
\mathbf{H}_{t}^{(1)} = {\phi_{1}\hspace{0pt}\left( \mathbf{X}_{t},\mathbf{H}_{t - 1}^{(1)} \right)}
```
``` math
\mathbf{H}_{t}^{(\ell)} = {\phi_{\ell}\hspace{0pt}\left( \mathbf{H}_{t}^{({\ell - 1})},\mathbf{H}_{t - 1}^{(\ell)} \right)}
```

The output $`\mathbf{O}_{t} \in {\mathbb{R}}^{n \times o}`$ where $`o`$ is the number of outputs is then computed as shown in Equation 21 ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview") where we only use the hidden state of layer $`L`$.

``` math
\mathbf{O}_{t} = {\phi_{o}\hspace{0pt}\left( {{\mathbf{H}_{t}^{(L)}\hspace{0pt}\mathbf{W}_{h\hspace{0pt}o}} + \mathbf{b}_{o}} \right)}
```

## 6 Bidirectional Recurrent Neural Networks (BRNNs)

Lets take an example of language modeling for now. Based on our current models we are able to reliably predict the next sequence element (i.e. the next word) based on what we have seen so far. However, there scenarios where we might want to fill in a gap in a sentence and the part of the sentence after the gap conveys significant information. This information is necessary to take into account to perform well on this kind of task zhang2019dive (24). On a more generalised level we want to incorporate a look-ahead property for sequences.

![Refer to caption](https://ar5iv.labs.arxiv.org/html/1912.05911/assets/x2.png)

Figure 2: Architecture of a bidirectional recurrent neural network

To achieve this look-ahead property Bidirectional Recurrent Neural Networks (BRNNs) Schuster1997BidirectionalRN (14) got introduced which basically add another hidden layer which run the sequence backwards starting from the last element zhang2019dive (24). An architectural overview can is visualised in Figure 2 ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview"). Here, we introduce a forward hidden state $`{\overset{\rightarrow}{\mathbf{H}}}_{t} \in {\mathbb{R}}^{n \times h}`$ and a backward hidden state $`{\overset{\leftarrow}{\mathbf{H}}}_{t} \in {\mathbb{R}}^{n \times h}`$. Their respective calculations are shown in Equation 22 ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview") and Equation 23 ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview").

``` math
{\overset{\rightarrow}{\mathbf{H}}}_{t} = {\phi\hspace{0pt}\left( {{\mathbf{X}_{t}\hspace{0pt}\mathbf{W}_{x\hspace{0pt}h}^{(f)}} + {{\overset{\rightarrow}{\mathbf{H}}}_{t - 1}\hspace{0pt}\mathbf{W}_{h\hspace{0pt}h}^{(f)}} + \mathbf{b}_{h}^{(f)}} \right)}
```
``` math
{\overset{\leftarrow}{\mathbf{H}}}_{t} = {\phi\hspace{0pt}\left( {{\mathbf{X}_{t}\hspace{0pt}\mathbf{W}_{x\hspace{0pt}h}^{(b)}} + {{\overset{\leftarrow}{\mathbf{H}}}_{t + 1}\hspace{0pt}\mathbf{W}_{h\hspace{0pt}h}^{(b)}} + \mathbf{b}_{h}^{(b)}} \right)}
```

For that, we have similar weight matrices as in definitions before but now they are seperated into two sets. One set of weight matrices is for the forward hidden states $`\mathbf{W}_{x\hspace{0pt}h}^{(f)} \in {\mathbb{R}}^{d \times h}`$ and $`\mathbf{W}_{h\hspace{0pt}h}^{(f)} \in {\mathbb{R}}^{h \times h}`$ while the other one is for the backward hidden states $`\mathbf{W}_{x\hspace{0pt}h}^{(b)} \in {\mathbb{R}}^{d \times h}`$ and $`\mathbf{W}_{h\hspace{0pt}h}^{(b)} \in {\mathbb{R}}^{h \times h}`$. They also have their respective biases $`\mathbf{b}_{h}^{(f)} \in {\mathbb{R}}^{1 \times h}`$ and $`\mathbf{b}_{h}^{(b)} \in {\mathbb{R}}^{1 \times h}`$. With that, we can compute the output $`\mathbf{O}_{t} \in {\mathbb{R}}^{n \times o}`$ with $`o`$ being the number of outputs and $`\frown`$ denoting the concatenation of the two matrices on axis $`0`$ (stacking them on top of each other).

``` math
\mathbf{O}_{t} = {\phi\hspace{0pt}\left( {{\left\lbrack {{\overset{\rightarrow}{\mathbf{H}}}_{t}^{\frown}\hspace{0pt}{\overset{\leftarrow}{\mathbf{H}}}_{t}} \right\rbrack\hspace{0pt}\mathbf{W}_{h\hspace{0pt}o}} + \mathbf{b}_{o}} \right)}
```

Again, we have weight matrices $`\mathbf{W}_{h\hspace{0pt}o} \in {\mathbb{R}}^{{2\hspace{0pt}h} \times o}`$ and bias parameters $`\mathbf{b}_{o} \in {\mathbb{R}}^{1 \times o}`$. Keep in mind that the two directions can have different number of hidden units.

## 7 Encoder-Decoder Architecture & Sequence to Sequence (seq2seq)

The Encoder-Decoder architecture is a type of neural network architecture where the network is twofold. It consists of encoder network and a decoder network whose respective roles are to encode the input into a state and decode the state to an output. This state usually has shape of a vector or a tensor zhang2019dive (24). A visualisation of this structure is shown in Figure 3 ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview").

![Refer to caption](https://ar5iv.labs.arxiv.org/html/1912.05911/assets/x3.png)

Figure 3: Encoder-Decoder Architecture Overview alternated from: zhang2019dive (24)

Based on this Encoder-Decoder architecture a model called Sequence to Sequence (seq2seq) seq2seq (16) got proposed for generating a sequence output based on a sequence input. This model uses RNNs for the encoder as well as the decoder where the hidden state of the encoder gets passed to the hidden state of the decoder. Common applications of the model are Google Translate seq2seq (16, 23), voice-enabled devices seq2seqspeech (13) or labeling video data venugopalan2015sequence (18). It mainly focuses on mapping a fixed length input sequence of size $`n`$ to an fixed length output sequence of size $`m`$ where $`n \neq m`$ can be true but isn’t a necessity.

A de-rellod visualisation of the proposed architecture is shown in Figure 4 ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview"). Here, we have a encoder which consists of a RNN accepting a single element of the sequence $`\mathbf{X}_{t}`$ where $`t`$ is the order of the sequence element. These RNNs can be LSTMs or Gated Recurrent Units (GRUs) to further improve performance seq2seq (16). Further, the hidden states $`\mathbf{H}_{t}`$ are computed according to the definition of the hidden states in the used RNN type (e.g. LSTM or GRU). The Encoder Vector (context) is a representation of the last hidden state of the encoder network which aims to aggregate all information from all previous input elements. This functions as initial hidden state of the decoder network of the model and enables the decoder to make accurate predictions. The decoder network again is built of a RNN which predicts an output $`\mathbf{Y}_{t}`$ at a time step $`t`$. The produced output is again a sequence where each $`\mathbf{Y}_{t}`$ is a sequence element with order $`t`$. At each time step the RNN accepts a hidden state from the previous unit and itself produces an output as well as a new hidden state.

![Refer to caption](https://ar5iv.labs.arxiv.org/html/1912.05911/assets/x4.png)

Figure 4: Visualisation of the Sequence to Sequence (seq2seq) Model

The Encoder Vector (context) was shown to be a bottleneck for these type of models since it needed to contain all all the necessary information of a source sentence in a fixed-length vector which was particularly problematic for long sequences. There have been approaches to solve this problem by introducing Attention in for example attention1 (4) or attention2 (10). In the next section, we take a closer look at the proposed solutions.

## 8 Attention Mechanism & Transformer

The Attention Mechanism for RNNs is partly motivated by human visual focus and the peripheral perception attention_blog (21). It allows humans to focus on a certain region to achieve high resolution while adjacent objects are perceived with a rather low resolution. Based on these focus points and adjacent perception, we can make inference about what we expect to perceive when shifting our focus point. Similarly, we can transfer this method on our sequence of words where we are able to perform inference based on observed words. For example, if we perceive the word eating in the sequence “She is eating a green apple” we assume to observe a food object in the near future attention_blog (21).

Generally, Attention takes two sentences and transforms them into a matrix where each sequence element (i.e. a word) corresponds to a row or column. Based on this matrix layout we can fill in the entries to identify relevant context or correlations between them. An example of this process can be seen in Figure 5: A gentle Introduction and Overview") where white denotes high correlation while black denotes low correlation. This method isn’t limited to two sentences of a different languages as seen the example but can also be applied to the same sentence which is then called self-attention.

![Refer to caption](https://ar5iv.labs.arxiv.org/html/1912.05911/assets/x5.png)

Figure 5: Example of an Alignment matrix of “L’accord sur la zone économique européen a été signé en août 1992” (French) and its English translation “The agreement on the European Economic Area was signed in August 1992”: attention1 (4)

### 8.1 Definition

To help the seq2seq model to better deal with long sequences the attention mechanism got introduced. Instead of constructing the Encoder Vector out of the last hidden state of the encoder network, attention introduces shortcuts between context vector and the entire source input. A visualisation of this process can be seen in Figure 6: A gentle Introduction and Overview"). Here, we have source sequence $`\mathbf{X}`$ of length $`n`$ and try to output a target sequence $`\mathbf{Y}`$ of size $`m`$. In that regard the formulation is rather similar to the one we described before in Section 7 ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview"). We have an overall hidden state $`\mathbf{H}_{t'}`$ which is the concatenated version of the forward and backward pass as shown in Equation 25: A gentle Introduction and Overview"). Also, the hidden state of the decoder network is denoted as $`\mathbf{S}_{t}`$ while the encoder vector (context vector) is denoted as $`\mathbf{C}_{t}`$. Both of these are shown in Equation 26: A gentle Introduction and Overview") and Equation 27: A gentle Introduction and Overview") respectively.

``` math
\mathbf{H}_{t'} = \left\lbrack {{\overset{\rightarrow}{\mathbf{H}}}_{t'}^{\frown}\hspace{0pt}{\overset{\leftarrow}{\mathbf{H}}}_{t'}} \right\rbrack
```
``` math
\mathbf{S}_{t} = {\phi_{d}\hspace{0pt}\left( \mathbf{S}_{t - 1},\mathbf{Y}_{\mathbf{t} - \mathbf{1}},\mathbf{C}_{\mathbf{t}} \right)}
```

The context vector $`\mathbf{C}_{t}`$ is a sum of hidden states of the input sequence each weighted with an alignment score $`\alpha_{t,t'}`$ where $`{\sum_{t' = 1}^{T}\alpha_{t,t'}} = 1`$. This is shown in Equation 27: A gentle Introduction and Overview") as well as Equation 28: A gentle Introduction and Overview").

``` math
\mathbf{C}_{t} = {\sum\limits_{t' = 1}^{T}{\alpha_{t,t'} \cdot \mathbf{H}_{t'}}}
```
``` math
\alpha_{t,t'} = {{align}{(\mathbf{Y}_{t},\mathbf{X}_{t'})}} = \frac{\exp\left( {{score}{(\mathbf{S}_{t - 1},\mathbf{H}_{t'})}} \right)}{\sum_{t' = 1}^{T}{\exp{({{score}{(\mathbf{S}_{t - 1},\mathbf{H}_{t'})}})}}}
```

The alignment $`\alpha_{t,t'}`$ connects an alignment score for the input at position $`t'`$ and the output at position $`t`$. This score is based on how well this pair matches attention_blog (21). The set of all alignment scores defines how much each source hidden state should be considered for each output attention_blog (21). Please see Appendix B: A gentle Introduction and Overview") for a more easy and visual explanation of the attention mechanism in the seq2seq model.

### 8.2 Different types of score functions

Generally, there are different implementations for this score function which have been used in various works. Table 1: A gentle Introduction and Overview") gives an overview over their respective name, equation and the usage in publications. Here, we have two trainable weight matrices in the alignment model denoted as $`\mathbf{v}_{a}`$ and $`\mathbf{W}_{a}`$.

|  |  |  |
|----|----|----|
| Name | Equation for: $`{score}{(\mathbf{S}_{t},\mathbf{H}_{t'})}`$ | Used In |
| Content-base | $`{cosine}{\lbrack\mathbf{S}_{t},\mathbf{H}_{t'}\rbrack}`$ | graves2014neural (8) |
| Additive | $`\mathbf{v}_{a}^{\top}\hspace{0pt}{\tanh\mathbf{W}_{a}}\hspace{0pt}{\lbrack\mathbf{S}_{t};\mathbf{H}_{t'}\rbrack}`$ | bahdanau2014neural (3) |
| Location-Base | $`{softmax}{({\mathbf{W}_{a}\hspace{0pt}\mathbf{S}_{t}})}`$ | luong-etal-2015-effective (11) |
| General | $`\mathbf{S}_{t}^{\top}\hspace{0pt}\mathbf{W}_{a}\hspace{0pt}\mathbf{H}_{t'}`$ | luong-etal-2015-effective (11) |
| Dot-Product | $`\mathbf{S}_{t}^{\top}\hspace{0pt}\mathbf{H}_{t'}`$ | luong-etal-2015-effective (11) |
| Scaled Dot-Product | $`\frac{\mathbf{S}_{t}^{\top}\hspace{0pt}\mathbf{H}_{t'}}{\sqrt{n_{s\hspace{0pt}o\hspace{0pt}u\hspace{0pt}r\hspace{0pt}c\hspace{0pt}e}}}`$ | attention (17) |

Table 1: Different score functions with their respective equations and usage alternated from: attention_blog (21)

The Scaled-Dot-Product used in attention (17) scales the dot-product by the number of characters of the current word which is motivated by the problem that when the input is large, the softmax function may have an extremely small gradient which is a problem for efficient learning.

### 8.3 Transformer

By encorporating this Attention Mechanism the Transformer attention (17) got introduced which achieves parallelization by capturing recurrence sequence with attention but at the same time encoding each item’s position in the sequence based on the encoder-decoder architecture zhang2019dive (24). In fact, for that it doesn’t use any recurrent network units and entirely relies on the self-attention mechanism to improve performance. The encoding part of the architecture is made out of several encoders (e.g. six encoders in attention (17)) while the decoder part consists out of decoders with the same amount as the encoders. A general overview over the architecture is illustrated in Figure 7: A gentle Introduction and Overview").

Here, each encoder component consists out of two sub-layers which are Self-Attention and a Feed Forward Neural Network. Similarly, those two sub-layers are found in each decoder component but with a Encoder-Decoder Attention sub-layer in between them which works similarly to the Attention used in the seq2seq model. The deployed Attention layers are not your ordinary attention layers but a method called Multi-Headed Attention which improves performance of the attention layer. This allows the model to jointly attend to information from different representation subspaces at different positions which in easier terms runs different chunks in parallel and concatenates the results attention (17). Unfortunately, explaining the design choices and mathematical formulations contained in multi-headed attention would be to much details at this point. Please refer to the original paper attention (17) for more information. The architecture shown in Figure 7: A gentle Introduction and Overview") also deploys skip connections and layer normalisation for each sub-layer of the encoder as well as the decoder. One thing to note is that the input as well as the output get embedded and a positional encoding is applied which represents the proximity of sequence elements (see Appendix C: A gentle Introduction and Overview")).

![Refer to caption](https://ar5iv.labs.arxiv.org/html/1912.05911/assets/x7.png)

Figure 7: Model Architecture of the Transformer: attention (17)

The final linear and softmax layer turn the vector of floats which is the output of the decoder stack into a word. This is done by transforming the vector through the linear layer into a much larger vector called a logits vector transformer_blog (1). This logits vector has the size of the learned vocabulary from the training dataset where each cell corresponds to the score of a unique word transformer_blog (1). By applying a softmax function we turn those scores into probabilities which sum up to $`1`$ and therefore we can choose the cell (i.e. the word) with the highest probability as output for this particular time step.

## 9 Pointer Networks (Ptr-Nets)

Pointer Networks (Ptr-Nets) pointer (19) adapt the seq2seq model with attention to improve it by not fixing the discrete categories (i.e. elements) of the output dictionary a priori. Instead of yielding an output sequence generated from an input sequence, a pointer network creates a succession of pointers to the elements of the input series pointer_blog (25). In pointer (19) they show that by using Pointer Networks they can solve combinatorial optimization problems such as computing planar convex hulls, Delaunay triangulations and the symmetric planar Travelling Salesman Problem (TSP).

Generally, we apply additive attention (from Table 1: A gentle Introduction and Overview")) between states and then normalize it by applying the softmax function to model the output conditional probability as seen in Equation 29 ‣ Recurrent Neural Networks (RNNs): A gentle Introduction and Overview").

``` math
\mathbf{Y}_{t} = {{softmax}\left( {{score}\left( \mathbf{S}_{t},\mathbf{H}_{t'} \right)} \right)} = {{softmax}\left( {\mathbf{v}_{a}^{\top}\hspace{0pt}{\tanh\mathbf{W}_{a}}\hspace{0pt}{\lbrack\mathbf{S}_{t};\mathbf{H}_{t'}\rbrack}} \right)}
```

The attention mechanism is simplified, as Ptr-Net does not blend the encoder states into the output with attention weights. In this way, the output only responds to the positions but not the input content attention_blog (21).
